# 2025-11-08 AI 大事件

北京时间 2025 年 11 月 8 日（星期六）。谷歌研究团队在官方博客公布 Nested Learning，把持续学习问题重构为一组嵌套的子优化问题，目标是让模型像人脑一样不断吸收新技能而不遗忘旧知识。两人小团队用两周复刻 DeepSeek-OCR 的低 token 高压缩核心，两张 H200 就能完成训练。UCSD 与英特尔研究人员提出多智能体强化学习框架 PettingLLMs，首次实现通用的「群体强化」。

## 1. 谷歌 Nested Learning：把持续学习写成嵌套的子问题

据谷歌研究团队官方博客，Nested Learning 是一种新型机器学习方法：它把模型视为一系列嵌套的子优化问题，每个子问题拥有独立的工作流程，旨在缓解甚至避免「灾难性遗忘」问题。传统模型在学习新任务时往往丢失旧任务知识，而该方法通过结构化优化提升持续学习能力。

问题的背景被写得很清楚：尽管过去十年神经网络和训练算法取得显著进展，大语言模型仍面临持续学习的挑战。人类大脑凭借神经可塑性实现知识累积与自我改进，为 AI 提供了理想范本；Nested Learning 借鉴这一理念，使模型在不断吸收新技能的同时保持对已有知识的记忆，把机器学习推向更类人化的方向。

这篇官方文章还附带面向社区的论文提交入口（arXiv 页面可在谷歌研究博客对应文章中找到）。它的意义与 11 月初另一条新闻形成呼应：当模型开始具备「自己学新东西而不覆盖旧东西」的结构化机制，智能体的长期记忆与自我迭代才有了更可靠的实现路径。

## 2. DeepOCR：两周复刻 DeepSeek-OCR，两张 H200 就能训

据量子位报道，一个两人小团队仅用两周就复刻了此前被硅谷热议的 DeepSeek-OCR，复刻版名叫 DeepOCR，还原了原版低 token 高压缩的核心优势，在关键任务上追上了原版表现。它完全开源，且无需依赖大规模算力集群，在两张 H200 上就能完成训练。

原版爆红的原因被复盘得很清楚：大模型处理长文本时，算力随序列长度呈二次方增长，几百页文档就能把显存撑爆；DeepSeek-OCR 提出了反常识的解法——把文字渲染成图片，用视觉模态当压缩媒介，原本要几千个文本 token 承载的内容几百个视觉 token 就够了，压缩比能做到 7~20 倍，且 10 倍压缩下准确率仍能保持 97%，因此被称为「AI 的 JPEG 时刻」。

复刻策略是先把原版的逻辑架构精准还原。灵魂在 DeepEncoder 编码器，团队严格遵循原版设计，采用「局部处理—压缩—全局理解」的三阶段串联结构：先用 SAM-base 处理高分辨率图像，把 1024×1024 的图切成 16×16 的补丁，靠窗口注意力控制激活内存，生成 4096 个初始 token 也不会让显存过载；然后用 16× 卷积压缩器加两层 3×3 卷积把 4096 个 token 砍到 256 个，同时把特征维度从 256 扩到 1024，为后续全局注意力减负；最后由 CLIP-large 接手，它不读原图，只处理压缩后的 256 个 token，用密集全局注意力抓取文档语义，避开纯全局注意力的内存爆炸问题。复刻版还像原版一样把 CLIP 的补丁特征与展平后的特征结合。

## 3. PettingLLMs：多智能体的「群体强化」

据量子位报道，来自 UCSD 和英特尔的研究人员提出通用化多智能体强化学习框架 PettingLLMs，支持任意组合的多个 LLM 一起训练，首次实现了 LLM 智能体的通用「群体强化」。框架结合树状采样与角色化奖励机制。

研究背景是：大量研究表明，多智能体工作流在未经训练的情况下就能相对单智能体显著提升任务表现；但现有 LLM 智能体训练框架都针对单智能体，多智能体的群体强化学习机制仍是空白。已被验证有效的 GRPO（Group Relative Policy Optimization）算法，其核心机制是针对同一个输入多次采样生成一组候选回答，在组内评估并计算相对优势。

把 GRPO 直接搬到多智能体多轮环境有一个核心困难：这种优势计算依赖一个关键假设——组内用于比较的候选回答必须基于完全相同的上下文生成。而在多智能体场景下，即使针对同一个初始问题，不同智能体在不同轮次收到的 prompt 差异显著，例如负责编程的智能体在第二轮的 prompt 不仅含原始问题，还可能融合了自己生成的代码以及其他智能体生成的单元测试。若仍把跨轮次、跨智能体的回答当作一个「group」计算优势，就直接违反 GRPO 的前提假设。PettingLLMs 正是针对这一缺口提出方案。
