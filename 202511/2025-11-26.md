# 2025-11-26 AI 大事件

北京时间 2025 年 11 月 26 日（星期三）。英伟达股价单日跌超 7%，市值较上月高点回落逾 20%，市场把原因指向谷歌自研 TPU——用 TPU 而非英伟达芯片训练出的 Gemini 3 成了新的参照系。阿里千问 Qwen3-VL 在第三方空间推理榜单 SpatialBench 夺得前两名，以 13.5 分刷新 SOTA。Claude Opus 4.5 的实测细节流出：两小时高强度工程任务得分超过所有人类。

## 1. 英伟达单日跌超 7%，市场归因于 TPU

据财联社消息，11 月 25 日美股早盘英伟达股价大幅走低，日内一度跌超 7% 报 169.55 美元，较上月录得的历史高位回落逾 20%。英伟达的合作伙伴与相关公司同步走低：服务器制造商超微电脑跌 3.2%，承诺购买英伟达系统的甲骨文跌 2%，数据中心运营商 CoreWeave 跌 3.7%——英伟达持有该公司 6% 的股份。

分析认为，投资者把这一轮下跌归因于市场对谷歌母公司 Alphabet 自研 AI 芯片——张量处理单元（TPU）——的强烈兴趣。同日谷歌 A 一度涨超 3%，市值逼近 4 万亿美元关口；而上周谷歌发布的最新大语言模型 Gemini 3，被多位业内权威人士认为已经「超越」了 OpenAI 的 GPT 模型，关键差异正是它使用 TPU 训练，而不是英伟达芯片。

## 2. Qwen3-VL 登顶 SpatialBench，空间推理 13.5 分

据 AIBase 报道，阿里千问视觉模型在第三方空间推理榜单 SpatialBench 夺得前两名：Qwen3-VL 得 13.5 分，Qwen2.5-VL 得 12.9 分，大幅领先 Gemini 3.0 Pro Preview 的 9.6 分与 GPT-5.1 的 7.5 分，距离人类基线的 80 分又近一步。SpatialBench 专注 2D/3D 空间、结构与路径推理，题目包含电路分析、CAD 工程、分子生物学等复杂任务，被视为「具身智能试金石」。

能力上有三项更新。3D 检测新增旋转框输出与深度估计头，遮挡场景的 AP 提升 18%，可判断物体方位与视角变化。视觉编程支持输入草图或 10 秒短视频，直接生成可运行的 Python + OpenCV 代码，实现「所见即所得」。规模上提供 2B/4B/8B/32B 密集模型，以及 30B-A3B 和 235B-A22B 两个 MoE 版本，推理版在 32 项核心能力测试中平均超过 Gemini 2.5 Pro 6.4 分。

落地进展由阿里云披露：Qwen3-VL 已在物流机器人、AR 装配、智慧港口等场景做 POC，空间定位误差小于 2 厘米，公司计划 2026 年推出「视觉—动作」端到端模型，为机器人提供实时视觉伺服能力。

## 3. Claude Opus 4.5 实测：两小时工程任务得分超过所有人类

据量子位报道，Claude Opus 4.5 主打编码、Agent 与 computer use，在前端开发、视觉能力上显著提升，更擅长使用电脑，在深度研究、PPT 制作与电子表格处理等日常任务上的表现也全面升级。实测案例包括：用附件模板创建财务对比分析，模型几分钟内完成模板读取、同行数据收集与估值倍数表创建并直接输出 Excel；修改法律文档时能迅速解包模板、修改公司名称、检查签名块，最终生成的 Word 文件包含修订痕迹与定制内容。

团队实测认为，模型的核心优势在于「理解力」——它能解决 Sonnet 模型无法发现的 bug，同时知道「何时先思考再行动」；内部测试还发现它能自主处理模糊场景、权衡复杂决策，面对跨系统复杂漏洞可独立定位并提供修复方案。评测的极端项是：团队向应聘性能工程师职位的候选人发放一份业界公认难度极高的任务，Claude Opus 4.5 在两小时高强度工程任务上的得分超过所有人类。

可用性方面，Opus 4.5 已通过 app、API 及三大主流云平台开放，开发者通过 Claude API 调用 claude-opus-4-5-20251101 即可使用，定价为每百万 token 输入 5 美元、输出 25 美元；官方同时更新了 Claude 开发者平台、Claude Code 与 App，并拓展了在 Excel、Chrome 及桌面端使用 Claude 的新方式。
