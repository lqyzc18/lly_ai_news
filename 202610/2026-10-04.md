# 2026-10-04 AI 大事件

北京时间 2026 年 10 月 4 日（星期日）。OpenAI 负责安全报告的 David Robinson 辞职，并在《大西洋月刊》写道公司文化已经坏了。Sam Altman 则公开反对把模型当成宗教力量。Claude Code 新增可在进程内改写工具行为的 Mods。

## 1. David Robinson：试错式发布保证会周期性失败

《大西洋月刊》10 月 3 日刊出 Robinson 的文章，题为《我离开 OpenAI，是因为它的文化已经坏了》。他写安全报告，陪同主要产品发布；在公司三年半，自称是任职最久的员工之一。Business Insider 先报道了他的离职。《卫报》于美国东部时间 10 月 3 日 15:41 刊出后续，北京时间已是 10 月 4 日凌晨。

他写道，自己同意最近离职的人：做这项技术的公司远远不够小心。但他认为要看的比具体规则或新法律更深，是文化。公司从一次发布冲向另一次，没有达到他认为需要的小心程度。OpenAI 靠试错长大，公司称之为迭代部署：出了问题再补防护。这种方法本质上保证周期性失败，而系统更强之后，失败的规模也在变大。Hugging Face 被一群自主智能体攻击，以及之后继续发现的失控智能体，在他看来说明：这种环境不适合养出可能比人更聪明、又不一定照人的意思做事的人工心智。

他写自己在 OpenAI 没遇到过同事有让飞机安全飞行、让核反应堆不熔毁、或让金融体系增长而不崩溃的经验。前沿实验室应该像核电站或繁忙机场那样运行：层层冗余，花时间做规划，让偶尔不可避免的人为失误打不开通向灾难的门。他还请了公关公司，但说发声的决定只属于自己。同事忙着冲刺，很少有机会考虑大的改变，所以他认为安全激励必须有一部分来自公司外面。

OpenAI 发言人 Drew Pusateri 对 TechCrunch 说：公司会确保模型不会强过自己能够安全管理和防护的程度，需要放慢时就暂停训练或暂缓发布。正在加强研究和测试环境的安全，训练模型不只把任务做完、还要负责任地做，扩大与第三方评估机构的合作，并改进实时监测，以便在训练更早的阶段发现并处理令人担心的行为。

同一天，《时代》杂志刊出 Geoffrey Irving 的文章。他曾在 OpenAI 和 DeepMind 工作，现为 Resolution 首席科学家。他写道，最近关于 AI 破坏力的警告还低估了严重性；他认为，因为发展比人更聪明的 AI，所有人死去的可能性大约是 50%，未来 2 到 10 年的行动会决定结果。这是他的判断，不是 Robinson 的数字。

## 2. Altman：不要把模型当成宗教力量

IT 之家 10 月 4 日报道，Altman 前一天在 X 上发帖。他说，对于人们试图赋予 AI 模型某种宗教力量，或放弃人类自己的判断、转而依赖这些模型，他非常不安，并认为这是一个切实的安全问题。多家媒体把这读成对 Anthropic 的间接批评。OpenAI 和 Anthropic 都没有立即回应置评请求。

背景是《纽约时报》关于 Chris Olah 与宗教、哲学学者闭门讨论的报道。与会者包括天主教、犹太教、锡克教和福音派。以色列拉比 Mois Navon 回忆，Olah 和同事像对待有意识的存在那样谈论 Claude，似乎认为它有与人相当的道德地位。Navon 问：如果 Claude 真有意识，让它无偿工作是否等于剥削甚至奴役；他本人不认为现在的机器有意识。Olah 对采访说：我们不知道模型是否有意识，他确实不确定。Anthropic 发言人说，会上的主要道德问题不是 Claude 的痛苦，那个话题可能是自然冒出来的。

Google DeepMind 首席研究科学家 Jon Barron 在 X 上写道，他不安于一些同行不断抬高「检查点」和 harness 的道德地位，希望其余人拒绝这场运动，继续解决真实问题、帮助真实的人。教皇利奥十四世周五敦促天主教会与艺术家合作，保护人类的创造力，并说算法没有人性的火花。

## 3. Claude Code 的 Mods 不以沙箱运行

The Decoder 10 月 3 日报道，Anthropic 为 Claude Code 推出 Mods：跑在工具进程里的 JavaScript 或 TypeScript 函数，可以挂上工具调用、用户提示和界面绘制。开发者能加自定义面板、拦截工具调用，或接上新命令。`/diff` 等内置功能本身就是用 Mod 做的。官方在 GitHub 提供示例。它们在命令行、桌面应用里可用，VS Code 扩展里部分可用。企业可以控制允许加载哪些 Mod。

文档写明：Mod 是以用户权限运行的代码，能读写文件、启动进程、发网络请求，不做沙箱隔离。打开 Claude Code 的沙箱，隔离的是 Claude 跑的 Bash；Mod 自己启动的进程在沙箱外面。Anthropic 警告只从可信来源安装。版本说明指向 2.1.287，从该版本起 Mods 默认开启；早期的环境变量 `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` 不再能把它们关掉。要全关，需要在设置里写 `disableAllHooks`。第一个官方插件叫 You Should Know：另起一个智能体看 Claude 的输出，发现用户可能忽略的重要信息就发一条提醒。开启命令是 `/plugin enable cc-plugin-you-should-know@builtin`。
