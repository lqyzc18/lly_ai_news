# 2024-08-21 AI 大事件

北京时间 2024 年 8 月 21 日（星期三）。三条发布都发生在美东 8 月 20 日的工作时段：OpenAI 开放 GPT-4o 的微调能力并给出每天免费的一百万 token 额度；微软开源 Phi-3.5-vision 多模态模型；火山引擎在上海办的 AI 创新巡展上展出了豆包语音与视觉模型的升级。

> 本期记 3 条：OpenAI 开放 GPT-4o 微调、每天免费 100 万 token；微软开源 Phi-3.5-vision；字节火山引擎升级豆包语音与视觉模型。

## 1. OpenAI 开放 GPT-4o 微调，每天免费赠送 100 万 token

OpenAI 官方发布说明《Fine-tuning now available for GPT-4o》标注的日期是 8 月 20 日，页面未给出具体发布时刻。按美国厂商多在美国工作日白天发布、换算成北京时间落在次日的保守口径，本篇归入 8 月 21 日。

这次开放意味着 GPT-4o 正式进入微调阶段。企业可以用自有数据对模型做定制，指令、语气、输出格式都可以按业务要求固化下来；配合结构化输出（Structured Outputs），还能约束模型按 JSON schema 返回结果，直接对接既有系统而不必再写一层解析。

费用安排上，OpenAI 承诺每天为开发者赠送 100 万个免费 token 用于微调训练。这项补贴的实际作用是降低试用门槛：过去要用微调能力做验证，需要先付费跑一轮才能看到效果，现在可以先用赠送额度把数据格式、样本量和超参试出来，再决定投入。另一层背景是竞争——8 月中旬 Meta 发布了 Llama 3.1，Claude 也在持续迭代，开源阵营与闭源阵营在“够用”的边界上互相挤压，闭源厂商必须把定制化能力这个此前相对薄弱的环节补上。

## 2. 微软开源 Phi-3.5-vision，128K 上下文的多模态小模型

微软发布并开源 Phi-3.5-vision-instruct，这是 Phi-3.5 系列中首个多模态版本，可处理文本与图像输入，上下文长度达到 128K token。

小参数模型的多模态化是 2024 年下半年开源社区的一条明确路线。微软的 Phi 系列一直主张“规模够用即可”，把重点放在实际性能与部署成本上；Phi-3.5-vision 把长上下文和多模态结合起来，目标是让单卡甚至边缘设备上的多模态应用成为可能。对开发者来说，这意味着在调用外部 API 之前，先有一个可以完全私有化部署、且没有调用次数限制的备选方案。

## 3. 火山引擎升级豆包语音与视觉模型

火山引擎在 8 月 21 日举办的 AI 创新巡展上海站上，展示了豆包大模型的全面升级与对话式 AI 实时交互方案的增强。官方称豆包大模型综合能力提升 20.3%，同时升级了语音模型与视觉模型。

实时交互是这轮升级的重点：全双工语音、端到端语音理解、视觉理解与动作预测这几项能力被整合进同一套方案，目标是让对话助手在打断、抢话、语气识别这些细节上表现得更接近真人。火山引擎同时对外推出了 Realtime API，把这套实时交互能力以接口形式提供给开发者。字节的思路与 OpenAI 的实时语音 API 类似，都是把"能听、能看、能立刻回应"打包成一项服务能力。
