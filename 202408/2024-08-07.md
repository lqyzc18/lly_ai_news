# 2024-08-07 AI 大事件

北京时间 2024 年 8 月 7 日（星期三）。当天的两条消息分属中美两侧：OpenAI 在 API 里推出结构化输出（Structured Outputs），并同步发布新模型 gpt-4o-2024-08-06；国内这边，零一万物被曝完成新一轮数亿美元融资，知情人士称腾讯之外还有国际战投与东南亚财团参与，公司未予置评。

> 本期记 2 条：OpenAI 推出 API 结构化输出与 gpt-4o-2024-08-06；零一万物完成新一轮数亿美元融资，估值约 104 亿元人民币。

## 1. OpenAI 推出 API 结构化输出，gpt-4o-2024-08-06 同步发布

OpenAI 官方发布说明《Introducing Structured Outputs in the API》标注的日期是 8 月 6 日，页面未给出具体发布时刻。按美国厂商在美国工作日白天发布、换算成北京时间多在当日深夜或次日的保守口径，本篇把这条归入 8 月 7 日。

结构化输出补的是 JSON 模式留下的缺口。此前一年前 DevDay 发布的 JSON 模式只保证输出是合法 JSON，不保证符合开发者给定的某个具体 Schema；新功能要求模型输出严格匹配开发者提供的 JSON Schema。官方给出的两种用法是：函数调用时在函数定义里设置 `strict: true`，适用于所有支持工具调用的模型，包括 gpt-4-0613、gpt-3.5-turbo-0613 及之后的版本；在 `response_format` 参数里新增 `json_schema` 选项，适用于不做工具调用、直接按结构作答的场景，可用的模型是当天的 gpt-4o-2024-08-06 和 gpt-4o-mini-2024-07-18。

效果数字来自公司自测。在复杂 JSON Schema 跟随能力的评测上，新模型 gpt-4o-2024-08-06 配合结构化输出拿到 100%，对照组 gpt-4-0613 不到 40%。公司说明了实现路径的两步：先训练新模型理解复杂 Schema，这一步在该基准上是 93%；再叠加一层确定性的工程约束，把采样限制在符合 Schema 的 token 上，也就是把 JSON Schema 转成上下文无关文法来约束解码，最终把一致率提到 100%。

限制也写得很明确。结构化输出只支持 JSON Schema 的一个子集；首次使用新 Schema 时有额外延迟，官方称典型 Schema 首次处理通常在 10 秒以内、复杂 Schema 可能接近 1 分钟，之后会缓存加速；模型可以选择拒答，API 会返回单独的 refusal 字段；达到最大输出长度等停止条件时结果可能不完整；与并行函数调用不兼容，需要把 `parallel_tool_calls` 设为 false；提供的 Schema 不符合零数据保留（ZDR）资格。

可用范围上，结构化输出在 API 中正式可用。函数调用形式覆盖所有支持函数调用的模型，可在 Chat Completions、Assistants、Batch 三个 API 上使用；`response_format` 形式支持 gpt-4o-mini 和 gpt-4o-2024-08-06 及其微调版本，两种形式都可配合视觉输入。价格上，换到 gpt-4o-2024-08-06 后输入价降 50% 至每百万 token 2.50 美元，输出价降 33% 至每百万 token 10.00 美元。

## 2. 零一万物完成新一轮数亿美元融资，估值约 104 亿元人民币

8 月 7 日有媒体报道，李开复创办的 AI 大模型独角兽公司零一万物已经完成新一轮融资，金额达数亿美元。知情人士表示，本轮参与方包括某国际战投、东南亚财团等多家机构。每日经济新闻报道说，接近公司的知情人士向记者表示该融资消息属实；零一万物对该融资消息未予回应。证券时报同一天转发了同一篇报道。

这是零一万物今年内的第二轮融资。去年 11 月零一万物获阿里云投资，那轮之后估值已超 10 亿美元，跻身独角兽行列；这一轮投资方均为国际资本，媒体据此判断公司可能继续发力海外市场。李开复今年 5 月曾对媒体表示，零一万物将在几周内完成 2.5 亿美元 Pre-A 轮融资的第二部分，并在年底前开始为 A 轮融资寻找投资者，如今融资落地。他此前还讲过，美国等国际市场有更好的付费意愿和消费习惯，因此公司在进入国内市场之前已率先在国际市场试水并取得反馈；公司披露海外生产力应用总用户接近千万，营收今年预期过亿元人民币，面向 C 端的一站式 AI 工作平台“万知”也是先在海外试水、明确读文档与 PPT 制作等高价值场景后才在国内上线。

估值口径需要说明。按 9 月的行业盘点报道，最新估值约 104 亿元人民币；公司没有披露这一数字。零一万物由李开复于 2023 年创立，2023 年 11 月获阿里云投资后估值超 10 亿美元，这次是阿里之外的重要资本补充。

放到行业背景里看，这是国产大模型融资潮的一起。每日经济新闻根据 IT 桔子和公开资料梳理，今年以来全球 AIGC 领域已有 107 起融资事件，国内大模型公司融资金额在亿元级别的有 20 起；“新 AI 六小龙”（零一万物、MiniMax、百川智能、智谱 AI、阶跃星辰、月之暗面）中有五家今年已获亿元级融资。工信部信息通信经济专家委员会委员盘和林认为，相比去年的融资潮，今年的投资人更关注应用端落地，比如月之暗面是因为 Kimi 的用户增长，百川智能则因为在工业等垂直领域的落地；李开复则呼吁创业者关注 TC-PMF（技术成本产品市场契合度），拒绝共享单车式的烧钱打法。
