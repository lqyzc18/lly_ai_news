# 2024-08-23 AI 大事件

北京时间 2024 年 8 月 23 日（星期五）。当天的重点是一篇在今天上午公开的 arXiv 论文：AI21 的 Jamba 团队放出 Jamba-1.5 系列开源模型，把 256K 的有效上下文做进了开放权重模型里。产品侧，Google AI Studio 上线了新的提示词库，Captions 则开放了视频生成与编辑的 API。

> 本期记 3 条：AI21 开源 Jamba-1.5 系列（256K 上下文）；Google AI Studio 推出提示词库；Captions 开放 AI 视频生成与编辑 API。

## 1. AI21 开源 Jamba-1.5：开放权重模型里最长的 256K 有效上下文

论文《Jamba-1.5: Hybrid Transformer-Mamba Models at Scale》于美东 8 月 22 日 17:38（UTC）在 arXiv 提交并当日公布，公开时刻换算成北京时间是 8 月 23 日 8 时，因此本篇归入 23 日。论文作者为 Jamba 团队（领衔作者 Barak Lenz），来自 AI21。

Jamba 是 Transformer 与 Mamba 的混合专家（MoE）架构，目标是同时拿到高吞吐、低显存和 Transformer 级别的质量。这次发布两个尺寸：Jamba-1.5-Large 激活参数 94B，Jamba-1.5-Mini 激活参数 12B，两者都做了指令微调，有效上下文长度 256K token——论文称这是当时开放权重模型中最长的。官方强调的不是单项跑分，而是在长上下文基准上超过其他开放权重模型，同时保持高吞吐。

推理成本是这次发布的重点之一。论文同时提出 ExpertsInt8 量化技术，使 Jamba-1.5-Large 在处理 256K token 上下文时可以放进 8 张 80GB 显存的机器里，且不损失质量。模型权重以 Jamba 开放模型许可证发布，ExpertsInt8 一并开源。对想把长文档业务本地化、又不愿意申请商业授权的团队，这套组合的性价比是这一年开放权重阵营里少见的。

## 2. Google AI Studio 推出全新提示词库

Google AI Studio 上线了新的提示词库（gallery），把一批可直接使用的提示词按场景整理好，供用户测试和参考。库里的样例覆盖多种能力形态，包括长篇文本上下文测试与原生多模态输入。

这类"提示词样板间"的价值在于把提示词工程从个人手艺变成可复用的工程实践。Google 在 Gemini 上线初期就强调过提示词是使用门槛的一部分，把结构化的样例库放进 AI Studio，等于把最佳实践直接放在开发者动手的第一屏。对新用户，它降低了写出第一个可用提示词的难度；对老用户，它提供了可横向比较的基准。

## 3. Captions 开放 AI 视频生成与编辑 API

Captions 推出面向开发者的 AI 视频生成与编辑 API 工具，覆盖视频生成与编辑两类能力，面向社交媒体与营销内容生产场景。官方把这套 API 定位为给创作者与开发者提供可编程的视频生产能力。

把视频生成从"网页工具"变成"接口"，是这一年生成式视频产品的共同走向。模型能力在收敛，而真正的差异化转移到了工作流的嵌入程度：广告、电商、教育类产品需要在既有系统里批量生成和修改视频，有 API 才能做到。Captions 的用户基数与移动端创作场景，恰好是这类接口最容易先跑通的地方。
