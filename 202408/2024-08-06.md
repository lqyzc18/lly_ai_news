# 2024-08-06 AI 大事件

北京时间 2024 年 8 月 6 日（星期二）。OpenAI 在当天的开发者更新里同时放了两样东西：API 的结构化输出（Structured Outputs），以及配套的新模型 gpt-4o-2024-08-06。官方发布说明的时间戳是美东 8 月 6 日 6 时（协调世界时 10 时），北京时间当日 18 时。

> 本期记 1 条：OpenAI 推出 API 结构化输出，并发布 gpt-4o-2024-08-06。

## 1. OpenAI 推出 API 结构化输出，JSON 模式评测得分 100%

OpenAI 官方发布说明《Introducing Structured Outputs in the API》写明，模型输出现在可以严格遵循开发者提供的 JSON Schema。上一层是去年 DevDay 发布的 JSON 模式，它只保证输出是合法 JSON，不保证符合某个具体 Schema；结构化输出补的就是这一层。

两种用法。第一种是函数调用，在函数定义里设置 `strict: true`，适用于所有支持工具调用的模型，包括 gpt-4-0613、gpt-3.5-turbo-0613 及之后的版本；第二种是新增的 `response_format` 参数里的 `json_schema` 选项，适用于不做工具调用、直接按结构作答的场景，可用模型是最新发布的 gpt-4o-2024-08-06 和 gpt-4o-mini-2024-07-18。当 `response_format` 带 `strict: true` 时，模型输出会与提供的 Schema 一致。

效果数字来自公司自测。在复杂 JSON Schema 跟随能力的评测上，新模型 gpt-4o-2024-08-06 配合结构化输出拿到 100%，对照组 gpt-4-0613 不到 40%。公司说明了实现路径的两步：先训练新模型理解复杂 Schema，这一步在该基准上是 93%；再叠加一层确定性的工程约束，把采样限制在符合 Schema 的 token 上，也就是把 JSON Schema 转成上下文无关文法来约束解码，最终达到 100% 的一致率。

限制也写得明确。结构化输出只支持 JSON Schema 的一个子集；首次使用新 Schema 时会有额外延迟，官方称典型 Schema 首次处理通常在 10 秒以内，复杂 Schema 可能接近 1 分钟，之后会缓存下来加速；模型可以选择拒答，API 会返回单独的 refusal 字段；达到最大输出长度等停止条件时结果可能不完整；与并行函数调用不兼容，需要把 `parallel_tool_calls` 设为 false；提供的 Schema 不符合零数据保留（ZDR）资格。

可用范围上，结构化输出在 API 中正式可用（GA）。函数调用形式覆盖所有支持函数调用的模型，以及在 Chat Completions、Assistants、Batch 三个 API 上使用；`response_format` 形式支持 gpt-4o-mini 和 gpt-4o-2024-08-06 及其微调版本。两种形式都可配合视觉输入。价格上，换到 gpt-4o-2024-08-06 后，输入价降 50% 至每百万 token 2.50 美元，输出价降 33% 至每百万 token 10.00 美元。
