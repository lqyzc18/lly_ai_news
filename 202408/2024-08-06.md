# 2024-08-06 AI 大事件

北京时间 2024 年 8 月 6 日（星期二）。OpenAI 这一天挤了三件事：清晨在 API 里推出结构化输出并同步发布 gpt-4o-2024-08-06；下午，联合创始人 John Schulman 在 X 上宣布离职加入 Anthropic，总裁 Greg Brockman 宣布休假到年底，ChatGPT 负责人 Peter Deng 也已离职；晚间，人形机器人初创公司 Figure AI 发布第二代人形机器人 Figure 02，同日进入宝马美国工厂实训。

> 本期记 3 条：OpenAI 推出 API 结构化输出与 gpt-4o-2024-08-06；OpenAI 联创 Schulman 离职加入 Anthropic、总裁 Brockman 休假；Figure AI 发布第二代人形机器人 Figure 02。

## 1. OpenAI 推出 API 结构化输出，JSON 模式评测得分 100%

OpenAI 官方发布说明《Introducing Structured Outputs in the API》的时间戳是协调世界时 8 月 6 日 10 时，北京时间当日 18 时。模型输出现在可以严格遵循开发者提供的 JSON Schema。上一层是去年 DevDay 发布的 JSON 模式，它只保证输出是合法 JSON，不保证符合某个具体 Schema；结构化输出补的就是这一层。

两种用法。第一种是函数调用，在函数定义里设置 `strict: true`，适用于所有支持工具调用的模型，包括 gpt-4-0613、gpt-3.5-turbo-0613 及之后的版本；第二种是新增的 `response_format` 参数里的 `json_schema` 选项，适用于不做工具调用、直接按结构作答的场景，可用模型是同日发布的 gpt-4o-2024-08-06 和 gpt-4o-mini-2024-07-18。当 `response_format` 带 `strict: true` 时，模型输出会与提供的 Schema 一致。

效果数字来自公司自测。在复杂 JSON Schema 跟随能力的评测上，新模型 gpt-4o-2024-08-06 配合结构化输出拿到 100%，对照组 gpt-4-0613 不到 40%。公司说明了实现路径的两步：先训练新模型理解复杂 Schema，这一步在该基准上是 93%；再叠加一层确定性的工程约束，把采样限制在符合 Schema 的 token 上，也就是把 JSON Schema 转成上下文无关文法来约束解码，最终达到 100% 的一致率。

限制也写得明确。结构化输出只支持 JSON Schema 的一个子集；首次使用新 Schema 时会有额外延迟，官方称典型 Schema 首次处理通常在 10 秒以内，复杂 Schema 可能接近 1 分钟，之后会缓存加速；模型可以选择拒答，API 会返回单独的 refusal 字段；达到最大输出长度等停止条件时结果可能不完整；与并行函数调用不兼容，需要把 `parallel_tool_calls` 设为 false；提供的 Schema 不符合零数据保留（ZDR）资格。

可用范围上，结构化输出在 API 中正式可用（GA）。函数调用形式覆盖所有支持函数调用的模型，可在 Chat Completions、Assistants、Batch 三个 API 上使用；`response_format` 形式支持 gpt-4o-mini 和 gpt-4o-2024-08-06 及其微调版本，两种形式都可配合视觉输入。价格上，换到 gpt-4o-2024-08-06 后输入价降 50% 至每百万 token 2.50 美元，输出价降 33% 至每百万 token 10.00 美元。

## 2. OpenAI 高层：联创 Schulman 离职加入 Anthropic，总裁 Brockman 休假到年底

当地 8 月 6 日周一，OpenAI 联合创始人 John Schulman 在 X 发帖，表示将离开 OpenAI 加入竞争对手 Anthropic。中文媒体在北京时间当日 14 时已经报道这则消息，所以本篇归入 8 月 6 日。舒尔曼 2016 年从加州大学伯克利分校拿到博士学位后加入 OpenAI，九年来负责领导 ChatGPT 与 API 的后期训练工作；今年 6 月公司设立安全与保障委员会，他被任命为对齐科学负责人，向董事会提供建议。

他在帖子里写的理由是：“这个选择源于我希望深入研究 AI 对齐，开启职业生涯的新篇章，重返实际技术工作。我决定在 Anthropic 追求这一目标，我相信我可以获得新的视角”，并特意强调离职不是因为公司缺乏对对齐研究的支持，“相反，公司领导层一直非常致力于在这一领域进行投资”，“这是个人决定”。帖下，Sam Altman 回复感谢并写道“更重要的是，我们会非常想念你，并让你为这里感到骄傲”，OpenAI 研究主管 Bob McGrew、ChatGPT 官方号也留言告别，先前已加入 Anthropic 的 Jan Leike 则表示很高兴能再次合作。

总裁一侧，同日公司发言人确认联合创始人兼总裁 Greg Brockman 将休假至今年年底，他称这是九年来共同创办公司后的“第一次放松”，“我们的使命还远未完成，我们还需要建立一个安全的 AGI”。产品副总裁 Peter Deng 也已离职，据彭博社报道他在过去几个月离开公司，他去年加入 OpenAI，此前在 Meta、Uber 和 Airtable 任职。

这已经是 OpenAI 今年第三轮高层流失。此前 Andrej Karpathy 于 2 月离开，超级对齐团队负责人 Jan Leike 和首席科学家 Ilya Sutskever 在 5 月离开，超级对齐团队随之解散；Sutskever 表示正在参与创办新公司 Safe Superintelligence Inc.。舒尔曼没有说明离职的具体生效时间，Anthropic 也未就此事置评。

## 3. Figure AI 发布第二代人形机器人 Figure 02，已进宝马工厂实训

北京时间 8 月 6 日晚，人形机器人初创公司 Figure AI 发布第二代人形机器人 Figure 02（美国当地 8 月 6 日）。公司自己的说法是：“这是地球上最先进的 AI 硬件，距离向工业用户销售量产人形机器人的目标又近了一步。”

硬件是重新设计过的。Figure 02 的“皮肤”从上一代 Figure 01 的镀铬金属外观改成黑色哑光，内部布线全部收进躯干和关节，电池容量提高 50% 到 2.25KWh，公司希望它每天能工作约 20 小时。灵巧手是官方视频的重点：手部有 16 个自由度，负载能力与人类相当，可抓取 25 公斤物体，比上一代多 5 公斤，每根手指由一个集成单元驱动。感知方面，机器人身上装了 6 个 RGB 摄像头，分别位于头部、胸前和后背，搭载视觉语言模型（VLM）对物理世界做常识性视觉推理，并有语音到语音推理模型，通过机载麦克风和扬声器与人对话。公司称相比上一代，Figure 02 的计算能力和 AI 推理能力提高了 3 倍，能够“完全自主地执行实际的 AI 任务”。

落地进展是同步公布的。宝马当天宣布，首次在其美国斯帕坦堡工厂使用 Figure AI 的人形机器人，Figure 02 在持续数周的测试中于真实生产环境里把钣金零件插入车身结构，精度可达毫米级。宝马生产总监 Milan Nedeljkovic 的评价是：“人形机器人技术领域的发展前景广阔。我们希望陪伴这项技术从研发走到产业化。”公司背景上，Figure AI 成立于 2022 年，今年 3 月完成 6.75 亿美元融资，投资方包括英伟达、OpenAI、微软以及贝索斯，投后估值 26 亿美元；按协议，Figure AI 将与 OpenAI 合作开发下一代人形机器人的 AI 模型，并使用微软 Azure 承载 AI 基础设施、训练与存储。
