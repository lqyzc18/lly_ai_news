# 2025-06-11 AI 大事件

北京时间 2025 年 6 月 11 日（星期三）。当天中国侧的发布集中在字节跳动 2025 FORCE 原动力大会：火山引擎推出豆包大模型 1.6 与视频生成模型 Seedance 1.0 pro，并同步升级 Agent 开发平台、云原生服务与 AI IDE 产品 TRAE。海外侧则是模型与工具的双线推进：OpenAI 推出 o3-pro 并把 o3 的价格下调八成，Mistral 发布首个推理模型系列 Magistral，Figma 则推出官方 Dev Mode MCP 服务，把设计稿直接接进 AI 编码工具。

## 1. 字节跳动 FORCE 大会：豆包大模型 1.6、Seedance 1.0 pro 与火山引擎 MCP

字节跳动在 6 月 11 日举行的 2025 FORCE 原动力大会上，火山引擎正式发布豆包大模型 1.6 与全新的视频生成模型 Seedance 1.0 pro，并同步升级 Agent 开发平台和 AI 云原生服务。字节跳动 CEO 梁汝波在会上表示，公司将坚定不移地做一家领先的创新科技企业，持续投入以追求智能领域的突破，并全力服务于产业应用。

定价是这次发布最醒目的部分。豆包大模型 1.6 采用统一定价模式，开创了按"输入长度"区间定价的先河：在企业常用的 0-32K 输入范围内，价格为每百万 token 输入 0.8 元、输出 8 元。性能方面，豆包 1.6 在多个国际权威测评中表现优异，尤其是在复杂推理和竞赛级数学等测试中名列前茅。火山引擎总裁谭待表示，该模型不仅支持多模态理解，还具备图形界面操作能力；相比豆包 1.5，1.6 在电商识图、自动驾驶数据标注等场景的应用更为成熟。

产品线上的另一条线是 Seedance 1.0 pro 与语音模型。火山引擎同时发布豆包·语音播客模型与豆包·实时语音模型：前者只需输入一句话、网页链接、长文本或文档，就能搜索学习、生成播客脚本并创作出双人对话式播客，秒级产出且带互相附和、插话、犹豫等播客节奏，自带深度搜索可跟进热点话题；后者专注于实时语音识别与生成。此外还发布了火山引擎 MCP 服务，深度链接 Agent 开发体系、大模型工具生态与云服务，与 TRAE、火山方舟、扣子等产品打通，为开发者提供超 200 种服务选择；AI IDE 产品 TRAE 也迎来升级，新增代码补全、局部代码生成、代码重构、批量修改与知识问答，自今年 1 月上线以来月活用户已超 100 万。

## 2. OpenAI 推出 o3-pro，o3 价格下调八成

OpenAI 在美东时间 6 月 10 日发布 o3-pro，并把 o3 的价格下调 80%，两件事同日落地，折合北京时间 6 月 11 日上午。中文媒体在当天上午 10 时前后集中报道。

o3 的新定价是：输入 token 从每百万 10 美元降至 2 美元，输出 token 从每百万 40 美元降至 8 美元，缓存输入 token 另有额外 75% 折扣、定价为每百万 0.5 美元。报道认为，新价格使 o3 的使用成本与 GPT-4o 相当甚至更低，显著提升了它在开发者市场的吸引力。o3-pro 则作为高性能版本同步推出，支持更多的软件工具集成，特别适合需要高细节与准确度的企业与开发者。

代价是速度。OpenAI 表示，o3-pro 的响应时间通常会比 o1-pro 慢，"我们建议在需要可靠性而非速度的情况下使用它，等待几分钟"。o3-pro 现已向 Pro 和 Team 用户开放，取代原来的 o1-pro，Enterprise 与 Edu 用户需等到下周。同日还有一条产品新闻：ChatGPT 语音模式升级，引入更多语言翻译，交流更自然。

同日 OpenAI CEO 萨姆·奥尔特曼的博客《温和的奇点》被广泛转述。他在文中给出的资源消耗数字引发讨论：每次 ChatGPT 查询平均消耗水量约 0.000085 加仑，约合 1/15 茶匙，每次查询的电力消耗也相对较低。文中还提出了一组时间表式的判断：2026 年出现能发现新颖见解的 AI 系统，2027 年出现能在现实世界执行任务的机器人，到 2030 年代智能与能量都极大丰富。

## 3. Mistral 发布首个推理模型系列 Magistral

法国人工智能实验室 Mistral 宣布正式推出其首个推理模型系列 Magistral，包含 Magistral Small 与 Magistral Medium 两个版本，目标是提升数学、物理等学科的逻辑推理能力。Mistral 表示，Magistral 通过分步骤解决问题，以提高结果的一致性和可靠性。

Magistral Small 拥有 240 亿参数，已在 Hugging Face 上以 Apache 2.0 许可证开放下载。报道把它与 OpenAI 的 o3、谷歌的 Gemini 2.5 Pro 放在同一条线上比较——这些模型都是通过显式的推理步骤来换取准确度，差别在于推理链的呈现方式与成本。

Mistral 在同期还有两条消息：据报道其年销售额已突破 1 亿美元，公司员工规模约 250 人，并计划进行新一轮融资；此前一天它还发布了面向企业的编码助手 Mistral Code，主打在企业自有基础设施上本地部署完整 AI 技术栈。一家成立时间不长的欧洲公司同时推进推理模型、企业编码助手和自建算力，反映出欧洲模型厂商在合规与数据主权上的差异化路线。

## 4. Figma 推出官方 Dev Mode MCP 服务

Figma 正式推出其官方的 Dev Mode MCP（Model Context Protocol）服务器 Beta 版，通过标准化协议把 Figma 的设计数据直接传递给 AI 编码工具，目标是提升从设计到代码的转换效率与准确性。

这个服务支持与多种 AI 编码工具无缝集成，包括 VS Code with Copilot、Cursor、Windsurf 以及 Claude Code 等。采用 SEE 模式（简化、增强、效率），免除了传统 MCP 配置的繁琐步骤，开箱即用。此前 Figma 已有社区版 MCP，但官方服务在数据结构的完整度与稳定性上更可控。

设计到代码的自动化是这一年来设计工具厂商的必争之地。与"把设计稿转成图片再交给模型"的做法不同，官方 MCP 的价值在于暴露的是结构化、可被程序读取的设计数据：图层、约束、组件属性与变量都能被精确引用。这决定了生成的代码是"看起来像"还是"真正基于设计系统"。Beta 阶段的具体能力边界与授权方式，以 Figma 官方文档为准。

## 5. 火山引擎：豆包日均调用量 16.4 万亿 token，市占率 46.4%

同在 FORCE 大会，火山引擎总裁谭待披露了一组运营数据：截至 2025 年 5 月底，豆包大模型的 token 日均调用量已达 16.4 万亿，是其发布初期的 137 倍。谭待表示，豆包大模型自推出以来持续迭代优化，广泛应用于内容创作、智能客服、数据分析等场景。

另一组数字来自 IDC 的最新市场数据：火山引擎目前占据 46.4% 的大模型市场份额，稳居国内第一。这两个数字放在一起看，反映出中国大模型市场的竞争重心正在从技术能力转向落地规模——调用量是真实业务负载的直接体现，而份额则说明这种负载已经形成足够大的迁移成本壁垒。

需要说明的是，份额的统计口径与"大模型市场"的具体定义有关，不同机构对公有云、私有化部署与 token 消耗的计量方式并不一致，46.4% 这一数字应理解为 IDC 在其口径下的统计结论，而非全行业唯一答案。137 倍的增长同样需要放在发布初期基数极低的背景下理解。
