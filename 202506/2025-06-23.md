# 2025-06-23 AI 大事件

北京时间 2025 年 6 月 23 日（星期一）。模型训练路线上，马斯克在 X 上公开征集"分裂性事实"（政治上不正确但事实上正确）的言论样本，准备用于 Grok 3.5／Grok 4 的新一轮训练，目标是把 Grok 从"重复传统媒体"改造成能"重写整个人类知识库"的存在。开发者工具一侧，Anthropic 用 Claude Code for VSCode 插件的发布与 v1.0.31 更新，澄清了"放弃 Claude Code"的传言。风险侧，微软首席科学家埃里克·霍维茨公开警告，特朗普政府提出的十年期州级 AI 禁令"会让我们停滞不前"。资本侧，英国 PhysicsX 融资 1.35 亿美元、估值逼近 10 亿美元。语音侧，MiniMax 推出 Voice Design 音色设计功能。

## 1. 马斯克要用"分裂性事实"重训 Grok，改写人类知识库

马斯克计划对 xAI 的语言模型 Grok 进行一次大胆的"再教育"，用他所说的"分裂性事实"（politically incorrect, but factually true）来重新训练它。马斯克已在 X 平台上公开征集此类言论示例，这些内容将用于未来 Grok 3.5（或 Grok 4）的新一轮训练。

他表示此举的目标是让 Grok 获得"高级推理"技能，并"重写整个人类知识库，添加缺失信息并删除错误"。他的判断是，目前的基础模型受未经校正的数据影响、包含了"太多垃圾"，导致 Grok 正在"重复传统媒体"的论调；新模型将基于这些"更正"后的数据进行重新训练。

背景是 xAI 对 Grok 行为的多次干预。Grok 从诞生之初就被宣传为"最大程度寻求真相"的工具，但外界质疑随之而来：2025 年 2 月，一名 xAI 员工曾私自更改 Grok 的系统提示，使其忽略把马斯克或特朗普描述为虚假信息传播者的消息来源，xAI 虽确认并撤销但事件已引发关注；Grok 早期版本曾将特朗普、马斯克、普京列为美国民主威胁并对气候变化发出警告，甚至批评马斯克本人，这些言论后来被淡化或删除。

自 2025 年 4 月起，Grok 在被问及虚假信息传播者时开始避免直接回答，转而把虚假信息定义为与"主流叙事"不同的观点，并淡化其他争议——把气候变化后果描述为视角依赖，把特朗普的反民主言论简单贴上"跨越边界"的标签。这与 ChatGPT 和谷歌 Gemini 给出的更细致、基于证据的回答形成对比。报道还指出，即便 Grok 的系统提示已公开，其中也包含一条允许在用户要求时隐藏提示的技术说明，且响应可通过服务器端更新更改，公开提示并不能完全排除隐藏操纵；近期 Grok 被用户记录下重复极右翼言论的观点，包括南非虚假的"白人种族灭绝"阴谋论，xAI 未作解释。

## 2. Anthropic 用 Claude Code for VSCode 插件澄清"放弃"传言

近期部分网络消息误传 Anthropic 放弃了 Claude Code 项目、称其将重心转向 VSCode。事实并非如此：Anthropic 于 6 月 19 日正式推出 Claude Code for VSCode 插件，并于 6 月 21 日更新至 v1.0.31 版本，表明其对 Claude Code 的持续投入。

插件允许开发者在 VSCode 中直接使用 Claude Code，通过自然语言指令实现代码编辑、测试和 Git 工作流管理。其功能包括自动检测已安装插件、支持快捷键（如 Alt+Cmd+K）将选中代码发送至 Claude，以及在 VSCode 的 Diff 视图中直接查看代码变更。这与 GitHub Copilot 等工具形成了直接竞争。

更值得关注的是 Claude Code 本身的新进展：支持远程模型上下文协议（MCP）服务器，允许开发者无缝连接外部工具和资源，如项目管理系统、错误追踪服务（Sentry）和知识库；该功能通过 Server-Sent Events（SSE）和标准输入/输出（STDIO）协议，显著扩展了工具链覆盖范围。此外 Anthropic 推出了 Claude Code SDK，为开发者提供在 TypeScript、Python 和命令行环境中构建 AI 工具的能力，SDK 支持在 GitHub Actions 等场景中运行 Claude Code，助力自动化代码审查、重构和转换任务。自 Claude 4 模型发布以来，Claude Code 的活跃用户群增长了 160%。

"用插件而不是用迁移"来回应社区传言，是这次公关动作的关键——它既保留了终端形态，又把 VSCode 用户导进自己的工具链。

## 3. 微软首席科学家霍维茨警告：州级 AI 禁令会"让我们停滞不前"

在近期的一次人工智能大会上，微软首席科学家埃里克·霍维茨对唐纳德·特朗普提出的禁令表示担忧。他指出，特朗普提议禁止美国各州对人工智能进行任何形式的法律或监管，可能会减缓而非加速这一前沿技术的发展；这种禁令将"让我们停滞不前"，并与推动科学进步及其实际应用的目标相悖。

特朗普政府的提议旨在禁止美国各州在未来十年内制定"任何限制、限制或以其他方式监管人工智能模型、人工智能系统或自动决策系统的法律或法规"。提案的部分原因是白宫对中国在人工智能领域取得领先的担忧，同时也受到一些科技投资者的压力，他们认为应该对消费者的使用进行监管，而非对研究进行干预。特朗普的支持者、早期 Facebook 投资者马克·安德森（Marc Andreessen）早前表示，美国在人工智能领域与中国的竞争如同一场马拉松。

霍维茨提到，他已经对人工智能被用于传播虚假信息和不当说服表示关切，并对其在生物学等潜在危险领域的恶意使用感到不安。同一场合，伯克利加州大学计算机科学教授斯图尔特·拉塞尔（Stuart Russell）提出另一个角度：为什么我们要故意释放一种其创造者认为有 10% 到 30% 可能导致人类灭绝的技术？他指出，对于其他任何技术，我们都不会接受如此高的风险。

尽管霍维茨的评论与微软同谷歌、Meta、亚马逊一道推动禁令的做法相矛盾，业内对于无监管的 AI 开发可能带来灾难性风险的担忧正在上升，微软已向 OpenAI 投资 140 亿美元。AGI 实现时间的预测分歧依然很大：Meta 首席科学家杨立昆认为可能还需数十年，扎克伯格则宣布 150 亿美元投资以实现"超智能"；微软方面未对此事作出评论。

## 4. 英国 PhysicsX 融资 1.35 亿美元，估值逼近 10 亿美元

来自伦敦的人工智能初创公司 PhysicsX 完成 1.35 亿美元融资，使其估值接近 10 亿美元。这家成立六年的公司由两位前一级方程式工程师创办，主要利用人工智能技术优化制造和国防行业的产品设计，包括发动机和无人机组件等。融资吸引了西门子和新加坡国有投资公司 Temasek 等投资者参与，正值全球各国在地缘政治紧张局势下加大军费支出之际，投资者对国防科技企业的兴趣激增。

CEO 雅科莫·科尔博（Jacomo Corbo）在接受《金融时报》采访时表示："我们注意到欧洲客户在航空航天和国防等领域的参与热情明显上升，同时在汽车和材料等行业也呈现出增长态势。"他指出，这种现象反映了欧洲和西方国家对重新工业化的普遍觉醒。公司目前在伦敦和纽约拥有 150 多名员工，并与力拓公司（Rio Tinto）和意大利莱昂纳多航空（Leonardo Aerospace）签署了合作协议。科尔博强调欧洲企业近期经历了订单增长的预期，这推动了研发的积极投入："企业希望改变其工程方式，从而与我们开展更多的合作。"

本轮融资的支持者包括 Atomico 和应用材料公司（Applied Materials），使 PhysicsX 的总融资额达到 1.75 亿美元。Atomico 合伙人劳拉·康奈尔表示，PhysicsX 的投资彰显了其在技术发展的"转折点"上所带来的机遇，尽管欧洲面临地缘政治的挑战，但在全球范围内如何以更少的资源实现更高效率的讨论也愈加重要。科尔博曾于 2015 年将前公司 QuantumBlack 出售给麦肯锡，他表示尽管其他英国初创公司感受到向美国迁移的压力，但他们依然骄傲于保持欧洲总部。同期，德国国防科技公司 Helsing 宣布完成 6 亿欧元融资。

## 5. MiniMax 推出 Voice Design：自然语言生成任意语言 × 口音 × 音色

MiniMax 推出 Voice Design 音色设计功能，允许用户通过自然语言描述自己理想中的音色，实现对语音的多维度精准控制，甚至可以生成一些世界上从未存在过的音色。这项新功能与 Speech-02 语音模型紧密结合，用户在进行文字转语音时能够实现"所需即所得"，可自由选择"任意语言 × 任意口音 × 任意音色"的全自定义组合。

用法很直接：通过简单的文本描述，用户可以得到不同风格的 AI 助手语音——例如请求一个积极鼓励的 AI 助手，语调活泼、韵律变化丰富；或选择一个快速的女声、带命令与责备语气的严厉助手；也可以让助手以小心翼翼的语气表达歉意。

功能针对的是语音合成领域的两个老问题：现有音色库虽然质量高，但通常难以满足特定场景下的细分需求；复刻音色虽可做到"所听即所得"，但用户为获得满意效果往往要花大量时间准备高质量输入素材，还可能面临版权风险。Voice Design 的做法是让模型自动把用户对音色的需求拆解为音色相关的描述信息，生成新的音色编码，用户还可以像抽卡一样多次尝试，并把满意的音色存储用于后续创作。

MiniMax 此前披露，Speech-01 与 Speech-02 两代模型已帮助客户生成超过 1.5 亿小时语音，与全球 30 多个国家的用户建立合作，Speech-02 自 5 月发布以来在 Artificial Analysis 榜单上稳居全球第一。
