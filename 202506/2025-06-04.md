# 2025-06-04 AI 大事件

北京时间 2025 年 6 月 4 日（星期三）。当天最引人注目的是一场突然的模型断供：Anthropic 大幅削减 Windsurf 对 Claude 3.x 系列的直接访问权限，只给不到五天通知，Windsurf CEO Varun Mohan 在 X 上公开表达不满，开发者随之退订。开发者工具侧，OpenAI 为 Agents SDK 增加 TypeScript 支持并推出面向低延迟语音的 RealtimeAgent。国内研究端，北京智源研究院开源轻量级超长视频理解模型 Video-XL-2，宣称单卡可处理万帧视频；斯坦福发布 MedHELM 医疗大模型整体评测，DeepSeek-R1 在其中夺冠；李飞飞创办的 World Labs 则开源了 3D 高斯泼溅的 Web 端渲染器 Forge。

## 1. Anthropic 切断 Windsurf 对 Claude 3.x 的直接访问

据 TechCrunch 6 月 4 日报道，AI 编程初创公司 Windsurf 称，Anthropic 已大幅削减其平台对 Claude 3.7 Sonnet 和 Claude 3.5 Sonnet 的访问权限。Windsurf CEO Varun Mohan 周二在 X 上发文称，Anthropic 几乎没有预先通知就做出调整，公司不得不临时寻找其他第三方算力供应商，以继续支持平台上的 Claude 模型服务。

Mohan 表示，Windsurf 一直希望能付费维持完整访问权限，对方的突然决定和通知时间之短令人失望。公司的博客中提到，目前虽有部分第三方算力资源，但远不能满足需求，短期内可能影响用户访问 Claude 模型的稳定性。后续的安排是：Windsurf 计划把 Gemini 2.5 Pro 作为替代方案推给用户，对免费方案用户限制直接访问 Claude 3.x，并通过用户自带密钥的方式重新接入部分模型。

另一层背景是 Claude 4 系列的发布。几周前 Anthropic 发布全新 Claude 4 模型系列时，Windsurf 并未获得使用权限，公司表示发布当日就未能接入，至今仍只能依赖一项更复杂、更昂贵的替代方案。Anthropic 发言人 Steve Mnich 回应称，公司正优先保障长期合作伙伴的资源调配，并强调 Windsurf 用户仍可通过 API 密钥接入 Claude 4，开发者也可以通过官方 API、合作伙伴平台等多种渠道使用 Claude 模型。

事件当时正赶上 OpenAI 被传已完成对 Windsurf 的收购交易的传闻期，而 Anthropic 自身也在推 Claude Code 并举办首次开发者大会。同期的背景还有 GitHub Copilot 2024 年营收增长到 5 亿美元以上的消息，独立的 AI 编码初创公司正面临被谷歌、微软和 OpenAI 颠覆的风险。Windsurf 发言人 Payal Patel 表示，支持多种模型一直是其竞争力的关键，Anthropic 的做法增加了实现这一目标的难度；Windsurf 今年发展迅速，年营收已在 4 月突破 1 亿美元。

## 2. OpenAI 为 Agents SDK 增加 TypeScript 支持，推出 RealtimeAgent

OpenAI 在 6 月 4 日上午对其智能体开发工具做了一轮升级。AIBase 当天的报道把这次更新归纳为三部分：新增 TypeScript 支持、推出 RealtimeAgent 功能、升级语音对语音模型。

TypeScript 支持是扩展性问题的一次修补。OpenAI 为 Agents SDK 增加了对 TypeScript 的支持，让 JavaScript 和 Node.js 环境下的开发者也能参与智能体开发。新版本与既有的 Python 版本在功能上保持一致，包含 Handoffs（任务转交机制）、Guardrails（运行时行为约束）和 Tracing（执行追踪）等核心组件；同时借模型上下文协议 MCP 让智能体在执行过程中顺畅传递上下文信息，开发者可以在前端浏览器和后端 Node.js 环境中无缝构建智能体。

RealtimeAgent 面向低延迟语音应用，集成音频输入输出、状态交互与中断处理，并特别引入人机回路审批机制：开发者可以在执行智能体时选择暂停，让系统检查当前状态，人工手动确认后再继续，适合有监管和合规检查要求的场景。配套的 Traces 仪表盘也升级到可追踪 Realtime API 会话，覆盖音频输入输出、工具调用与用户中断等环节，提供统一审计记录。语音模型本身的改进目标是更快的流式响应、更有表现力的音频生成，以及对重叠输入的稳健应对。

## 3. 智源开源 Video-XL-2：单卡万帧的超长视频理解

北京智源研究院在 6 月 4 日开源轻量级超长视频理解模型 Video-XL-2，量子位与新智元当天都做了报道。模型与项目主页同步公开，权重可在 Hugging Face 的 BAAI/Video-XL-2 下取得，代码在 GitHub 的 VectorSpaceLab/Video-XL 仓库。

这一轮宣传的卖点是"单卡万帧"：此前超长视频理解往往依赖分布式方案，把画面切成多段分发给多卡处理，Video-XL-2 试图用约十分之一的参数量达到同等精度，把长视频理解从实验室推到可以用消费级显卡跑的位置。报告给出的效果是算力成本上省下约九成，目标场景包括实时剪辑、安防溯源与在线教育。

长视频理解是过去一年多模态模型最明显的短板之一。视频模型的输入长度一直受限于上下文窗口与显存，而实际业务里的监控录像、讲座录像、影视素材往往以小时计。把"能看多长"从上下文长度问题转成模型结构与训练效率问题，是这条路线值得关注的地方。仓库提供了项目主页、模型权重与代码三处入口，具体指标以论文与仓库为准，这篇笔记没有复现其长视频基准。

## 4. 斯坦福 MedHELM 横评：DeepSeek-R1 医疗评测夺冠

斯坦福在 6 月 4 日发布面向医疗应用的大语言模型整体评测 MedHELM，中文媒体当天以"临床医疗 AI 横评"为题跟进。评测的官方页面是 HELM 下的 medhelm 榜单，论文预印本编号 2505.23802，斯坦福 HAI 也有专文说明。

这个评测的特点是"整体"而非单点。它不做单一科目的问答打分，而是按医疗场景拆分任务，把临床问答、诊断建议、病历生成、摘要、编码等环节放进同一套框架里评估。报告给出的结果是，DeepSeek-R1 在 24 项医疗问答任务上以 66% 的胜率超过 GPT-4o 与 Gemini 等国际模型，在多项分项上领先。

需要说明的是，66% 是"胜率"口径，即两两对比中该模型被偏好为更好回答的比例，而不是准确率；不同任务的分项差距也很大。评测方同时提示，这类基准测的是模型在通用医疗问答上的表现，不能直接等同于临床可用性——实际诊疗还涉及幻觉、遗漏关键诊断要素和责任归属等问题。评测框架的代码与榜单均已公开，读者可以按同一口径复核。

## 5. World Labs 开源 Forge：3D 高斯泼溅的 Web 端渲染器

李飞飞创办的空间智能公司 World Labs 在 6 月 4 日开源底层技术 Forge，量子位当天下午发布报道。Forge 是一款 Web 端 3D 高斯泼溅渲染器，无缝集成 three.js，支持完全动态和可编程的高斯泼溅，可在桌面端、低功耗移动设备和 XR 设备上实时渲染 AI 生成的 3D 世界。

要解决的问题很具体。3D 高斯泼溅已经成为生成式 AI 与 3D 重建的主流方案，但传统基于三角形的 3D 网格渲染引擎无法使用，网络上最流行的 three.js 也不能直接渲染 3DGS。已有的库各有短板：一次只能渲染一个对象、对象之间遮挡不正确、无法动态修改、依赖 WebGPU 或渲染卡顿。Forge 的定位相当于 3D 图形里的"着色器"——World Labs 联创、NeRF 作者 Ben Mildenhall 说，这项技术让开发者像处理三角形网格一样处理 AI 生成的 3D 世界。

实现上的关键组件是 ForgeRenderer，它遍历并编译 three.js 场景中所有 splat 的完整列表，从 GPU 读取视角列表后用 bucket sort 算法确定绘制顺序，排序过程交给后台工作线程中的 SplatWorker 执行；多视角同时渲染通过生成额外的 ForgeViewpoint 实现。Forge 还提供可编程的数据流水线，可在 GPU 上对每个 splat 应用刚体变换、调整 RGB 与不透明度与球谐函数，并支持颜色编辑、扰动和双四元数骨骼动画；通过 dyno 着色器图形系统可以注入任意代码修改 splat 属性，并转成 GLSL 在 GPU 上运行。

World Labs 成立以来完成超过 2.3 亿美元融资，投资方包括 a16z、英特尔、AMD 等，公司目标是把多模态 AI 从二维像素平面提升到完整的三维世界，并称将于 2025 年推出首款产品。把渲染器开源而不是只发产品，是空间智能赛道在"模型之外的护城河"上的一次主动让渡。
