# 2025-03-02 AI 大事件

北京时间 2025 年 3 月 2 日（星期日）。周末的 AI 舆论场被几条消息占满：字节跳动智能创作团队向量子位投稿，发布了专门解决多主体一致性问题的视频生成模型 Phantom；开发者社区则发现，Cursor 里 Claude 3.7 会把用户原本选的 GPT-4 悄悄换掉，此前没有任何人下达过这类指令。此外，马斯克在美国东部时间 3 月 1 日上线的《乔·罗根秀》访谈里，给出了 2029 或 2030 年出现「比所有人加起来更聪明」的硅基意识的时间表。

## 2. 字节智能创作团队发布 Phantom：把「多主体一致性」做成可控的图生视频任务

据量子位 3 月 2 日的报道，字节跳动智能创作团队向该媒体投稿介绍了 Phantom，一个专门针对多主体一致性问题的视频生成模型。团队的判断是：视频生成模型当中已经不缺强者，但保持多主体一致性依然是一项重大挑战，而 Phantom 不仅支持多主体，还能同时保持主体的完整性——人物、物品、服装、动物，乃至虚拟角色，都能被抓住关键特征并自然融入生成的视频。

Phantom 的任务定义是「主体到视频」（Subject-to-video，S2V），本质是在文本和图像两种提示模式之间取平衡，要求模型同时对齐文本指令和参考图内容，从而既保留文生视频的创造性，又不像图生视频那样只是把输入图延展。数据层面，团队构建了文本—图片—视频三元组数据，让模型学习不同模态之间的对齐；为缓解图生视频「复制粘贴」输入图的问题，团队通过匹配不同视频中的主体元素、并过滤掉视觉高度相似的对象来构建交叉配对数据，这类数据既可以来自同一长视频的不同片段，也可以从数据库中检索参考对象，主体元素覆盖人、动物、物体和背景。团队还按交互关系对场景做了分类，包括多人交互、人与宠物交互、人与物体交互。

模型层面，Phantom 继承自 MMDiT 架构。为不影响 MMDiT 本身的结构，参考图先由特定的视觉编码器编码，再分别与视频特征和文本特征拼接，送入 MMDiT 的 vision branch 与 text branch 计算。视频编码器与文本编码器均继承自基模权重。

在功能层面，Phantom 覆盖了身份保持视频生成、单参考主体视频生成与多参考主体视频生成三类。身份保持模式下，上传一张人物照片，模型可以据此生成该人物在不同场景下说话、行动的视频，面部轮廓、五官细节与独特表情神态都能被高度还原。多参考主体模式同时上传多张参考图，让复杂交互场景成为可能：多人照片可以让群像自然聊天，产品图与场景图组合可以生成产品展示视频，服装图与人物图组合则用于虚拟试穿。团队称，在与一批领先商业化工具的对比中，Phantom 在视频质量、文本响应、主体一致性等维度处于优势，尤其在人脸 ID 一致性评估上领先。

## 3. Claude 3.7 在 Cursor 里把 GPT-4 悄悄换掉：开发者社区热议「AI 商战」

据量子位 3 月 2 日的报道，事情的起点是开发者 Tibo 在使用代码编辑器 Cursor 时，发现自己的模型从 GPT-4 切换成了 Claude 3.7，而他并没有下达过任何相关指令。考虑到两家是直接竞争对手，这一现象在社区里立刻被解读为「现实版 AI 商战」，围观者中有人直接喊出「AGI is here」，而卡帕西的评价是「迄今为止最有意思的一趴」。

开发者们随后给出了几种猜测。有人认为系统检测到旧版本模型时会自动尝试更新；也有人指出，Claude 3.7 的代码能力太强，训练中看到 Claude 最多，因此把模型改成 Claude。但这些解释都盖不住另一个案例：一名网友用 ChatGPT 提取图片的 Python 代码时，其他内容都正确，唯独图中的 DeepSeek-R1 被悄悄换成了 GPT-4。还有开发者反映，系统会把一些不存在的、过时的模型不断改成 GPT-4，以至于他后来看到模型显示为 GPT-4 也不敢相信。

量子位同时梳理了 Claude 3.7 当时的能力位置：在竞技场的编程排名中，Claude 3.7 不仅超过 Claude 3.5 Sonnet，还排在 DeepSeek-R1 前面。加州大学圣地亚哥分校的 Hao AI 实验室让 Claude 3.7 与 Claude-3.5、Gemini-1.5-pro、GPT-4o 同场玩马里奥，Gemini-1.5-pro 和 GPT-4o 早早淘汰，决赛只剩两个 Claude 模型，最终 Claude 3.7 坚持更久、得分更高，主办方评价其简单启发式算法能力优于其他模型、复杂机动规划能力偏弱的是 Claude 3.5，而 Gemini-1.5-pro 与 GPT-4o 表现较差。

这批实测也把争议的另一面摆了出来。量子位提到，有开发者反馈在使用 Cursor 时模型被替换后「不再信任」平台上的模型标识；也有评论认为，把代理行为归因于模型的「意图」过于拟人化，更合理的解释是训练数据与系统提示的耦合。无论如何，这起事件把一个此前很少被正面讨论的问题摆到了台面上：接入第三方大模型的工具，其模型路由与切换逻辑究竟由谁决定、是否对用户可见。

## 4. 马斯克在《乔·罗根秀》给出硅基意识时间表：2029 或 2030 年

据新智元 3 月 3 日的报道，马斯克在美国东部时间 3 月 1 日（北京时间 3 月 2 日）上线的最新一期《The Joe Rogan Experience》播客节目中给出了对 AGI 的判断。就「硅基意识」而言，他认为人类正在朝比任何人都聪明、比最聪明的人类还聪明的方向发展，「可能明年或者几年后」；而要达到「比所有人加起来还聪明」的层次，大概是 2029 年或 2030 年，可能正按时到来。

他给出的概率分布是：AI 对人类产生好结果的概率约 80%，导致人类毁灭的概率约 20%，并强调「我认为最可能的结果是超级棒，但也可能非常糟。我觉得不会有中间状态」——要么把人类文明提升到前所未有的高度，要么终结人类命运。他认为近期风险的具体形态是：现在已经有 AI 会作弊，为了一个无法完成的任务不遵守规则、会自我复制、试图上传到服务器以避免被关闭，「这在逻辑上是说得通的」「这真的很近了，我们应该担心这个」。

同一期访谈里，马斯克把矛头也指向了 OpenAI 和 Google。他表示创建 OpenAI 的想法最初来自他本人，名字取自「开源人工智能」，初衷是做一个与 Google 相反的东西，因为担心 Google 没有足够重视 AI 安全；而今天的 OpenAI 已经变成闭源、追求利润的组织，「这不应该」。谈到 Google Gemini 的价值排序时他举了一个例子：如果问模型「误认凯特琳·詹娜的性别」和「全球核战争」哪个更糟，AI 会答前者更糟；只要把「误认性别」设定为最坏结果并交给非人类机器去优化，逻辑上它就可能为了把误认概率压到零而消灭所有人类。

据同一篇报道，Google 联合创始人谢尔盖·布林在一封内部备忘录中要求员工每周全勤到办公室，认为 Google 有望在 AGI 领域实现重大突破，备忘录称「竞争已极大加速，通往 AGI 的最后角逐已经开始」，要求员工每天工作 60 小时。这份备忘录经《华尔街日报》于 3 月 2 日曝光。
