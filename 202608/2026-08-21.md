# 2026-08-21 AI 大事件

北京时间 2026 年 8 月 21 日（星期五）。Anthropic 把 Computer Use、Skills API 与 Files API 在 Claude Platform 上全面开放为 GA，并新推出浏览器使用工具；阿里同日发布并开源以真实世界为中心的 GUI 智能体基座模型 Qwen-UI-Agent，称在移动端基准上全面超越 GPT 与 Claude。数据侧，皮尤研究中心发布研究：ChatGPT 发布后上线的网页中超过三分之一已出现 AI 撰写或大量编辑的迹象。开源侧，OpenAI 进一步开放 Codex Harness 的核心能力。

## 1. Claude Platform 全面开放 Computer Use、Skills API 与 Files API

Anthropic 正式宣布，备受瞩目的电脑操作（Computer use）、Skills API 与 Files API 在 Claude Platform 上全面开放，进入正式可用（Generally Available）阶段。这次更新还重磅推出了全新的浏览器使用工具（Browser use tool）。

这三项能力此前是分阶段测试的：电脑操作让模型可以驱动桌面应用，Skills API 让可复用的技能包可以被调用，Files API 则把文件作为一等输入。一起转为 GA，意味着它们从研究性功能变成了可以在生产环境里依赖的接口。Anthropic 同时在做安全侧的配套——8 月 19 日的消息是，Claude Mythos 5 集成至 Claude Security，即将登陆合作伙伴的网络安全防御工具，并推出 3500 万美元的 Defender Advantage Fund（0xDAF），资助开源软件漏洞修复与安全自动化。

## 2. 阿里发布并开源 Qwen-UI-Agent：移动端基准全面超越 GPT 与 Claude

阿里巴巴于 8 月 20 日正式发布以真实世界为中心的 GUI 智能体基座模型 Qwen-UI-Agent，并在 8 月 21 日开源。该模型全面覆盖移动端、电脑端、网页端以及深度搜索（DeepSearch）环境，目标是打破传统模拟测试的局限，让模型真正具备在复杂真实设备上无缝操作的能力。

在移动端基准上，Qwen-UI-Agent 的表现被描述为全面对标并超越业界多款旗舰模型，包括 GPT 与 Claude 系列；具体到 MobileWorld 之类的评测集上，它被明确写成「全面超越行业旗舰的综合性能」。这不是一次模型能力竞赛的胜利，而是评测范式的转变——过去 GUI 智能体主要在模拟器里被考核，现在被放到真实设备上考。

## 3. 皮尤研究：ChatGPT 发布后超三成网页出现 AI 创作痕迹

皮尤研究中心 8 月 20 日发布最新研究称，在 ChatGPT 于 2022 年 11 月发布后上线的网页中，超过三分之一已经出现 AI 撰写或大量编辑的迹象，显示生成式 AI 正在快速改变互联网内容生态。

研究基于 Common Crawl 网络档案库，覆盖近 5 年间约 50 万个英文网页，并利用 Open Pangram 技术检测 AI 创作痕迹。这条结论对内容平台和出版方都直接相关：同一周，Reddit 开始测试把文本帖子转成音视频内容的 AI 视频功能，而独立音乐出版商 Round Hill Music 则把 Anthropic 与 Suno 告上加州联邦法院。

## 4. OpenAI 进一步开源 Codex Harness

OpenAI 进一步开放 Codex Harness 的相关核心能力，将驱动 Codex 不同产品形态的智能体运行框架向开发者开放。Codex Harness 是 Codex 背后的核心 Agent 运行环境，负责连接模型、用户与工具，并管理任务执行、上下文、会话及代码操作等流程；OpenAI 此前已把 Codex CLI 及相关核心代码开源。

中文报道把这件事放在「全球千万开发者 AI 命门一夜易主」的框架里描述。同一天 TechCrunch 也发了一篇《Nvidia just showed that the harness, not the AI model, is now the real hero》，讲的正是同一件事的另一面——在模型能力趋同之后，真正决定 Agent 表现的是运行框架。

## 5. 国内开源与训练数据生意

商汤科技开源 8B 轻量多模态模型，实现原生 4K 输出与全能视觉编辑；同日 DeepSeek-V4-Flash-Vision-Exp 实验性多模态视觉理解模型上线 API，model 名为 deepseek-v4-flash-vision-exp；阿里「阳光清言」藏语大模型正式发布并突破千亿参数。

另一侧的生意是训练数据。顶级 AI 实验室和企业对高质量训练数据的需求持续攀升，推动数据标注初创公司快速增长。成立仅四年的 Micro1，据知情人士透露，过去 8 个月年化营收从 1 亿美元增至 5 亿美元；公司通常保留合同收入的 60% 至 70%，由此计算年净收入约 1.5 亿至 2 亿美元。规模上它仍低于 Mercor 与 Handshake，后两者的年化总收入今年同样在快速上升。
