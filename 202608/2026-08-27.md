# 2026-08-27 AI 大事件

北京时间 2026 年 8 月 27 日（星期四）。研究侧，加州理工用 AI 攻克量子化学 60 年难题，报道的说法是 1 块显卡做完原本 7800 块卡的活。工程侧，Anthropic 发布 AI-Native 软件开发流程，Claude Code 也被记录为能替用户起草「反馈报告」。学术侧，《自然》子刊刊出一项关于语言多样性的观察：当 8 亿人都在用 AI 写作时，语言多样性正在快速消失。商业侧，MiniMax 的 ARR 被记录为暴涨 500%、token 暴涨 2000%。

## 1. 加州理工用 AI 攻克量子化学 60 年难题

加州理工用 AI 攻克了量子化学领域一个 60 年难题。中文报道给出的对比是：1 块显卡做完原本需要 7800 块显卡的活。

这类工作的共同特征是「不再逐步逼近」——传统路线下，量化方法的精度依赖于体系规模与经典算力，几十年的难题往往卡在算力与算法两端；而一旦把问题改写成可被模型直接拟合的形式，规模就不再是唯一约束。同期还有一条相邻成果：单卡可跑 18 万原子的分子模拟方案，被描述为终结了分子模拟的「规模焦虑」。

## 2. Anthropic 发布 AI-Native 软件开发流程

Anthropic 发布 AI-Native 软件开发流程，中文报道的判断很直接：时代变了，该换套模式了。这份流程的提出背景，是 Claude Code 在 Anthropic 内部已经能端到端承担日常维护——8 月 16 日披露的数字是 388 个 PR 全部由 AI 操刀、180 个已被合并。

工具侧同期有新动作：Claude Code 又进化了，能替用户起草「反馈报告」。在 Anthropic 内部的实验频道里，Claude Tag 每天跑一组例行任务，覆盖 iOS、Android、桌面端、Web、CLI 和 Agent SDK 六类环境，到点自己上班、找问题、改代码、提 PR，再根据人工反馈调整任务规则。配套的还有 Cursor 推出的 Origin 代码托管平台，以及阿里新发布的 Qoder——把 AI 编程工具升级为面向所有人的智能体工作台。

## 3. 《自然》子刊：当 8 亿人都在用 AI 写作，语言多样性正在快速消失

《自然》子刊刊出一项观察：当 8 亿人都在用 AI 写作时，语言多样性正在快速消失。这条结论与皮尤研究中心一周前的发现形成呼应——那项研究基于 Common Crawl 档案，覆盖近 5 年约 50 万个英文网页，用 Open Pangram 技术检测 AI 创作痕迹，得出的结论是 ChatGPT 发布后上线的网页中超过三分之一已出现 AI 撰写或大量编辑的迹象。

两项研究指向同一个变化：模型输出正在成为互联网内容的默认语料，而默认语料会反过来塑造下一代模型的输入分布。

## 4. 具身智能：一个登顶开源榜单，一个不用后训练就能学会

原力灵机 DM0.5 登顶 RoboDojo，并且全开源、连权重与训练方式一并放出，报道用的措辞是「且 clone 且珍惜」。中文报道给它的是「具身大满贯」的评价。

另一条更热的报道是硅谷今日最受关注的具身模型：不用后训练，看一遍就学会。同一周，宇树与智元共用一个大脑的 Demo 被展示，10 分钟一镜到底；原力灵机之外的另一家公司把机器人从「上班用」的比赛现场拉回来，拿到双榜第一。数据侧，一家已经把机器人卖到 500 个家庭的公司在半年里拿到 3 轮共 10 亿元融资。

## 5. MiniMax ARR 暴涨 500%，Loopit 转向自建互动世界模型

MiniMax 的 ARR 被记录为暴涨 500%、token 暴涨 2000%，中文报道的标题直接写成「这就是 Agent 红利吧」。这与同月 MiniMax H3 全模态模型开源后被吐槽「价格卷到几分钱」是同一条线索——开源铺量、Agent 用量放大，营收结构随之改变。

另一条来自 Loopit。对话陈炜鹏的解释是，Loopit 有了 1500 万件作品之后，决定做自己的互动世界模型；这家公司此前因视频世界模型被马斯克点赞，又在评测上拿下第一。同期 Cursor 与 DeepSeek Harness 各自在 Agent 框架上继续推进——后者被记录为「真正野心，是 Agent 的自进化」。
