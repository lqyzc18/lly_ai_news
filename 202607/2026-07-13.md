# 2026-07-13 AI 大事件

北京时间 2026 年 7 月 13 日（星期一）。Anthropic 与 OpenAI 在同一个凌晨前后把额度政策一起改了：Anthropic 在 7 月 12 日晚间（美东时间）宣布再次延长付费订阅内含的 Claude Fable 5 使用期，并把 Claude Code 的周额度上限提高 50%；OpenAI 则临时取消 ChatGPT Plus、Business、Pro 套餐的 5 小时用量限制，称 Codex 活跃用户已突破 600 万。国内一侧，阶跃星辰在上海发布自有终端品牌 STEPX、全球首个智能体原生操作系统 Step AOS，以及首款大模型原生智能体手机 STEPX Neo。

> 本期记 3 条：Anthropic 延长 Fable 5 订阅期并上调 Claude Code 周额度、OpenAI 取消 5 小时用量限制并优化 GPT-5.6 Sol、阶跃星辰发布 STEPX 终端品牌与 Step AOS 操作系统。

## 1. Anthropic 延长 Fable 5 使用期，Claude Code 周额度上限提高 50%

北京时间 7 月 13 日凌晨，Anthropic 宣布将付费用户的 Claude Fable 5 订阅期限延长，同时把 Claude Code 的周额度上限提高 50%。Anthropic 官方在社交账号上给出的措辞是延长促销期至当月结束前的太平洋时间深夜，并同步延长 Claude Code 周额度提高 50% 的期限。

适用范围是 Claude Pro、Max 和 Team 套餐，以及席位制 Enterprise 套餐中的 Premium 席位。免费套餐、席位制 Enterprise 的 Standard 席位、按量计费的 Enterprise 套餐都不参与，API 调用也继续按标准价格单独计费。促销期间，用户最多可以把每周套餐使用额度的 50% 用在 Fable 5 上；Fable 5 消耗的是用户原有的周额度，且消耗速度快于其他 Claude 模型，如果此前已经在别的模型上用掉了一部分，可用于 Fable 5 的额度会相应减少。当额度达到周套餐上限的 50% 后，用户可以启用 usage credits 按实际用量继续使用，也可以切换到其他 Claude 模型继续消耗剩余额度。

Fable 5 在促销期内可通过 Claude 网页版、移动端、桌面端、Claude Cowork、Claude Code、Claude Design、Claude for Microsoft 365、Claude for Teams 和 Claude Tag 使用。

这条调整的背景是模型本身的价格结构。Fable 5 促销期结束后将只能通过预付费的 usage credits 继续使用，输入每百万 token 10 美元、输出每百万 token 50 美元，是 Opus 4.8 单价的两倍，也是 Anthropic 为公开发售模型开过的最高价。此前 Fable 5 的订阅内含期限已经多次后移，社区对"规则每次都在线上临时改"颇有意见。

## 2. OpenAI 临时取消 5 小时用量限制，GPT-5.6 Sol 首轮效率优化落地

Claude 的调整没出多久，OpenAI 的 ChatGPT 与 Codex 团队成员 Thibault Sottiaux 就在 X 上公布了三项更新。第一，临时取消 ChatGPT Plus、Business 和 Pro 套餐的 5 小时用量限制。第二，准备对 GPT-5.6 Sol 做全面的效率优化，降低完成相同任务所消耗的额度。第三，由于 Codex 活跃用户突破 600 万，OpenAI 为用户统一提供使用限额重置。

7 月 13 日上午，Sottiaux 称 GPT-5.6 Sol 的首轮推理优化已经完成。OpenAI 把优化节省下来的成本转化为所有订阅套餐的更多使用量，预计可以让用户在同等额度下多用约 10%。这次调整的起因是 OpenAI 查明了部分用户额度消耗过快的原因：GPT-5.6 Sol 的产品上下文上限由 GPT-5.5 的 272k 提高至 372k 之后，系统扣除的用量高于预期；目前上下文上限已被恢复至 272k，额度消耗速度应当明显下降，OpenAI 计划完成进一步优化后再次开放 372k 上下文。

OpenAI 还承认，GPT-5.6 Sol 在 high 和 xhigh 推理档位下调用多 Agent 的频率略高于预期，自动审查功能也存在效率问题，相关修复仍在推进。公司此前一度通过调整模型推理强度来测试额外用量是否与推理设置有关，目前已把相关设置恢复原状。API 价格没有变化：Sol 输入每百万 token 5 美元、输出 30 美元，Terra 为 2.5 美元与 15 美元，Luna 为 1 美元与 6 美元。

两家公司前后脚放宽限制，把竞争焦点直接拉到了用户实际能用到的额度上。在模型能力差距不断收窄的阶段，可用额度、消耗速度和订阅性价比正在成为新的筹码。

## 3. 阶跃星辰：STEPX 终端品牌、Step AOS 与首款智能体原生手机

7 月 13 日，阶跃星辰在上海发布自有终端品牌 STEPX，同步推出智能体原生操作系统 Step AOS（Step Agentic-native OS）与新一代个人智能体阶跃 Amoo，并展出旗下首款大模型原生智能体手机 STEPX Neo，完整打通了从基础模型、智能体系统到硬件终端的链路。

支撑这一体系的是阶跃自研的 Step Edge 端侧模型，专为终端硬件定制，具备低延迟本地推理、全模态本地隐私处理和端云协同调度能力，可依托终端独立完成轻量化智能任务，复杂场景再联动云端旗舰模型。在这套产品体系里，大模型是智能体的"大脑"，Step AOS 是它的运行环境，AI 原生终端则是智能体走进物理世界的载体，三者围绕"为人服务、也对 AI 友好"的原则设计。

Step AOS 是从零重构的底层框架，把硬件和原有系统的能力转化为智能体可直接调用的算力、可理解的数据和可调用的能力，用户只需表达任务意图，全链路由智能体自主完成。系统具备记忆、决策与执行、安全三大核心特征：双域记忆结构经国际权威评测达 SOTA 级别，官方称日常问答的记忆召回最快只需 15 毫秒；端云多脑协同让简单的事快反应、复杂的事深思考。阶跃同时联合上海人工智能实验室发布《新一代智能体系统安全技术白皮书》及《端侧大模型网络安全指南》，首次系统提出"可信、可见、可控、可逆"的智能体安全框架。

STEPX Neo 的意义在于它把系统假设彻底改了。传统操作系统围绕"人操作应用"构建，阶跃则从智能体的运行需求出发，把模型、软件、硬件作为一体化架构从零设计。董事长印奇给出了一组对照：被装进以"人操作应用"为核心的传统系统之后，智能体单步操作的成功率虽可达 95%，但串联 20 步后会跌至三成。在安全侧，STEPX Neo 是首批通过《人工智能终端智能化分级》系列国家标准 L3 级别测试的终端产品，也是目前唯一获得 L3 级证书的智能体手机。

生态上，STEPX 已与携程、支付宝、滴滴、美团、WPS、剪映等平台达成深度合作，覆盖出行订票、日常消费、本地生活、文档办公、视频剪辑等高频场景；同时与 B 站联合发起「STEPX 狂想计划」，把终端形态的 定义权部分交给用户。阶跃表示，将在近期举行的世界人工智能大会期间展示全栈大脑 2.0 落地场景的能力。
