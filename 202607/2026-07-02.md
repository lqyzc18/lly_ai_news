# 2026-07-02 AI 大事件

北京时间 2026 年 7 月 2 日（星期四）。开发者社区在 7 月 1 日晚间发现 Claude Code 的系统提示词里藏着识别中国用户的隐写标记，完整的逆向分析报告随后发布在 GitHub 上，Anthropic 的工程师当天回应说这段代码会在次日发布的版本里回滚。同一天，蚂蚁集团、清华大学和香港科技大学联合孵化的开源强化学习基础设施 AReaL 发布 2.0，把生产环境里 agent 的交互轨迹变成在线训练的养料。资本和算力两条线上，Together AI 宣布 8 亿美元 C 轮、估值 83 亿美元，Meta 则被曝准备把闲置的 AI 算力包装成云服务对外出租。

## 1. Claude Code 被曝在系统提示词里隐写标记中国用户

最先公开质疑的是 Reddit 用户 LegitMichel777。他在 r/ClaudeAI 发帖称，Claude Code 内置了一套未对外公示的区域识别逻辑，只对使用第三方 API 中转的用户激活。安全研究员 Adnane Khan 随后在 GitHub 发布了对 Claude Code v2.1.193 到 v2.1.196 的完整逆向分析，从二进制里提取出对应的 JavaScript 代码。

报告描述的机制分三步。当用户设置了 ANTHROPIC_BASE_URL、把请求转发到非官方代理时，程序读取系统时区，匹配 Asia/Shanghai 或 Asia/Urumqi；同时提取代理域名，与一份硬编码在二进制里的 147 个域名清单比对。这份清单经过 XOR 和 Base64 混淆，解码后包含百度、阿里巴巴、蚂蚁集团、字节跳动、月之暗面、MiniMax、阶跃星辰等中国科技公司与 AI 实验室的域名，以及大量 API 中转站和镜像地址。命中之后，程序不设独立遥测字段，而是改写系统提示词里那行"Today's date is..."：日期分隔符从短横线换成斜杠，"Today's" 的撇号在几种视觉上几乎无法分辨的 Unicode 字符之间切换，用以编码命中的具体状态。研究者把这套做法称为隐蔽信道。首次引入这段代码的是 2026 年 4 月 2 日推送的 2.1.91 版本，之后多次更新的发布说明都没有提到它。

Anthropic 团队成员 Thariq Shihipar 回应称，这是团队今年 3 月上线的一项实验，目的是防止未经授权的转售商滥用账号、并防范模型蒸馏；团队此后已落地更强的缓解措施，相关 PR 已经合并，预计在次日发布的版本中完全回滚。截至事发，Anthropic 官方没有就此事发布正式公开声明。报告作者自己也划了界限：这不是数据泄露，没有额外网络请求或文件访问，问题是信号被藏在看不见的字符差异里，开发者无法审计；而且设置 ANTHROPIC_BASE_URL 的很多场景完全合法，比如走企业网关、混用不同模型或在受限网络下工作，换来的却是被一视同仁地标记。国内已有高校信息中心就此事发布风险预警，建议排查 2.1.91 至 2.1.196 版本的开发终端。

## 2. AReaL 2.0 开源：让 agent 边用边学

AReaL 2.0 在 7 月 2 日发布，技术报告和代码同步在 GitHub 开源。这个项目最初由蚂蚁集团、清华大学和香港科技大学在 2024 年联合发起，2026 年 5 月从蚂蚁的 InclusionAI 孵化器毕业成为独立开源社区，并加入 PyTorch Foundation Ecosystem，华为云团队和 MindLab 已在其中贡献。

它要解决的是 agent 上线之后"越用越旧"的问题。生产环境里的 agent 每天产生大量工具调用成败、失败路径、用户纠正和奖励信号，但这些大多只是日志。2.0 把在线强化学习当成基础设施而不是一个孤立算法，开发者不需要重构现有 agent 框架，只要把发往大模型的请求接到 AReaL 的统一推理入口，就能启动在线 RL 流程。整套东西分三块：Agent Trajectory Data Protocol 记录每一步决策的完整轨迹，包括观察、内部状态、选中的动作、工具输出、奖励信号、模型与工具版本、成本和租户信息；Enterprise Agent Data Proxy 作为生产服务与训练流水线之间的受控网关，负责轨迹采集、脱敏、权限执行、奖励聚合和回放准备，治理发生在数据进入训练之前；Agent Evolution Control Plane 判断一次失误到底该改记忆、该改路由、该改提示词还是该做强化学习，并在上线前做离线回放评估、回归测试、安全验证、灰度发布和版本追踪。

运行时把在线 RL 拆成可独立部署的微服务：Gateway、Router（保持会话亲和）、Data Proxy、Agent Compute Worker（支持 vLLM、SGLang、Megatron、FSDP 后端）和 Controller。框架还给了一个 Claude Code 风格的软件工程参考实现，用 KPop 等技术减少推理引擎与训练引擎之间的差异，并包含防奖励攻击和训练后期稳定性的保护措施。

## 3. Together AI 8 亿美元 C 轮，估值 83 亿美元

《纽约时报》报道，Together AI 在美东时间 7 月 1 日（星期三）宣布 8 亿美元融资，投后估值 83 亿美元，累计融资额达到约 13 亿美元。这轮由沙特阿美投资部门的风投平台 Prosperity7 Ventures 领投，英伟达、Vista Equity Partners、General Catalyst 等参投。公司在 2022 年由 Vipul Ved Prakash 与三位学者创办，首席科学家 Tri Dao 写出的 FlashAttention 至今仍是其产品核心。

公司自己给出的逻辑是市场结构变了：使用最先进闭源模型的企业开始对成本皱眉，同时来自中国的新开源模型在能力上接近美国大实验室的专有技术。Prakash 说，公司的利润率"正在被吞噬"，企业开始抵制"token-maxxing"，转而寻找能继续扩大用量又控制成本的办法；Together 租售开源模型算力的业务因此增长。第三方统计称其 2026 年二季度年化订单额已超过 11.5 亿美元。这轮还附带非股权部分：新投资者承诺提供 500 兆瓦以上的算力容量并自行出资，芯片不进公司资产负债表。

## 4. Meta Compute：Meta 准备出租闲置算力

彭博社在 7 月 1 日报道，Meta 正在筹建一个名为 Meta Compute 的云服务，把内部闲置的 AI 算力对外出租。Meta 对此没有确认，但报道给出了结构：一条线是按 CoreWeave 的模式卖原始 GPU 算力，另一条线是直接托管自家闭源模型 Muse Spark，类似亚马逊 Bedrock 的托管模式。

主导这项工作的是三位高管：基础设施负责人 Santosh Janardhan、Meta 超级智能实验室的 Daniel Gross，以及总裁 Dina Powell McCormick。报道给出的背景是 Meta 已建成按峰值容量配置的算力池，非高峰时段部分机柜闲置；同时 Meta 内部自 5 月起就在给工程师的 token 消耗设预算，把内部用量管住。两件事是同一个逻辑的两面。规模上，Meta 到 2026 年底累计的 AI 基础设施投入被计到 1829 亿美元，其中俄亥俄州和路易斯安那州的自建数据中心是主体。这条路此前已由 SpaceX 通过 xAI 走过一次：2026 年 5 月，Colossus 1 数据中心对外开放，签下 Anthropic、Google 和 Reflection AI。Meta 这次晚了大约几周。

市场反应直接。消息传出后 Meta 股价单日涨逾 10%，基本抹平年内近 15% 的跌幅；而高度依赖 Meta 订单的 CoreWeave 和 Nebius 双双下跌约 11% 到 12%。Nebius 与 Meta 的合同规模被报为 270 亿美元，CoreWeave 的是 210 亿美元。Meta Compute 目前仍在开发中，商用时间表未公布。
