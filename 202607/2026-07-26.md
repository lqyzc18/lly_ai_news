# 2026-07-26 AI 大事件

北京时间 2026 年 7 月 26 日（星期日）。开源自研基座与"上手"框架在同一天密集落地。前一天 7 月 25 日，Anthropic 发布 Claude Opus 5、微软公开预览 MAI-Image-2.5-Pro 与 MAI-Voice-2-Flash，模型与工具链的竞争在同一周连成一条线；腾讯 Robotics X 实验室在 WAIC 2026 期间开源三款具身基座模型，首席科学家张正友详解"三层脑"架构，把机器人的响应压到 2 至 3 秒；阿里千问 AI 平台发布，一个 API Key 即可调用 Qwen、Kimi、DeepSeek 等百余系列模型；上海新智具身联合复旦大学可信具身智能研究院发布 Neo 系列三份技术报告，用 3 万小时触觉数据补齐机器人的"手感"。

> 本期记 3 条：腾讯开源三大具身基座模型、阿里千问 AI 平台发布、新智具身与复旦发布 Neo 系列触觉三报告。

## 1. 腾讯开源三款具身基座模型：以"三层脑"把机器人反应压到 2 至 3 秒

7 月 26 日，在 WAIC 2026 期间，腾讯 Robotics X 实验室正式开源三款具身基座模型：Hy-Embodied-VLM、RxBrain 与 VLA。首席科学家张正友在同场介绍了"三层脑"架构，这是这次发布的核心思路：让认知、感知与执行以不同频率运行，从而破解机器人反应慢这一老大难问题，把整体响应压到 2 至 3 秒。

这次发布同时回顾了腾讯具身智能平台 Tairos 一年的进展。按腾讯方面的说法，中国厂商在 WAIC 2026 期间密集开源基础模型与 Agent 工具链，腾讯的开源动作属于这一波动作的一部分——从 Kimi K3 的 2.8 万亿参数，到腾讯的三款具身基座模型，再到腾讯云 CodeBuddy NPC 与千问 AI 平台，开源加工具链正在重构开发者生态。

## 2. 阿里千问 AI 平台发布：百余系列模型一个 API Key 调用

7 月 26 日，阿里千问 AI 平台发布。该平台聚合了 Qwen、Kimi、DeepSeek 等百余系列模型，开发者用一个 API Key 即可调用，同时开源了 qianwen-ai 等 Skill，使 Agent 能够自主选择模型、发起调用并完成部署。

这一发布的定位可以放在当天中国厂商的密集开源动作里看：腾讯 Robotics X 实验室开源三款具身基座模型、腾讯云 CodeBuddy NPC 在此前已发布，字节、蚂蚁等厂商也有各自的动作。

## 3. 新智具身与复旦：3 万小时触觉数据，统一具身智能的触觉"方言"

7 月 26 日，上海新智具身智能科技有限公司（NeoteAI）联合复旦大学可信具身智能研究院发布 Neo 系列三份技术报告，把触觉从"辅助模态"推为"核心基建"。

Neo-Foundation 解决的是数据底座问题。不同传感器输出的凝胶形变图、电容矩阵或六维力向量互不兼容，就像缺乏统一语法的方言。其 NeoData 数据集包含超 3 万小时视觉-触觉交互视频、约 140 万条操作片段与 33 亿个时间步，对应 80 亿帧 RGB 画面和 100 亿帧触觉图像，动用 Franka、Piper、UR5e 等 6 种机器人本体，覆盖 450 项真实长程任务，由 90 位操作员采集，已开源其中 5 千小时。配套的 NeoForce 统一表征模型则让模型无论底层硬件如何都能学到可迁移的"触觉普通话"。

Neo-VTLA 走的是"触觉预判"路线：不依赖滞后的当前触觉，而是预测未来 50 步内的触觉演变，用紧凑潜在 Token 结合视觉上下文预判滑移与受力趋势。官方实测称，插插头任务成功率达 85%（同类视觉方案仅 60%），拔钥匙任务达 99%（视觉方案 35%）。它还突破了模仿学习只依赖专家成功轨迹的限制，机器人可从失败数据中自主进化，毛巾折叠、书包收纳、纸箱折叠三项长程任务的成功率分别从 50%、35%、20% 升至 95%、80%、75%。

Neo-TWAM 则把触觉放进世界模型，采用视频、触觉、动作三个异步专家网络的混合专家架构，总参数量 72 亿，约为全宽方案的一半。官方称其仿真平均成功率达 84.5%（世界模型最强基线为 36%），真机 8 项任务平均成功率 46.3%（LingBot-VA 为 21.9%）。项目数据与模型已开源。
