# 2023-03-14 AI 大事件

北京时间 2023 年 3 月 14 日（星期二）。Anthropic 发布新一代 AI 助手 Claude，同步给出高性能版 Claude 与更轻量、更便宜、更快的 Claude Instant；同一天 OpenAI 发布多模态大模型 GPT-4，可接收图像与文本输入、输出文本。两家都把「更少产生有害输出」「更可引导」和「专业考试中胜过绝大多数人类」当作卖点。

## 1. Anthropic 发布 Claude 与 Claude Instant

Anthropic 的公告写：在与 Notion、Quora、DuckDuckGo 等关键伙伴以封闭 alpha 形式合作了几个月之后，团队已经在真实使用场景中谨慎测试过系统，「准备更广泛地提供 Claude，让它能在关键、前沿的用例中规模化发挥作用」。

Claude 是基于 Anthropic 在「有帮助、诚实、无害」系统上研究成果的下一代 AI 助手，通过对话界面和开发者控制台里的 API 提供，能做摘要、搜索、创作与协作写作、问答、编码等各类对话与文本处理任务，同时保持较高的可靠性与可预测性。公告强调的差异点有三条：早期客户反馈 Claude 「产生有害输出的可能性小得多」、更容易对话、也更可引导，用户可以用更少的力气拿到想要的结果；它还可以按用户指定的人格、语气与行为来调整。

当天提供两个版本：Claude 是当前技术最先进的高性能模型，Claude Instant 是更轻量、更便宜、也快得多的选项。公告说未来几周还会有更多更新。Quora 方面，Claude 通过 Poe 平台提供给用户，Quora 负责社区与传播的负责人 Autumn Besselman 说，用户评价 Claude 的回答「详细且容易理解，交流感觉像自然对话」。

Anthropic 官网这篇公告的时间戳是协调世界时 3 月 14 日 7 时 00 分，北京时间是当天 15 时。

## 2. OpenAI 发布 GPT-4

OpenAI 的技术报告把 GPT-4 定义为「一个大规模多模态模型，可以接收图像与文本输入并生成文本输出」。摘要里的关键句是：虽然 GPT-4 在许多现实场景中仍不如人类，但它在多种专业与学术基准上表现出接近人类水平的表现，包括「通过模拟律师资格考试，成绩约在应试者的前 10%」。报告写明，GPT-4 是一个基于 Transformer 的模型，预先训练目标是预测文档中的下一个 token；后训练的对齐过程让它在事实性与遵循预期行为两项指标上都有改善。

报告还交代了工程上的一件特殊事：项目的一个核心组件是开发出在各种规模下行为可预测的基础设施与优化方法，「这使我们能够用训练算力不超过 GPT-4 百万分之一的模型，准确预测 GPT-4 表现的某些方面」。技术报告本身没有公布参数量、训练算力与训练数据规模。

据中文媒体对官方材料的转述，GPT-4 参加的统一律师资格考试、法学院入学考试 LSAT、SAT 数学与阅读等多项专业考试中，得分高于 88% 的应试者；模拟律师资格考试成绩约在前 10%，SAT 阅读约前 7%，SAT 数学约前 11%。OpenAI 称 GPT-4 在内部对抗性事实性评估中，产生正确回应的可能性比最新版 GPT-3.5 高 40%。OpenAI 同时提醒，GPT-4「不了解训练数据截止日（2021 年 9 月）之后发生的事」，有时会犯简单的推理错误，会轻信用户明显的虚假陈述，有时会像人一样在难题上失败，例如在生成的代码里引入安全漏洞。

使用方式上，GPT-4 先向 ChatGPT Plus 订阅用户开放，开发者可申请 API 权限。OpenAI 提到的合作方包括 Duolingo、Stripe、Khan Academy、摩根士丹利和冰岛政府；微软表示新款必应将运行在 GPT-4 之上。当晚大量新订阅用户涌入，OpenAI 的付款系统一度被挤爆。
