# 2023-03-01 AI 大事件

北京时间 2023 年 3 月 1 日（星期三）。OpenAI 正式推出面向商业用户的 ChatGPT API 与 Whisper 语音转文字 API：基于 GPT-3.5 的 gpt-3.5-turbo 定价每千 token 0.002 美元，OpenAI 称自 2022 年 12 月以来已把 ChatGPT 的运行成本压低 90%。中文媒体在 3 月 2 日转发时称其为「商业版 ChatGPT」，并把发布时间记为美方 3 月 1 日。

## 1. ChatGPT API：0.002 美元每千 token

继 2022 年 11 月向公众推出 ChatGPT 之后，OpenAI 开始向有意在自己产品里提供同类 AIGC 服务的企业提供付费接入。这次提供的 API 基于与 ChatGPT 同款的 GPT-3.5 模型，模型名 gpt-3.5-turbo，定价为每 1000 个 token 0.002 美元。OpenAI 的解释是，token 可以理解为一个一个非结构化的单词，1000 个 token 大约对应 750 个词；这个价格比当时的 GPT-3.5 模型便宜 90%。公司给出的成本口径是：自 2022 年 12 月以来，通过系统级优化已经把 ChatGPT 的运行成本降低了 90%。

首批接入方已经上线。图片与短视频社交平台 Snap 推出名为「My AI」的可定制聊天机器人，供付费订阅用户使用；拥有 6000 万学生用户的 Quizlet 提供了能出题考验学生的家教机器人；面向跨境电商的 Shopify 平台上线了聊天机器人导购；Instacart 与 Speak 也在首批名单里。API 还提供企业专属实例（dedicated instances）选项。

## 2. Whisper API：每分钟 0.006 美元

OpenAI 最早在 2022 年 9 月推出 Whisper 语音转文字模型，这次正式给出可供商业伙伴付费接入的 API 接口，定价每分钟 0.006 美元。Whisper API 支持对语音文件做转录与翻译，支持包括英语、中文、阿拉伯语、日语、德语、西班牙语在内的几十种语言。

官方产品说明文档给出的测试数据是：在业界常用的 FLEURS 数据集上，Whisper large-v2 在识别英语、意大利语、德语时的单词错误率能控制在 5% 以下，但识别中文的错误率达到 14.7%，可能的原因是训练数据中中文语料不足。OpenAI 同时提醒，由于模型会对语音做「下一个词」的主动预测，生成的文本中可能包含说话者实际上没有说过的词。
