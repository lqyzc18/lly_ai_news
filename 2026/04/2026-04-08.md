# 2026-04-08 AI 大事件

北京时间 2026 年 4 月 8 日（星期三）。国产模型在调用量榜单上再次刷新纪录：阿里 Qwen3.6-Plus 上线后登顶 OpenRouter 全球大模型调用榜，单日调用量首次突破 1 万亿 Token。安全一侧，Claude Code 源码泄露事件的后续发酵出首个高危漏洞，漏洞成因直指「为省 Token 而牺牲安全」；苹果、亚马逊、OpenAI 则因涉嫌非法爬取 YouTube 数据被创作者集体起诉。算力账本同一天被翻开两页：Meta 计划借款 30 亿美元建设 AI 数据中心，奥特曼首度解释 Sora 停用的真正原因——算力缺口大到无法想象。

> 本期记 4 条：阿里 Qwen3.6-Plus 登顶 OpenRouter、Claude Code 源码泄露后被挖出首个高危漏洞、苹果/亚马逊/OpenAI 因 YouTube 数据被起诉、Meta 借款 30 亿美元建数据中心与 Sora 停用内幕。

## 1. 阿里 Qwen3.6-Plus 登顶 OpenRouter：单日首破 1 万亿 Token

阿里通义实验室 4 月 2 日发布的 Qwen3.6-Plus，在上线次日即登顶 OpenRouter 全球大模型调用榜，单日调用量首次突破 1 万亿 Token。此前该模型在发布当晚已登上 OpenRouter 日榜榜首，本次是把这个位置延续到了全球总量维度。

这个数字需要和它的定价放在一起看。Qwen3.6-Plus 默认支持 100 万 token 上下文窗口，通过阿里云百炼调用，每百万 tokens 输入最低 2 元，API 兼容 OpenAI 与 Anthropic 协议，可直接接入 Claude Code、Qwen Code、OpenClaw 等工具。调用量能冲上榜首，一半来自价格，一半来自「不用改代码就能换过去」的兼容性。

同一周的另一条消息来自 MiniMax：公司确认 MiniMax 2.7 本周开源，官方口径是 Token 成本将进一步下探。开源模型与低价 API 互相抬价的循环，正在把调用量榜单变成国产厂商的主战场。

需要说明的是，OpenRouter 的调用量是平台自身口径的统计，不等于模型在全行业范围内的实际使用量。

## 2. Claude Code 源码泄露后被挖出首个高危漏洞

Claude Code 源码泄露事件的后续有了新进展。3 月 31 日打包进 npm 的那份未混淆 TypeScript 源码，在社区流传之后被安全研究者从中挖出首个高危漏洞。漏洞的成因被概括为「为省 Token 牺牲安全」——在实现层面为了减少 token 消耗而引入的逻辑，反而带来了可被利用的缺陷。

这条链路的完整脉络是：3 月 31 日 Anthropic 把含约 51.2 万行源码的 source map 打进 claude-code v2.1.88；随后公司依据 DMCA 要求 GitHub 下架超过 8100 个仓库，误伤了大量无关项目；4 月 1 日公司承认误操作并撤回大部分请求。源码本身已被大规模 fork 与重写，社区在几小时内就产出了十几个变体实现。

这个案例的教训被反复强调：一次打包配置的疏忽，会在几天内演变成版权、平台治理、供应链安全三个方向的问题。原仓库上的一个漏洞，足以让所有基于泄露代码的二次实现同时暴露。

## 3. 苹果、亚马逊、OpenAI 因 YouTube 数据被集体起诉

苹果、亚马逊与 OpenAI 遭创作者集体诉讼，指控三家公司涉嫌非法爬取 YouTube 内容用于模型训练。这条诉讼在 4 月上旬成为内容与版权领域最受关注的案件之一，此前 OpenAI 在 3 月底关停 Sora 视频应用、谷歌在 4 月 1 日推出 Veo 3.1 Lite，两条视频模型的动作与这条诉讼构成了同一个议题的两面。

版权边界上的另一条同期进展来自音乐领域：环球、索尼等顶级唱片公司与 AI 音乐平台 Suno 的版权谈判陷入僵局，诉讼一触即发。唱片公司与生成式 AI 平台的谈判破裂，比创作者诉讼更能说明问题——前者是既有版权方与新分发渠道的议价，后者往往涉及训练数据的合法性。

两条线索合起来指向一个结论：在生成式内容全面进入生产的阶段，训练数据的来源授权正从「行业惯例」变成「必须逐案确认的合同义务」。

## 4. Meta 借款 30 亿美元建数据中心，奥特曼首谈 Sora 停用

Meta 计划借款 30 亿美元建设 AI 数据中心，以支撑未来的算力需求。同一天，奥特曼首次解释 Sora 停用的内幕，给出的原因是算力缺口「大到无法想象」。此前 3 月 31 日 OpenAI 已结束 Sora 视频生成业务，并关停在 ChatGPT 内试运营的购物功能；Greg Brockman 在 3 月底确认公司资源正全面倾斜到整合多模态能力的「超级应用」，新预训练代号「Spud」随即曝光。

把两件事放在一起，OpenAI 的取舍就很清楚：视频生成是一条吃算力、但在公司整体产品矩阵里权重有限的业务线，而通用多模态助手是它要押注的下一个主战场。Meta 借债建数据中心则是另一种姿态——它选择用资产负债表为算力买单。

同期算力与基础设施侧还有几条值得留痕：谷歌被曝拟建 933 兆瓦天然气电厂以支撑庞大的 AI 数据中心运转；英伟达开源 CaP-X 框架，让机器人可以「现写代码控制自己」并自动沉淀技能库；星海图完成 20 亿元 B+ 轮融资，估值突破 200 亿元，刷新具身智能单笔融资纪录；清华 AIR 联合水木分子开源 OpenBioMed Skills，把药研实验、计算与文献推理封装成可调用技能。
