# 2026-04-06 AI 大事件

北京时间 2026 年 4 月 6 日（星期一）。Anthropic 罕见地承认 Claude Code 用户的用量额度消耗速度远超设计预期，自动化工作流被打断，公司把「配额消耗」列为工程团队的优先事项。《纽约客》的一篇调查则把矛头指向 OpenAI 内部：报道基于 Ilya Sutskever 与 Dario Amodei 的内部备忘录，称公司在转为营利实体后系统性地削减了安全承诺，原本承诺把 20% 算力给超级对齐团队的承诺，实际只拿到 1%–2%。用户隐私一侧，Perplexity 被指即使在「隐身模式」下仍把对话内容与邮箱地址共享给 Google 和 Meta 的广告平台。另有一项覆盖 515 家高增长初创企业的实地实验，给出了 AI 使用与营收之间最直接的一组数字。

> 本期记 4 条：Claude Code 配额消耗远超预期、《纽约客》调查 OpenAI 的安全承诺、Perplexity 被指泄露对话数据、515 家初创企业的 AI 实地实验。

## 1. Anthropic：Claude Code 的配额消耗「远超预期」

Anthropic 公开承认，Claude Code 用户触达用量额度的速度远快于公司原先的预期，多个自动化工作流因此中断。公司的表述是：配额消耗已经成为工程团队的首要优先事项，Pro 与 Max 订阅用户尤其明显，在业务高峰期会话额度被消耗的速度比过去快得多。

这条承认的时间点值得留意。就在几天前，Anthropic 刚刚因为第三方 Agent 框架消耗算力不成比例而切断了它们对订阅额度的调用权（4 月 4 日生效）。两件事指向同一个张力：Claude Code 的实际使用强度，已经明显超出按普通对话产品设计的订阅经济模型的承受范围。Anthropic 此后对订阅用户的速率限制做过上调。

本篇未定位到 Anthropic 官方就此发布的完整说明页面，具体的额度数值与调整幅度，本文只记「已承认并列为优先事项」这一事实，不代为估算。

## 2. 《纽约客》：OpenAI 如何在营利化中稀释安全承诺

《纽约客》刊出一篇基于内部备忘录与采访的调查报道。核心指控是：OpenAI 在转向营利实体、并与微软重签合作条款的过程中，系统性地拆解了此前对外承诺的安全机制。最具体的一条数字来自超级对齐（superalignment）团队——公司曾承诺把约 20% 的总算力拨给该团队，实际到位比例只有 1% 到 2%。

报道把这段历史与 3 月底的人事与融资节点连在一起看：OpenAI 在 3 月 31 日完成 1220 亿美元融资、投后估值 8520 亿美元，随后 COO 与 AGI 部门 CEO 相继离任。这篇调查的基调与 Anthropic 一侧形成对照——同一家公司对外同时扮演着安全承诺者与安全批评对象。

需要说明的是，报道内容属媒体基于内部文件的调查性质，其中对具体人员动机的归因带有记者判断，不等于公司方面的确认。

## 3. Perplexity 被指在「隐身模式」下仍共享对话数据

一项集体诉讼指控 AI 搜索引擎 Perplexity 在其产品中嵌入 Google 与 Meta 的追踪器，即使用户开启「隐身模式」也无法避免，付费用户的对话内容与邮箱地址等个人信息仍被共享。指控援引的法规框架下，每次违规的潜在罚款金额为 5000 美元。

这条指控在当周的舆论场里被归入同一个更大的类别：AI 助手被当成广告投放的高价值渠道，而用户对「我用的是 AI 不是搜索引擎」这件事的预期，与产品实际的数据流之间存在落差。与之对照的是同一天另一条相反方向的消息——Google 发布了纯离线的 iOS 听写应用 Google AI Edge Eloquent，模型下载后可完全在设备端处理，数据不出机器。两条消息放在一起，恰好划出了这一周 AI 产品隐私立场的两端。

## 4. 515 家初创企业的实地实验：AI 用例多 44%，收入高 1.9 倍

一项由 Hyunjin Kim 完成、被 Ethan Mollick 转发推广的实地研究覆盖了 515 家高增长初创企业，方法是把 AI 生产案例展示给其中一部分公司，再与对照组比较。结果是：看到案例的公司自报 AI 用例数量多出 44%，完成任务数多出 12%，营收高 1.9 倍，对外融资需求少了约 39.5%。

研究本身把最大的摩擦点归到一个具体问题上——「映射问题」，即企业难以判断 AI 究竟能在自己业务的哪一环产生价值。这是比「用不用 AI」更前置的一个问题，也是很多企业停留在试点阶段的原因。

同一周，高盛发布报告，认为 AI 驱动的需求正在支撑半导体投资的强劲势头，2026 年收入增速仍将保持高位；报告同时引用「AI 带来平均 23% 生产率提升」的研究，并指出公司层面的实际效率增益更高，约为 33%。这类数字来自高盛引用的研究口径，不是高盛自己的测算。
