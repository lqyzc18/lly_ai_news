# 2026-07-31 AI 大事件

北京时间 2026 年 7 月 31 日（星期五）。国产模型这边连出两条：DeepSeek 在官方更新日志里挂出 V4-Flash 正式版 API 公测，Agent 能力重做后训练、官方给出的 Terminal Bench 2.1 得分 82.7，并原生支持 Responses API；华为则把 5050 亿参数的 openPangu-2.0-Pro 权重、基础推理代码与技术报告一次性开源，这是国内第一个在昇腾 NPU 上原生训练的大规模 MoE 模型。资本与算力侧的两条更大：一家数据中心开发商正就 150 亿美元融资进入最终磋商，为 Anthropic 在得州哈伯德建 1.6 吉瓦配套自备电厂的算力园区，谷歌为 Anthropic 的租金与电费义务提供担保、换取项目约 20% 的股权；国家发改委在新闻发布会上披露，机构测算"十五五"时期算力网建设将新增直接投资 4 万亿元。

## 1. DeepSeek V4-Flash 正式版 API 上线公测

7 月 31 日，DeepSeek 在官方 API 文档的更新日志里挂出 DeepSeek-V4-Flash 更新条目：V4-Flash 正式版 API 上线公测，调用方式不变，模型名设置为 `deepseek-v4-flash` 即可使用最新版本。

官方给出的基准成绩是这一版的核心：Terminal Bench 2.1 为 82.7，NL2Repo 54.2，Cybergym 76.7，DeepSWE 54.4，Toolathlon verified 70.3，Agents' Last Exam 25.2，Automation Bench（公开集）25.1，DSBench-FullStack 68.7，DSBench-Hard 59.6。文档注明，对公开基准集中的 Code Agent 任务，正式版使用 DeepSeek Harness 极简模式（即将发布）作为测试框架，并使用 max 档位，topp 设为 0.95、temperature 设为 1.0；DSBench-FullStack 与 DSBench-Hard 是内部使用的全栈开发与 Coding Agent 难题测试集。正式版原生支持 OpenAI Responses API 格式并针对 Codex 做了适配。

架构上没有改动。文档写明 DeepSeek-V4-Flash-0731 的模型结构、尺寸与 DeepSeek-V4-Flash-Preview 保持一致，仅重新进行了后训练，重点放在增强智能体能力上；本次只升级了 V4-Flash 的 API 接口，V4-Pro 与 APP/WEB 端模型未做更改，V4-Pro 正式版将会尽快发布。价格维持在低位，缓存命中输入 0.2 元每百万 token、未命中输入 1 元、输出 2 元。

## 2. 华为开源 openPangu-2.0-Pro：5050 亿参数，昇腾原生训练

7 月 31 日，华为宣布 openPangu-2.0-Pro 的模型权重、基础推理代码与技术报告正式开源上线。该模型在 6 月 12 日的 HDC 2026 上由余承东预告，是华为开源盘古 2.0 系列的旗舰版本，此前的 Flash 版（92B）已于 6 月 30 日开源。

华为云官方文档给出的参数是：基于昇腾 NPU 训练的大规模混合专家（MoE）语言模型，参数规模约 505B，每 token 激活参数约 18B，支持 512K 上下文长度，训练数据总量约 34T tokens；后训练阶段完成快慢合一微调（SFT）、多专项强化学习（RL），并通过在线蒸馏（OPD）完成能力合一。架构上采用 DSA+SWA 独立分层混合注意力（层级配比 1:2）、4 支流 mHC 残差结构、3 头 MTP 自投机模块，训练采用 Muon 优化器。

推理侧的官方数字是：在 128K 上下文长度下，该模型版本的最低 TPOT 时延为 9.55 毫秒，在 TPOT 为 20 毫秒的条件下单卡吞吐可达 1326 token/s；昇腾原生训练效率可提升 30%。华为称该模型针对昇腾算力与鸿蒙生态做了深度优化，设计目标之一是辅助 Agent 执行系统级任务。按华为公布的开源路线图，openPangu 2.0 的预训练代码、后训练代码与训练算子等 7 大组件自 6 月 30 日起陆续释放。

## 3. Anthropic 得州算力园区 150 亿美元融资进入最终磋商，谷歌担保换 20% 股权

据知情人士披露，数据中心开发商 Nexus Data Centers 正就 150 亿美元融资进入最终磋商，由摩根士丹利牵头的银行财团提供贷款，用于在得克萨斯州哈伯德市为 Anthropic 建设大型算力园区及自备发电厂。融资结构由 140 亿美元过渡贷款与一笔循环信贷额度构成，园区配套一座装机可达 1.6 吉瓦的天然气自备电厂。

其中的关键结构是谷歌的担保：谷歌为 Anthropic 数十亿美元的机房租金与电费支付义务提供担保，一旦 Anthropic 违约由谷歌代为履约，担保范围覆盖 Anthropic 已签署的四份数据中心租赁协议及对应的购电协议，电力由园区配套的表后自备电厂供给；担保额度被限定在满足银行完成这笔融资所需的最低保障金额。作为提供担保的对价，谷歌预计将获得该数据中心与电厂项目约 20% 的股权。

硬件侧，Anthropic 计划在该园区大规模部署谷歌与博通联合开发的 TPU，这批芯片由 Anthropic 与博通另行签署的卖方信贷协议单独融资。报道还称，Anthropic 已与美国多家数据中心开发商签署十余份预租赁协议，目标在未来数年锁定至少 10 吉瓦算力容量。这套模式由今年入职的前 Stack Infrastructure 高管 Tim Hughes 负责。背景上，Alphabet 上周披露，截至 6 月 30 日其信用衍生品兜底协议对应的最大潜在风险敞口已升至 438 亿美元；此前谷歌也曾为最终承租方为 Anthropic 的 TeraWulf、Hut8 等数据中心提供过财务兜底。

## 4. 巨头财报季：亚马逊资本支出上调至 2200 亿美元，Meta 提高 AI 资本支出下限

亚马逊披露将 2026 年技术与 AI 相关资本支出计划上调至约 2200 亿美元，较此前指引大幅增加，AWS 二季度收入同比增长 37%；CEO 安迪·贾西表示 AI 基础设施需求持续强劲。此前 Meta、Alphabet 也已上调全年资本开支指引，美股四巨头全年资本支出上限合计有望逼近 7500 亿美元。

Meta 同日把 2026 年 AI 资本支出下限提高至 1300 亿美元，第二季度营收突破 600 亿美元。微软的财报则给出两个标志性数字：Azure 全年营收首次突破 1000 亿美元，Azure 及其他云服务同比增长 43%，Microsoft 365 Copilot 付费用户突破 3000 万。

## 5. 发改委：十五五算力网将新增直接投资 4 万亿元

国家发改委在 7 月新闻发布会上披露了上半年进展：我国 AI 自主创新步伐加快，首个全国产 10 万卡 AI 超集群正式投用，全国智能算力规模达到去年同期的 2.8 倍，国产大模型全球下载量突破 100 亿次，建成高质量数据集超 12 万个。机构测算"十五五"时期算力网建设将新增直接投资 4 万亿元。

发改委表示，下一步将加快人工智能法立法进程，深入实施"东数西算"工程，统筹布局算力设施。
