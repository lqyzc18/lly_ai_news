# 2026-05-05 AI 大事件

北京时间 2026 年 5 月 5 日（星期二）。OpenAI 总裁 Greg Brockman 当天出庭作证，说马斯克 2017 年就要求取得 OpenAI 完全控制权，部分理由是筹 800 亿美元去火星。xAI 把 Grok 4.3 推上 API，Artificial Analysis 的智能指数 53 分、GDPval-AA 1500 Elo，价格比上一代低三到五成。港理工与四川大学的 SignThought 被 ACL 2026 主会接收为口头报告，第一次在手语翻译里插进一条可追踪的"隐式思维链"。浙大与上海 AI Lab 发布 SciGraph-SCP Server，把 68 个学科知识图谱封装成科学智能体可以直接调用的服务。另外，5 月 1 日到 2 日宣布的 ChatGPT 与 OpenClaw 打通、Codex 上线"电子宠物"，到这几天仍在中文开发者社区发酵。

## 1. Brockman 出庭：马斯克 2017 年要过 OpenAI 的完全控制权

当地时间 5 月 5 日，OpenAI 总裁 Greg Brockman 在加州庭审的第二天出庭作证。据《齐鲁晚报》转述的庭审内容，他说，与现在的态度不同，马斯克当年其实支持把 OpenAI 改造成营利性公司，并且要求取得公司的完全控制权，部分原因是需要筹措 800 亿美元资金用于他的火星殖民计划。

Brockman 回忆的是 2017 年 8 月的一次会面。他称当时唯一的掌舵人候选只有 Altman 一人；马斯克明确表态，若架构改制落地，他希望出任 OpenAI 的领导者，"归根结底，他要掌握公司全部控制权"，并称何时放弃全权掌控由他个人决定。他描述那次会面起初气氛融洽，但在谈到一套马斯克并不认可的潜在股权架构方案时，马斯克当场翻脸称"我拒绝接受"，最终愤然离场，并扬言在问题妥善解决前停止向公司追加投资。马斯克本人已于 2018 年 2 月退出 OpenAI 董事会。

同一天 Brockman 承认，他个人持有的 OpenAI 股权价值近 300 亿美元，另持有两家 Altman 投资的初创企业股份以及 Altman 家族基金 1% 的权益，但他本人从未向公司投入任何个人资金；马斯克向 OpenAI 捐过 3800 万美元。法庭上另一方的律师则举证暗示 Brockman 本人对 OpenAI 的商业利益抱有觊觎。2019 年 3 月，OpenAI 完成架构重组，在非营利主体下设立营利性业务实体，此后的融资累计超过 1000 亿美元。这些均为庭审当天的口头证词，尚未形成书面结论。

## 2. ChatGPT 与 OpenClaw 打通，Codex 上线"宠物"和自主迭代

5 月 1 日到 2 日之间，OpenAI 方面先后在社交平台确认两件事：ChatGPT 账号可以直接登录 OpenClaw，OpenClaw 可直接使用 ChatGPT 的订阅额度，不需要另配 API 密钥；以及 Codex 桌面端新增一批功能。中文社区在 5 月 2 日到 4 日之间集中转述了这批消息。

最被讨论的是"宠物"。按 OpenAI Developers 文档，在 Codex 编辑器里输入 /pet 即可唤醒一只像素风虚拟宠物，也可以从 Settings > Appearance > Pets 面板里选内置的八只之一，或用 Cmd+K 呼出命令菜单执行 Wake Pet、Tuck Away Pet。宠物悬浮在 macOS 桌面上，会显示当前工作状态——正在运行、等待输入还是等你 review——并带一条进度提示，功能上等同于一个长了眼睛的状态栏。想自定义的话，需要安装 hatch-pet skill，再执行 Force Reload Skills，然后输入一句自然语言指令，Codex 就会照着最近的工程内容生成一只。OpenAI 研究员 Dominik Kundel 做过一个演示，把自己的狗变成了一只能放在桌面的电子宠物狗。

功能上更实的是两个新命令。/goal 加上一个目标描述，Codex 会自动拆解任务、规划步骤、自主迭代直到目标达成，期间可以暂停、恢复或清除目标；Ralph loop++ 强化循环逻辑，用于自愈和连续改进。同期还有浏览器提速 30%、浏览器中的设备工具栏支持响应式测试与多设备模拟，以及一键迁移——在"设置-通用-导入 Agent 配置"里把其他平台上的插件、Agent 和项目配置导入 Codex。这些都与 OpenAI 总裁此前"Codex 正从代码助手变成全能 App"的说法对得上。

在对面，Anthropic 对 OpenClaw 的围堵也在升级。据开发者 Theo 的实测，在一个空仓库里，只要 git commit message 含"OpenClaw"字符串，对 Claude Code 说一句"hi"就会立刻断连、额度清零——仓库是空的，prompt 只有一个 hi，模型读到 git 历史里那个词就自己踢了。Anthropic 自 4 月改价封号起就在做这件事。OpenAI 方面对此事的公开表态集中在产品侧，Altman 另表示 Codex 与 Claude Code 之间的"投票比较"没有意义，建议用最适合自己的工具。同期的另一条官方说法是，GPT-5.5 上线一周，OpenAI 称其为"迄今为止最强大的模型发布"。

## 3. Grok 4.3 走向 API，53 分智能指数与 37% 的降价

Grok 4.3 的上线是分阶段做的：4 月 17 日以 Beta 形式在 Grok 里上线，仅对 SuperGrok Heavy 付费会员开放；4 月 19 日向 Heavy 订阅用户推送 Early Access 测试版；5 月初 xAI 对外官宣并开放 API，中文报道在 5 月 1 日、2 日、5 日三个日期上都有记载，API 正式上线的官方口径以 xAI 自己的公告为准。

跑分在 5 月 2 日到 4 日间随中文解读一起流出：Artificial Analysis 的 Intelligence Index 给 53 分，GDPval-AA 拿到 1500 Elo，比 Grok 4.20（0309 v2）的 1179 高 321 分，在该榜上超过 Gemini 3.1 Pro Preview、Muse Spark、GPT-5.4 mini 和 Kimi K2.5；榜单上代理工具调用与指令遵循第一，ValsAI 企业领域第一。xAI 给出的规格是 100 万 token 上下文窗口、文本与图像输入、约 5000 亿参数规模，输出速度约 196 tokens/s，首 token 延迟偏高。xAI API 上线说明给出的定价是输入每百万 token 1.25 美元、输出 2.50 美元，分别比 Grok 4.20 便宜约 37% 和 58%。

这一版的定位是工作型模型而非追求参数规模。工具侧强化了工具调用、网页搜索、X 搜索、代码执行、文件搜索和 RAG，官方称可在聊天中直接生成 PPTX、PDF 和 XLSX 文件。百度百科收录的条目也记了它的取舍：AA-Omniscience 准确率有所提升，但非幻觉率相应下降。xAI 研究员 Eric Jiang 在 X 上确认有比 Grok 4.3 更大的模型正在训练中。Artificial Analysis 的分数与定价均引自该机构和 xAI 自己的材料，本文未做独立复算。

## 4. SignThought：给手语翻译插一条"隐式思维链"

香港理工大学与四川大学的联合团队 5 月 4 日公布 SignThought 框架，论文《Think in Latent Thoughts: A New Paradigm for Gloss-Free Sign Language Translation》被 ACL 2026 主会接收并推荐为口头报告。第一作者是港理工博士生江奕飏，指导老师为李青教授与魏骁勇教授，代码开在 GitHub 的 fletcherjiang/SignThought。

出发点是一个具体的观察：同一个手型配上不同的运动轨迹、空间位置、身体朝向和面部表情，含义可能完全不同——"停车""撞击""行驶"可以是同一个起手式。现有 gloss-free 方法把"决定该表达什么语义"和"在长视频里定位支持这一语义的时序证据"强行耦合在一起，结果是语义规划不稳定、注意力分散，句子表面流畅却没对上视频里的核心关系。SignThought 的做法是在视频和文本之间插一条有序的 latent thoughts 链：Sign Encoder 先把视频编码成稠密的时序证据特征，Latent Chain-of-Thought Thinking Module 用一组可学习的 thought slots 把长视频压缩成一条有顺序的中间语义链，Dual-Stream Decoder 先做语义规划再回到视频里找证据（plan-then-ground）。thoughts 还能作为可追踪的锚点，把生成的文本对应到输入视频的具体时间区域。

结果是在 PHOENIX14T、CSL-Daily、How2Sign、OpenASL 和自建的 LC-HKSLT 五个基准上都取得最好的 gloss-free BLEU-4，并在其中四个上取得最高 ROUGE。PHOENIX14T 上是 27.22 BLEU-4 / 54.50 ROUGE，CSL-Daily 上 23.92 / 50.99；增益在更大的数据集上更明显，How2Sign 的 BLEU-4 从此前方法的 9.37 提到 13.39，OpenASL 从 13.21 提到 19.55。消融实验显示，去掉 latent thinking module 掉分最多，单独去掉因果 thought 更新、结构化路由、双流解码或 thought-guided 先验注入也都会退化。

团队同时开源了香港手语数据集 LC-HKSLT，主体来自公开视频场景的播报式内容，只保留句子级监督、不引入 gloss 标注，总计 1311 小时视频、432K clips、14 位 signer，SLT 词表 125,833；论文的实验用的是其中整理出的 30 小时子集，以便与现有中文手语翻译基准可比。预训练后再在 30 小时子集微调，LC-HKSLT 上的成绩从 21.15 BLEU-4 / 47.87 ROUGE 提到 30.22 / 60.01。

## 5. SciGraph-SCP：把 68 个学科图谱封装成智能体可调用的服务

浙江大学联合上海人工智能实验室、同济大学等发布 SciGraph-SCP Server，称为首个专为科学智能体打造的 AI 原生（AI-Native）科学图谱开放服务，4 月底上线并陆续见诸报道。它依托上海 AI Lab 推出的科学智能上下文协议（SCP）做协议级统一封装，再通过 SkillNet 完成技能化封装，支持从 OpenClaw、华为 JiuwenClaw 等开源智能体框架直接调用。

规模是它的主要卖点：已集成覆盖数学、物理、生物、化学、材料等 8 个细分学科的 68 个科学知识图谱，拥有 3.7 亿以上实体和 37 亿以上三元组。在保留全图谱统一服务的同时，平台延伸出生命科学（SciGraph-Bio）、物质科学（SciGraph-Material）、数理科学（SciGraph-MathPhys）和地球科学（SciGraph-Earth）四个粗粒度学科专属服务。以化学图谱 ElementKG 为例，它含约 2309 万个节点、7400 余万条关系，涵盖分子、化学反应、实验流程、实验试剂、实验装置、元素等 13 种实体类型，由 97 种关系类型相连，支持从实验设计到结果分析的全流程查询。所有工具按 MCP 协议封装，研究者不必本地部署图数据库，几行 Python 即可远程访问。

团队此前已在《国家科学评论》（National Science Review）发表关于知识图谱驱动 AI 科学发现的综述。服务上还演示了基于 SciGraph 构建面向科学家的大模型知识维基 SciLLM-Wiki，思路是"图谱定骨架、模型赋语义"：由图谱先定位概念之间的结构化连接，再由大模型结合领域文献做语义填充与进展归纳。相关工作得到科技创新 2030—"新一代人工智能"国家科技重大专项支持。服务入口在书生 Intern-Discovery SCP Server 与 OpenKG 的 SciGraph 服务目录。
