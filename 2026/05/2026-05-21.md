# 2026-05-21 AI 大事件

北京时间 2026 年 5 月 21 日（星期四）。中国厂商在这一轮几乎同时把 Agent 这条主线推到了产品层：5 月 20 日阿里云在杭州开峰会，宣布完成"芯片—云—模型—推理"全栈 Agent 化升级，发布自研 AI 芯片真武 M890 与 128 卡超节点服务器、面向 Agent 的独立产品官网"千问云"，以及旗舰模型 Qwen3.7-Max。同一时间窗里，DeepSeek 被曝已内部组建 Harness 团队、要做"DeepSeek Code Harness"直接对标 Claude Code；深圳国家超级计算中心公布 1.54 艾级的纯 CPU 超算"澜闪"；智象未来发布超两千亿参数的原生全模态图像模型 HiDream-O1-Image-Pro。资本一侧，月之暗面据《彭博》报道已通知投资人拆除红筹架构，为赴港 IPO 铺路。

## 1. 阿里云峰会：真武 M890、128 卡超节点、千问云与 Qwen3.7-Max

5 月 20 日，2026 阿里云峰会在杭州举行，阿里云宣布完成"芯片—云—模型—推理"全栈 Agent 化升级，主题是"为 Agentic 时代，全栈就绪"。阿里云资深副总裁刘伟光的说法是，Agent 突破临界点之后可以 24 小时不间断工作，对 AI 和云的需求无穷无尽，阿里要建设中国最大的 AI 工厂。这是国内云厂商第一次围绕 Agent 做全栈产品发布。

芯片一侧，平头哥新一代训推一体 AI 芯片真武 M890 首次亮相：自研并行计算架构，144GB 显存，片间互联带宽 800GB/s，性能是上一代真武 810E 的 3 倍，原生支持从 FP32 到 FP4 的多种精度。配套的是磐久 AL128 超节点服务器，搭载自研互联芯片 ICN Switch 1.0，可让 128 张 AI 芯片组成一台计算机，P2P 时延低于 150ns，主打 Agent 场景下的海量并发推理与训练，目前已上线阿里云百炼，支持 Qwen、DeepSeek、Kimi 等主流模型。平头哥还首次公布路线图：未来两年将推出真武 V900、真武 J900 两代。平头哥半导体副总裁高慧的解释是，一个 Agent 执行任务时可能在毫秒间连续发起数十次模型调用，需要 CPU、GPU、网络和存储紧密协同。截至峰会，真武系列芯片累计出货 56 万片，服务中国电信、中国一汽、浦发银行等 20 多个行业的 400 多家客户。

模型一侧是新一代千问旗舰 Qwen3.7-Max。官方口径是，它在三方机构 Arena 全球大模型盲测总榜上超过 Kimi-K2.6、DeepSeek-v4-pro、GLM-5.1，与 GPT、Claude、Gemini 的最强模型接近，位列国产模型第一。阿里给出一个比跑分更直接的案例：在训练时从未接触过的真武 M890 芯片上，Qwen3.7-Max 只凭一份任务说明，从零开始自主工作 35 小时，通过自主编程和超 1000 次工具调用，独立完成了一个生产级 AI 计算内核的编写与调优，最终性能较官方版本提升 10 倍，全程没有人类干预。通义大模型事业部负责人周靖人说这是范式转移："从对齐人类偏好，到对齐任务目标。过去我们追求的是模型'说得好'，现在要求模型'做得到'。"

云的形态也改了。阿里云推出成立 17 年来第一个独立于主站的 AI 产品官网"千问云"，首页不是导航，而是一行可执行的 Agent 指令：安装 Skills `npx skills add QianWen-AI/qianwen-ai`。官网提供 Qwen、GLM、Kimi、DeepSeek、Wan 等 150 多款模型的 API，并把模型服务能力封装成 Skills 与 CLI 工具，智能体可以直接解析这条指令、学会整站能力并自主调用；阿里云同时上线了 Skills 门户。阿里云首席技术官李飞飞给的理由是，传统云的交互逻辑是为人设计的，而 Agent 工作负载是"无规律弹性、短生命周期、瞬时起量即走"。百炼平台同期全面开放，与月之暗面、MiniMax、智谱、阶跃星辰、爱诗科技、生数科技达成合作，GLM-5.1、MiniMax M2.7、Kimi K2.6 等模型已上架。背景数字是上周的财报：阿里 AI 模型及应用服务 ARR 已超 80 亿元，预计年底突破 300 亿元；Agent 驱动的 MaaS 收入将取代 ECS 成为阿里云最大的产品线。

## 2. DeepSeek 组建 Harness 团队，做"DeepSeek Code Harness"

据"甲子光年"援引知情人士的消息，5 月 19 日至 20 日间，DeepSeek 已内部组建一支名为 Harness 的团队，聚焦代码智能体产品的研发，内部直接对标 Anthropic 的 Claude Code。DeepSeek 资深研究员陈德里随后在社交平台证实："DeepSeek 正在组织一个新的 Harness 团队，做 Harness 方向的产品和研究，简单来说就是对标 Claude Code，做 DeepSeek Code Harness。"

官方招聘页面同期上线两个专属岗位——Harness 产品经理与 Harness 研发工程师，工作地点在北京海淀区融科资讯中心，招聘描述把核心路径写成"Model + Harness = Agent"：模型负责推理与生成，Harness 是模型之外的工程层，包括上下文管理、工具调用、文件读写、终端执行、测试反馈和任务规划。岗位职责里明确写着，新成员要深度参与"DeepSeek 桌面端 Agent 产品"的研发全过程，并定义公司在代码智能体领域的技术路线与产品标准。

这和 DeepSeek 过去以开源基座模型为主的定位不同。此前开发者社区已经自发做过对标 Claude Code 的开源终端项目 DeepSeek-TUI，官方这次亲自下场，意味着它要收回终端入口的主导权，并把真实项目里的测试反馈接回模型训练闭环。消息目前来自媒体报道和研究人员自述，DeepSeek 没有发布正式公告，团队规模、负责人和上线时间均未公布。

## 3. 深圳"澜闪"超算：纯 CPU 架构做到 1.54 艾级

5 月 20 日，中国国家超级计算中心（深圳）公布部署了一套 1.54 艾级的超算，名为"澜闪"（LineShine），配置里没有 GPU。这套机器的核心是定制 Armv9 架构的 LX2 处理器，国家超算中心没有公开研发方，芯片研究机构 Jon Peddie 直接称其为华为的 LX2；它可能是华为自研的高性能计算专用处理器，也可能是国家超算中心与华为联合设计，或由其他受中国政府支持的高性能计算处理器厂商独立研发。

规模上，整机由 20480 个计算节点组成，每节点 2 颗 LX2，合计 40960 颗处理器、2451840 个 CPU 核心，通过灵启高速网络 LQLink 互联，单节点网络带宽 1.6 Tb/s。单颗 LX2 含 2 个计算芯粒、共 304 核，分成 8 个 CPU 集群、每集群 38 核，全核集成 ARM 可扩展向量扩展（SVE）与可扩展矩阵扩展（SME）单元，支持 FP64、FP32、BF16、FP16 和 INT8。内存子系统是这台机器最特别的地方：封装内集成 32GB HBM、带宽最高 4TB/s，封装外配最高 256GB DDR5，辅以专用直接内存访问引擎（SDMA）在两者之间迁移数据；每颗处理器有 4 个 HBM 域和 4 个 DDR 域，共 16 个非统一内存访问域。

算力上，BF16 训练算力为 1.54 艾次/秒；在训练一个 63 亿参数的地球观测生成式压缩模型时，峰值可达 2.16 艾次/秒。FP64 理论峰值合计 2.47 艾次/秒，但实际 FP64 吞吐量尚未公布。整机内存带宽与互联是这套设计能成立的原因：纯 CPU 架构把计算和内存留在同一片硅上，规避了异构计算中高成本、高带宽占用的 CPU-GPU 数据传输，能构建更大的统一内存池，适合长上下文和检索增强任务。

短板同样明确：相比 CPU+GPU 异构系统，纯 CPU 架构的能效比更低、高密度 AI 运算吞吐更弱，这也是全球主流厂商普遍采用异构架构的核心原因。另外，公开信息止于峰值浮点吞吐和核心数，HPL、HPCG 等标准基准上的持续性能没有公布，因此它与 GPU 系统的实际差距仍无法直接比较。参照系是 xAI 的"巨像"集群，据估算理论峰值约 497.9 艾次/秒——但那是数万张英伟达 GPU 堆出来的，性质不同。

## 4. 智象未来发布 HiDream-O1-Image-Pro：超两千亿参数的原生全模态图像模型

5 月 19 日，智象未来在北京以"Imaging the World"为主题举办首届技术开放日，正式发布基于原生全模态架构 Unified Transformer（UiT）打造的图像大模型 HiDream-O1-Image-Pro，参数量超过 2000 亿，官方称在通用文生图、高保真文字渲染、图像编辑等任务上取得 SOTA 表现。公司同时宣布完成新一轮亿级融资，深创投、金浦投资、财鑫资本、复聚资本等参与——这是半个月内第二次融资，此前刚完成超 5 亿元一轮，投资方包括安徽省产投、合肥产投、东方富海。

架构上的说法是"从单模态拼接走向原生融合"：模型把原始图像像素、离散文本标记和任务条件统一纳入一个连续的共享标记空间，让图像、文本与多任务条件在底层表征上融合，而不是各走一套编码器。创始人兼 CEO 梅涛的表述是，"很多'多模态大模型'本质仍是单模态拼接，原生多模态从一开始就把'世界的规则'刻进模型里"。联合创始人兼 CTO 姚霆补充佐证：此前采用同一架构的开源版本 HiDream-O1-Image 以 8B 参数登顶 Artificial Analysis 文生图榜开源模型全球第一，是该榜前 20 名中参数量最小的版本；这次发布的闭源 Pro 版在复杂文本渲染、指令编辑、多主体个性化上全面刷 SOTA。

商业化上，智象未来是"模型+智能体"的 1+1+3 架构：底层 HiDream 系列模型，中间 HiHarness 企业服务平台，上层三个智能体——商业营销 HiBurst（自称 TikTok 官方 TOP5 服务商，年产电商营销视频超百万条）、影视创作"帧赞"（累计制作短漫剧超 5000 分钟，入驻专业团队超千家）、社媒创作 vivago（登顶 Product Hunt 日榜第一，覆盖 100 多个国家和地区、超 4000 万用户）。开放日现场还与上海电影集团上影新视野基金、蓝色光标、捷成世纪、倍尔健康达成战略合作。公司把下一步指向"从视觉生成走向世界模型"。

## 5. 月之暗面拆除红筹架构，为赴港 IPO 铺路

据《彭博》5 月 19 日援引知情人士报道，月之暗面（Moonshot AI）已通知其投资者，将重整公司架构以符合北京方面对寻求海外上市的中国公司日益严格的要求，方式是把"红筹架构"拆掉——即由在境外注册的实体持有境内资产和业务的结构。这是在为在香港进行首次公开发行铺路。

月之暗面由清华大学前教授杨植麟于 2023 年初创立，投资者包括阿里巴巴、腾讯、美团、小红书和五源资本，最新估值已超过 200 亿美元。据报道，本月初月之暗面将完成约 20 亿美元的新一轮融资，投后估值突破 200 亿美元，由美团旗下产业基金美团龙珠领投，中国移动与中信产业基金参投。今年 3 月就曾传出月之暗面拟来港上市，当时报道称已就潜在 IPO 与中金、高盛磋商。

同属"AI 六小虎"的智谱和 MiniMax 已先后在香港上市，阶跃星辰据报本月完成近 25 亿美元融资并拆除红筹架构。截至目前，月之暗面没有就上市时间表、募资规模或承销安排作出公开确认。
