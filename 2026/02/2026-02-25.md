# 2026-02-25 AI 大事件

北京时间 2026 年 2 月 25 日（星期三）。本期记 3 条。Meta 与 AMD 签下 6 吉瓦、规模上千亿美元的算力协议，这是半导体史上最大单笔 AI 基础设施合同之一；阿里云百炼推出 7.9 元首月的编程订阅，把 AI 编程的价格战打到地面；阿里同时开源三款中型 Qwen3.5 模型。

## 1. Meta 与 AMD：6 吉瓦、上千亿美元的算力绑定

据 CNBC、路透社与美联社报道，AMD 与 Meta 于当地时间 2 月 24 日宣布达成一项五年战略合作协议，AMD 将为 Meta 下一代 AI 基础设施提供**总计 6 吉瓦的定制版 Instinct 加速 GPU**，覆盖多代产品。

金额上两家口径略有差异：美联社认为该协议可能价值超过 1000 亿美元；格隆汇援引协议称订单价值约 600 亿美元。无论取哪个数字，这都已被称为半导体行业历史上最大的单笔 AI 基础设施合同之一。技术细节上，这批 GPU 基于 MI450 架构、为 Meta 业务负载专门优化，首批 1 吉瓦规模的部署预计于 2026 年下半年开始出货。协议还延伸到 CPU：Meta 将部署"数百万颗"AMD EPYC CPU，并成为第六代 EPYC CPU 的首发客户。

交易结构里最值得玩味的是股权条款。AMD 向 Meta 授予股票认股权证，允许其以每股 0.01 美元的行权价分批购买至多 1.6 亿股 AMD 普通股，约占公司总股本的 10%；触发条件是双方达成特定技术与商业里程碑、且 AMD 股价触及 600 美元目标位。周一 AMD 收盘价为 196.6 美元。消息带动 AMD 盘前一度涨超 14%。

Meta 的算力饥渴有明确出处。公司第四季度财报显示营收与利润双双超预期，并预计今年与 AI 相关的资本支出将达到 1150 亿至 1350 亿美元，几乎是去年的两倍；Meta、亚马逊、谷歌、微软四家合计约 6500 亿美元。扎克伯格在声明中说："我们很高兴与 AMD 建立长期合作伙伴关系，共同部署高效的推理计算能力，并提供个人超级智能。"AMD 董事长兼 CEO 苏姿丰则表示，此次合作涵盖 Instinct GPU、EPYC CPU 及机架式 AI 系统。

值得注意的是这并不是 Meta 第一次对冲单一供应商：2 月 17 日 Meta 刚与英伟达达成"多代"合作协议，承诺使用数百万颗英伟达当前及下一代芯片，Meta 也将成为其 Grace CPU 服务器首次大规模部署的平台。分析师 Ben Bajarin 指出，本次协议与 Meta—英伟达协议的关键不同，在于**首次涉及部署定制 GPU**。

## 2. 阿里云百炼 Coding Plan：7.9 元首月，AI 编程价格战开打

据证券时报与新浪财经报道，2 月 25 日阿里云百炼推出 Coding Plan 订阅服务，一次打包 Qwen3.5、GLM-5、MiniMax M2.5、Kimi K2.5 四款国产顶级开源模型的 API，**Lite 基础套餐新用户首月仅需 7.9 元**（每月最多 18000 次请求），Pro 高级套餐首月 39.9 元（每月 90000 次请求）。阿里云称，这是全球云厂商中首创的"打包"订阅模式。

订阅后用户可在 Qwen Code、Claude Code、Cline、OpenClaw 等 AI 工具之间自由切换。阿里云方面表示，这一套餐的主要受众是开发者群体——正是此前被 20 美元月费的 Cursor Pro、10 美元的 GitHub Copilot Pro 挡在门外的那批人：学生、独立开发者、转行新人。

价格战的底气来自模型本身。Qwen3.5-Plus 总参数 3970 亿、激活 170 亿，原生多模态并面向 Agent 任务做了专项优化；GLM-5 上线后 API 服务供不应求；MiniMax M2.5 在 SWE-bench Verified 上达到 80.2%，与 Claude Opus 4.6 的 80.8% 几乎持平，但成本只有后者的 1/20。

## 3. 阿里开源三款中型 Qwen3.5：把"小尺寸高性能"推到底

同一天，阿里在 Coding Plan 上线之外，还开源了三款中等规模的 Qwen3.5 模型：**Qwen3.5-35B-A3B、Qwen3.5-122B-A10B 以及 Qwen3.5-27B**。据华尔街见闻，这三款模型均创下同等规模模型的性能新高，且**可直接部署于消费级显卡**。

配套的还有托管模型 Qwen3.5-Flash，已在阿里云百炼上线，每百万 Token 输入价格低至 0.2 元。Qwen3.5 本身是原生多模态模型，支持文本、图片及视频输入，能够解析最长两小时的视频内容。

"参数翻倍、推理成本下降、国产算力全栈跑通"是这一轮国产模型密集发布的共同特征。GLM-5 在 Coding 与 Agent 能力上取得开源 SOTA，MiniMax M2.5 一周内登顶 OpenRouter 调用量榜首，周调用量涨到 3.07T tokens，环比增长 524%——两家的模型在开源智能体项目 OpenClaw 中都成了最受欢迎的选择之一。Token 消耗的量级变化，直接改写了算力采购的账本。
