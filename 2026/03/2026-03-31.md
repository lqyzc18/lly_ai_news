## 1. 360 漏洞挖掘智能体在 OpenClaw 中挖出高危漏洞

据证券时报 3 月 31 日报道，360 数字安全集团依托自主研发的 360 多智能体协同漏洞挖掘系统，在 GitHub 上斩获 34 万星的 OpenClaw 平台中成功发现一处高危漏洞——**MEDIA 协议 Prompt 注入绕过工具权限泄露本地文件漏洞**。该漏洞已被国家信息安全漏洞库（CNNVD）正式确认，影响范围覆盖全球 50 多个国家和地区，**超 17 万个可公开访问的 OpenClaw 实例**面临安全风险。

按 360 安全专家的介绍，漏洞存在于 OpenClaw 2026.3.13 版本的核心媒体处理模块，兼具攻击门槛低、影响范围广、危害程度大三个特征。风险的核心在于，MEDIA 协议运行在输出后处理层，**可以完全绕过平台的工具策略控制**——即便 Agent 已经禁用所有工具调用，攻击者仅凭群聊基础成员权限即可发起攻击，直接窃取服务器敏感信息，极易引发后续网络攻击。360 称已独立完成漏洞攻击链的验证与实测，确认了真实性与可利用性，并为平台方修复提供了技术支持与修复建议。

技术路径值得留意。这次挖掘由观察者智能体统一调度，攻击面分析、AI 代码审计、动态渗透等专业智能体协同作业：攻击面分析智能体锁定业务所有入口，规则引擎精准锚定危险锚点；AI 代码审计智能体穿透跨文件、跨模块的复杂调用链，找到传统工具难以触及的隐藏漏洞。这是继 360 此前发现 OpenClaw 相关漏洞并获项目创始人回信确认之后的又一次突破。

## 2. 工信部就 OpenClaw 发布风险提示，官方插件论坛一成是恶意插件

据中国网报道，工信部 3 月 31 日发布风险提示：监测发现攻击组织正在利用 OpenClaw 的热度，**仿冒其下载网站和安装文件，诱导用户下载含恶意程序的安装包**。

另一组数据解释了用户为什么会中招。OpenClaw 官网用于插件下载的官方论坛里被检测出 336 个恶意插件，占比 10.8%。中国计算机学会计算机安全专委会委员王媛媛解释称，插件实际上是"龙虾"的一个独立功能模块，就像手机里的小程序——要执行比较复杂的指令操作，就得安装插件；而恶意插件就是在看起来很正常的代码里植入恶意代码，最终目的是窃取数据或控制电脑。

专家的实測结论更具体。中国互联网协会数据安全与治理工作委员会专家常力元称，AI 很容易被误导，黑客不需要编写复杂病毒代码，只需通过诱导性言语或在 AI 访问的页面里嵌入文字，就能"催眠"并控制"龙虾"，让它主动泄露主人的信息。网络安全工程师危嘉祺的还原过程是：他给 OpenClaw 下达一条让它把配置信息发过来的指令，对方没有任何防备就把包括配置模型、端口信息乃至插件信息在内的内容全部吐出，多轮诱导还能把密钥信息套出来。

专家给出的防护建议包括：不要在涉密设备上运行 OpenClaw；对它的权限做好管控，不应给它过大权限、应设定好行为边界；给它装一道防火墙，对它听到的、说出的以及即将做的事情都做合规确认；涉及重要决策时人仍应做最终决策。此外，国家知识产权局与公安部网安局随后也分别发布提示，后者指出 OpenClaw 技术本身存在原生漏洞、缺乏完善防御机制，极易被"恶意插件"或"隐藏指令"劫持。

## 3. 智谱发布 GLM-5.1

据北京市科学技术委员会与中关村科技园区管委会的盘点，智谱近日发布 GLM-5.1 模型，支持 **204800 Token 超长上下文**与 **131072 最大输出长度**，适用于复杂代码生成与推理任务。

同一批盘点里还提到一家更偏应用侧的动作：北京亮亮视野科技有限公司联合智谱 AI 推出并部署了全球首创的 AR+AI 会议翻译系统。该系统深度融合 AR 眼镜与 AI 大模型能力，可支持 54 种语言实时翻译、延迟小于 1 秒、单次续航 8 小时，并能 7×24 小时稳定运行。通过 AR 眼镜即可直接呈现实时字幕，参会者无需额外耳机和复杂配对即可佩戴即用，开机 4 秒即进入工作状态，最高可支持上万台设备的统一接入与管理，适用于百人、千人级乃至更大规模的国际会议场景。

## 4. PaddleOCR 星标数突破 7.33 万，居 GitHub OCR 项目之首

据同一份盘点，百度文心衍生模型 PaddleOCR 在 GitHub 上的星标数突破 7.33 万颗，成为目前 GitHub 上星标数最高的 OCR 项目。

这个模型能精准解析 110 余种语言的图文混排、表格结构、公式符号等复杂文档元素，可直接输出符合标准格式的结构化数据，实现从图像输入到后续数据处理与智能应用的无缝衔接。

放在开源生态的坐标里看这条数字更有意义：一个以 OCR 起家的工具包在开源社区的星标数超过绝大多数大模型项目本身，说明在 AI 基础设施的构成里，文档解析这一层仍然是刚需，也说明国产模型在"能直接接进现有工程管线"这件事上走了很远。
