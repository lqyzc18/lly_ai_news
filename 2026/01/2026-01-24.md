# 2026-01-24 AI 大事件

北京时间 2026 年 1 月 24 日（星期六）。本期记 4 条。英伟达 CEO 黄仁勋完成 2026 年首次访华，下午现身上海陆家嘴菜市场、晚上出席英伟达上海年会；Anthropic 为 Claude Code 换上 Tasks 与 MCP Tool Search；OpenAI 的 CFO 提出"按结果计费"；Angi 裁员 350 人并把原因直接写成 AI 效率。

## 1. 黄仁勋 2026 年首次访华：从菜市场到上海年会

据澎湃新闻报道，1 月 24 日下午，英伟达 CEO 黄仁勋现身上海陆家嘴街道乳山路锦德菜市场，边走边逛；当晚他参加了英伟达上海年会。这是他今年首度来华——23 日下午抵达上海，首站到访英伟达位于上海张江的新办公室。

据《参考消息》援引外媒报道，黄仁勋随后前往英伟达的上海新办公室与员工见面，回答了员工关注的问题，并回顾了公司 2025 年的主要事件。消息人士称，他此行行程与 2025 年初基本一致，主要是参加上海、北京和深圳分公司的新年晚会以及供应商答谢会；本趟行程以"逛吃"为主，不安排媒体采访。

在行程之外，黄仁勋在瑞士达沃斯世界经济论坛上的表态被反复引用。据 21 世纪经济报道，他表示 AI 时代是人类历史上最大规模的基础设施建设，将会创造大量就业机会，这些工作都与技术工种相关——需要管道工、电工、建筑工人、钢铁工人、网络技术人员以及安装调试设备的人员，"他们的工资已经上涨，几乎翻了一番"；建造芯片工厂、计算机工厂或人工智能工厂的人能拿到六位数的美国工资，并不需要计算机科学博士学位。他还认为 AI 不会简单取代人类工作，而会通过自动化任务创造更高价值的就业，带动数万亿美元的新增投资。

一个政策背景是出口管制：当地时间 1 月 13 日，美国联邦公报显示美方放宽了对英伟达 H200 芯片出口到中国的监管规定，商务部将对相关交易收取费用；1 月 15 日中国外交部对此表态，重申中方在输华芯片问题上的立场。

## 2. Claude Code：Tasks 取代 Todo，MCP Tool Search 上线

据 1 月 24 日的 Tech Digest 与德文版 KI-Tagesbericht 汇总（分别引用 Anthropic 官方、dotey 等来源），Anthropic 对 Claude Code 做了一次核心更新，引入 **Tasks** 功能专门用于复杂、长期工程项目的推进，并**完全替代了旧的 Todo 工具**。

这次改动的逻辑被解释为依赖 Opus 4.5 的上下文记忆与自主性：Tasks 支持在多个 agent 与会话之间实时广播任务状态，并引入"依赖管理"，任务数据原生存储在本地文件系统（`~/.claude/tasks`）下。报道认为，这把 AI 从一个简单的编码助手变成了能管理大型项目、自主协同工作的"数字工程师"。

同一时间，Anthropic 还为 Claude Code 上线了 **MCP Tool Search**：一种"懒加载"机制，让 Claude Code 按需动态发现工具，而不是一次性预加载全部工具定义，内部测试显示 token 开销下降 85%。

## 3. OpenAI 谈"按结果计费"，API 业务单月 ARR 增量超 10 亿美元

据 Axios 与 Altman 的 X 帖（均见 1 月 24 日的日报汇总），OpenAI CFO Sarah Friar 提出了转向"按结果计费"（Outcome-Based Pricing）的设想：按 AI 创造的价值（例如药物发现、商业利润）计费，而不是单纯按 token 计费。

这个表态在社区引发了负面反应，有人把它读作对"工厂产出征税"。同一天，Sam Altman 在 X 上宣布另一件事：公司过去一个月由 **API 业务**带来的年化收入（ARR）增量已突破 10 亿美元——他强调外界往往把 OpenAI 与 ChatGPT 直接画等号，但真正推动高速扩张的是负责对外接口与基础设施的 API 团队。

Friar 同期还提出了"模型授权"（licensing models）的设想：若 OpenAI 授权技术用于药物研发、合作方据此推出畅销药，OpenAI 将按协议分享该药品销售收入的一部分。她表示这类"共担风险、共享收益"的结构可能成为 OpenAI 未来重要的收入支柱之一。

## 4. Angi 裁员 350 人：把原因直接写成 AI 效率

据 Yahoo Finance（见 1 月 24 日 Tech Digest），家居服务平台 Angi（原 Angie's List）裁减了 **350 名员工，约占员工总数的 12.5%**，并把裁员原因直接归为"AI 驱动的效率提升"，预计每年可节省 7000 万至 8000 万美元。

这与同一天的其他几条消息放在一起看，是一个方向：一边是 OpenAI 把 API 收入讲成十亿美元量级的增量，一边是应用层公司把"AI 效率"写进裁员公告。Anthropic 的 Claude Code 把 Todo 换成 Tasks 以支撑长周期自主工程，OpenAI 的 CFO 谈按结果分成，Angi 裁掉 12.5% 的员工——三件事都指向同一个判断：AI 在这一阶段最先改变的是流程成本，而不是产品形态。
