# 2022-03-21 AI 大事件

北京时间 2022 年 3 月 21 日（星期一）。阿里巴巴把支撑淘宝搜索、推荐与广告的大规模稀疏模型训练/预测引擎 DeepRec 正式开源；字节跳动 AML 团队自研的火山引擎大模型训练框架 veGiantModel 公开；谷歌云 Vertex AI 的分布式训练优化实践也被系统梳理，其中 Fast Socket 与 Reduction Server 是两块核心。

## 1. 阿里巴巴开源 DeepRec：千亿特征、万亿样本的稀疏模型引擎

据智源社区 3 月 21 日发布的消息，经历 6 年时间、在各团队的努力下，阿里巴巴集团大规模稀疏模型训练/预测引擎 DeepRec 正式对外开源，帮助开发者提升稀疏模型训练性能和效果。

DeepRec（PAI-TF）是阿里巴巴集团统一的大规模稀疏模型训练/预测引擎，广泛应用于淘宝、天猫、阿里妈妈、高德、淘特、AliExpress、Lazada 等业务，支持了淘宝搜索、推荐、广告等核心业务，支撑着千亿特征、万亿样本的超大规模稀疏训练。

技术上，DeepRec 在分布式、图优化、算子、Runtime 等方面对稀疏模型做了深度性能优化，同时提供了稀疏场景下特有的 Embedding 相关功能。它基于 TensorFlow 1.15、Intel-TF、NV-TF 构建，针对稀疏模型场景进行了定制化的深度优化，主要包含三类功能优化。

从推荐系统的角度看，"稀疏"才是真正的规模所在：稠密网络可以靠堆卡解决，而亿级 ID 的 embedding 表、稀疏特征与稠密网络的联合训练，一直是工业界最麻烦的部分。把这一层开源出来，对社区的价值远大于再开源一个模型结构。

## 2. 字节跳动开源 veGiantModel：火山引擎的大模型训练框架

据智源社区 3 月 21 日发布的消息，火山引擎大模型训练框架 veGiantModel 公开，它是字节跳动 AML 团队内部开发的框架。

文章先交代了大模型训练给现有训练系统带来的主要挑战。近些年 NLP 应用方面有所突破，BERT、GPT、GPT-3 等超大模型横扫各类 NLP 测试后，人们发现参数量越大模型在算法方面表现越好，于是纷纷向大模型方向发展，模型体积呈爆炸式增长。

而这种增长带来的挑战是三重的：显存压力、计算压力和通信压力。veGiantModel 基于 PyTorch 框架开发，以 Megatron 和 DeepSpeed 为基础，针对这三类压力分别做优化。官方给出的性能提升幅度是最高 6.9 倍，这也是当天智源社区把它选为头条的原因。

## 3. 谷歌云 Vertex AI 的分布式训练优化：Fast Socket 与 Reduction Server

据智源社区 3 月 21 日发布的消息，蓝昶在一次分享中介绍了谷歌云 Vertex AI 平台在分布式机器学习训练性能优化方面做的一系列工作。

文章的出发点是规模。随着机器学习模型和数据规模的增长，大规模分布式机器学习训练的性能越来越成为公有云用户关注的问题；模型越大，单机放不下，训练就必须在多机之间切分，而切分方式、通信效率与集合通信的实现方式共同决定了实际吞吐。

具体内容围绕三点展开：训练优化的背景、Fast Socket——NCCL 的高性能网络栈，以及用 Reduction Server 加速梯度聚合。其中梯度聚合是大规模同步训练中最容易被忽略的一环：所有工作节点每一步都要把梯度归约（reduce）到一致状态，通信的实现方式直接决定了集群有多少算力能真正用于计算。
