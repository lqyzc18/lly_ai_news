# 2025-11-10 AI 大事件

北京时间 2025 年 11 月 10 日（星期一）。OpenAI 发布 GPT-5-Codex-Mini，用四倍调用额度换取约 3 个百分点的基准分数下降，并会在配额接近上限时自动推荐切换。阿里发布升级版推理模型 Qwen3-Max-Thinking，在两项全球数学竞赛中取得满分。美团首款 AI 编程 IDE CatPaw 开启公测。

## 1. OpenAI 推出 GPT-5-Codex-Mini

据 AIBase 报道，OpenAI 近日正式发布 GPT-5-Codex-Mini，这是一款专为开发者打造的高性价比编程模型，继 9 月推出的 GPT-5-Codex 之后，再次拓宽智能编程的应用边界。前作 GPT-5-Codex 基于 GPT-5 架构，专注提升代码推理与生成能力，能在真实软件工程任务中执行新项目创建、功能扩展、测试编写与大规模代码重构等复杂操作，在 SWE-bench Verified 上取得 74.5%，超过此前的 GPT-5 High（72.8%）。

Mini 版是在性能与成本之间取得平衡的「轻量版」：开发者可获得比原版多 4 倍的调用额度，只牺牲少量模型性能。测试数据显示 GPT-5-Codex-Mini 得分 71.3%，在保持高准确率的同时极大降低了使用门槛。OpenAI 建议，开发者在处理中低复杂度任务或接近调用配额上限时优先选择 Mini；当调用量达到配额 90% 时，系统会自动推荐切换到 Mini 版本，以确保项目进度不受限制。

可用性方面，GPT-5-Codex-Mini 已支持 CLI 和 IDE 扩展，API 接口也将于近期开放。得益于 GPU 效率提升，OpenAI 已为 ChatGPT Plus、Business 与 Edu 用户提升 50% 调用上限，Pro 与 Enterprise 用户还将享受优先的速度与资源分配。OpenAI 团队同时对 Codex 底层架构做了全面优化，解决了此前因服务器流量与路由负载造成的性能波动问题，让开发者在高峰时段也能获得稳定一致的调用体验。

## 2. Qwen3-Max-Thinking：两项数学竞赛满分

据 AIBase 报道，阿里巴巴集团发布升级版人工智能推理模型 Qwen3-Max-Thinking，在两项全球顶级数学竞赛中取得满分——美国邀请数学考试（AIME）与哈佛-麻省理工数学锦标赛（HMMT）均为 100% 准确率。这使它成为首个在这两项考试中取得满分的中国 AI 推理模型。

模型出自阿里 AI 与云计算部门的 Qwen3-Max 系列，参数量超过 1 万亿。Qwen3-Max 于 9 月底发布，原始的 Qwen3 则在 4 月推出。阿里云在发布会上表示，Qwen3-Max 在国内外主要竞争对手中表现突出，包括 Anthropic 的 Claude Opus 4、DeepSeek 的 V3.1、xAI 的 Grok 4 以及 OpenAI 的 GPT-5 Pro。

模型还参与了 Alpha Arena 举办的加密货币实盘交易对决：两周内 Qwen3-Max 实现 22.3% 的投资回报，而其他模型表现不一，OpenAI 的 GPT-5 遭遇 62.7% 亏损。目前 Qwen3-Max-Thinking 已通过 Qwen 聊天机器人的网页版和阿里云 API 向个人用户开放，Qwen 团队研究员林俊扬在社交媒体上透露，团队仍在继续推进后续工作。

## 3. 美团推出 AI 编程 IDE CatPaw

据 AIBase 报道，美团宣布其首款 AI 集成开发环境（IDE）产品 Meituan CatPaw 正式进入公测阶段。该产品以智能 Agent 与人类协作为核心，用户只需在官网下载安装即可申请邀请码参与体验，初始账号可发起 500 次对话，使用完毕后可申请增加额度。

产品提供 Ask 模式和 Agent 两种工作模式：Ask 模式适合简单问答任务，需要用户手动选择上下文；Agent 模式面向更复杂的项目问答与分析，系统会自动检索和补充信息。编码过程中 CatPaw 实时提供编码提示，开发者通过 Tab 键即可快速采纳补全建议，还可以通过配置规则（RULES）和文档（Docs）给 Agent 提供额外上下文，提升任务执行效果。

调试环节同样被覆盖：CatPaw 支持项目预览和调试，开发者完成前端编码后可在 IDE 内启动项目预览，快速修改预览元素，并能一键修复出现的错误。此外 Docs 允许用户添加常用知识库，在对话中直接获取相关资料，也可以粘贴链接为 Agent 补充临时信息，目标是让编码与调试过程更便捷高效。
