# 2025-10-07 AI 大事件

北京时间 2025 年 10 月 7 日（星期二）。OpenAI 开发者日把 ChatGPT 推向应用平台：Apps SDK 允许第三方应用直接跑在聊天界面里，AgentKit 用来搭自主代理，GPT-5 Pro 的 API 开放，Codex 转为正式可用。同一天，AMD 与 OpenAI 签下多年芯片协议，向其供应 6 吉瓦算力。字节跳动与 UCLA 的 Self-Forcing++ 把生成视频的长度推到 4 分 15 秒。

## 1. OpenAI 开发者日：ChatGPT 平台化，GPT-5 Pro 上线

据 AIBase 报道，OpenAI 在今年的开发者日上集中发布，把 ChatGPT 定位为深度集成的第三方应用平台，同时让开发者能构建替用户执行任务的自主代理。

Apps SDK 是关键的一步。开发者可以创建直接运行在 ChatGPT 聊天界面中的交互式应用，支持全屏模式并把上下文传给模型；SDK 基于 OpenAI 的模型组件协议（MCP）构建，增加了 HTML 渲染、登录和支付协议。演示里 Canva 生成海报和演示文稿，Zillow 直接在聊天里呈现交互式地图并响应「只有花园」这类自然语言筛选。首批合作伙伴包括 Booking.com、Canva、Coursera、Expedia、Figma、Spotify 和 Zillow，DoorDash、OpenTable、Target 与 Uber 后续加入。开发者可在开发者模式下测试应用，未来会推出应用目录和付费选项，这个 SDK 预计将完全取代旧版 ChatGPT 插件。

AgentKit 是构建自主代理的工具包，核心是拖放式的工作流工具 Agent Builder。现场演示中，OpenAI 只用八分钟拼出一个推荐会议的代理并立即发布。AgentKit 还包括聊天的 ChatKit、测试的 Evals 和管理数据访问的 Connector Registry；代理可通过强化微调（RFT）深度定制，该功能已在 GPT-5 上内测。Agent Builder 处于测试阶段，ChatKit 和 Evals 已正式发布，Connector Registry 正向 API 和企业客户推广。

模型侧的要点是 GPT-5 Pro 的 API。OpenAI 称它是自己迄今为止最先进的语言模型，用更多计算资源，接受文本和图像输入但只输出文本，支持 40 万 token 上下文窗口，最多允许 27.2 万 token 输出，仅可通过 Responses API 访问，定价为每百万输入 token 15 美元、每百万输出 token 120 美元。同时推出便宜约 70% 的 gpt-realtime-mini、便宜约 80% 的 gpt-image-1-mini，以及文本到视频模型 Sora 2 的 API。编码助手 Codex 转为普遍可用，自 5 月推出云代理以来使用量增长了十倍，并新增 Slack 集成、SDK 和管理工具。公司同时披露：ChatGPT 周用户已超过 8 亿，超过 400 万开发者在该平台开发，API 流量达到每分钟 60 亿个 token。

## 2. AMD 与 OpenAI 签下 6 吉瓦算力协议

AMD 与 OpenAI 宣布达成多年芯片供应协议，报道称交易价值达数百亿美元，AMD 将向 OpenAI 提供总计 6 吉瓦的计算能力。报道换算，这个规模足以满足多达 450 万户家庭的用电需求。

协议涵盖 AMD 多代 Instinct GPU 产品线，首批产品是 Instinct MI450。OpenAI 预计在 2026 年下半年接收首批 1 吉瓦算力，届时新芯片按计划部署。AMD 称即将推出的 MI450 系列将凭硬件和软件改进超越英伟达的同类产品 Rubin CPX，其中许多改进会采纳 OpenAI 的意见。AMD 现有的 MI355X 和 MI300X 也已用于 OpenAI 的部分工作负载。

## 3. 微软 RPG：用知识图谱替代自然语言规划

新智元 10 月 7 日的报道介绍微软提出的 RPG 框架。切入点是大模型写代码的现状：函数级、文件级生成已经可靠，但扩展到整个仓库时，数十上百个文件与交织的依赖让生成屡次翻车。现有方法多依赖自然语言规划来决定「做什么、怎么做」，这种做法直观却天生模糊、缺乏结构，难以长程稳定地追踪依赖，典型失效是功能提案不全或实现过程漂移、接口与模块边界错乱。

RPG 的做法是用图谱取代文字：节点代表功能与文件，边标注依赖与接口。基准结果显示，功能创新率 11~13%，代码通过率 69.7%，论文给出的对比是远超 Claude Code。报道把这条进展的意义放在为大规模 AI 开发铺路。

## 4. 字节与 UCLA：Self-Forcing++ 生成 4 分 15 秒视频

量子位报道，字节跳动与 UCLA 联合提出 Self-Forcing++，把自回归长视频生成的长度推到 4 分 15 秒。方法不更换模型架构，也不重新收集长视频数据集，而是利用教师知识与自生成视频片段来指导自回归生成。

演示片段包括一段 1 分 40 秒的海底世界 Vlog、3 分钟的无人机视角海岸线，以及跟随大象脚步纵览草原的 4 分 15 秒长镜头。报道指出，此前同期的长视频生成 SOTA（SkyReels）在同等时长下效果明显退化；Self-Forcing++ 在短时长上继承了 Self-Forcing 的画质，长时长生成的指标为 All kill，视觉稳定性大幅领先 CausVid 等方法。项目已开源。
