# 2025-12-26 AI 大事件

北京时间 2025 年 12 月 26 日（星期六）。OpenAI 与博通达成 10GW 定制芯片合作，定制推理引擎设计完成、预计 2026 年下半年首次部署数据中心，五年内将部署高达 10 吉瓦算力，标志「仅使用 GPU」的时代接近结束。通义实验室发布 Qwen Code v0.5.0，从命令行工具走向完整开发生态。智谱推出轻量级 AI 代码编辑器 Z Code。Liquid AI 发布仅 2.6B 参数的实验性模型 LFM2-2.6B-Exp。

## 1. OpenAI 与博通达成 10GW 定制芯片合作

据 AIBase 报道，OpenAI 与博通（Broadcom）达成一项重大合作，标志传统「仅使用 GPU」的时代即将结束。双方已完成定制 AI 推理引擎的设计阶段，预计 2026 年下半年首次投入数据中心使用；该计划将在未来五年内部署高达 10 吉瓦（GW）的计算能力。

这款新芯片不是现有硬件的简单复制，而是专门为「o1」系列推理模型和未来 GPT 版本量身定制。与英伟达通用的 H100 或 Blackwell 芯片不同，OpenAI 的新芯片采用「系统阵列」设计，特别优化了 Transformer 架构中的密集矩阵乘法计算。据业内消息，芯片将使用台积电最先进的 3 纳米工艺生产，博通还把其行业领先的以太网架构和高速 PCIe 互联直接集成进芯片设计中，以支撑高达 10GW 的计算能力；业界专家预测，这种硬件与软件的共同设计将改变 AI 的经济格局。

## 2. Qwen Code v0.5.0：从命令行工具到完整开发生态

据 AIBase 报道，通义实验室发布 Qwen Code v0.5.0，标志着这一由阿里云打造的智能编程助手，正从单一命令行工具加速转型为覆盖全链路的开发生态平台。本次更新不仅强化核心编码能力，还在插件集成、工程上下文理解与开发者协作支持等方面实现突破。

新版本首次引入多工具协同架构，支持与 VS Code、JetBrains 系列等主流 IDE 深度集成，并可通过插件机制调用代码审查、测试生成、依赖分析等第三方服务，用户不再局限于终端命令，而能在图形化环境中实现「写—测—调—部署」一体化操作。工程级上下文理解能力也显著增强：新版可自动加载整个代码库索引，在生成或修改代码时保持全局一致性，避免「局部正确、整体冲突」的常见问题，例如用户要求「为用户服务添加 JWT 鉴权」时，模型能自动识别现有认证模块结构并在相关控制器、配置中保持一致。

## 3. 智谱推出轻量级 AI 代码编辑器 Z Code

据 AIBase 报道，智谱发布名为「Z Code」的轻量级 AI 代码编辑器，目前处于 Alpha 测试阶段，支持 Mac 和 Windows 系统，目标是降低使用命令行 AI 编程工具（如 Claude Code、Codex、Gemini）的门槛，为开发者提供更友好的编程体验。

其设计理念是通过一个统一的可视化桌面，把多种 AI 编程工具的功能整合在一起：用户只需输入一个 API 密钥，即可便捷地在不同编程 Agent 之间切换。除了基础代码编辑功能，Z Code 还引入安全的文件版本管理、代码审查和任务 Agent 等实用特性，致力于打造一站式 AI 辅助开发环境。核心功能包括对 Claude Code、Codex 和 Gemini 等 Agent 工具的 CLI 支持，用户可通过自然语言与 Agent 对话，提出问题和下达指令以完成编码与分析任务。

## 4. Liquid AI 发布 2.6B 实验性模型 LFM2-2.6B-Exp

据 AIBase 报道，边缘 AI 初创公司 Liquid AI 在圣诞节当天发布最新实验性模型 LFM2-2.6B-Exp。这是一款仅有 26 亿参数的小型开源模型，在多项关键基准测试中表现出色，尤其在指令跟随能力上超越了参数量高达数百亿的 DeepSeek R1-0528，被誉为「最强 3B 级模型」。

模型基于 Liquid AI 第二代 Liquid Foundation Models（LFM2）系列的 2.6B 基础模型，通过纯强化学习（RL）方式进行后训练优化，无需监督微调暖启动或大型教师模型蒸馏。它继承了 LFM2 的混合架构优势，结合短程门控卷积和分组查询注意力（GQA），支持 32K 上下文长度，专为手机、笔记本、物联网设备等边缘设备设计以实现高效本地部署。Liquid AI 表示该实验检查点主要针对指令跟随、知识问答和数学推理等领域优化，适用于代理工作流、RAG 检索、数据提取等场景。
