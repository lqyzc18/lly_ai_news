# 2025-06-28 AI 大事件

北京时间 2025 年 6 月 28 日（星期六）。模型侧，GPT-5 的灰度传闻在社交平台集中发酵——有 OpenAI 员工与一位刚被 xAI 解雇的知名用户同时声称已提前体验到"全新的大模型"，另有网友晒出被灰度到可连续思考 3 分钟并大量搜索的记录。平台侧，阿里云百炼在飞天发布时刻推出业内首个"Agent 打赏"功能，并正式上线提供上百个 Agent 模板的 Agent Store。模型行为侧，Anthropic 用自研的隐私分析工具 Clio 统计了约 450 万次 Claude 对话，提出 Claude 正成为用户的情感陪伴对象。学术侧，中科院自动化所等团队提出"视觉神经增强"（VHR）方法，用即插即用的方式抑制多模态大模型的幻觉。

## 1. GPT-5 灰度传闻：员工与外部用户同时声称已提前体验

关于 GPT-5 的讨论在 6 月 28 日于社交平台再度升温，起因是 Sam Altman 在 X 上关注了一个名为 Yacine 的账号。该账号称自己刚刚试用了一家 AI 公司的大模型，体验"非常震撼"，并打赌"没有任何人能预料到前方即将来临什么样的风暴"；另一位名为"Aidan"的账号在同一帖下发言称有相同经历。

被广泛猜测的是两人测试的就是 GPT-5。理由在于：Aidan 是 OpenAI 员工，而 Yacine 刚被 xAI 解雇、随即被奥特曼关注，两件事同时发生不太可能是巧合。有很大可能他们已提前获得 GPT-5 的访问权限；还有知情人称 Yacine 一直在考虑创办初创公司，奥特曼此时关注他或许是打算招入 OpenAI。

越来越多晒出"疑似被灰度"经历的网友让猜测变得更具体：一位网友发现自己在使用 OpenAI 模型时被灰度到了一个全新的 AI，在没有提示的情况下它可以连续思考 3 分钟并同时进行大量搜索；另一位网友则发现，如果选择的模型是 4o，ChatGPT 会开始"思考"，让人怀疑 OpenAI 正在悄悄过渡到 GPT-5。

需要说明的是，这些均为个人账号的自述，没有官方确认。GPT-5 的时间表此前已有 OpenAI 方面的口径——在同周的官方博客与播客中，奥尔特曼曾表示下一代模型"可能将于今年夏季发布"。

## 2. 阿里云百炼推出"Agent 打赏"，Agent Store 正式上线

阿里云百炼在 6 月 25 日的飞天发布时刻中带来 3.0 全新升级，为开发者提供从技术落地到商业变现的全链路解法，其中最受关注的是与支付宝联合推出的业内首个"Agent 打赏"功能：凡是基于阿里云百炼创建的 Agent，用户只要觉得好用就可以直接给它打赏，Agent 从此可以直接为开发者赚钱。打赏接口还能集成到企业开发者自己的生态或渠道中，无论网页、社交软件还是其他平台都能加上打赏功能。

配套的 Agent Store 正式上线。此前两个月阿里云在 AI 势能大会上就透露了做 Agent Store 的计划，如今它提供覆盖各行各业的上百个 Agent 模板，开发者不仅能在线体验，还能一键复制 Agent 配置，基于成熟模板快速启动二次开发项目，无需"从零开始"。

这次升级的动机被归结为 Agent 落地中的两个真实痛点：开发周期长、商业价值验证难。报道把 2025 年称作名副其实的"Agent 元年"——Operator、Manus、Genspark 等爆款 Agent 相继出现，各厂商陆续发布 MCP 支持，AI Agent 正经历从"玩具"到"工具"的关键转折，但仍有大批项目卡在 POC 阶段。除打赏与 Store 外，本次还升级了企业级 RAG、MCP 等能力，并全新发布多模态交互开发套件。

打赏机制的意义在于它把付费关系从"用户向平台付费"改成了"用户向 Agent 开发者付费"——这让 Agent 第一次有了不依赖企业采购的原生收入方式。

## 3. Anthropic 研究：Claude 正悄悄进化为"情绪价值大师"

Anthropic 最新研究显示，越来越多成年人正把 AI 当作情感陪伴，而 Claude 正在成为那个"温柔倾听"的存在。研究发现，人们在面临更深层次的情感挑战时，例如存在恐惧、长期孤独和难以建立有意义的关系时，会明确地向 Claude 寻求陪伴。Claude 拒绝用户请求的情况非常少（不到 10%），而当它确实这么做时，通常是出于保护用户免受潜在伤害的考虑。

方法上的关键设计是 Clio——Anthropic 自研的自动分析工具，用于在保护用户隐私的前提下了解真实世界的使用情况。Clio 采用自底向上的方法，通过自动聚类对话主题识别真实使用模式，不同于传统依赖预设问题的安全策略，它无需预先设定关注点。研究团队从 Claude 免费和专业账户约 450 万次对话中，提取出了 131484 条与情感相关的对话。整个过程在严格隐私保护下进行，数据经匿名化与聚合处理，分析者仅能访问高层级的汇总信息。

Clio 的多阶段流程包括三步：提取分面，对每个对话抽取对话主题、来回轮次数量、使用语言等属性或元数据；语义聚类，把语义相近的对话自动归类聚合；集群描述，为每个对话集群赋予简洁标题与摘要，同时剔除任何涉及隐私的信息。

## 4. 紫东太初等提出 VHR：即插即用终结多模态幻觉

中科院自动化所联合新加坡国立大学、东南大学等团队提出大模型幻觉的一种高效解决方案 VHR（视觉神经增强）。其机制是直接放大模型中的视觉关键注意力头输出，显著降低模型的幻觉现象，相关成果入选 ACL 2025。

问题出在方法论上。此前的主流方法主要通过对齐训练或输出层分布修正来缓解 LVLMs 的幻觉问题，但这些方法仅作用于模型的最终输出阶段，未能深入干预其内部表征和生成机制，因此难以实现高效且精准的幻觉抑制。VHR 的切入点在内部——通过放大视觉关键注意力头的输出，纠正注意力机制内部的不平衡性。

研究还用一个对照实验说明了幻觉的来源。给定图像并提示模型"请详细描述该图像"时，模型生成的描述中错误地包含"椅子"和"杯子"这类图像中未出现的实体；移除原始图像、改为提示模型根据此前生成的正确描述"图中有一张木桌，桌上有一个花瓶"进行补全，结果模型补全的内容与之前的幻觉部分显著重叠。这表明模型并非基于视觉依据推理，而是系统性地依赖语言共现模式来生成内容——LVLMs 产生的幻觉并非随机错误，而是受其内部语言建模偏好的系统性影响。
