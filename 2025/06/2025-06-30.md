# 2025-06-30 AI 大事件

北京时间 2025 年 6 月 30 日（星期一）。开源侧最重的一条来自百度：文心大模型 4.5 系列正式开源，共十款模型，权重按 Apache 2.0 协议开放，并在飞桨上达到 47% 的模型 FLOPs 利用率。工具侧，Anysphere 推出 Cursor Web 版与移动版，把 AI 编码代理从桌面 IDE 扩展到浏览器与手机；阿里通义则发布 Qwen-TTS 文本转语音模型，以数百万小时语音训练支持多种中文方言。成本侧，谷歌把 Gemini 2.5 Pro 重新纳入 Google AI Studio 的免费层级，并把免费计算资源翻倍。医疗侧，上海瑞金医院携手华为开源了病理模型 RuiPath。

## 1. 百度开源文心大模型 4.5 系列：十款模型，47% 模型 FLOPs 利用率

百度正式发布文心大模型 4.5 系列模型并将其完全开源，用户可以通过文心一言立即体验。这一系列涵盖多种参数配置，包括激活参数为 47B 和 3B 的混合专家（MoE）模型，以及稠密型模型 0.3B 参数的设计，合计十款不同模型。

训练和推理使用飞桨深度学习框架，达到 47% 的模型 FLOPs 利用率。实验结果显示，该系列模型在多项文本和多模态基准测试中表现优异，尤其是在指令遵循、世界知识记忆、视觉理解和多模态推理等任务上取得 SOTA 水平的成绩。权重按 Apache 2.0 协议开源，允许进行学术研究和产业应用；飞桨同时提供开源的产业级开发套件，兼容多种硬件，降低后训练和部署门槛。

生态侧的配套也一并到位。开发者可通过 ERNIEKit 和 FastDeploy 等工具实现训练与部署，FastDeploy 支持多种硬件平台，提供高性能、低门槛的推理部署体验；官方还提供一站式使用指南，包括如何快速掌握模型的精调和对齐。此次开源不仅包括预训练权重和推理代码，还在多个平台提供下载和部署服务，用户可在飞桨星河社区和 Hugging Face 找到这些模型。此外百度推出了开放模型的 API 服务，可在百度智能云的千帆大模型平台上调用使用。全部项目已上传至 Hugging Face、GitHub 与飞桨星河社区，技术报告可在文心一言官方博客查阅。

把 0.3B 的稠密模型和 47B 激活的 MoE 放在同一批开源，指向的是端云一体的部署意图；47% 的 FLOPs 利用率则是这类大模型能否在自有集群上跑出经济性的关键指标。

## 2. Cursor 发布 Web 版与移动版，编码代理延伸到浏览器与手机

Anysphere 推出 Cursor Web 版及移动版，将 AI 编码代理从桌面 IDE 扩展至浏览器和移动设备。Cursor Web 版通过 cursor.com/agents 支持开发者在桌面、平板或手机上管理多个 AI 编码代理，涵盖代码审查、错误修复和功能构建等任务；借助 PWA 技术，Web 版可在 iOS 和 Android 设备上提供类原生体验，适合移动办公和远程协作。

工作流的完整度是关键。开发者可通过 Web 界面分配任务、查看代码并管理拉取请求；Web 版保留了桌面版的核心功能，如"BugBot"错误检测和"Memories"错误模式学习，并新增与 Slack 等工具的集成，方便任务通知和代理操作。报道特别提到，Web 版的高风险后台代理功能允许开发者离席时自动处理复杂任务。

社交媒体反馈显示，开发者对其便捷性和性能表现高度认可，认为它重塑了 AI 编码工具的使用方式。报道同时指出，低带宽环境下的性能表现仍需优化，Anysphere 计划增强离线支持和多模态交互。

从 1.0 到 Web 版的路径很清楚：把编码代理从"开发者坐在 IDE 前"解放成"任务在跑、人不在"。这与 Claude Code for VSCode、Windsurf 等工具的演进方向一致——竞争点正从补全质量转向任务调度与远程可观测。

## 3. 阿里通义发布 Qwen-TTS：方言语音合成，真实感媲美真人

阿里巴巴通义团队正式推出 Qwen-TTS 模型，这是基于大规模语音数据集研发的最新文本转语音模型，通过数百万小时的语音训练，生成的声音在自然度、韵律、节奏和情感表达上达到很高水平。用户通过 Qwen API 即可体验到接近真人发声的语音效果，适用于教育、娱乐、智能客服等多种场景。

多方言与双语音色是它的差异化设计。模型不仅支持标准普通话，还覆盖北京话、上海话和四川话三种中文方言；同时提供七种中英双语音色，包括 Cherry、Ethan、Chelsie、Serena、Dylan、Jada 和 Sunny，每种音色都经过调校以确保发音地道且富有表现力。

技术上支持流式音频输出，能够根据输入文本动态调整语调、语速和情感变化。相较于传统 TTS 模型，Qwen-TTS 在真实感和表现力上几乎无差别，在 SeedTTS-Eval 等特定评测中达到业内顶尖水平，这得益于其背后大规模语料库的训练支持以及通义团队在语音合成算法上的持续优化。通义此次通过 API 开放 Qwen-TTS，降低了使用门槛。

方言支持把语音合成的竞争从"音色像不像"推向"说的人是不是本地人"。在客服与有声内容这类场景里，方言覆盖度往往比通用音色的精致度更影响实际体验。

## 4. 谷歌把 Gemini 2.5 Pro 重新纳入免费层级，并把免费算力翻倍

谷歌宣布其旗舰 AI 模型 Gemini 2.5 Pro 的 API 重新纳入 Google AI Studio 的免费层级。谷歌 AI API 平台负责人表示："我们致力于为数百万开发者提供免费 API 套餐，Gemini 2.5 Pro 现已重新纳入免费层级，并可在 Gemini 应用程序中免费使用。为了应对高需求，我们已将免费计算资源翻倍，并正在探索未来继续开放免费版本的可能路径，例如设置终身调用限制或推出激励计划。"

这是一次政策回摆。此前谷歌在 5 月调整 Google AI Studio 的政策，限制免费用户访问 Gemini 2.5 Pro 系列模型，引发部分开发者对高性能模型访问成本的担忧。Gemini 2.5 Pro 作为谷歌迄今为止最先进的 AI 模型，支持高达 100 万 token 的上下文窗口，能处理文本、图像、音频和视频等多种输入类型，在编码、复杂推理和数据分析等任务上表现突出。

社区反应积极。重新免费的回归为开发者提供了在 Google AI Studio 和 Vertex AI 上进行高性能测试和原型开发的机会，尤其在需要处理大规模代码库或多模态任务的场景下。该模型在 WebDev Arena 和 LMArena 排行榜上的领先表现进一步巩固了它在 AI 开发领域的地位；与 OpenAI 的 o3-mini、DeepSeek 的 R1 等竞品相比，它在多模态处理和推理能力上展现了独特优势，尽管 API 定价在高输入量时略高于部分竞品。

限制依然存在：免费层级的 Gemini 2.5 Pro 受限于较低的调用速率。参考定价为输入每百万 token 1.25 美元、输出每百万 token 10 美元，超过 20 万 token 的请求会按更高费率计。

## 5. 上海瑞金医院携手华为开源 RuiPath 病理模型

6 月 30 日，上海瑞金医院携手华为开源病理模型 RuiPath，并被上海市数据要闻列入当期重点行业动态。这是国内三甲医院与头部 ICT 厂商在病理 AI 上的一次联合发布，路径与 6 月 5 日上海 AI 实验室推出的具身智能大脑框架 VeBrain 属于同一类努力——把垂直领域的基础模型交给专业机构自己使用，而不是停留在通用大模型的评测榜上。

病理 AI 的落点通常在两个环节：一是阅片速度，二是在数字切片上定位可疑区域、给出结构化提示供病理医生复核。这两个环节对模型的要求不同——前者要稳，后者要能给出可被医生采信的证据链。RuiPath 的开源让医院可以把模型接进自己的 PACS 与报告流程，而不必依赖外部服务。

需要说明的是，公开报道对该模型披露的指标有限；其临床准确率、适用病种与验证范围，应以瑞金医院与华为发布的论文或技术报告为准，这篇笔记不引用未经核实的评测数字。
