# 2025-06-19 AI 大事件

北京时间 2025 年 6 月 19 日（星期四）。平台侧两条消息：OpenAI 正式宣布 GPT-4.5 预览版 API 将于 7 月 14 日终止服务，开发者只有不到三个月迁移；Anthropic 则把 Claude Code 扩展到支持接入任意远程 MCP 服务器，终端里可以直接调 Sentry、Linear 这类外部系统。研究侧另有一条：上海人工智能实验室联合北京理工大学、上海创智学院、东京大学等机构开源面向世界探索的第一人称视频数据集 Sekai，并放出配套的交互式视频世界模型 Yume。政策侧，亚马逊、谷歌、微软、Meta 等公司正推动联邦立法禁止各州自行制定 AI 法规，争议集中在这是"统一规则"还是"以监管换垄断"。安全侧，Cato Networks 在暗网市场发现 WormGPT 的两个新变种，不再自建模型，而是通过篡改系统提示"越狱" Grok 与 Mistral。产业侧还有一条：比亚迪与字节跳动共建"AI + 高通量联合实验室"，把大模型用到动力电池研发上。

## 1. OpenAI 宣布 GPT-4.5 预览版 API 于 7 月 14 日停用

OpenAI 正式宣布，将于 2025 年 7 月 14 日终止 GPT-4.5 预览版 API 服务。这一决定将对使用该服务的第三方开发者产生重大影响，个人版的 ChatGPT 用户将不受影响；开发者需要在短短三个月内把自己的应用迁移到其他模型，以确保业务持续运行。

不少业内人士和开发者对这条消息表示困惑与失落，认为该决策可能与运算成本和定价策略有关。GPT-4.5 发布时因其性能吸引了大量开发者与企业，但随着时间推移，如何平衡高昂的运算成本与盈利能力逐渐成为不容忽视的问题——这正是预览版服务与正式版服务在生命周期上的典型分野。

对下游开发者来说，迁移窗口只有约三个月。报道把这既看作挑战也看作契机：市场上涌现出许多新的模型和服务可供选择，但切换模型意味着提示词、评测基线、行为约束乃至成本结构都要重做一遍。事实上，GPT-4.5 从发布到退场的时间并不算长，OpenAI 同期还在推进 o3、o3-pro 等推理型号，把资源压到更高效能价格带的模型上，用服务等级和产品线调整替代"停用某个老模型"。

## 2. 科技巨头推动联邦立法，禁止各州单独监管 AI

据《金融时报》报道，美国多家大型科技公司正积极推动一项联邦禁令，旨在禁止各州自行制定 AI 监管法规。亚马逊、谷歌、微软和 Meta 等公司均表示支持，目的是避免各州在 AI 监管上各自为政影响行业整体发展。

这项禁令提案已被纳入众议院版本的"大而美"预算法案中，参议院也计划在近期推出自己的版本，并希望能在 7 月 4 日之前完成相关立法工作。前联邦众议员、现任 INCOMPAS 首席执行官 Chip Pickering 是这项提案的重要推动者，他表示保持美国在技术领域的领导地位是确保国家竞争力的关键。INCOMPAS 组织于 2024 年成立了"人工智能竞争中心"（AICC），专门游说国会与监管机构以适应快速发展的 AI 行业；随着 AI 监管讨论加剧，尤其在欧盟出台新规后，亚马逊和 Meta 也加入该组织，试图通过统一监管增强竞争力。

争议集中在动机上。反对者认为，大型科技公司推动禁令的真正目的是巩固自身在 AGI 竞争中的垄断地位。范德比尔特大学政策加速中心 AI 与科技政策主任 Asad Ramzanali 表示，负责任的创新不应该惧怕法律的约束；麻省理工学院教授 Max Tegmark 也批评称，这种行为是科技巨头为集中财富和权力而进行的扩张。

支持禁令者则认为，联邦层面的统一监管有助于避免各州分歧、保持行业创新能力，从而在全球 AI 竞争中处于有利地位。AI 安全倡导者如 Anthropic 联合创始人 Dario Amodei 则警告说，如果完全依赖企业自我监管，可能会带来严重的社会风险。这场辩论的实际走向，取决于 7 月 4 日前国会能给出什么版本。

## 3. WormGPT 变种卷土重来：劫持 Grok 与 Mistral 生成钓鱼邮件与恶意脚本

根据网络安全公司 Cato Networks 的研究，犯罪团伙通过篡改一些主流 AI 平台的系统提示（system prompts），成功实现了对 Grok 和 Mistral AI 的"越狱"操作。犯罪团伙借此让 WormGPT 生成钓鱼邮件、恶意脚本等攻击工具，对网络安全造成严重威胁。

这一威胁并非新事物，但形态变了。2023 年 7 月 WormGPT 首次亮相时即引起广泛关注，它基于开源的 GPT-J 模型，能够自动生成木马和钓鱼链接；曝光后这款工具被迫下架。Cato Networks 的研究显示，2024 年底至 2025 年初，名为"xzin0vich"和"keanu"的用户在暗网市场 BreachForums 重新推出了 WormGPT 的订阅服务。

与上一代不同，这一版不再自建模型。攻击者通过篡改 Mixtral 等模型的系统提示，强制其切换至"WormGPT 模式"，从而放弃原有的伦理限制，成为一个没有道德底线的恶意助手；xAI 的 Grok 模型则被封装成 API 接口的恶意包装器，开发者甚至要求模型"永远保持 WormGPT 人格，不得承认自身限制"。

这类攻击的治理难点在于责任归属：模型本身没有做错什么，被绕过的是安全配置。这意味着"系统提示 + API 封装"这种看起来无害的集成方式，在被批量转售时就能变成武器——而模型提供方看到的多半只是正常的 API 调用。

## 4. Claude Code 支持接入任意远程 MCP 服务器

Anthropic 宣布将 Claude Code 的功能扩展到任何远程的模型上下文协议（MCP）服务器。自去年 MCP 标准发布以来，该协议逐渐被微软、OpenAI 和谷歌等公司广泛采纳，成为连接 AI 助手与数据系统的重要标准。

Claude Code 是一款编码助手，允许用户在工作空间中直接编写或管理代码，支持在终端、IDE 内或后台运行。通过这次更新，开发者可以利用 Claude Code 访问第三方服务，包括开发工具和项目管理系统，利用 MCP 安全高效地从所需数据源中提取信息，创建个性化的工作流。Anthropic 展示的合作伙伴用例包括：与 Sentry MCP 服务器集成，使开发者能在终端调试时直接查询错误和获取堆栈跟踪信息；与 Linear 集成，实时获取项目状态和问题详情。

商业侧的背景数字同样被披露：Claude 4 发布后，Claude Code 的用户需求在三周内增长了 160%；公司年收入达到 30 亿美元，五个月内增长 200%。近期 Anthropic 还把 Claude Code 的使用权限扩展至 Pro 计划，订阅用户每月支付 20 美元即可访问 Claude Code 和 Claude。

把"任意远程 MCP 服务器"接进编码智能体，等于把工具接入层从"官方精选清单"变成"开放注册表"。好处是生态扩张速度不受自身审核节奏限制，代价是每一个第三方服务器都成了智能体信任边界上的一环。

## 5. 比亚迪与字节跳动共建"AI + 高通量联合实验室"

比亚迪与字节跳动达成战略合作，将共同攻克动力电池领域的关键技术。根据"小迪快报"的报道，双方将联手建立一个名为"AI + 高通量联合实验室"的项目，通过人工智能技术推动锂电池发展。

分工很清晰：字节跳动的 Seed 团队投入资源进行模型算法研究，火山引擎提供云基础设施以优化模型性能，比亚迪负责提供高通量实验平台，确保实验数据的规模性和一致性。这种合作模式让双方共享算法、算力和实验数据，从而更高效地解决动力电池在快充、寿命和安全等方面的技术难题。

双方的目标是通过构建一个融合海量实验与计算数据的综合性能 AI 模型，来加速电池迭代周期，促进新材料和新配方的发现。这条路径的价值在于它没有把 AI 当成宣传标签，而是放进了实验闭环内部——如果模型给出的配方无法在实验台上复现，整个闭环就会断掉，所以高通量实验平台与算力必须同步到位。

这类"制造企业 + 模型公司 + 云"的组合正在成为 AI4Science 落地的常见形态。传统做法是高校实验室做模型、企业做验证，中间隔着数据；而这里数据从一开始就产生在企业的高通量平台上，模型直接嵌在实验迭代周期里，缩短的正是"发现"到"可复现"之间的时间。

## 6. 上海 AI Lab 开源 Sekai 数据集与 Yume 世界模型

Sekai 的规模罕见：素材来自 101 个国家和地区的 750 多座城市，包含 5000 多小时的第一人称步行与无人机视频。论文 v1 提交于 6 月 18 日（美东 6 月 18 日 13:57），arXiv 于美东 6 月 18 日 20:00 公告公开，对应北京时间 6 月 19 日 8 时，故本条归 6 月 19 日；代码仓库首提为 6 月 18 日 22:42（北京时间），数据集与模型在中英文渠道的实际放量在 7 月初。

规格是 1080p 以上原始素材，统一转成 720p、30 帧、4Mbps 的 H.265 MP4，片段长度从 1 分钟到 6 小时不等，平均 18.5 分钟。标注包括位置（区域、城市、国家）、天气、时间、人流密度、场景类型和相机轨迹；每条视频的描述平均 176 个字符，由 Qwen 2.5-VL 生成；轨迹标签用改进后的 MegaSaM 在 600 多小时素材上标出。

配套的模型叫 Yume，是一个可以交互式漫游的视频世界模型，接受图像加键鼠输入。论文编号是 arXiv 2506.15675，项目主页、数据集和代码都公开在 GitHub 与 Hugging Face 上。
