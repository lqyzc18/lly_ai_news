# 2025-03-20 AI 大事件

北京时间 2025 年 3 月 20 日（星期四）。OpenAI 同日上了两条产品线：北京时间 19 时在 API 中引入新一代音频模型，官方 RSS 的 pubDate 为 11:00 GMT；同日还推出高性能推理模型 o1-pro，输入每百万 token 150 美元、输出高达 600 美元。芯片侧，软银宣布以 65 亿美元收购服务器级芯片设计公司 Ampere Computing，补上自研 CPU 的短板。机器人侧，宇树科技宣布 G1 人形机器人完成侧空翻并稳稳站立，称其为全球首款能做到这一动作的人形机器人。视频侧，阶跃星辰开源 Step-Video-TI2V 图生视频模型，运动幅度与镜头运动都做到可控。

## 1. OpenAI 上线新一代音频模型 API，并推出昂贵的 o1-pro

北京时间 3 月 20 日 19 时，OpenAI 在官网发布《Introducing next-generation audio models in the API》（官方 RSS 的 pubDate 为 11:00 GMT），把新一代音频模型带进 API。同日 OpenAI 还发布官方消息，推出其最新的高性能推理模型 o1-pro，目前已向部分选定的开发者开放使用，尚未公布全面开放的时间表。

o1-pro 的定位是「高阶玩家专属」。按 OpenAI 的介绍，该模型可供位于 1 至 5 层的特定开发者使用，能力上支持视觉输入、函数调用和结构化输出，并能与 OpenAI 的 Responses 和 Batch API 无缝协作。代价同样被明确写进定价：输入每百万 token 150 美元，模型生成内容每百万 token 600 美元——相较 OpenAI 此前发布的其他模型明显更高。官方认为，增强的性能与丰富功能（如视觉理解与更灵活的 API 交互）会吸引需要处理复杂任务、对模型性能要求更高的开发者。

两条产品线放在一起看是同一套策略的两面：一端把多模态输入输出做成通用 API 能力，摊薄使用成本；另一端把最昂贵的推理能力单独定价，锁住高价值场景。音频模型进 API 之后，语音对话、语音转写这类此前需要拼装的链路，第一次有了官方的一体化接口。

## 2. 软银 65 亿美元收购 Ampere Computing：补上自研 CPU 的一块

据 3 月 20 日的报道，软银集团宣布将以 65 亿美元收购服务器级芯片设计公司 Ampere Computing。交易中，Ampere 的主要投资者甲骨文和凯雷集团也出售了各自持有的股份。

Ampere 专注于多核 CPU 设计，其 2023 年推出的「Ultra」型号支持 96 到 192 个核心，兼容 Armv8.6+ 架构与第 5 版服务器基础系统架构；2024 年又发布了 AmpereOne Aurora 芯片，计划达到 512 个核心，专门为 AI 工作负载设计。软银称收购 Ampere 将助力其「战略愿景，并推动 AI 和计算创新」。

软银集团 CEO 兼董事长孙正义的表态把它放进了更大的叙事里：「人工超级智能的未来需要突破性的计算能力。Ampere 在半导体和高性能计算方面的专业知识将加速这一愿景，并深化我们对美国 AI 创新的承诺。」Ampere 创始人兼 CEO Renée J. James 表示期待与软银集团顶尖科技公司产生协同效应。根据软银的声明，Ampere 预计将与软银集团生态系统中的其他公司展开合作，包括投资公司、合作伙伴等。

这一步与软银这一周的另外两笔动作连成线：3 月 14 日收购夏普堺工厂改造为 AI 数据中心，3 月 11 日与 OpenAI 签下 119 亿美元算力协议。从 GPU 算力到 CPU 设计，软银正在把「AI 基础设施」这条链上的关键节点都收进自己手里。

## 3. 宇树 G1 完成侧空翻：全球首款做到这一动作的人形机器人

据 3 月 20 日的报道，宇树科技对外宣布其 G1 人形机器人成功完成侧空翻，并在落地后稳稳站立、保持平衡。宇树称这是全球首款能够完成侧空翻的人形机器人，并表示在整个编程测试和拍摄过程中 G1 没有出现任何故障或损坏，展现了极高的成功率与可靠性。

宇树还发起了一场「机器人侧空翻真人挑战赛」，胜者将获得一台 G1 机器人。初步规则是：挑战者需原地正常站立直接起跳完成侧空翻，挑战有效期为 3 个月，更详细的规则后续公布。官方喊话是「从今天开始，全世界第一个能够复刻这个动作的真人，将获得一台 G1 人形机器人或其他等值礼物」。

这类动作的展示价值不止于噱头。人形机器人能完成侧空翻，意味着全身控制器在多轴协同、落地冲击与姿态恢复上的控制精度达到了可用水平——这类能力正是运动控制算法与本体结构设计共同决定的部分。

## 4. 阶跃星辰开源 Step-Video-TI2V：运动幅度与镜头运动都可控

据 3 月 20 日的报道，上海阶跃星辰开源其最新图生视频模型 Step-Video-TI2V。该模型基于 30B 参数的 Step-Video-T2V 训练而成，能够生成 102 帧、5 秒、540P 分辨率的视频，具备运动幅度可控和镜头运动可控两大核心特点，在动漫效果方面表现突出。官方称，与现有开源图生视频模型相比，它不仅在参数规模上提供了更高的上限，其运动幅度可控能力还能平衡视频生成结果的动态性与稳定性。

技术上有两项关键优化。第一是引入图像条件以提高生成视频与原图的一致性：与传统的 cross-attention 方法不同，模型把图像对应的向量表示与 DiT 第一帧对应的向量表示直接在 channel 维度拼接，从而确保生成视频与输入图片高度一致。第二是通过 AdaLN 模块引入视频动态性打分信息，使用户可以在生成时指定不同的运动级别，精准控制动态幅度，从而平衡动态性、稳定性和一致性。此外，团队还对主体动作和镜头运动进行了专项精准标注，进一步提升了模型在主体动态性和运镜效果上的表现。

模型的核心特点被归纳为运动幅度可控、多种运镜控制、动漫效果优异以及支持多尺寸生成：用户可以自由切换动态与稳定画面，生成从基本的推拉摇移、升降到复杂电影级运镜效果的视频。2025 年春天开源视频模型的密集发布，正在把「视频生成」从演示变成可被工程化使用的能力。
