# 2025-03-11 AI 大事件

北京时间 2025 年 3 月 11 日（星期二）。腾讯在 X 上宣布推出最新模型 Hunyuan-TurboS，被称为首款超大型混合 Transformer-Mamba MoE 模型，推理成本只有前代 Turbo 的七分之一。OpenAI 在北京时间 18 时发布《New tools for building agents》，推出面向智能体开发的 Responses API 与开源 Agents SDK。算力侧，CoreWeave 与 OpenAI 签下 119 亿美元、为期五年的战略合作协议，CoreWeave 还将向 OpenAI 发行 3.5 亿美元股票。硬件侧，智元 X-Lab 的「灵犀 X2」人形机器人在稚晖君的微博亮相，28 个自由度、全身无并联结构；微软与多所高校则开源了多模态基础模型 Magma。

## 1. 腾讯发布 Hunyuan-TurboS：首款超大型混合 Transformer-Mamba MoE 模型

据 3 月 11 日的报道，腾讯在 X 平台上正式宣布推出最新 AI 模型 Hunyuan-TurboS，被视为首款超大型 Hybrid-Transformer-Mamba MoE 模型。据 X 用户披露的信息，该模型融合了 Mamba 的高效长序列处理能力与 Transformer 的强上下文理解能力，试图解决传统纯 Transformer 模型在长文本训练和推理上的瓶颈——后者受 O(N²) 复杂度与 KV-Cache 问题困扰，处理长文本时效率低、成本高。

性能上的说法来自 X 用户 bayrashad：该模型在数学、推理和对齐性（Alignment）上击败了 GPT-4o-0806、DeepSeek-V3 以及多个开源模型，在知识领域（包括 MMLU-Pro 基准）也表现出强劲竞争力，而其推理成本仅为前代 Turbo 模型的七分之一。

后训练阶段的优化是另一条主线。据 csdognin 的帖子，Hunyuan-TurboS 整合了「慢思考」机制以提升数学、编程和推理能力，通过精细化指令调整增强对齐性与智能体执行效率，并针对英语训练做了优化。腾讯还为它升级了奖励系统，采用基于规则的评分、一致性验证以及代码沙盒反馈机制，以确保在 STEM 领域的准确性；生成式奖励机制的引入则提升了问答质量与创造力，同时减少奖励被操控的风险。

## 2. OpenAI 推出 Responses API 与 Agents SDK：把工具内建进模型接口

北京时间 3 月 11 日 18 时，OpenAI 在官网发布《New tools for building agents》（官方 RSS 的 pubDate 为 10:00 GMT），把智能体开发所需的接口和工具链一并推出。

核心是新的 Responses API。官方把它定位为构建智能体应用的新基础接口，与传统「补全一次、返回一次」的调用方式不同，Responses 把模型的多步推理与工具调用组织成一次请求，并直接内建网页搜索、文件搜索、计算机操作等工具，开发者不必再自己拼装外部检索与执行链路。

与之配套的是开源的 Agents SDK，官方把它定位为智能体应用的编排层，提供追踪、交接、护栏等构建智能体所需的基础能力，配套发布了示例与文档。两者共同指向同一件事：把「模型 + 工具 + 循环」这套此前由开发者各自拼凑的模式，收敛成平台侧的默认组件。

发布的时间点也与此前的动作连成一线：3 月 4 日 OpenAI 推出 NextGenAI 联盟，把 5000 万美元投向 15 家研究机构；3 月 11 日的这次更新，则把工具能力直接开放给开发者。OpenAI 的首席运营官 Brad Lightcap 在此前的表述里提到过「加速研究进展、培养下一世代 AI 人才」的方向，而 Responses API 与 Agents SDK 面向的是另一半——把智能体能力交到更多开发者手里。

## 3. CoreWeave 与 OpenAI 签下 119 亿美元协议：OpenAI 成为其股东

据 3 月 11 日的报道，GPU 云服务企业 CoreWeave 宣布与 OpenAI 达成一项价值 119 亿美元、为期五年的战略合作协议，由 CoreWeave 为 OpenAI 提供训练和交付模型所需的算力支持。协议同时包含一次股权安排：CoreWeave 将向 OpenAI 发行价值 3.5 亿美元的股票，使 OpenAI 成为 CoreWeave 的股东之一，尽管 CoreWeave 不会从这次股票发行中获得直接收益。

CoreWeave 联合创始人兼首席执行官迈克尔·英特拉托表示，这次合作展示了 CoreWeave 为全球顶尖 AI 实验室提供高性能基础设施服务的能力，强调在助力 AI 创新方面的长期承诺。Sam Altman 则指出，先进的 AI 系统需要强大的计算能力，与 CoreWeave 的合作是实现这一目标的重要步骤；这既丰富了 OpenAI 的基础设施组合，也与其同微软、甲骨文的商业合作形成互补。

CoreWeave 的体量与这条协议相称。这家 2017 年成立的公司凭借 GPU 云服务快速壮大，2024 年收入达到 19.2 亿美元，较 2023 年增长 8.4 倍，其中约三分之二来自微软；2024 年 5 月它完成了 75 亿美元融资。对 OpenAI 而言，在微软与甲骨文之外再绑定一家专门的 GPU 云厂商，是把算力供应从单一渠道变成多渠道的常规操作——只是这一次的价格足够大。

## 4. 智元 X-Lab 发布「灵犀 X2」：28 自由度、全身无并联结构

据 3 月 11 日的报道，知名开发者稚晖君在微博发布视频，展示智元机器人的最新产品「灵犀 X2」。这是一款搭载情感计算引擎的双足智能交互人形机器人，集成了运动、交互和作业三大智能功能。

硬件配置上，灵犀 X2 采用小脑控制器 Xyber-Edge、域控制器 Xyber-DCU 以及智能电源管理系统 Xyber-BMS，全身拥有 28 个自由度，且未使用任何并联结构，官方称这提供了极高的灵活性和动作精准度。

三项能力各有侧重。运动智能方面，它配备基于 Diffusion 的生成式动作引擎，能完成复杂动作生成；视频展示了它流畅行走、跑步、跳舞，还展示了骑自行车这样的高级平衡技能——官方称这在双足人形机器人领域实属罕见。交互智能方面，机器人搭载定制的多模态交互大模型，支持语音、视觉等多种交互方式，情感计算引擎使其能够理解人类情绪并做出相应反应，提升人机交互的自然度与沉浸感。作业智能方面，它可以装配灵巧手等末端执行器，具备精细操作能力，能完成复杂的抓取、放置与操作任务，因而在家庭服务、工业协作等场景中具备应用潜力。

值得注意的是发布节奏：3 月 10 日智元刚推出首个通用具身基座大模型 GO-1，次日又展示出硬件本体。基座模型与本体在同一周接连到位，指向的是「同一套模型跨形态迁移」的路线。

## 5. 微软联合多所高校开源 Magma：用标记集合与标记轨迹做具身行动

据 3 月 11 日的报道，微软、马里兰大学、威斯康星大学麦迪逊分校、韩国科学技术院与华盛顿大学的研究人员开发了多模态基础模型 Magma，论文链接为 arxiv.org/pdf/2502.13130，代码在 microsoft.github.io/Magma。（归日依据：论文 v1 提交于 2 月 18 日（美东 18 日 13 时），arXiv 于 2 月 19 日（美东）公告公开；微软等团队的开源发布在 3 月 11 日，论文公告与作品发布相差超过一周，按作品发布日归 3 月 11 日。）Magma 的定位是既保留视觉语言模型的语言理解能力（语言智能），又具备在视觉空间世界中进行规划和行动的能力（时空智能），从而完成从用户界面（UI）导航到机器人操作等各类智能体任务。

问题出在二维数字世界与三维物理世界之间的差异上。现有的大语言模型、图像生成模型都只在某几个模态的数据上操作，无法像人类那样与物理世界交互；而视觉—语言—行动（VLA）模型虽然能感知视觉刺激、语言输入等数据并生成具身行动，却普遍对任务做简化，导致多模态理解偏弱、跨任务和跨领域的泛化不足。

Magma 的做法是用「标记集合」（SoM）和「标记轨迹」（ToM）把视觉语言数据转化为可操作的任务。预训练阶段，图像中可操作的视觉对象（比如 UI 里的点击按钮）通过 SoM 标注以便行动定位；视频中物体的运动（比如人手或机械臂的动作轨迹）则通过 ToM 标注。研究方称，这一设计显著提升了模型的空间智能和任务泛化能力。
