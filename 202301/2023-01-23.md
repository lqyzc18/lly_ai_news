# 2023-01-23 AI 大事件

北京时间 2023 年 1 月 23 日（星期一）。微软宣布与 OpenAI 长期合作的第三阶段，通过一笔「多年期、数十亿美元」的投资加速 AI 突破；Azure 成为 OpenAI 在研究、产品与 API 服务上的独家云提供方。微软没有公布金额。这是双方继 2019 年和 2021 年之后的第三笔投资，五天前微软刚宣布裁减 1 万个岗位。

## 1. 微软：第三阶段合作的三项内容

微软官方博客的开头写：「今天，我们宣布与 OpenAI 长期合作的第三阶段，方式是投入一笔多年期、数十亿美元（multiyear, multibillion dollar）的投资，以加速 AI 突破，让这些收益能在全世界广泛共享。这次协议接续我们在 2019 年和 2021 年的前两笔投资，它延续我们在 AI 超级计算与研究上的持续合作，并使我们双方都能各自独立地将由此产生的先进 AI 技术商业化。」

公告列了三条。超级计算方面，微软将加大对专用超级计算系统开发与部署的投资，以加速 OpenAI 独立的 AI 研究，同时继续扩建 Azure 的 AI 基础设施。AI 体验方面，微软会把 OpenAI 的模型部署到自己的消费与企业产品线上，并引入基于 OpenAI 技术的新形态数字体验，其中包括让开发者直接调用 OpenAI 模型的 Azure OpenAI Service。独家云方面，Azure 作为 OpenAI 的独家云提供方，将支撑 OpenAI 在研究、产品和 API 服务上的全部工作负载。

纳德拉的声明是：「我们与 OpenAI 组成伙伴关系，是围绕着一个共同的雄心——负责任地推进前沿 AI 研究，并把 AI 作为一项新的技术平台来普及。」他补充，在合作的下一阶段，各行业的开发者与组织都将能借助 Azure 获得最好的 AI 基础设施、模型与工具链。奥尔特曼则说：「我们伙伴关系的过去三年很棒。微软与我们共享同样的价值观，我们很高兴能继续独立的研究，去打造惠及所有人的 AI。」

## 2. 官方措辞与结构安排

微软的措辞是「多年期、数十亿美元」，没有给出具体金额，也没有公布 OpenAI 的估值。这次投资延续了 2019 年 10 亿美元、2021 年之后延续到 2023 年的合作节奏。公告里给出的历史线索是：自 2016 年以来微软就在把 Azure 建成「面向世界的 AI 超级计算机」，双方在 2020 年公布了首台全球前五的超级计算机，之后又建了多套大规模 AI 超级计算系统；OpenAI 用这套基础设施训练出其模型，这些模型如今部署在 Azure 上，支撑 GitHub Copilot、DALL·E 2 和 ChatGPT 等产品。

按新华社的报道，新投资 deal 之后 OpenAI 仍将保持上限利润（capped-profit）结构，投资人的回报上限是本金的 100 倍。微软与 OpenAI 的这轮安排没有公开金额，媒体对具体规模的测算口径不一，本笔记不引用未经官方确认的数字。
