# 2026-06-01 AI 大事件

北京时间 2026 年 6 月 1 日（星期一）。这一天的两条主线都在具身与智能体这边：上海创智学院罗剑岚团队把大规模预训练的机器人世界模型 τ0-WM 放了出来，用「先推演再执行」的方式替代看到动作就照做；复旦大学与通义实验室 MobileAgent 团队则给出了 GUI 操作与工具调用混合动作空间的训练范式 ToolCUA，开源的 8B 模型在 OSWorld-MCP 上拿到 46.85%。微软的 SkillOpt 框架把 Agent 的技能文档当成可训练参数，是这周方法讨论的焦点。硬件侧，英伟达自研 CPU 的第一条产品线露出形态，传闻中的 GB10 迷你 PC 把 GPU 和 20 核 ARM CPU 合到一颗芯片上。人与钱的两条消息也值得记：DDIM 的提出者宋佳铭宣布离职，智谱、MiniMax、月之暗面、阶跃星辰四家的财务数字第一次被摆到台面上。

## 1. τ0-WM：把「先想再做」写进机器人基础模型

上海创智学院罗剑岚团队发布并开源了具身世界模型 τ0-WM，arXiv 编号 2606.01027，论文与代码在 5 月底上线。团队的说法是，这是目前预训练规模最大的开源具身世界模型之一。

结构上分三块。视频动作模型（Video Action Model, VAM）既生成动作也预测未来画面；动作条件视频仿真器（Action-Conditioned Video Simulator, ACVS）负责给定动作后推演会发生什么；两者之间用测试时计算（test-time computation）串起来——VAM 先采样一组候选动作，ACVS 对每条轨迹打分，最后执行评分最高的那条，而不是概率最高的那条。两个模块共享一个 diffusion transformer 骨干，可以单独使用。

数据规模是这项工作的重点。团队称预训练用了约 2.7 万小时异构数据，其中真机数据约 1.7 万小时、UMI 数据约 6000 小时，其余为第一视角人类视频，加上开源机器人数据和失败轨迹，最终配比约为 6:2:1。论文同时把「用真机数据做大规模预训练」列为区别于此前做法的地方。团队在四个长程精细操作任务（Toolbox、School Bag、Badminton、Faucet）上报告，平均成功率超过对标的 π0.5 和 Fast-WAM。

几个数字需要分开看。成功率是团队自测结果，没有第三方复现。单次前向循环约 180 到 220 毫秒，接近 5Hz，这是团队给出的工程口径。关于失败轨迹的价值，罗剑岚的说法是失败数据告诉模型「哪些动作看着合理、其实危险」，而不是直接给出正确答案。这些是作者与团队的表述。

## 2. ToolCUA：Agent 不会在 GUI 和工具之间选路

复旦大学和通义实验室 MobileAgent 团队提出 ToolCUA，面向 GUI 操作与工具调用混合的动作空间，解决一个反直觉的问题：给强模型接上工具，准确率反而下降。

论文里给出的对照是，把工具接到模型上以后，Qwen3VL-8B 的准确率从 29.0% 掉到 28.2%，Qwen3VL-235B 从 41.1% 掉到 38.1%，Claude-4-Sonnet 从 47.7% 掉到 43.5%，Claude-4.5-Sonnet 从 61.9% 掉到 48.4%。模型越强，下降越明显。原因是模型不会选路：要么几乎不用工具，要么在不该用的时候频繁调用。

训练分两阶段。第一阶段从已有的 GUI 轨迹出发，用多模态模型合成工具库，再把纯 GUI 轨迹改写成 GUI 与工具交错的轨迹，产出约 4000 个工具、约 18 万步的预热数据，以及 5000 条用于单轮强化学习的切换点数据。第二阶段是在真实环境里做长程滚动，优化一个「工具效率路径奖励」：工具适当性奖励只在成功轨迹上激活，路径效率奖励按组内相对长度给加减分。论文的消融显示，去掉这两项奖励后，准确率曲线在训练第 8 到 11 步出现下滑，最终比完整版本低约 7 个点。

结果是团队自测的。ToolCUA-8B 在 OSWorld-MCP 上准确率 46.85%，对照组 Qwen3-VL-8B-Instruct 为 28.23%，论文称相对提升约 66%；平均完成步数 14.93 步，是表中最低；工具调用率从 8.41% 升到 24.32%。同表里 Claude-4-Sonnet 为 43.54%，Claude-4.5-Sonnet 为 48.35%。在训练没见过的 Windows 桌面环境上，ToolCUA 得到 33.8%，高于 Qwen3-VL-8B 的 26.4% 和 32B 的 30.9%。代码、模型权重与项目页均已开源。

## 3. 微软 SkillOpt：把技能文档当成可训练参数

微软研究院开源了 SkillOpt，论文《SkillOpt: Executive Strategy for Self-Evolving Agent Skills》5 月 25 日发布在 arXiv，编号 2605.23904，代码以 MIT 许可放在 GitHub。

核心主张是：Agent 的技能文档是它的「外部权重」，不训练模型权重也能用训练模型的方式去训这份自然语言文档。循环分四步，和深度学习一一对应。Rollout 是前向传播，冻结的目标模型拿着当前技能跑一批任务，留下完整执行轨迹；Reflect 是反向传播，一个独立的优化器模型分开反思失败与成功的样本；Edit 是参数更新，产出添加、删除、替换三类结构化编辑；Validate 是验证门控，候选技能必须在留出验证集上确实变好才被接受，被拒的编辑进入缓冲区，避免重复提出同样的无效改动。

论文报告的规模是 7 个目标模型、6 个基准、3 种执行环境，共 52 个组合，SkillOpt 全部达到最优或并列最优。GPT-5.5 在直接对话模式下平均提升 23.5 分，GPT-5.4-nano 平均提升 24.9 分，跨模型与跨环境迁移实验也报告了正收益。文本学习率被设为每步最多 4 个编辑操作，去掉这个约束后 SearchQA 从 87.1% 降到 84.6%。这些是论文自测数字。

落地成本的说法来自微软研究院高级研究 SDE 杨一帆对 VentureBeat 的表述：社区框架里用 Claude Sonnet 跑一轮技能训练平均需要 1 到 5 美元，且是一次性成本，部署时只需要一份 best_skill.md，推理侧没有额外开销。方法有明确边界——它需要一个可打分的评估函数，对开放式创意任务并不适用。

## 4. 英伟达 GB10：自研 CPU 的第一个产品形态露头

据量子位报道，英伟达正在研发一款集成 GB10 超级芯片的迷你 PC，定位为 AI 开发者的本地沙盒。GB10 把 NVIDIA GPU 与 20 核 ARM CPU 合到一颗芯片上，CPU 和 GPU 共享 LPDDR5X 内存。报道给出的限制是带宽：GPU 实际可用带宽约 273 GB/s。

这是路线图上的一个信号，不是产品发布。芯片此前主要以 SoC 形态用于数据中心与机器人，英伟达自研 CPU 的动机之一是减少对外部 CPU 供应的依赖。报道提到更多细节将在随后的 Computex GTC 台北主会场公布，因此这一节记的是预告。带宽数字来自中文媒体的转述，未见英伟达官方材料给出同一数字。

## 5. 人才与财务：DDIM 之父离职，四小虎数字外流

DDIM（Denoising Diffusion Implicit Models）的提出者宋佳铭宣布离职。据量子位报道，DDIM 的采样加速技术几乎是所有主流扩散图像生成工具的底层支撑，离职消息的时间点正值 Luma AI 凭 Dream Machine、Uni-1.1 等产品进入全球多模态第一梯队。报道未说明离职原因与去向。

四家大模型公司的财务数据同期被摆了出来。据 36 氪报道，智谱市值超过 7000 亿元但亏损 47 亿元，同比扩大 59.5%；MiniMax 最早实现自负盈亏，海外收入占比超过 70%，毛利率从 12.2% 提升到 25.4%；月之暗面在 K2.5 模型发布后 ARR 迅速突破 2 亿美元；阶跃星辰获得莲花控股投资。

同期还有一条收缩的消息：王小川在 5 月 26 日受访时说公司成立快两年时陷入迷茫，看不清楚创造什么价值，随后百川智能宣布战略收缩，把核心资源全面投入医疗这一垂直方向。这些数字与说法均来自 36 氪的报道，公司方面没有逐项确认，市值口径与亏损口径也未在报道中给出统计区间。
