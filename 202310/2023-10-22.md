# 2023-10-22 AI 大事件

北京时间 2023 年 10 月 22 日（星期日，国庆假期第二十二天）。这一天有两条「小改动、大效果」的研究：马里兰州大学、纽约大学等机构提出的微调正则化方法 NEFTune，只用一行代码就能让模型性能提升至少 10%；香港中文大学团队被 NeurIPS 2023 收录的多模态查询方法，把开放世界目标检测的准确率提升了 7.8%。人物侧则是陶哲轩再一次公开推荐 GitHub Copilot——这次他用它完成了新论文里的一页证明。

## 1. NEFTune：一行代码换来至少 10% 的微调提升

大模型微调也有「免费的午餐」了：只需一行代码，就能让微调后的模型性能提升至少 10%。来自马里兰州大学、纽约大学等机构的研究人员提出了一种名为 NEFT（une）的微调方式——这是一种新的正则化技术，用于提高监督微调（SFT）模型的性能。

效果是可量化的：在 7B 参数量的 Llama 2 上甚至出现了性能翻倍的结果，Mistral 也有四分之一的增长。值得注意的是，这种方法虽然用在监督微调阶段，但 RLHF 模型同样能从中受益。工程上的门槛也极低——该方法已被 HuggingFace 收录进 TRL 库，只要 import 再加一行代码就能调用，而且没有显著的成本增加。

这项工作针对的是微调阶段一个长期被忽视的细节：SFT 的数据量通常远小于预训练，在这种小数据量下模型容易过拟合，而常用的正则化手段（权重衰减、早停、数据增强）在生成式任务上收益有限。NEFTune 的做法是在训练时对嵌入层注入噪声，强迫模型不依赖单一的强信号特征——这与「 dropout 抑制过拟合」的直觉类似，但作用点放在了嵌入表示而非隐藏单元上。

## 2. 多模态查询方法：让「找东西」不再依赖文本描述

大模型的「识图」能力已经很强了，为什么在做目标检测时还常常找错东西？被 NeurIPS 2023 收录的一篇论文给出了答案：我们让大模型「找东西」时，输入的往往是文本，而当描述有歧义或过于偏门时，模型就会大为困惑——比如「bat」到底是蝙蝠还是球拍，或者像「魔鳉」（Cyprinodon diabolis）这种冷门物种。

该论文提出了一种基于多模态查询的开放世界目标检测方法：在查询环节就把图像信息引入，而不是只用文字描述目标，从而解决上述歧义与偏门词汇带来的失败。量子位报道中给出的量化结果是准确率提升 7.8%。

这个问题在开放世界检测里尤其突出。闭集目标检测的类别是预先枚举好的，模型见过的类别越多越准；而开放世界检测要面对未知的类别，依赖文本描述就成了唯一的入口——描述的分辨率决定了检测的上限。MQ-Det 这类工作的意义在于把「描述」这个瓶颈从语言侧转移到了多模态侧。

## 3. 陶哲轩再安利 Copilot：论文里只有一页的证明

继给 GPT-4「代言」之后，Copilot 也被陶哲轩疯狂安利。他直言，在编程时 Copilot 能直接预测出他下一步要做什么；有了 Copilot 之后，研究做起来也更方便，陶哲轩也用它辅助自己完成了最新的研究成果。

细节很具体：这次论文中相关部分的内容其实只有一页，但具体完成这一页纸的证明，他足足写了 200 多行代码，用的还是新学的编程语言 Lean4。而在陶哲轩公开代码的 GitHub 页面上显示，Copilot 将写代码的速度提升了一半以上。他之所以选择 Lean4，是看中它的「重写策略」。

Lean4 是 Lean 4 定理证明器的形式化语言，学习曲线极陡——这正是这个案例的价值所在：如果连形式化证明这种「写给验证器看」的高门槛代码，Copilot 都能在一半时间内帮着写完，那么「AI 辅助编程」的适用边界就被推到了比 IDE 补全更远的地方。

同日 TechCrunch 还报道，亚马逊的人形机器人 Digit 面临一场重要测试——机器人进入真实仓库作业的阶段，测试结果将直接关系到人形机器人能否从试点走向规模部署。
