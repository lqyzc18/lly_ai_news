# 2023-07-26 AI 大事件

北京时间 2023 年 7 月 26 日（星期三）。Stability AI 在亚马逊 AWS 纽约峰会上发布开源图像模型 Stable Diffusion XL 1.0（SDXL 1.0），并成为 Amazon Bedrock 首批可选的文生图基础模型之一；同日 AWS 公布一批生成式 AI 更新，Amazon Bedrock 新增 Anthropic Claude 2、Cohere Command 与 Cohere Embed，Agents for Amazon Bedrock 预览版上线，基于英伟达 H100 的 EC2 P5 实例正式商用。

## 1. SDXL 1.0 发布

据 Stability AI 的发布新闻稿，7 月 26 日，公司宣布发布其旗舰文生图系列最新、最先进的模型 Stable Diffusion XL（SDXL）1.0，并同时以开放获取（open access）的方式向开发者释出权重与 API 接入。SDXL 1.0 由 35 亿参数基座模型与 66 亿参数的集成（ensemble）管线组成，refiner 在基座模型输出之上补上更准确的颜色、更高对比度和更精细的细节；这是当时参数规模最大的开放获取图像模型之一。

在生成质量上，新模型相比前代能生成更鲜明准确的颜色、更好的对比度、光影效果；成像流程被精简，可在数秒内输出完整 1 兆像素（1024×1024）分辨率的图像，并支持多种宽高比。此次发布同时开放 Stability AI API、Stability AI 的 GitHub 页面以及面向消费者的 Clipdrop 与 DreamStudio 三个入口；Stability API 还新增了微调 beta 功能，用少量（最少五张）图片即可把生成效果专门化到特定人物、产品上，该功能正在与早期合作伙伴做有限测试，将于未来数周开放。

## 2. 生成式 AI 的使用规模

按官方公布的数据，自 4 月 13 日 SDXL beta 上线以来，ClipDrop 用户已用该模型生成超过 3500 万张图像，Stability AI 的 Discord 社区平均每天生成 2 万张图像。此前在 6 月发布的 SDXL 0.9 是仅供研究使用的版本，它提供了大量使用场景测试数据，让开发者能够据此微调模型以获得更好结果；这次发布的 1.0 就是在这一轮精修之后的结果。

Stability AI CEO Emad Mostaque 表示，最新的 SDXL 模型代表了公司在把最前沿的开放获取模型带给 AI 社区方面的下一步，在 Amazon Bedrock 上首发 1.0 也体现了公司与 AWS 为开发者和客户协同提供解决方案的承诺。

## 3. AWS 纽约峰会的一批更新

SDXL 1.0 是在 AWS 年度纽约峰会上发布的，并成为 Amazon Bedrock 首发模型之一。AWS 数据库、分析与机器学习副总裁 Swami Sivasubramanian 表示，模型选择对最大化客户在生成式 AI 上的价值至关重要，Bedrock 正是为了让客户能够以全托管体验获取并定制最合适的顶级基础模型；随着 SDXL 1.0 加入，客户可以用上最先进的文生图基础模型来构建和扩展新的生成式 AI 应用。

同批发布的基础模型还有 Anthropic Claude 2 与 Cohere 的 Command、Embed 三款；Bedrock 推出 Agents for Amazon Bedrock 预览版，开发者可以通过简单的 API 把基础模型安全地连接到自有数据源并自动编排任务，无需编写代码。基础设施侧，AWS 与英伟达宣布基于 H100 的 EC2 P5 实例正式商用；AWS Entity Resolution 宣布正式可用（GA）；QuickSight 推出生成式 AI 助手 QuickSight Q，OpenSearch Serverless 推出向量引擎预览。SDXL 1.0 同时上架 Amazon SageMaker JumpStart。

## 4. 开放获取路线与商业化的绑定

SDXL 1.0 以 CreativeML OpenRAIL++-M 协议发布，允许在保留署名与使用限制的前提下商用，权重与代码同步在 GitHub 开放；这延续了 Stability AI 一贯的开放获取路线，也是它能在两个月内积累起千万级生成量、同时被云厂商纳入托管服务目录的原因。

Stability AI 与 AWS 的绑定则始于 2022 年：当年 Stability AI 选择 AWS 作为首选云厂商，在 Amazon SageMaker 上构建其基础模型；今年 4 月 Amazon Bedrock 上线时，Stable Diffusion 就是最早可用的基础模型之一。发布 SDXL 1.0 前一周，Stability AI 刚上线新的开发者平台站点，并推出草图转图像的 Stable Doodle，上线一周内生成图像超过 300 万张。这一连串动作说明它正在把「开放权重 + 消费级应用 + 云托管分发」三条线同时铺开。
