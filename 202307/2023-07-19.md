# 2023-07-19 AI 大事件

北京时间 2023 年 7 月 19 日（星期三）。Meta 发布 Llama 2 系列开源权重模型，参数规模 7B、13B、70B 三档，上下文窗口 4096 token，预训练用了 2 万亿 token 的公开网络数据，并首次允许一定条件下的商业使用。官方博客按太平洋时区标注的发布日为 7 月 18 日。

## 1. Llama 2：发布即开放商用

Meta 与微软联合发布 Llama 2 下一代模型，同时放出预训练权重和对话版权重（Llama 2-Chat）。参数规模为 7B、13B、70B 三档，另有 34B 的基座与对话模型在论文中报告但因红队测试未完成而未发布。四个规格都使用仅含解码器的 Transformer、4096 token 上下文窗口和 32000 词表的 SentencePiece 分词器；34B 与 70B 配置使用分组查询注意力，7B 与 13B 使用普通多头注意力。

与前代 LLaMA 相比，公开可见的变化包括：上下文窗口从 2048 翻倍到 4096 token，预训练 token 数增加约 40%，数据清洗与配比重做，以及在两个较大配置中引入分组查询注意力。分组查询注意力让 34B 与 70B 模型在查询头之间共享键值投影，减小了生成时的键值缓存占用，目的是提升推理的可扩展性。

许可证方面，Llama 2 社区许可授予非独占、全球、不可转让、免版税的有限使用权，研究与大量商业用途都在授权范围内，但有若干条件：分发方必须提供许可并保留 Meta 指定的署名声明；使用须符合适用法律与 Llama 2 可接受使用政策；材料或其输出不得用于改进其他大语言模型（Llama 2 及其衍生模型除外）；发布前一个月月活超过 7 亿的机构须另行向 Meta 申请许可；就材料或输出提起特定知识产权诉讼将终止授权。Meta 在发布时称其为开源，但开源社区协会（OSI）随后回应称该许可不满足开源定义，因为它限制了部分用户和领域，「开放权重」才准确描述了其中的技术事实。

## 2. 训练与评测

所有规格都用 AdamW（beta 0.9 与 0.95）、余弦学习率调度、2000 步预热、权重衰减 0.1、梯度裁剪 1.0，以及 400 万 token 的全局批大小训练。论文称训练损失在处理的 2 万亿 token 过程中持续下降，运行时未出现饱和。预训练在 Meta 的研究超算集群与内部生产集群上进行，使用 NVIDIA A100 80GB GPU，两种环境的网络互联与功率上限不同（350W 或 400W）。

论文报告的分词后训练流程是：先做有监督微调，研究团队报告称少量精心审核的样本优于数百万条第三方低质样本，在收集到 27540 条标注后停止并微调两个 epoch，损失只在回答 token 上计算；随后是有用性与安全性两套奖励模型，分别训练，共用到 1418091 组内部成对比较，混合公开偏好数据后奖励模型共 2919326 组比较；再用拒绝采样与 PPO 做五轮 RLHF。对话模型还使用 Ghost Attention：在微调时把控制指令合成放到后续用户消息旁边，训练后移除重复指令，论文报告角色、语言或格式约束在约 20 轮对话内的保持能力明显增强。

评测数字均为开发者自报结果。基座模型在 MMLU 五样本上 7B 为 45.3、13B 为 54.8、70B 为 62.6；HumanEval 与 MBPP 平均通过率 7B 16.8、13B 24.5、70B 27.8。对话模型 70B 对比 gpt-3.5-turbo-0301，在约 4000 条单轮与多轮提示的人工比较中取得 36% 胜率、31.5% 平局；安全性方面公司称违规率较低，但同时说明多轮对话比单轮更容易产生违规。
