# 2023-07-06 AI 大事件

北京时间 2023 年 7 月 6 日（星期四）。当日主线是2023 世界人工智能大会（WAIC）上海开幕：30 余款大模型、20 余款机器人、10 余款芯片集中首发与OpenAI 全面开放 GPT-4 API（8K 上下文），并宣布 7 月内向 ChatGPT Plus 用户开放 Code Interpreter。

## 1. 2023 世界人工智能大会（WAIC）上海开幕：30 余款大模型、20 余款机器人、10 余款芯

产业与生态2023 世界人工智能大会（WAIC）上海开幕：30 余款大模型、20 余款机器人、10 余款芯片集中首发。第六届世界人工智能大会 7 月 6—8 日在上海世博中心及世博展览馆举行，由上海市政府与国家发改委、工信部、科技部、国家网信办、中科院等七部门共同主办，主题“智联世界 生成未来”。5 万平方米主展览创历届之最，参展企业超 400 家、优秀初创企业超 50 家、首发首展新品 30 余款，集中展示 30 余款大模型、20 余款智能机器人、10 余款大模型应用芯片。工信部副部长徐晓兰在开幕式称，我国人工智能核心产业规模已达 5000 亿元，企业数量超 4300 家。

2023-07-06 至 07-08，上海世博中心及世博展览馆5 万平方米展览、参展企业超 400 家、首发新品 30 余款工信部口径：AI 核心产业规模 5000 亿元、企业超 4300 家华为昇腾 AI“大模型超级工厂”、百度文心一格、Amazon Bedrock 获评“镇馆之宝”OpenAI 全面开放 GPT-4 API（8K 上下文），并宣布 7 月内向 ChatGPT Plus 用户开放 Code Interpreter。OpenAI 在官方博客宣布 GPT-4 API 取消候补名单，所有有成功付费记录的 API 开发者立即可调用 8K 上下文版本，7 月底前向新开发者开放，随后按算力供给提升速率限制。

同期 GPT-3.5 Turbo、DALL·E、Whisper API 一并转为正式可用。官方称自 3 月推出 Chat Completions API 以来，其调用量已占 API GPT 总用量的 97%，并宣布 ada/babbage/curie/davinci 等 11 个 Completions API 旧模型将于 2024 年 1 月 4 日下线。Code Interpreter 将在一周内向全部 ChatGPT Plus 用户开放。GPT-4 API 上下文 8K（32K 版本当时仍未开放）Chat Completions API 占 API GPT 用量 97%11 个 Completions API 旧模型 2024-01-04 下线微调能力（GPT-4 / GPT-3.5 Turbo）预计年内推出
