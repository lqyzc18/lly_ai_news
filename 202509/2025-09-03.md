# 2025-09-03 AI 大事件

北京时间 2025 年 9 月 3 日（星期三）。微软开源 14B 参数的 rStar2-Agent 数学推理模型，官方称训练高效且泛化能力强。苹果与学术机构联合发布 STARFlow 图像生成系统，并在 Hugging Face 推出 FastVLM 试用版。法国 Mistral 推出企业级 AI 平台与新模型，性能超过 GPT-4o 而成本更低。

## 1. 微软开源 rStar2-Agent

微软开源 14B 参数的 rStar2-Agent 数学推理模型，官方称训练高效且泛化能力强。同一天，谷歌 Gemini API 上线 URL Context 功能，可深度处理网页、PDF 和图像等内容；微软 Copilot 推出免费多文件分析功能，支持跨文件推理并新增学习模式。

## 2. 苹果连发两个开源模型

苹果与学术机构联合发布 STARFlow AI 图像生成系统，性能接近主流模型；并在 Hugging Face 推出 FastVLM 视觉语言模型试用版，官方称提速 85 倍并保持数据隐私。

## 3. Mistral 与智谱的两个动作

法国 Mistral 推出企业级 AI 平台与新模型，性能超 GPT-4o 且成本更低。智谱则推出面向 Claude Code 的专属包月套餐，20 元一个月，支持 GLM-4.5 及 GLM-4.5-Air 模型。

生态侧，腾讯优图实验室开源 Youtu-Agent 智能体框架，微软与美政府签协议免费提供 365 Copilot 服务；清华等机构联合研究表明 SSRL 可显著提升 Search Agent 的训练效率与稳定性。
