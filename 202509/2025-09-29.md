# 2025-09-29 AI 大事件

北京时间 2025 年 9 月 29 日（星期二）。DeepSeek 正式发布实验性版本新模型 DeepSeek-V3.2-Exp，在 V3.1-Terminus 基础上引入 DeepSeek 稀疏注意力机制，官方称 API 价格将降低 50% 以上。OpenAI 推出 ChatGPT 即时结账服务，可购买 Etsy 与部分 Shopify 平台的商品。蚂蚁百灵则开源了两款思考模型，把推理成本降到同等密集模型的十分之一。

## 1. DeepSeek-V3.2-Exp

DeepSeek 正式发布实验性版本新模型 DeepSeek-V3.2-Exp，这是其向新一代架构迈进的中间步骤。

该版本在 V3.1-Terminus 的基础上引入了 DeepSeek 稀疏注意力机制（DSA），旨在优化长文本的训练和推理效率。相比前一版本，官方称无论长文本还是短文本任务性能都没有实质下降，但在实际部署的推理成本测试中，端到端的加速效果和成本节约效果非常显著——这为之后的模型提供了一条「性能不降、成本骤减」的工程路径。官方 App、网页端和小程序已同步更新，API 价格大幅降低，开发者调用成本将降低 50% 以上。

## 2. ChatGPT 即时结账；xAI 第六次起诉 OpenAI

OpenAI 推出 ChatGPT 即时结账服务，用户可以直接在对话中购买 Etsy 以及部分 Shopify 平台的商品。马斯克旗下 xAI 第六次起诉 OpenAI，指其挖走核心员工并窃取商业机密。

产品与安全侧还有几条：OpenAI 秘密测试 ChatGPT 新安全路由系统，能自动切换模型处理敏感或情绪化对话；OpenAI 推出 ChatGPT 家长控制，可关联账户并自定义设置；阿里云发布 Qwen3Guard 安全模型，优化分类任务并支持多语言。

## 3. 开源模型与算力引擎

蚂蚁百灵开源两款思考模型，推理成本降至同等密集模型的十分之一。京东推出国产芯片 xLLM 推理引擎，提升 AI 部署性能并降低成本。优必选与天奇签订 3000 万机器人采购合同，Walker 系列订单累计近 4.3 亿元。

研究一侧，加州理工团队创造了全球最大中性原子量子计算机，单比特操控精度达 99.98%；中国农科院研发 AlphaCD，可设计基因编辑工具，相关成果登上《细胞研究》。

## 4. 消费与娱乐侧

趣丸科技推出国内首个对话式音乐创作 Agent Tunee，并全球公测。苹果发布 Manzano 图像模型，性能比肩 GPT-4o 与 Nano Banana。德国海德堡用 AI「城市扫描仪」提高停车执法效率，违章率下降。
