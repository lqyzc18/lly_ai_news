# 2025-09-05 AI 大事件

北京时间 2025 年 9 月 5 日（星期五）。Anthropic 宣布禁止中资企业使用其服务，国内智谱、商汤日日新等模型厂商随即推出兼容计划，方便开发者快速迁移。月之暗面发布 Kimi K2 的最新版本 0905，上下文长度从 128K 扩到 256K。字节跳动的 Seedream 4.0 同日上线。

## 1. Anthropic 禁止中资企业使用其服务

Anthropic 宣布禁止中资企业使用其 AI 服务，理由是应对法律与国家安全风险。官方说法里，中国控股公司被排除在外。

国内厂商当天的反应是给出替代方案：智谱、商汤日日新等模型厂商宣布推出兼容计划，方便开发者快速迁移。智谱在本周还推出了 20 元包月的 GLM Coding Plan，可接入 Claude Code 使用，并推出兼容 Claude 协议的 API 搬家计划。

## 2. Kimi K2-0905 与 Seedream 4.0

月之暗面发布 Kimi K2 模型的最新版本 0905，显著提升真实编程任务中的表现，Agentic Coding 能力有进步，前端编程体验改善，上下文长度从 128K 扩到 256K，并继续提供输出速度 60 到 100 token/s 的高速 API。

字节跳动 Seed 宣布 Seedream 4.0 上线，并同步新增扣子空间的设计模式，支持多图融合、组图生成和画面修改。

## 3. 其他几条消息

OpenAI 向免费用户开放 ChatGPT Projects 功能。谷歌开源 3.08 亿参数的端侧嵌入模型 EmbeddingGemma，可在无网络环境下运行，性能与尺寸翻倍的 Qwen-Embedding-0.6B 相当。法国 Mistral AI 获 20 亿欧元投资，估值达 120 亿欧元。苹果则传出计划明年春天推出自研 AI 搜索引擎「世界知识问答」，用来增强 Siri 的搜索能力。
