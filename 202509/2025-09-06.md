# 2025-09-06 AI 大事件

北京时间 2025 年 9 月 6 日（星期六）。阿里通义千问推出 Qwen3-Max-Preview，参数量超过 1 万亿，是全球第一个免费开放的万亿参数模型。开发工具一侧，Cursor 正式发布 Background Agents API，处于 Beta 阶段，允许开发者以编程方式创建并管理可在 GitHub 仓库中自主工作的 AI 编码 Agent。

## 1. 阿里发布 Qwen3-Max-Preview

阿里通义千问 Qwen3-Max-Preview（Instruct）模型正式上线，参数量超过 1 万亿，是全球第一个免费开放的万亿参数模型。

官方称该模型在多项权威基准测试中表现出全球领先的性能，包括通用知识、数学推理、编程以及人类偏好对齐等领域，超过 Claude-Opus 4 和 Kimi-K2 等竞争对手。内部测试和早期用户反馈显示，Qwen3-Max-Preview 不仅具备更强的智能水平和更广的知识面，还在对话能力以及 Agent 任务和指令遵循方面展现出卓越性能。

## 2. Cursor 发布 Background Agents API

Cursor 正式发布 Background Agents API，目前处于 Beta 阶段。该接口允许开发者以编程方式创建并管理可在 GitHub 仓库中自主工作的 AI 编码 Agent，这些 Agent 能够自动响应用户反馈、修复缺陷、更新文档等。

## 3. 同日的其他消息

腾讯 ARC 实验室公开了 AudioStory 项目，实现基于大语言模型的长时叙事音频生成：通过 LLM 把复杂指令拆解成带时间顺序的子任务，在视频配音、音频续写、长音频合成等应用中保持情节连贯与情感一致。

产品侧，OpenAI 为 ChatGPT 推出「对话分支」功能，改变单一对话模式；智谱推出兼容 Claude 协议的 API 搬家计划；特斯拉 Robotaxi 应用对公众开放，马斯克称年底将不再配安全员。
