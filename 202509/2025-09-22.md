# 2025-09-22 AI 大事件

北京时间 2025 年 9 月 22 日（星期二）。xAI 推出轻量级模型 Grok 4 Fast，官方称计算量下降 40%、单任务成本最高减少 98%。DeepSeek 线上模型升至 V3.1-Terminus，在「人类最后的考试」上的成绩从 15.9 提升到 21.7。美团发布高效推理模型 LongCat-Flash-Thinking，在保证 90% 准确率的前提下，比不使用工具调用节省 64.5% 的 token。

## 1. Grok 4 Fast 与 DeepSeek V3.1-Terminus

xAI 推出轻量级模型 Grok 4 Fast，主打打破智能与成本之间的界限。据 Artificial Analysis 的报告，Grok 4 Fast 在众多智能基准测试中表现出色，与 Gemini 2.5 Pro 相当、仅次于 GPT-5，得分为 60 分。

成本是它的卖点：API 层面每百万输入 token 仅需 0.2 美元、每百万输出 token 0.5 美元，相较于 Gemini 2.5 Pro 等领先模型便宜约 25 倍；在执行同样任务时消耗的 token 显著减少，为 6100 万。这一版首次把推理模式和非推理模式合二为一，支持 200 万 token 上下文。

DeepSeek 同日发布 V3.1-Terminus，针对用户反馈做了改善，增强语言一致性，缓解中英文混杂及偶发字符问题，同时优化了 Code Agent 和 Search Agent 的表现。成绩上，HLE 从 15.9 提升到 21.7，仅次于 Grok-4 的 25.4 和 GPT-5 的 25.3，超过 Gemini 2.5 Pro 的 21.6。模型已在官方 App、网页端、小程序与 API 同步更新。

## 2. 美团发布 LongCat-Flash-Thinking

美团发布高效推理模型 LongCat-Flash-Thinking。美团表示，基于 AIME25 实测数据，该模型在框架下展现出更高效的智能体工具调用能力：在确保 90% 准确率的前提下，相较于不使用工具调用节省了 64.5% 的 token。

模型已在 Hugging Face 和 GitHub 全面开源，也可以在官网体验。这是美团在 8 月底开源 LongCat-Flash 之后，把「思考」这条线也补齐了。

## 3. 谷歌提出新的 Agent 研究框架

谷歌突破传统「规划—检索—生成」模式，提出新的研究框架，先打草稿再迭代修正。方向上，它承认当前 pipeline 里检索与生成之间的接口是效率损失的主要来源之一。

同一批消息里，Meta 为 Facebook Dating 推出 AI 助手及新功能，官方称年轻用户匹配次数有所增长但规模仍逊于对手；百度智能云推出面向企业级视觉理解的大模型 Qianfan-VL 系列并开源；IBM 发布小型视觉语言模型 Granite-Docling-258M。

## 4. 硬件与研究侧

联发科推出新一代旗舰 5G 智能体 AI 芯片天玑 9500，NPU 性能提升且功耗降低。谷歌 DeepMind 更新其核心 AI 安全框架，把模型阻止关闭或修改自己等风险也纳入考量。Meta 发布新款 Meta Ray-Ban Display 智能眼镜，并计划 2027 年推出具备双屏功能以及全息 AR 眼镜。
