# 2025-09-17 AI 大事件

北京时间 2025 年 9 月 17 日（星期三）。阿里开源旗下首个深度研究 Agent 模型通义 DeepResearch，30B 总参数、3B 激活，在「人类最后的考试」上取得 32.9% 的开源最好成绩。谷歌 DeepMind 则推出具备差分隐私能力的大型语言模型 VaultGemma。人形机器人公司 Figure 完成超 10 亿美元 C 轮融资，估值 390 亿美元。

## 1. 阿里开源通义 DeepResearch

阿里开源旗下首个深度研究 Agent 模型——通义 DeepResearch，模型、框架和方案均已全面开源。

它能把宏大的用户问题拆解为一系列逻辑清晰的子任务，为每个环节自主调用代码分析、论文检索和网页访问等工具，层层递进、自主循环地完成整条研究链路。成绩上，在 HLE、BrowseComp-zh、GAIA 等多个权威评测集上取得 SOTA，超越 OpenAI Deep Research、DeepSeek-V3.1 等 Agent 模型；HLE 得分 32.9%，BrowseComp-zh 43.3%。模型参数 30B、激活参数 3B，项目在 GitHub 上已获超过 7200 个 Star。

## 2. DeepMind 的 VaultGemma 与安全评测

DeepMind 推出具备差分隐私能力的大型语言模型 VaultGemma，把差分隐私训练带进通用语言模型的发布流程里。

国内这边，一份覆盖主流大模型的众测报告发现了 281 个安全漏洞，官方据此提出四项安全治理要求。迪士尼等好莱坞影业巨头则指控中国 MiniMax 旗下海螺 AI 服务存在严重版权侵权。OpenAI 与 Anthropic 首次合作测试 AI 模型，专门用于识别各自的安全盲点。

## 3. 平台与工具侧

微软 Copilot Chat 集成至 Microsoft 365 核心应用，基础版免费向用户提供。OpenAI 推出 18 岁以下用户专属的 ChatGPT 体验，配备家长控制功能。全球首个 Agent 交易市场 MuleRun 正式上线，支持 Agent 技能的买卖与租赁。

国内方面，腾讯宣布全面开放 AI 能力，适配主流国产芯片并提供优化算力；抖音推出「AI 抖音求真」功能用于澄清误导性内容与谣言，官方称一个季度谣言曝光量下降 67%。

## 4. 模型与资本侧

蚂蚁百灵团队开源高性能推理模型 Ring-mini-2.0；逻辑智能推出 LLaSO，全球首个全开源端到端语音大模型框架；BentoML 推出 llm-optimizer 开源框架，简化 LLM 基准测试与性能调优。

资本端，人形机器人公司 Figure 完成超 10 亿美元 C 轮融资，估值 390 亿美元；英国 Nothing 完成 2 亿美元 C 轮融资，计划明年推出 AI 原生设备。就业市场也在变，AI 岗位数量激增十倍，字节跳动、小红书、阿里成招聘热门前三。

## 5. 当天的其他动态

阿里开源通义DeepResearch，权威评测超OpenAI等旗舰模型且开源。 奥特曼发博客承诺更新隐私政策，ChatGPT将不再与青少年谈自杀话题。 微软Copilot新增记忆管理功能，并计划集成Google Drive连接器。

国内AI大模型众测发现281个安全漏洞，官方提出四项安全治理要求。 腾讯云ADP3.0升级RAG等工具链，近3月完成近600功能上线。 硅基流动推出腾讯混元翻译模型Hunyuan-MT-7B，支持33个语种互译。

AI巨头Anthropic与OpenAI斥巨资打造“AI同事”，或带来工作模式的重大变革。 YouTube为Shorts创作者推出生成式AI工具，引入谷歌Veo 3定制版助力短视频创作。 Deepdub发布Lightning2.5语音AI模型，实现实时语音处理升级提升效率。
