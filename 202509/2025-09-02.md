# 2025-09-02 AI 大事件

北京时间 2025 年 9 月 2 日（星期二）。腾讯发布并开源首个支持原生 3D 重建的超长漫游世界模型混元 Voyager。通义实验室发布开源智能体开发框架 AgentScope 1.0。国际厂商一侧，OpenAI 计划在印度建 1GW 级「星际之门」数据中心，法国 Mistral 则推出企业级 AI 平台与新模型，性能超 GPT-4o 而成本更低。

## 1. 腾讯混元发布混元 Voyager

腾讯混元 3D 世界模型系列的最新成员 HunyuanWorld-Voyager（混元 Voyager）正式发布，成为首个支持原生 3D 重建的超长漫游世界模型。

这个模型专注在 AI 的空间智能方向，目标是把高保真的 3D 场景漫游能力推进到虚拟现实、物理仿真和游戏开发等领域——从「生成一段视频」走向「在一个世界里待一会儿」。原生 3D 重建是关键：场景不是渲染出来的画面，而是可被测量、可被漫游的几何体。

## 2. 通义 AgentScope 1.0 与苹果的 Asa

通义实验室发布开源智能体开发框架 AgentScope 1.0，以提升开发效率。苹果推 AI 聊天机器人 Asa，用于提升员工的产品知识和销售技巧，目前仍在测试阶段。

微软发布实验性 AI 中心 Copilot Labs，首推文本转语音工具。即梦 AI 联合火山引擎开放 AI 模型 API 服务，帮助企业高效接入实现创意。

## 3. 工具链与研究侧

微软开源 14B 参数的 rStar2-Agent 数学推理模型，官方称训练高效且泛化能力强；清华等机构联合研究表明 SSRL 可显著提升 Search Agent 的训练效率与稳定性。腾讯优图实验室开源 Youtu-Agent 智能体框架，架构灵活、成本低；DeepSeek 则发布大模型训练原理，把预训练与优化训练两个环节拆开讲。

平台侧，谷歌 Gemini API 上线 URL Context 功能，可深度处理网页、PDF 和图像等内容；微软 Copilot 推出免费多文件分析功能，支持跨文件推理并新增学习模式。

## 4. 生态与合规

苹果与学术机构联合发布 STARFlow AI 图像生成系统，性能接近主流模型；并在 Hugging Face 推出 FastVLM 视觉语言模型试用版，官方称提速 85 倍且保持数据隐私。智谱推出面向 Claude Code 的专属包月套餐，20 元一个月，支持 GLM-4.5 及 GLM-4.5-Air。

微软与美国政府签协议，免费提供 365 Copilot 服务，推动 AI 和数字技术应用。视觉中国版权交易平台升级 AI 生成内容标识，确保内容透明度可追溯。
