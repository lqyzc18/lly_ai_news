# 2025-04-15 AI 大事件

北京时间 2025 年 4 月 15 日（星期二）。OpenAI 以 API 形式推出 GPT-4.1 模型家族，全面超过 GPT-4o，同时给出 GPT-4.5 的停用时间表：2025 年 7 月 14 日起停止通过 API 提供。苹果在 iOS 18.5、macOS 15.5 测试版里开始对用户数据做基于设备的隐私中心分析。开源一侧，DeepSeek 宣布将开源推理引擎，Google 也放出面向智能体开发的开源 Agent SDK。

## 1. OpenAI 发布 GPT-4.1 家族，GPT-4.5 定了下线日期

OpenAI 以 API 形式推出 GPT-4.1 模型家族，包括 GPT-4.1、GPT-4.1 mini 和 GPT-4.1 nano。官方说法是它们在编码、指令遵循和长上下文理解方面表现出色。

同批披露的还有一条时间表：OpenAI 计划在 2025 年 7 月 14 日停止通过 API 提供 GPT-4.5，此前该模型于 2 月 27 日作为研究预览版发布。另据同期的中文早报，GPT-4.1 系列由中科大校友 Jiahui Yu 领衔打造，三款模型均拥有最高 100 万 token 的超长上下文窗口，知识截止日期更新至 2024 年 6 月；GPT-4.1 nano 是 OpenAI 首个 nano 尺寸的模型。

## 2. 苹果：iOS 18.5 测试版里的设备端隐私分析

据 4 月 16 日的每日 AIGC 早报，苹果计划在 iOS 18.5、macOS 15.5 测试版中开始对用户数据进行基于设备的、以隐私为中心的分析，并将其与合成数据进行比较，以改进 AI。

同一批报道还提到苹果披露的 AI 隐私保护技术细节，运用差分隐私与合成数据保障隐私。

## 3. DeepSeek 将开源推理引擎，谷歌放出开源 Agent SDK

据 4 月 15 日的每日 AI 早报，DeepSeek 宣布将开源推理引擎，与现有开源项目合作提取可复用组件。同一天，谷歌发布开源 Agent SDK，一站式支持智能体开发，简化构建流程。

中国一侧另有两条应用层面的消息：据同一天的早报，高德地图推出全球首个 AI 导航智能体，实现智能出行与情感交互；蚂蚁集团推出"百大 AI 名医"计划，百位名医的 AI 助手一年内上线，首批已在支付宝上线。
