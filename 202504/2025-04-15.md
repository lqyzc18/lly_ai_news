# 2025-04-15 AI 大事件

北京时间 2025 年 4 月 15 日（星期二）。OpenAI 以 API 形式推出 GPT-4.1 模型家族，全面超过 GPT-4o，同时给出 GPT-4.5 的停用时间表：2025 年 7 月 14 日起停止通过 API 提供。苹果在 iOS 18.5、macOS 15.5 测试版里开始对用户数据做基于设备的隐私中心分析。开源一侧，DeepSeek 宣布将开源推理引擎，Google 也放出面向智能体开发的开源 Agent SDK。国产模型一侧，智谱开源了 GLM-4-Air-0414 与 GLM-Z1 系列，并正式启动 IPO 辅导，成为大模型"六小龙"中首家启动上市流程的公司。

## 1. OpenAI 发布 GPT-4.1 家族，GPT-4.5 定了下线日期

OpenAI 以 API 形式推出 GPT-4.1 模型家族，包括 GPT-4.1、GPT-4.1 mini 和 GPT-4.1 nano。官方说法是它们在编码、指令遵循和长上下文理解方面表现出色。

同批披露的还有一条时间表：OpenAI 计划在 2025 年 7 月 14 日停止通过 API 提供 GPT-4.5，此前该模型于 2 月 27 日作为研究预览版发布。另据同期的中文早报，GPT-4.1 系列由中科大校友 Jiahui Yu 领衔打造，三款模型均拥有最高 100 万 token 的超长上下文窗口，知识截止日期更新至 2024 年 6 月；GPT-4.1 nano 是 OpenAI 首个 nano 尺寸的模型。

同日 OpenAI 还发布了 GPT-4.1 提示工程指南，放在 openai-cookbook 仓库中，以 notebook 形式提供可复现的示例。发布模型与发布调优方法同天进行，这在 OpenAI 的节奏里并不常见——它意味着 4.1 系列的很多能力需要靠提示词组织才能兑现，而提示词技巧的迁移成本被提前摆到了开发者面前。

把 nano 这个尺寸单独拿出来看更有意思：GPT-4.1 nano 是 OpenAI 第一个 nano 档模型，与 100 万 token 上下文搭配，构成的是"极低成本 + 极长上下文"这一在批量处理任务上很少见的组合。此前 API 侧最小的尺寸是 mini，很多企业做文档级预处理时只能承受 mini 的单价。

## 2. 苹果：iOS 18.5 测试版里的设备端隐私分析

据 4 月 16 日的每日 AIGC 早报，苹果计划在 iOS 18.5、macOS 15.5 测试版中开始对用户数据进行基于设备的、以隐私为中心的分析，并将其与合成数据进行比较，以改进 AI。

同一批报道还提到苹果披露的 AI 隐私保护技术细节，运用差分隐私与合成数据保障隐私。

这条思路值得单独点出：苹果没有选择"把数据发回服务器再分析"，而是把差分隐私计算放到设备上跑，再用合成数据作为对照基准。前者解决的是"原始数据不出设备"，后者解决的是"连统计量也不泄露"——如果两者的差分足够小，就能在不暴露任何单条用户数据的前提下判断模型改进是否有效。对一家把隐私当作产品卖点的公司来说，这是把叙事落到了固件与模型迭代流程里。

放到 WWDC 2025 的时间线上看，这个动作的时点也合理：Apple Intelligence 当时在美区推进，模型侧的迭代需要一条不依赖用户原始数据的评估路径，否则每次改模型都要重新走一遍隐私合规审批。

## 3. 智谱开源 GLM-4-Air-0414 与 GLM-Z1 系列，32B 媲美 DeepSeek R1

智谱开源了 32B / 9B 系列的 GLM 模型，报道给出的对比是 32B 版本参数规模媲美 DeepSeek R1，而生成速度快 8 倍。同一批发布的还有三类模型：沉思模型 GLM-Z1-Rumination、推理模型 GLM-Z1-Air，以及基座模型 GLM-4-Air-0414，各有 9B 和 32B 两个版本。

"Air"这一命名指向的正是这类模型的核心取舍——在激活参数受控的前提下把推理速度做上去。与同期开源的推理模型普遍把算力堆在采样步数上不同，智谱选择用更少激活参数、更多并行度换取吞吐，这也是它把"速度快 8 倍"作为主打的理由。

同一天智谱还启动了 IPO 辅导程序，目标是成为 A 股首家大模型公司。这让它成为大模型"六小龙"里第一家启动上市流程的公司，辅导计划拟在 2025 年 8 至 10 月完成。选在这个时点启动，与国内大模型公司普遍在 2025 年推进商业化、同时需要为算力投入建立公开融资渠道的节奏吻合。

## 4. MCP 成为当日最密集的协议层动向

DeepSeek 宣布将开源推理引擎，与现有开源项目合作提取可复用组件。同一份早报还提到，谷歌发布开源 Agent SDK，一站式支持智能体开发，简化构建流程。

国内一侧的协议层动作同样密集。腾讯云大模型知识引擎升级，新增对 MCP 协议的支持，赋能应用开发；中国一侧另有两条应用层面的消息——高德地图推出全球首个 AI 导航智能体，实现智能出行与情感交互，蚂蚁集团推出"百大 AI 名医"计划，百位名医的 AI 助手一年内上线，首批已在支付宝上线。

把 MCP 当作开发者协议只是其中一半含义。DeepSeek 宣布将开源推理引擎、谷歌发布开源 Agent SDK、腾讯云把 MCP 支持加进知识引擎，这些动作指向同一个方向：智能体需要的不只是能调用工具，还要有一层统一的能力发现与接入机制。蚂蚁的"百大 AI 名医"计划则是这条链的下游——把专业服务装进智能体后，谁来提供这些专业能力、由谁结算、如何约束风险，决定了它能否真正跑起来。

## 5. 阿里通义与小鹏、字节的同日动作

同一天的另两条消息覆盖了数字人与芯片。阿里通义实验室推出新型数字人生成模型 OmniTalker，音视频合成更真实，相关论文为 arXiv 2504.02433，并提供了在线体验空间。小鹏汽车自研的图灵 AI 芯片将于 2025 年量产，用于支持 L4 自动驾驶。

马斯克同日宣布特斯拉即将推出纯 AI 全自动驾驶解决方案，把自研图灵芯片的量产时间表与"纯 AI 全自动驾驶"的路线绑在一起说，指向的是同一件事：不依赖人类司机的量产车型需要车端算力，而车端算力的瓶颈已经变成模型推理而不是感知。OmniTalker 则是另一种资源密集型推理的产物——数字人要求毫秒级的语音与口型同步，延迟预算比文本模型紧得多，这也是它单列一个模型而不是并入通义通用模型的原因。
