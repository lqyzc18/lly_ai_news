# 2025-02-08 AI 大事件

北京时间 2025 年 2 月 8 日（星期六）。DeepSeek 的落地潮从云厂商蔓延到终端：腾讯云正式上线 R1 与 V3 原版模型的 API 并率先打通联网搜索，荣耀、七彩虹、百度智能云的行业应用也相继接入。生成侧也有新动作：谷歌把 Imagen 3 放进 Gemini API、每张 0.03 美元，Pika 推出 Pikadditions 把人或物「P」进视频，Meta 则用 VideoJAM 框架补上视频模型的运动一致性短板。

## 1. 腾讯云上线 DeepSeek 全系 API，打通联网搜索

据 2 月 8 日的报道，腾讯云宣布完成对深度求索大模型的深度整合，正式上线 DeepSeek-R1 与 V3 原版模型的 API 接口，并接入自研的大模型知识引擎，同步开放联网搜索能力。腾讯云称，凭其在推理并发与生成速率上的优化，用户可以获得更稳定、安全、低门槛的使用体验，开发者只需在云上三步即可完成 API 调用。

知识引擎提供的能力被逐项列出：文档解析、拆分、embedding 与多轮改写。应用搭建模式下，知识引擎内置 DeepSeek-R1 与 V3，开发者可按需选择模型并用拖拉拽方式搭建应用；企业用户还可上传私域知识，借助平台自研的长文本 embedding、OCR 与多模态能力，以及 LLM+RAG 框架，解决知识处理与答案生成的全链路难点。

联网搜索是这次的重点之一。腾讯云称其率先支持在构建大模型应用时配置联网搜索能力，可以突破预训练数据的时间限制；该功能依托腾讯云搜索增强 API 接口，由搜狗搜索引擎提供支持。报道没有披露上线区域、限流阈值与价格。

## 2. 终端与行业应用密集接入 DeepSeek

据 2 月 8 日的报道，荣耀 YOYO 智能体商店宣布正式上线 DeepSeek-R1 尝鲜版，用户升级系统后即可在 YOYO 助理中体验；七彩虹科技则宣布其「虹光 AI」智能模型助手全面接入满血版 DeepSeek R1 模型，其方案基于 Transformer 架构并采用 MLA 与 DeepSeek MoE 技术，官方称可降低内存占用、减少缓存需求。

行业应用侧，百度智能云推出客悦、曦灵、一见和甄知四款新应用并接入最新版 DeepSeek，覆盖智能外呼、数字人视频脚本生成、视觉智能分析与知识管理等场景；公司称正在加速验证这些应用在金融、交通、政务、汽车、医疗及工业等领域的适配性。阿里系的钉钉则成为阿里体系里第一个接入的产品。

## 3. 谷歌 Imagen 3 进 Gemini API，Pika 推出 Pikadditions

据 2 月 8 日的报道，谷歌正式推出最新图像生成模型 Imagen 3，已在 Gemini API 上向开发者开放。官方给出的能力描述是能生成多种风格的高质量图像，包括超现实主义作品、印象派风景、抽象作品与动漫角色；用户可自由控制宽高比与生成数量，并通过简化的文本提示把创意转成图像。初期只对付费用户开放，价格为每幅图像 0.03 美元。

为打击虚假信息与不当归属，Imagen 3 生成的所有图像都带有不可见的数字水印 SynthID，可被识别为 AI 生成作品。官方同时提供了 Python 代码示例，开发者设置 API 密钥、输入提示词即可调用；谷歌计划把更多生成媒体模型整合进 Gemini API。

视频侧，Pika Labs 推出 Pikadditions，允许用户把任意对象或角色无缝添加到现有视频中，同时保留原视频与声音。该功能支持 Pika 1.5、2.0、2.1 与 Pika Turbo 模型，覆盖 iOS 与 Android；使用流程是上传至少 5 秒的视频片段、选择要添加的对象并上传相应图像、再用文本提示描述如何融入视频。功能还提供互动阴影与扩展动作捕捉，让新增元素在动态表现上更接近真实。

## 4. Meta 提出 VideoJAM，联合外观与运动表示

据 2 月 8 日的报道，Meta 研究团队提出视频生成新框架 VideoJAM，针对的是现有生成模型难以真实捕捉复杂运动、动态与物理现象的问题。团队的判断是根源在于传统的像素重构目标偏向提升外观真实感，却忽略了运动的一致性；VideoJAM 的做法是鼓励模型学习联合的外观—运动表示，为视频生成注入有效的运动先验。

框架包含两个互补单元：训练阶段扩展了目标，让模型同时预测生成的像素与对应的运动，二者来自同一个学习表示；推理阶段引入「内在引导」机制，用模型自身不断演变的运动预测作为动态指导信号，引导生成朝一致的运动方向发展。团队强调，VideoJAM 不需要修改训练数据或扩展模型，可以应用到任何视频生成模型上。

验证结果显示，VideoJAM 在运动一致性上达到业界领先水平，超过了多个竞争激烈的专有模型，同时提升了生成图像的视觉质量。团队还展示了 VideoJAM-30B 在复杂运动类型上的表现，包括滑板运动员的跳跃、芭蕾舞者在湖面上旋转等场景；与基线模型 DiT-30B 相比，VideoJAM 在运动生成质量上有显著提升。项目入口也已公开。

## 5. 路透独家：Ilya 的 SSI 洽谈新一轮融资，估值 200 亿美元

据 2 月 8 日的报道（路透社独家稿的美国时间标注日为 2 月 7 日），Ilya Sutskever 领衔创办的「安全超级智能」（Safe Superintelligence，SSI）初创正在洽谈新一轮融资，预计估值将达到 200 亿美元，较 2024 年 9 月的 50 亿美元整整翻了 4 倍。上一轮中，SSI 分别从红杉资本、Andreessen Horowitz、DST Global 等五家风投筹集了 10 亿美元，这一次的金额尚未披露。

这家公司成立于 2024 年 6 月，联合创始人除 Sutskever 外，还有前苹果 AI 项目负责人 Daniel Gross 与前 OpenAI 研究员 Daniel Levy，使命被表述为「开发安全的超级智能」——比人类更聪明但与人类利益保持一致的 AI。外界对它的技术与产品知之甚少，甚至至今没有任何产品和收入。

吸引投资者的是 Sutskever 的声誉与路线判断。作为早期 Scaling 的倡导者，他主张投入海量算力与数据改进模型；但他也较早预见到可用于训练的数据池日益萎缩带来的上限，转而在推理阶段投入资源，其团队后来发展出的技术成为 OpenAI o 系列推理模型的基础，即测试时 Scaling。SSI 明确告诉投资者不要期待短期回报，要把发展进程与短期商业压力隔离开来；报道对比称，OpenAI 去年创造了近 40 亿美元收入、预计今年将达 116 亿美元。同期基础模型公司的融资热度不减：OpenAI 的谈判可能把估值翻倍至 3000 亿美元，Anthropic 也在敲定估值 600 亿美元的新一轮融资。
