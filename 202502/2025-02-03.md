# 2025-02-03 AI 大事件

北京时间 2025 年 2 月 3 日（星期一）。OpenAI 的「深度研究」（Deep Research）功能上线，卖点是一道被称作「人类终极考试」的测试上拿到 26.6% 的准确率，官方也承认它可能把权威信息和谣言搞混。国内这边，秘塔 AI 搜索宣布融合 DeepSeek-R1 满血版，把推理能力和全网实时检索接在一起；腾讯云的 HAI 平台上架了 DeepSeek-R1 全系列，主打三分钟完成部署。

## 1. OpenAI 上线「深度研究」，人类终极考试准确率 26.6%

2 月 3 日（美东 2 日），OpenAI 推出名为「深度研究」（Deep Research）的新功能，面向需要深入查证的用户，官方点名的场景包括金融、科学、政策、工程等方向的专业工作，以及买车、买家电、买家具这类需要多方比较的购买决策。

能力上的关键补充是分析、处理用户上传文件的能力。据报道，该模型在一项名为「人类终极考试」（Humanity's Last Exam）的测试中取得 26.6% 的准确率，远高于其他同类模型——这项测试由数百名专家出题，难度被定位在普通大学高年级水平以上。

OpenAI 对局限也写得很直白：该功能可能混淆权威信息与谣言，生成的报告里也可能出现格式错误。为降低这类风险，「深度研究」的输出会附带详细引用和思考总结，方便用户自行核验。功能上线时向 ChatGPT Pro 用户开放，每月限制 100 次查询，Plus 和 Team 用户稍后获得支持，企业版再往后。报道还指出，这一功能与谷歌两个月前推出的同名 AI 功能相似，并且暂不在英国、瑞士和欧洲经济区提供。

## 2. 秘塔 AI 搜索融合 DeepSeek-R1 满血版

2 月 3 日，秘塔 AI 搜索宣布融合 DeepSeek-R1 满血版，把推理能力接上全网实时信息。按官方的说法，这一步同时接上了秘塔背后的数千万高质量论文信息，形成「国产最强推理 + 全网实时搜索 + 高质量知识库」的组合。

量子位在报道中给出的理由是，DeepSeek-R1 的短板之一恰是联网搜索缺失——R1 本身不联网，而秘塔的强项是联网检索与论文库，两边拼起来才能同时拿到推理强度和时效性。报道随后的实测用例是让模型构建哪吒票房预测模型，用以观察复杂推理加检索的表现。

这类「国产搜索 + 国产推理模型」的整合在 2 月初集中出现：同一周内，硅基流动在华为云昇腾上上线了 R1 与 V3 的推理服务，腾讯云 HAI 也上架了 DeepSeek-R1 全系列。推理模型的开放许可，让搜索和云厂商可以在几天内把能力接进自己的产品。

## 3. 腾讯云 HAI 上架 DeepSeek-R1 全系列，三分钟完成部署

据 2 月 3 日的报道，腾讯云 HAI 平台已上架 DeepSeek 系列模型，包括 671B 参数的 V3 与 R1 原版，以及由 R1 蒸馏得到、参数规模从 70B 到 1.5B 不等的小模型系列。平台同时限时开放了 R1 模型的免费在线体验。

部署流程被压缩到三分钟以内。此前开发者自行部署需要处理硬件配置、驱动安装、网络连接、存储配置、环境设置、框架安装和模型下载等一整套环节；现在只需在 HAI 控制台新建 DeepSeek-R1 应用，按指引完成授权，就可以通过站内信拿到密码，进入 ChatbotUI 可视化界面，或在 JupyterLab 里用命令行加载模型。

命令行路径的细节也一并公开：在 HAI 控制台选择「算力连接」再到「JupyterLab」，新建 Terminal 输入 `ollama run deepseek-r1` 即可加载默认的 1.5B 模型，对性能不满意的开发者可以用指令自行切换到 7B、8B 或 14B 规格。按腾讯云的说法，DeepSeek-R1 采用 MIT 许可，允许用户通过蒸馏技术训练其他模型，这是这批模型能被云平台快速上架的前提。

## 4. 斯坦福等推出 s1：训练成本不足 50 美元的推理模型

据 2 月 3 日的报道（论文 arXiv 2501.19393 的 v1 提交于 1 月 31 日 18 时 48 分，按 arXiv 每晚 20:00（美东）公布的排期，公开时刻落在北京时间 2 月 3 日上午），斯坦福大学与华盛顿大学团队发布 s1 推理模型《s1: Simple test-time scaling》。报道称其训练成本不足 50 美元，代码与数据已在 GitHub 开源。

方法是蒸馏加监督微调：团队从现成的基础模型出发，用谷歌的 Gemini 2.0 Flash Thinking Experimental 作教师模型生成推理轨迹，再以监督微调把推理能力提取出来。数据侧，团队构建了 1000 个精选问题及其对应答案、并附上问题背后的「思考」过程，训练使用 16 块 Nvidia H100 GPU。

报道把 s1 与 DeepSeek 的「顿悟时刻」并置讨论：这种做法在小成本下复现了推理能力的涌现，也引发了模型商品化的讨论——如果任何人都能以相对低的成本复制出价值数百万美元的模型，头部实验室的护城河在哪里。报道还提到，OpenAI 曾指控 DeepSeek 不当使用其 API 数据进行模型蒸馏，而 s1 走的正是一条更便宜的蒸馏路线。
