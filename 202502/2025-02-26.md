# 2025-02-26 AI 大事件

北京时间 2025 年 2 月 26 日（星期三）。DeepSeek 的「开源周」进入第三天，发布支持 FP8 的通用矩阵乘法库 DeepGEMM，在 Hopper GPU 上算力可达 1350+ TFLOPS，而核心逻辑只有约 300 行代码。价格侧同日转向：DeepSeek 宣布每晚 00:30 至 08:30 的错峰优惠，V3 价格降至原价五折、R1 降至两成五，并确认 API 充值服务恢复。模型成本一侧，Anthropic 澄清 Claude 3.7 Sonnet 的训练成本为「数千万美元」。

## 1. DeepSeek 开源周第三日：DeepGEMM 与 300 行代码

据 2 月 26 日的报道，DeepSeek 在「开源周」第三天推出 DeepGEMM——一款支持 FP8 通用矩阵乘法（GEMM）的开源库，专为密集型和混合专家（MoE）矩阵运算设计，为 DeepSeek-V3 与 R1 模型的训练与推理提供支持。官方消息通过 X 平台发布。

性能数字是：在英伟达 Hopper GPU 上，DeepGEMM 可实现高达 1350+ TFLOPS 的 FP8 计算性能。官方强调其核心逻辑仅约 300 行代码，却能在大多数矩阵尺寸上超越专家调优的内核；该库无需复杂依赖，采用即时编译（JIT）技术，支持密集布局与两种 MoE 布局，设计上「像教程一样干净」，便于开发者学习使用。社区的反馈集中在两点：FP8 性能与简洁设计，以及对 MoE 模型高效训练的支持可能推动 Hopper 架构上的进一步创新。

这是 DeepSeek 开源周的第三个项目：前两天分别是聚焦快速语言模型架构的 FlashMLA 与面向专家并行通信的 DeepEP。报道未说明 DeepGEMM 是否计划适配 Blackwell 等更新架构。

## 2. DeepSeek 错峰优惠：夜间 V3 半价、R1 两成五

据 2 月 26 日的报道，DeepSeek 宣布为优化用户体验、提升服务效率，即日起在北京时间每日 00:30 至 08:30 的夜间空闲时段推出错峰优惠活动。活动期间 API 调用价格大幅调整：DeepSeek-V3 的价格下调至原价的 50%，DeepSeek-R1 更低至原价的 25%。官方的用意是鼓励用户在夜间空闲时段充分利用平台资源。

同日另一个进展是充值恢复。DeepSeek 于 2 月 6 日因服务器资源紧张暂停了 API 充值服务，官方在 2 月 25 日宣布充值已正式恢复，用户可以再次充值并用上错峰价格。这条线索也解释了本月初「服务器繁忙」传闻的来龙去脉：算力紧张并非模型本身的问题，而是高并发下的服务容量问题。

优惠是否长期、是否会与此前「DeepSeek-chat 优惠期 2 月 8 日结束」后的新定价叠加，报道没有说明。

## 3. Claude 3.7 训练成本披露，与国产芯片部署 R1 满血版

据 2 月 26 日的报道，沃顿商学院教授伊桑·莫里克透露，Anthropic 公关部门澄清旗舰模型 Claude 3.7 Sonnet 的训练成本为「数千万美元」，且使用的计算资源来自 Google Cloud。这条澄清是对外界关于「前沿模型训练成本」的猜测的回应，把 Claude 3.7 的成本量级框定在数千万美元。

部署侧，智源社区开源了 FlagOS 的升级版本，首次实现 DeepSeek-R1 满血版在多种芯片上的高效快速部署。此前把 R1 满血版跑在消费级或国产算力上主要依赖 KTransformers 一类异构方案，FlagOS 的升级把「多芯片适配」推进到系统软件层。

两条消息合起来看，一端是闭源前沿模型公开成本口径，另一端是开源模型把部署门槛往下压。报道未给出 FlagOS 适配的芯片型号清单、各芯片上的实测吞吐，也没有说明 Anthropic 是否披露更细的成本构成。

## 4. 家电与汽车：美的 DeepSeek 空调、零跑 B10 双模型

据 2 月 26 日的报道，家电厂商美的推出首款 DeepSeek 空调，主打语音控制带来的交互升级——这是把大模型能力直接装进家电的一个具体样本。与之同期，汽车厂商零跑公布 B10 的信息：这款 15 万级车型首搭激光雷达，并同时接入 DeepSeek 与通义千问两套大模型，3 月 10 日开启预售。

两条消息指向同一个趋势：模型正在从 App 层下沉到硬件产品，成为交互的默认入口。报道没有披露 DeepSeek 空调的上市时间与覆盖机型，也没有说明零跑 B10 上两套模型各自承担的任务。
