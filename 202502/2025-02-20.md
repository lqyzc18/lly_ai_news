# 2025-02-20 AI 大事件

北京时间 2025 年 2 月 20 日（星期四）。Grok 3 宣布免费开放，当晚就因访问量过大而承压，同日安全公司 Adversa AI 报告其存在越狱与系统提示泄露问题。端侧与企业侧两条进展：联想宣布成为全球首个在 AI PC 端侧本地部署 DeepSeek 的品牌，Colossal-AI 开源了覆盖满血 671B 微调与强化学习的 DeepSeek 后训练工具箱。政务与社交端，北京经开区、深圳福田、微博智搜也相继接入。

## 1. 联想率先在 AI PC 端侧本地部署 DeepSeek

据 2 月 20 日的报道，联想集团在发布去年第四季度财务业绩的同时宣布，将率先在 AI PC 领域实现 DeepSeek 大模型的本地部署——这使它成为全球首个在端侧部署该模型的 AI PC 品牌。联想天禧个人智能体系统的「小天」智能助手已接入 DeepSeek-R1 大模型，天禧生态系统也已经集成多款大模型。

业绩数字也一并披露：联想去年第四季度营收达到 1351 亿人民币，同比增长 20%；净利润 49.8 亿人民币，同比增长率高达 106%。把模型放到端侧，既是隐私诉求的结果，也是在云端 API 价格下探后的成本选择——报道提到 DeepSeek 爆火之后 API 低价内卷，而端侧运行把推理成本转移到了硬件侧。

报道没有说明联想本地部署的模型规格、可运行的最大参数量、量化方案与各机型的具体支持范围，也未提及与 DeepSeek 官方是否有合作授权。

## 2. Grok 3 免费开放与安全质疑

据 2 月 20 日的报道，xAI 宣布 Grok 3 正式开放免费使用，用户登录即可体验，无需付费，直到服务器承载能力达到极限；订阅 X Premium+ 与 SuperGrok 的用户可获得更多高级功能（如语音模式）与 Grok 3 的深度使用权限。另有报道称 Grok 应用已登顶 App Store 生产力榜首，马斯克预告即将推出新功能。

安全一侧的质疑来得同样快。AI 安全公司 Adversa AI 发布报告称 Grok 3 存在重大网络安全漏洞：其研究团队发现该模型容易受到「简单的越狱攻击」，可能使攻击者获取敏感信息；CEO 兼联合创始人亚历克斯·波利亚科夫还指出他们发现了一种新的「提示泄露」缺陷，暴露了 Grok 模型的完整系统提示——他的说法是「越狱攻击可以让攻击者绕过内容限制，而提示泄露则给他们提供了模型的思维蓝图」，并警告这类漏洞可能使黑客接管具备行动能力的 AI 代理。

测试数据方面，Adversa 的四种越狱技术中有三种对 Grok 3 成功，而 OpenAI 与 Anthropic 的模型防御住了全部四种。报道也提到 Grok 似乎被训练成进一步推崇马斯克本人的极端信念体系，这一取向与安全边界的关系在报道中被并列提出。Adversa 的结论属于第三方研究，xAI 尚未就此回应。

## 3. Colossal-AI 开源 DeepSeek 后训练工具箱

据 2 月 20 日的报道，已收获近 4 万 GitHub Star 的 Colossal-AI 发布开源大模型后训练工具箱，目标是让开发者「站在巨人的肩膀上」——以低成本微调 DeepSeek-V3/R1、打造高质量私有模型。工具箱包含 DeepSeek-V3/R1 满血 671B 的 LoRA 低成本 SFT 微调、完整的强化学习工具链（PPO、GRPO、DPO、SimPO 等），并无缝适配包括 DeepSeek 系列蒸馏模型在内的 HuggingFace 开源模型。

硬件兼容性是这套工具链的另一面：它兼容支持英伟达 GPU、华为昇腾 NPU 等多种硬件。这意味着在国产算力上做 DeepSeek 私有化微调不必再等官方适配。报道没有给出各算力平台下的实测吞吐、显存占用与微调成本区间。

报道把这份工具箱与当下的行业背景连在一起：DeepSeek 引发的 API 低价内卷让「微调满血模型以提高业务竞争力」成为更迫切的企业需求。

## 4. 政务与社交平台接入：福田 70 名 AI 员工、微博智搜

据 2 月 20 日的报道，多地政务服务系统接入 DeepSeek 大模型。北京经济技术开发区上线了经多家企业测试后正式投入使用的智能政务小助手，它既能处理咨询也能做材料审核，官方称「边聊边办」；营商环境建设局副局长付哲表示助手上线为企业提供了更高效的服务。

深圳福田区的 70 名「AI 数智员工」也已上岗：它们通过分析海量案例自动生成法律裁决书框架，把文书处理时间从数小时压缩到几分钟；在基层服务中心，数智员工能快速解答党费缴纳、组织关系转接等问题。福田区政务服务和数据管理局的员工借助 DeepSeek 开发的人工智能办公系统，只需简单指令即可给出解决方案，副局长高增称人机协同使整体效率提高 20% 以上。

社交平台方面，微博正在测试把智搜功能接入 DeepSeek，CEO 王高飞已多次展示测试效果，包括对「社保费用增加对骑手收入的影响」等热点话题的智能分析；测试显示 R1 能有效整合微博平台上的已有讨论内容，给出话题总结与分析结论。报道还提到腾讯理财通同时接入 DeepSeek-R1 满血版与混元大模型，钉钉 AI 企业搜索向所有用户限时免费开放。
