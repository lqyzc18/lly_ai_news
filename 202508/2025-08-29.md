# 2025-08-29 AI 大事件

北京时间 2025 年 8 月 29 日（星期五）。OpenAI 推出实时语音模型 GPT-RealTime，一个模型完成从音频输入到音频输出的全流程。字节跳动发布 OmniHuman-1.5，腾讯混元开源 HunyuanVideo-Foley，xAI 则发布主打低价的编程模型 Grok Code Fast 1。

## 1. OpenAI 推出 GPT-RealTime

OpenAI 发布全新的 GPT Realtime 实时语音大模型。这是 Speech-to-Speech（S2S）模型，能通过单个模型与 API 完成从音频输入到音频输出的全流程，显著降低交互延迟并充分保留语音细节。

GPT Realtime 以「端到端语音理解—推理—合成」为核心路径，解决传统「识别—推理—合成」多阶段带来的延迟与风格割裂问题。OpenAI 同期优化了 Realtime API 的相关功能。

## 2. 字节 OmniHuman-1.5 与腾讯混元 HunyuanVideo-Foley

字节发布 OmniHuman-1.5，能依据图像和语音生成匹配的角色动画视频。腾讯混元开源 HunyuanVideo-Foley，输入视频和文字即可配上电影级音效——这是生成式视频里最后一块常靠人工配音完成的工序。

阿里推出首个数据分析 Agent「智能小Q」，可快速完成数据解读和报告生成。同日，OpenAI 与 Anthropic 首次合作测试 AI 模型，用于识别各自的安全盲点，官方把这称作行业协作的开始。

## 3. 一笔 83 亿美元的融资与几处产品更新

资本与商业侧另有几条：OpenAI 计划出售股权，目标估值 5000 亿美元；微软正与 OpenAI 深入谈判，以达成能持续获取关键 OpenAI 技术的协议，这条协议直接关系到重组后微软与 OpenAI 的关系。

终端侧，腾讯元宝加入微信视频号评论区，提供实时问答与总结功能；DeepSeek 采用华为 AI 芯片训练部分模型，降低对英伟达的依赖；百度搜索 AI 助手全量上线极速模型，官方称生成速度超 DeepSeek V3.1 五倍；苹果推出 Xcode 26 Beta 7，支持 GPT-5 且集成 Claude 功能。
