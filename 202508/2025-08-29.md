# 2025-08-29 AI 大事件

北京时间 2025 年 8 月 29 日（星期五）。OpenAI 推出实时语音模型 GPT-RealTime，一个模型完成从音频输入到音频输出的全流程。字节跳动发布 OmniHuman-1.5，腾讯混元开源 HunyuanVideo-Foley，xAI 发布编程模型 Grok Code Fast 1。

## 1. OpenAI 推出 GPT-RealTime

OpenAI 发布全新的 GPT Realtime 实时语音大模型。这是 Speech-to-Speech（S2S）模型，能通过单个模型与 API 完成从音频输入到音频输出的全流程，显著降低交互延迟并充分保留语音细节。

GPT Realtime 以「端到端语音理解—推理—合成」为核心路径，解决传统「识别—推理—合成」多阶段带来的延迟与风格割裂问题。OpenAI 同期优化了 Realtime API 的相关功能。

## 2. 字节 OmniHuman-1.5 与腾讯混元 HunyuanVideo-Foley

字节发布 OmniHuman-1.5，能依据图像和语音生成匹配的角色动画视频。腾讯混元开源 HunyuanVideo-Foley，输入视频和文字即可配上电影级音效。

## 3. 阿里推出数据分析 Agent「智能小Q」

阿里推出首个数据分析 Agent「智能小Q」，可快速完成数据解读和报告生成。同日，OpenAI 与 Anthropic 首次合作测试 AI 模型以识别安全盲点，xAI 则发布主打低价的编程模型 Grok Code Fast 1，定价 0.2 美元每百万输入 token、1.5 美元每百万输出 token。
