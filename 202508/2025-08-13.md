# 2025-08-13 AI 大事件

北京时间 2025 年 8 月 13 日（星期三）。Anthropic 为 Claude Sonnet 4 开放 100 万 token 上下文 beta，并首次实行分级定价：上下文超过 20 万 token 时，输入每百万 token 6 美元、输出 22.5 美元。工程与工具一侧，字节跳动开源基于 PyTorch 原生的全模态训练框架 VeOmni，GitHub 则被并入微软 CoreAI 集团。

## 1. Claude Sonnet 4 开放 100 万 token 上下文

Anthropic 开放 Claude Sonnet 4 的 100 万 token 上下文窗口 beta，面向 usage tier 4 及具定制速率限制的 API 组织，需要使用 context-1m-2025-08-07 beta 头。相比原先的 20 万 token 提升 5 倍，用户可以在单个请求中处理超过 7.5 万行代码的完整代码库或多个研究论文。

这是 Anthropic 第一次分级定价：当上下文超过 20 万 token 时启用更高单价，输入 6 美元、输出 22.5 美元每百万 token。该能力于 8 月 26 日扩展至 Google Cloud Vertex AI。

## 2. 字节开源 VeOmni；GitHub 并入微软 CoreAI

字节跳动 Seed 宣布开源 VeOmni 框架，推动全模态大模型（同时具备文本、图像、语音和视频处理能力）的研究与应用。VeOmni 基于 PyTorch 原生训练，采用以模型为中心的分布式训练方案，简化复杂的并行逻辑。实验表明，基于 VeOmni，300 亿参数的 MoE 模型在训练效率上有显著提升，吞吐量超过 2800 tokens/sec/GPU，且可扩展至超长上下文序列。

同日，GitHub 将不再独立运营，被并入微软 CoreAI 集团，微软也不再为其寻找新 CEO。

## 3. 其他几条值得记的消息

阿里通义千问推出 Qwen Code，用户每日免费使用 2000 次，不受 token 额度限制。DeepSeek 全面宕机后修复，官方深夜宣布网页和 API 已恢复。Perplexity 提出以 345 亿美元的价格收购谷歌 Chrome 浏览器，这仍是传闻，未获双方确认。
