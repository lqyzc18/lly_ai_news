# 2025-08-06 AI 大事件

北京时间 2025 年 8 月 6 日（星期三）。OpenAI 发布开放权重模型 gpt-oss-120b 与 gpt-oss-20b，称其为「全球最佳开放模型」。谷歌 DeepMind 推出第三代通用世界模型 Genie 3，可以 24 帧每秒实时导航、720p 保持数分钟一致性。Anthropic 则抢先发布 Claude Opus 4.1。

## 1. OpenAI 发布 gpt-oss-120b 与 gpt-oss-20b

OpenAI 发布两个开放权重的 MoE 模型：gpt-oss-120b 和 gpt-oss-20b，支持 Apache 2.0 商业化。这两款模型针对 AI Agent 做过专门训练，具备函数调用、网络搜索和 Python 执行等功能。

性能与部署的取舍被说得很清楚：gpt-oss-120b 在性能上可与 o4-mini 相媲美，但需要 80GB GPU；gpt-oss-20b 则可以在 16GB 的配置下使用。联合创始人 Sam Altman 表示，这次发布标志着最先进的开放权重推理模型的推出。

## 2. 谷歌 DeepMind 推出 Genie 3

谷歌 DeepMind 宣布推出第三代通用世界模型 Genie 3，可以生成前所未有的多样化交互式环境。给出文本提示，Genie 3 能生成动态世界，以每秒 24 帧的速度实时导航，并以 720p 的分辨率保持几分钟的一致性。

与前代 Genie 1/2 以及 Veo 2、Veo 3 不同，Genie 3 是第一个允许实时交互的世界模型，一致性和真实感也有提升。

## 3. Anthropic 发布 Claude Opus 4.1

Anthropic 发布 Claude Opus 4.1，针对 Agent 任务、真实世界编码和推理做了显著升级，新版本已向 Claude 用户开放并上线 API，定价与 Opus 4 相同。官方称相较 Opus 4，Opus 4.1 在大多数能力上都有提升，多文件代码重构的表现尤其突出。

## 4. 谷歌推出 Gemini Storybook

谷歌在 Gemini 中推出 Storybook，用户只需简短描述故事内容，即可生成一本包含插图的图文书。这本书共 10 页，每页包括一段朗读文字和配图，用户还可以选择故事风格，例如黏土动画或漫画风格。支持图片上传后，家长可以上传孩子的画作并围绕其创作故事。Storybook 已在全球上线，支持多种语言和设备，但页面主角外形一致性不足的问题仍然存在。
