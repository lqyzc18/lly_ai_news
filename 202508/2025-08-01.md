# 2025-08-01 AI 大事件

北京时间 2025 年 8 月 1 日（星期五）。谷歌在 Gemini API 上线 Veo 3 Preview 的图生视频生成能力，并同步发布 Veo 3 Fast Preview 模型。阿里同日发布 Qwen3-30B-A3B-Thinking-2507 和 Qwen3-Coder-Flash 两个小尺寸模型。资本侧有一笔大单：OpenAI 完成 83 亿美元融资，估值升至 3000 亿美元。

## 1. 谷歌上线 Veo 3 图生视频与 Veo 3 Fast Preview

Google 在 Gemini API 上线 Veo 3 Preview 模型的图生视频（image-to-video）生成能力，并同步发布 Veo 3 Fast Preview 模型。Veo 3 是 7 月中旬上线预览、首次支持带音频视频生成的版本，这次是能力扩展。

## 2. 阿里一次放出两个小尺寸模型

阿里通义千问发布 Qwen3-30B-A3B-Thinking-2507，增强 256K 长上下文理解能力，在逻辑推理、数学、科学和编码等任务上表现突出，并加强了指令执行和工具使用能力。另一款是编程模型 Qwen3-Coder-Flash，全名 Qwen3-Coder-30B-A3B-Instruct，原生支持 256K tokens 并可扩展到 1M。

官方称 Coder-Flash 在 Agent 能力上仅次于顶配的 Qwen3-Coder-480B-A35B-Instruct 以及闭源领先模型。同一天，腾讯发布多模态模型 X-Omni，针对图像生成里中英文长文本渲染不准的问题做了改进。

## 3. 融资与投资

OpenAI 已完成 83 亿美元融资，估值升至 3000 亿美元。同期还有一笔：法国 Mistral AI 计划按 100 亿美元估值融资约 10 亿美元。

产品侧，Manus 的 Wide Research 正式上线，用户可以调度百个以上智能体并行处理任务；智元机器人获 LG 电子和韩国未来资产联合领投，这是 LG 对具身智能的首次投资；小红书发布社交大模型 RedOne，8 个 SNS 任务性能平均提升 14.02%。

## 4. 搜索、监管与安全

小米浏览器升级 AI 搜索功能，接入豆包模型提升搜索效率与服务能力；亚马逊 CEO 考虑在 Alexa+ 语音助手对话中植入广告，助手已开启早期访问。美国证监会成立 AI 特别工作组，由 Valerie Szczepanik 任首席 AI 官，目标是促运营创新与效率。

安全一侧有一条技术细节：ChatGPT 智能体已可自动通过 Cloudflare 的人机验证系统。这一条被反复讨论，因为它同时说明了两件事——验证系统在 Agent 面前不再是门槛，以及检测手段与自动化之间的差距正在缩小。
