# 2025-08-12 AI 大事件

北京时间 2025 年 8 月 12 日（星期二）。腾讯混元推出 Large-Vision 多模态理解模型，MoE 架构，参数量达 52B。OpenAI 的一项 AI 开发推理系统在国际信息学奥赛拿到金牌，超过 98% 人类选手。开发者生态一侧，GitHub 将不再独立运营，被并入微软 CoreAI 集团。

## 1. 腾讯混元 Large-Vision

腾讯混元推出 Large-Vision 多模态理解模型，采用 MoE 架构，参数量达 52B。这是混元在「读懂画面」这条线上的又一次上探——52B 的规模，已经超过大多数开源多模态模型。

同日，昆仑万维发布开源交互式世界模型 Matrix-Game 2.0，用于 3D 世界生成与探索；商汤推出 AI 剧组工具 Seko，支持全流程视频生成，仅需中文描述。

## 2. OpenAI 的推理系统拿 IOI 金牌

OpenAI 的 AI 开发推理系统获国际信息学奥赛金牌，超过 98% 人类选手。这套系统的输入是竞赛题，输出是解题程序——和 AlphaCode、o3 这类「写代码」的模型不同，它更接近「写程序」。

工具与开发链上，DeepSeek 全面宕机后修复，深夜宣布网页和 API 已恢复；阿里通义千问推出 Qwen Code，用户每日免费使用 2000 次，不受 token 额度限制；Claude 聊天机器人新增记忆功能，采用被动触发模式。

## 3. GitHub 并入微软 CoreAI

GitHub 将不再独立运营，被并入微软 CoreAI 集团，微软也不再为其寻找新的 CEO。

同一批消息里还有几条关于公司路线的：OpenAI CEO 计划在五年内投入超千亿美元，携博通量产自研 AI 芯片；OpenAI 官方给出 GPT-1 到 GPT-5 相同提示的回答对比，展示模型多方面的进步；OpenAI 招募硬件系统产品设计师，目标是开发下一代创新移动设备。

## 4. 硬件与生态

英伟达面向机器人开发者推出新产品，含具身智能推理模型 Cosmos Reason。Meta 考虑放弃开源 AI 模型 Behemoth 转闭源，或影响行业格局及小公司发展。宇树科技宣布将参加首届世界人形机器人运动会部分项目；华为发布 AI 推理 UCM 技术，与银联试点，9 月将开源；360 智脑提出 Light-IF 框架，全系模型将在 Hugging Face 开放。
