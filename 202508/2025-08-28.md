# 2025-08-28 AI 大事件

北京时间 2025 年 8 月 28 日（星期四）。字节跳动发布 OmniHuman-1.5，能依据图像和语音生成匹配的角色动画视频；腾讯混元开源 HunyuanVideo-Foley，输入视频和文字即可配上电影级音效。xAI 则发布主打低价的编程模型 Grok Code Fast 1。

## 1. xAI 发布 Grok Code Fast 1

xAI 发布主打低价高吞吐的 AI 编程模型 Grok Code Fast 1，采用全新架构从零训练，擅长 TypeScript、Python、Java、Rust、C++ 与 Go。

定价是 0.2 美元每百万输入 token、1.5 美元每百万输出 token，缓存输入 0.02 美元。它在 GitHub Copilot、Cursor、Cline、Windsurf 等首发合作伙伴处限时免费开放一周。

## 2. 字节发布 OmniHuman-1.5

字节发布 OmniHuman-1.5，能依据图像和语音生成匹配的角色动画视频。腾讯混元开源 HunyuanVideo-Foley，输入视频和文字即可配上电影级音效——这是生成式视频里最后一块常靠人工配音完成的工序。

## 3. 一批产业侧消息

OpenAI 与 Anthropic 首次合作测试 AI 模型，用于识别各自的安全盲点，官方把这称作行业协作的开始。阿里推出首个数据分析 Agent「智能小Q」，可快速做数据解读和报告生成。百度智能云千帆 4.0 上线，推出 Agent 核心服务平台。

另有一条值得记：YouTube 承认使用 AI 修改视频以提高清晰度，但没有获得创作者同意，引来创作者的担忧。这正是 AI 生成内容标识新规落地前后的典型摩擦。
