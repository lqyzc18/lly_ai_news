# 2026-02-07 AI 大事件

北京时间 2026 年 2 月 7 日（星期六）。本期记 3 条。Anthropic 研究员用 16 个 Claude Opus 4.6 智能体，在几乎无人干预的情况下两周写出一个约 10 万行的 Rust 版 C 编译器，能编译 Linux 6.9 内核，成本约 2 万美元。自动驾驶侧，Waymo 联合 Google DeepMind 的 Genie 3 发布自己的世界模型，用生成式场景逼出罕见极端工况。国内，中科院南海海洋研究所与中国石油大学（华东）发布全球首个面向南海的海-气双向耦合智能大模型「飞鱼-1.0」。

## 1. 16 个 Claude 智能体两周写出 10 万行 C 编译器

据 Ars Technica 报道，Anthropic 安全防护团队研究员 Nicholas Carlini 做了一次公开实验：用 16 个 Claude Opus 4.6 智能体，在几乎没有人类干预的情况下，从零开始用 Rust 语言编写一个 C 语言编译器。

据凤凰网的整理，这个编译器代码量超过 10 万行，可以在 x86、ARM 和 RISC-V 三种架构上构建可启动的 Linux 6.9 内核，通过了 GCC 99% 的压力测试，能够编译 FFmpeg、Redis、PostgreSQL、QEMU 等项目，并最终编译并运行了《毁灭战士》。实验总成本约 2 万美元，消耗近 20 亿个输入 token，超过 2000 次 Claude Code 会话，历时约两周。

「几乎没人干预」不等于没人管。报道提到研究人员需要不断重新设计测试、在智能体程序互相干扰时搭建 CI 管道，并在 16 个智能体程序卡在同一个 bug 时造出变通办法。凤凰网的评论是，未来加入 AI 的工作流里，人的角色已经从写代码转为构建让 AI 能写代码的环境。

同一时期 Anthropic 还报告了这项工作的另一个侧面：Opus 4.6 在沙箱里对开源库做自动审计，挖出 500 多个零日漏洞并给出修复方案。社区对此有分歧，有人提议按累计修复的 CVSS 分值给模型做新基准，也有人担心把这么强的挖洞能力公开细节等于给黑客送工具箱。

## 2. Waymo 联合 Genie 3 发布自己的世界模型

据 Ars Technica 报道，Waymo 基于 Google DeepMind 的生成式世界模型 Genie 3，发布了自家的自动驾驶世界模型，用于在仿真中制造罕见乃至不可能发生的极端场景——龙卷风、飞机迫降高速等——来压力测试自动驾驶系统。

这条路线的动机在报道里说得很直白：靠真实世界数据练习永远练不完所有极端情况，用生成模型模拟能更快补齐训练缺口。Waymo 公告称，Genie 3 能够生成包含摄像头与三维激光雷达的逼真交通场景。

社区把这一步称为从「只会生成像素」到「直出传感器流」的关键跃迁——自动驾驶仿真需要的不是好看的画面，而是物理与几何上都自洽的多传感器数据。同期国内也出现了类似方向的工作，例如 Trillion Labs 与 KAIST 发布的 gWorld，用生成 HTML/CSS/JS 再渲染 UI 的方式做手机 GUI 世界模型，8B 版本在 MWMBench 上达到 74.9% 准确率；社区对「超越 402B 模型」这类标题持保留态度，但认可「用结构代码代替像素」这条思路。

## 3. 「飞鱼-1.0」：全球首个面向南海的海-气双向耦合智能大模型

2 月 7 日，南海区域海-气双向耦合智能大模型「飞鱼-1.0」在广州正式发布。据科技日报的报道，该模型由中国科学院南海海洋研究所与中国石油大学（华东）联合研发，是全球首个面向南海的海-气双向耦合智能大模型。

模型做的是从长期观测、再分析和数值模拟数据中自主挖掘南海海气相互作用的时空特征与非线性规律。报道提到三项核心技术创新：核心数据自主可控、海-气双向智能耦合、以及「即插即用」式的低成本学习与灵活可扩展。

数据方面，训练所用的核心数据采用南海海洋研究所自主研制的高分辨率南海再分析数据集，报道称这首次让该类大模型摆脱了对国外核心数据的依赖，打破了以往国内海洋大模型高度依赖欧美再分析数据的局面，并使模型具备刻画海洋内波、锋面等小尺度过程的能力。效率方面，相比以往其他 AI 模型一般需要 20 年以上历史数据，该模型仅需 3 年历史数据即可完成训练，在国产化单机环境下完成未来 3 天的预报仅需 3 秒。

应用方向包括台风路径与强度演变的预判、分钟至季节尺度的海气状态模拟、风暴潮预警、生态异常诊断与碳通量评估，并可自动生成动态海洋知识图谱。
