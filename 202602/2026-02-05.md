# 2026-02-05 AI 大事件

北京时间 2026 年 2 月 5 日（星期四）。本期记 3 条。国际奥委会主席考文垂在米兰宣布，国际奥委会已基于阿里千问大模型打造了奥运史上首个官方大模型，米兰冬奥会因此被称为「史上最智能」的一届奥运会。面壁智能开源 MiniCPM-o 4.5，用 9B 参数把全双工全模态实时交互搬进端侧。开发者侧，GitHub 平台把 Anthropic 的 Claude 与 OpenAI 的 Codex 两个编程智能体一并接入，Copilot 付费用户可以在网页、移动端和 VS Code 中直接调用。

## 1. 米兰冬奥会：奥运史上首个官方大模型出自阿里千问

2 月 5 日，米兰冬奥会开幕在即，国际奥委会主席柯丝蒂·考文垂在米兰国际转播中心举行的活动上宣布，国际奥委会已基于阿里千问大模型打造了奥运史上首个官方大模型。考文垂在现场称，得益于千问大模型的技术支撑，2026 米兰冬奥会展现了奥林匹克运动的智能化未来，将成为史上「最智能」的一届奥运会。

这一模型分两侧落地。赛务侧，国际奥委会在面向各国奥委会工作人员的网站上线了「国家奥委会 AI 助手」，据报道它依托千问大模型的多语言理解能力并通读了数百万字官方手册，代表团成员用母语提问即可得到从资格审核到后勤调度的解答。公众侧，国际奥委会将在官网 Olympics.com 上线基于千问大模型打造的「奥运 AI 助手」，面向全球观众回答赛事规则与奥运历史类问题。

直播生产环节也已接入。基于千问大模型 Qwen-VL 开发的自动媒体描述系统投入运行，实时识别进球、犯规等关键事件并生成描述。内容生产方面，米兰冬奥组委会基于阿里万相大模型创作了一组面向全球粉丝的多媒体宣传素材，这是 AIGC 首次大规模应用于冬奥会内容生产环节。

转播侧，阿里云针对「雪地背景纹理单一、缺乏特征点导致视觉盲区」的问题采用多模型融合算法攻克雪地场景高精度重建难题，该技术已部署于 10 个核心竞赛场馆，覆盖高山滑雪、跳台滑雪、冰球等超过三分之二的比赛项目。考文垂把阿里称作奥林匹克运动「具有变革性的合作伙伴」，并在演讲最后说：「这份 AI 能力，正是米兰冬奥会留给世界的『永恒礼物』。」

## 2. 面壁智能开源 MiniCPM-o 4.5：9B 参数的全双工端侧全模态模型

面壁智能开源全模态模型 MiniCPM-o 4.5。量子位的报道把它定位为「行业首个可以即时自由对话的大模型」：不同于以往多模态模型串行处理、先听完再想再说的结构，MiniCPM-o 4.5 首次引入全双工多模态实时流机制，视频与音频输入流、文本与语音输出流并行运行、互不阻塞。

在实现上，离线的模态编解码器被改造成支持流式输入输出的在线版本，语音侧采用文本与语音 token 交错建模；推理时用时分复用机制把对齐在毫秒级时间线上的多模态输入输出统一建模。架构上采用端到端全模态设计，以稠密特征把 SigLip2 视觉编码器、Whisper-medium 音频编码器、CosyVoice2 语音解码器与 Qwen3-8B 语言模型直接连到主干。模型还取消了传统的 VAD（语音活动检测）机制，改由语言模型以 1Hz 的频率自行决定是否介入回应，因此能被打断、也能主动提醒或评论。

规模与部署方面，模型为 9B 参数，支持视频、音频、文本输入与文本、语音输出。量子位报道提到的口径是：常规模式首 token 延迟控制在 0.6 秒以内，int4 量化后显存占用约 11GB，手机端量化后可实现每秒 6~8 token 的解码，英文长语音 WER 为 3.37%，OCR 识别得分 89.0；自研 3D-Resampler 在 VideoMME 上把视频推理时间开销压到同级模型的约 1/10；通过自研 FlagOS 统一软件栈适配了天数智芯、华为昇腾、平头哥、海光、沐曦等 6 款芯片。这些均为厂商自评。

面壁智能联合创始人兼 CEO 李大海把公司的定位讲得很直接：「我们最大的差异化就是我们只做端，而且我们把端做到极致。」该模型计划与面壁首款 AI Native 端侧开发板「松果派」配套推出，计划于今年上市。

## 3. GitHub 接入 Claude 与 Codex：多模型协作进入 IDE

2 月 5 日多家中文科技媒体集中报道，GitHub 平台已把 Anthropic 的 Claude 和 OpenAI 的 Codex 两个编程智能体集成进来，Copilot Pro Plus 与 Enterprise 用户可以在网页端、移动端以及 VS Code 中直接使用，开发者可以自行选择由哪个智能体处理任务，并对比不同 AI 给出的解决方案。

这条消息的落点是把多模型选择权交还给开发者。此前编程智能体在各家平台上是各自封闭的，开发者往往要在不同工具之间切换；接入到同一个代码托管平台后，模型选择变成了每次任务的一个参数。

同日国内媒体还记录了其他几条与开发者生态相关的信息：苹果 Xcode 26.3 正式支持 Agentic Coding 并集成 Claude Agent SDK，同时引发开发者对代码泄露的隐私担忧；微软 365 Copilot 活跃用户规模同比增加 10 倍，人均对话次数翻番，企业付费席位数同比增长 160%；微软还与康泰纳仕、赫斯特、美联社等合作推出出版商内容市场，允许出版商向 AI 公司授权内容。
