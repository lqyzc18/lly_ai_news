# 2026-02-24 AI 大事件

北京时间 2026 年 2 月 24 日（星期二）。本期记 4 条。Anthropic 发文指控 DeepSeek、月之暗面和 MiniMax 用约 2.4 万个虚假账户进行了 1600 万次交互来"蒸馏"Claude，并给它起了个名字叫"工业规模蒸馏攻击"；马斯克随即公开嘲讽。同一时间，Claude Code Security 上市后引发的连锁反应在股市上兑现，IBM 一夜重挫逾 13%。

> 本期记 4 条：Anthropic 的蒸馏指控与马斯克回击、指控背后的时间线与中国三家的应对、Claude Code Security 与网安股暴跌、IBM 单日重挫逾 13%。

## 1. Anthropic 指控三家中国公司"工业规模蒸馏攻击"

据新京报贝壳财经与 TechWeb 报道，Anthropic 于美国时间 2 月 23 日发布官方博客文章，**指控 DeepSeek（深度求索）、月之暗面（Moonshot AI）和 MiniMax（稀宇科技）通过"模型蒸馏"大规模非法获取 Claude 的核心能力**。

Anthropic 的具体表述是：这三家公司违反其服务条款与区域访问限制，通过搭建约 **2.4 万个虚假账户**，与 Claude 产生了总计超过 **1600 万次**交互，目标直指 Claude 的代理推理、工具使用与编码能力；Anthropic 为此创造了一个说法——"**工业规模蒸馏攻击**"（distillation attacks），并把这类行为上升到国家安全高度，称其"强化了出口管制的合理性"，甚至可能帮助"部署前沿 AI 用于进攻性网络行动、虚假信息运动和大规模监控"。Anthropic 称，通过 IP 地址关联、请求元数据和基础设施指标，它把这些行为"高置信度"归因到具体实验室，甚至追踪到具体研究人员。

三家公司的规模差异在原文里其实写得很清楚。**MiniMax 超过 1300 万次交互**，明确针对代理编码、工具使用与编排，Anthropic 特别指出其在新模型发布后 24 小时内就把将近一半流量转向新系统；**月之暗面超过 340 万次交互**，目标涵盖代理推理与工具使用、编码与数据分析、计算机使用代理开发以及计算机视觉，意在重建 Claude 的推理轨迹；**DeepSeek 约 15 万次交互**，重点是提取 Claude 在多样化任务中的推理能力。技术手段上，Anthropic 指的是一种被称为"九头蛇集群架构"（hydra cluster architectures）的代理服务方式。

马斯克的回击几乎同时出现。他在 X 上转发并写道："他们（中国人）怎么敢偷 Anthropic 从人类程序员那儿'顺'走的东西？""Anthropic 公司大规模窃取训练数据，并为此支付了数十亿美元的赔偿金。这是不争的事实。"他指的是 2025 年 9 月 Anthropic 因从 LibGen、PiLiMi 等盗版网站下载超 700 万本受版权保护图书训练模型，而向以作家安德里亚·巴茨（Andrea Bartz）为首的全球作家集体支付 15 亿美元和解金一事。截至发稿时，被点名的三家中国公司均未公开回应。

## 2. 这次指控的时点，以及它背后的争吵

Anthropic 博文里有一句自相矛盾的话：它承认"前沿 AI 实验室会定期蒸馏自己的模型，为客户提供更小、更便宜的版本"。也就是说，蒸馏本身被承认为正当手段，区别只在于"谁在蒸馏谁"。

更值得注意的是发布的时点。据《品玩》等媒体梳理的时间线：2 月 16 日 Axios 报道五角大楼警告 Anthropic 将"付出代价"并威胁将其列为"供应链风险"；2 月 18 日 CNBC 报道双方合同谈判陷入僵局；2 月 20 日 NBC 报道称双方关系"达到沸点"，起因是 Anthropic 高管向 Palantir 询问 Claude 是否被用于当月美军突袭委内瑞拉总统马杜罗的行动；2 月 23 日 Axios 报道国防部长 Hegseth 将于次日召见 Dario Amodei，而同一天 xAI 与五角大楼签下接受"所有合法用途"条款的协议。Anthropic 的蒸馏博文恰好在 CEO 被召见的前一天发出，也在 2 亿美元国防合同悬而未决之际发出。

Anthropic 自身的记录也被翻了出来。就在一个月前，法院解封的 4000 多页文件披露了 Anthropic 内部的"巴拿马计划"（Project Panama）：公司花费数千万美元从二手书商大量购买实体书，用工业液压切割机切掉书脊、高速扫描每一页后销毁纸张回收，内部文件称目标是"破坏性扫描全世界的书"，计划在六个月内处理 50 万到 200 万本。联合创始人 Ben Mann 也曾从盗版网站 LibGen 下载数百万本书用于早期模型训练。

法律层面的分歧同样清楚。AI 模型的输出在美国法律框架下并不享有版权保护——美国版权局 2025 年 1 月确认版权保护要求人类作者身份，"仅提供提示词不使输出受版权保护"。因此这类行为更接近服务条款违约，而非知识产权盗窃。有法律分析认为，即便 Anthropic 能证明蒸馏确实发生，也很难拥有被提取数据的版权，合同法路径可能比知识产权法更有效。

## 3. 中国三家的回应：技术指标而非口水

被点名的三家都没有正面回应，但同期披露的运营数据构成了另一种回答。

据新京报贝壳财经报道，**月之暗面**方面透露，在完成上一轮 5 亿美元融资仅一个多月后，将完成新一轮**超 7 亿美元**融资并再次超募，本轮由阿里、腾讯、五源、九安等联合领投；新一轮 100 亿至 120 亿美元估值的融资已经开启，并已收到多家机构意向。连续两轮超 12 亿美元的融资，创下近一年来大模型行业的最高融资纪录。调用量方面，Kimi K2.5 发布不到一个月，近 20 天累计收入已超过 2025 年全年总收入；根据 OpenRouter，Kimi K2.5 的调用量在 OpenClaw 的模型调用榜中排名第一。

**MiniMax** 向该报记者披露，春节前夕开源新一代模型 M2.5，发布 12 小时内登顶 OpenRouter 热度榜，一周内登顶调用量榜首，**周调用量暴涨至 3.07T tokens**；官方随后确认 M2.5 带动了 100K 至 1M 长文本区间的增量调用需求，而这正是 Agent 工作流的典型消耗场景。**DeepSeek** 则延续其一贯的开源路线，2026 年以来已发表多篇论文并开源最新研究成果，同时正对新模型进行灰度测试。

## 4. Claude Code Security 的连锁反应：IBM 一夜重挫 13%

据 TechCrunch 与中文财经媒体的报道，Anthropic 推出 Claude Code Security，把静态扫描与运行时防护嵌入模型原生接口，一键完成大规模代码审计与漏洞检测，官方称实测准确率达到 SOTA。**产品发布当日，全球网络安全板块市值蒸发逾百亿美元**。

冲击波还蔓延到了传统 IT 基础设施。据新浪财经报道，IBM 就因 Anthropic 表示 Claude Code 可替代运行在其主机上的 Cobol 语言，**股价创下 2000 年以来最大单日跌幅，周一重挫超 13%**。老旧系统现代化赛道随之升温。

这构成了 OpenAI 在 2 月 28 日那轮融资之外的一条暗线：当大模型开始真正接管遗留代码，冲击的就不只是软件股，而是运行在大型机上的几十年存量系统。
