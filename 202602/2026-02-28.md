# 2026-02-28 AI 大事件

北京时间 2026 年 2 月 28 日（星期六）。本期记 3 条。OpenAI 宣布规模达 1100 亿美元的新一轮融资，估值 7300 亿美元，并首次向投资者更新了 2030 年的算力支出与收入口径；苹果发布 Xcode 26.3，把 Claude 与 Codex 变成可调用的"虚拟同事"。

> 本期记 3 条：OpenAI 1100 亿美元融资的条款与参与方、OpenAI 更新后的算力与收入预期、苹果 Xcode 26.3 接入 Claude 与 Codex。

## 1. OpenAI 1100 亿美元融资：7300 亿美元估值，三家各出重金

据 CNBC 2 月 27 日（美国时间）报道，OpenAI 宣布一轮规模达 **1100 亿美元**的融资，**投前估值 7300 亿美元**——作为参照，OpenAI 去年 10 月的二级市场融资对应估值为 5000 亿美元。落到北京时间，这轮融资发生在 2 月 28 日。

参与方的结构说明了这一轮的性质：亚马逊 500 亿美元、英伟达 300 亿美元、软银 300 亿美元，其余约 90% 的资金来自战略投资者。亚马逊的 500 亿美元分两笔到位——先 150 亿，其余 350 亿待"未来数月条件满足时"支付。路透社援引的分析普遍把这一轮解读为**软银 400 亿美元过桥贷款的配套动作**：这笔贷款 12 个月无担保、2027 年 3 月到期，由摩根大通、高盛、瑞穗、三井住友、三菱日联五家银行安排，2026 年 3 月 27 日签署，用途正是为软银通过愿景基金二期向 OpenAI 追加 300 亿美元投资提供资金。无担保加 12 个月期限的组合，被市场普遍读作承销行对 OpenAI 在一年内完成 IPO 的判断。

## 2. 算力的账：OpenAI 向投资者更新了 2030 年的口径

同一份报道里，OpenAI 给投资者更新了长期资本支出规划：到 **2030 年算力总支出约 6000 亿美元**，此前 Altman 曾提过 1.4 万亿美元的口径；按路透社报道，OpenAI 2030 年总收入预计超过 2800 亿美元。这两个数字合在一起，勾勒出的不是一家需要持续输血的创业公司，而是一个自我造血规模将超过两万亿美元的产业。

算力来源的安排同样具体。OpenAI 此前已与 AWS 签有 380 亿美元的协议，并将在未来八年追加 1000 亿美元；**AWS 成为 OpenAI 新 agent builder 产品"Frontier"的独家第三方云分发方**。OpenAI 计划用英伟达 Vera Rubin 架构承载 **3GW 推理与 2GW 训练**。把这些数字与同期英伟达财报放在一起看——英伟达刚交出单季 623 亿美元的数据中心营收、并称已部署的 Blackwell 基础设施算力达 90 亿瓦且满负荷——就能理解为什么两家公司的算力账要互相印证：OpenAI 的资本开支曲线，本质上是英伟达营收曲线的上游注脚。

## 3. 苹果 Xcode 26.3：Claude 与 Codex 成了"虚拟同事"

据蓝点网与 cnBeta 消息，经过数周测试，苹果于 2 月 27 日正式发布 Xcode 26.3 正式版（Build 17C529）。这次更新的标志性意义被概括为：苹果的开发者工具从"代码补全"时代正式迈入"智能体编码"（Agentic Coding）时代。

变化集中在一件事上——**Xcode 26.3 正式支持直接调用 Anthropic 的 Claude Agent 与 OpenAI 的 Codex**。此前 Xcode 的智能功能只停留在辅助层面；现在 AI 不再只是帮你填空，而是像一个"虚拟同事"那样理解需求、自主规划架构、编写完整代码，并执行项目构建与调试。更新同时增加了对 **MCP 协议**的支持，这意味着任何兼容该协议的第三方智能体和工具都能无缝接入开发流程。

交互方式随之改变。开发者只需用自然语言描述需求（例如"在登录界面增加对深色模式的支持"），智能体就会自动读懂项目结构、创建文件并验证结果，整个过程几乎不需要手动调整。上手路径也被压缩到三步：更新到 Xcode 26.3，在设置中启用"AI 智能体"功能，必要时配置 Apple 账户或 Claude／OpenAI 的 API 密钥，之后即可在聊天窗口或工具栏直接下达指令。

这条产品线与同期产业动作是同向的。Anthropic 与 OpenAI 的旗舰编程工具正在被主流 IDE 原生接入，而同一周里，OpenRouter 的数据第一次显示中国大模型的周调用量超过美国模型，阿里云百炼也把 Qwen3.5、GLM-5、MiniMax M2.5、Kimi K2.5 四款开源模型打包进 7.9 元首月的编程订阅——开发者入口之争，已经从"选哪个模型"变成了"从哪个渠道调用"。
