# 2026-02-22 AI 大事件

北京时间 2026 年 2 月 22 日（星期日）。本期记 3 条。微软把 Windows 任务栏变成 AI 智能体的窗口入口；开源智能体框架 OpenClaw 因代币风波全面封禁加密货币关键词；千问"一句话下单"在春节把山西运城一家县城副食店带成了爆单现场。

> 本期记 3 条：Windows 11 任务栏开放"与虚拟助手共享任意窗口"、OpenClaw 封禁加密货币相关关键词、千问"一句话下单"带火县城小店。

## 1. 微软把任务栏变成 AI 智能体的入口

据 IT 之家与 Windows Latest 报道，微软正在为 Windows 11 任务栏测试一项名为"从任务栏与虚拟助手共享任意窗口"的新选项，Copilot 和 Microsoft 365 Copilot 等受支持的应用可以直接从任务栏界面访问用户选择的任意窗口。

操作逻辑是：把鼠标悬停在任务栏上的应用缩略图时，会出现"分享给 Copilot"按钮；点击后 Copilot 可以读取窗口里的可见内容、总结信息、建议回复，或者高亮 UI 元素并用自己的光标引导用户完成操作。这条链路被设计为**只读的辅助层**——AI 能看到用户所见内容，但不会控制应用，也不会与受保护内容交互。

Windows Latest 发现，微软正在使用一个名为 `Windows.UI.Shell.ShareWindowCommandSource` 的 Windows API，让 Teams 等应用接入任务栏。这个 API 原本是为通讯应用设计的、标记为"受限访问功能"，微软似乎正在扩展它的底层架构，使 AI 智能体能够注册为共享目标，让 Windows 直接从任务栏传递选定的窗口 ID。到目前为止只有 Copilot 与 Microsoft 365 Copilot 进入白名单，第三方 AI 智能体需要微软开发者批准才能加入。

值得注意的是权限模型的变化：以前"与 Copilot 共享"是悬停缩略图时的一个动作，现在被规范化成一个系统级开关。用户可以逐个开启或关闭某个 AI 智能体，截图显示每个智能体左侧有 6 个点、可长按拖动调整优先级。该功能默认关闭，可在"设置 > 个性化 > 任务栏 > 任务栏行为"下找到。

这被外界看作微软把 Windows 打造为"智能体操作系统"计划的一部分。微软此前已在测试"Ask Copilot"，该功能有望取代传统的任务栏搜索，成为一键调用 Copilot 语音与视觉能力的入口。

## 2. OpenClaw 全面封禁加密货币关键词

据 BlockBeats 2 月 22 日报道，开源 AI 智能体框架 OpenClaw 因代币风波在官方 Discord 服务器**全面禁止提及"Bitcoin""crypto"等关键词**，即便是中性技术讨论也不例外，甚至有用户因为引用比特币区块高度做基准测试而被移出服务器。

事件的源头要回溯到项目更名期间。OpenClaw 由开发者 Peter Steinberger 发起，最初名为 Clawdbot，因与 Anthropic 旗下模型 Claude 名称近似收到商标警告，随后短暂更名为 Moltbot，最终定名 OpenClaw。就在旧 GitHub 与 X 账号释放、新账号尚未完成交接的窗口期，诈骗方抢注账号并推出基于 Solana 的假代币 CLAWD，引发投机炒作，其市值一度飙升至 1600 万美元，在创始人公开否认关联后暴跌逾 90%。Steinberger 随后表示永远不会发行代币，并强调任何以其名义发币的项目均为骗局。

另一条同期进展是人事与治理的调整：Steinberger 目前已加入 OpenAI 负责个人代理部门，OpenClaw 则转为独立开源基金会运作。尽管争议不断，项目社区仍在扩张，但官方立场已明确——与加密领域保持距离。

## 3. 千问"一句话下单"把县城小店带成了爆单现场

据潮新闻报道，这个春节山西运城市稷山县的杨鹏创副食店因为一款智能应用迎来了销售高峰。店主杨鹏创的说法是："三部手机一起都接不过来单，最忙的时候吃饭时间都没有。但心里面就是挺高兴的。"

数字很具体。店里平时一天也就接 20 多单，**千问活动一上线，最多的时候一天接了 1300 多单**；十来天下来一共接了 5000 多单，是去年春节的七八倍。最忙的时候他们喊来了淘宝闪购的运营人员一起帮忙接单打包。5000 多单里卖得最多的是鸡蛋——当地过年期间家家户户的刚需，杨家做鸡蛋生意 30 多年，靠的是乡亲们的口口相传。

爆单的直接触发点是补贴组合。过年期间当地一盘鸡蛋价格大概十五六元，千问推出 25 元的免单券，买一盘基本不用花钱，买两盘减去 25 元也花不了多少钱；活动后来无缝衔接"每日首单必减"，最低也能减 3 块 8。顾客还反向"安利"起了店主——"我们也是通过顾客的口中，才知道怎么用"，年轻顾客手把手教他在千问 APP 里用语音说一句"帮我买鸡蛋"，AI 就能自动选好商品、扣减优惠，直接下单到他店里。

对店主来说，技术就这么落地了：县域小店第一次通过一句话接住了从线上来的订单，而它的供给能力、品质口碑和线下骑手网络，恰好构成了这套模式能跑通的前提。
