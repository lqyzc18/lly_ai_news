# 2024-10-02 AI 大事件

北京时间 2024 年 10 月 2 日（星期三）。OpenAI 开发者日（DevDay）当天凌晨在北京时间落地，Realtime API 公开测试、Prompt Caching、模型蒸馏与视觉微调四项开发者能力同时发布；人事方面，OpenAI 联合创始人 Durk Kingma 宣布加入 Anthropic；监管方面，欧盟委员会依 DSA 向 Snapchat、TikTok、YouTube 三家平台发出信息索取函，焦点直指推荐算法；产品侧，Character.AI 在与谷歌完成 27 亿美元授权交易后聘请前 YouTube 高管出任首席产品官。

> 本期记 4 条：OpenAI DevDay 发布 Realtime API 等四项能力；OpenAI 联合创始人 Durk Kingma 加入 Anthropic；欧盟依 DSA 问询三大平台的推荐算法；Character.AI 聘 Erin Teague 任首席产品官。

## 1. OpenAI DevDay：Realtime API 公开测试，语音交互下沉到开发接口

美东 10 月 1 日上午的 OpenAI DevDay 上，公司发布 Realtime API 公开测试版，开发者可以借此构建接近实时的语音到语音交互，官方提供六种音色。这批音色与 ChatGPT 语音模式不同，且不允许接入第三方音色以规避版权问题；被外界广泛讨论的那款与 Scarlett Johansson 高度相似的音色则完全不在可选范围内。

演示环节由 OpenAI 开发者体验负责人 Romain Huet 主持：一个行程规划应用允许用户用语音与助手讨论即将到来的伦敦行程并得到低延迟回答，助手还能在回答时于地图上标注餐厅位置；另一个例子是让模型打电话向人工询问活动餐饮订单，但 API 本身不能直接呼叫餐厅，需要开发者接入 Twilio 之类的通话接口完成。值得注意的是，OpenAI 并未强制模型在通话中自报家门，这一披露义务暂时留给开发者，可能与加州即将生效的披露要求有关。

OpenAI 首席产品官 Kevin Weil 在会前对记者表示，首席技术官 Mira Murati 与首席研究主管 Bob McGrew 的离职不会影响公司进度，并称「我们不会放慢脚步」。公司称其平台上的开发者数量已超过 300 万，两年间 API 访问成本下降 99%。这一届 DevDay 没有发布任何新模型，等待完整版 o1 和 Sora 的开发者需要再等一等；上一届主打的 GPT Store 也没有新进展。

## 2. Prompt Caching、模型蒸馏与视觉微调：开发者成本被重新定价

同场还发布了三项面向 API 的能力。Prompt Caching 允许开发者在多次调用之间缓存常用上下文以降低成本并改善延迟，OpenAI 称可节省 50%，而数月前率先推出同类功能的 Anthropic 承诺的是 90% 折扣。

模型蒸馏功能允许开发者用 o1-preview、GPT-4o 等大模型的输出，去微调 GPT-4o mini 一类的小模型；OpenAI 同步上线了一个 beta 版的评测工具，方便开发者直接在 API 内测量微调后模型的表现。视觉微调则把图像纳入 GPT-4o 的微调素材，用于提升涉及视觉理解任务的表现，OpenAI API 产品负责人 Olivier Godement 对 TechCrunch 表示，开发者不能上传受版权保护的图像、暴力或违反安全政策的素材。

节奏上，这是 OpenAI 在 Meta、谷歌持续压价的背景下把开发者成本当成主战场的一年：Realtime API 压的是交互延迟，Prompt Caching 压的是重复上下文单价，模型蒸馏压的是推理成本，而视觉微调把多模态能力开放给了更小的模型。

## 3. OpenAI 联合创始人 Durk Kingma 加入 Anthropic

美东 10 月 1 日下午，OpenAI 较不为人所知的联合创始人之一 Durk Kingma 宣布将加入 Anthropic。他在 X 上连发数条消息说明此事，表示自己会主要在荷兰远程办公，但没有透露将加入 Anthropic 哪个团队或担任什么职务；Anthropic 发言人的回应是请媒体参考 Kingma 本人的帖子。

Kingma 拥有阿姆斯特丹大学机器学习博士学位，曾在谷歌担任研究员，后作为研究科学家加入 OpenAI 初创团队，牵头算法团队开发生成式模型相关技术与方法，涉及 DALL-E 3 等图像生成器和 ChatGPT 等大语言模型。2018 年他离开 OpenAI 转型为天使投资人与顾问，同年 7 月重回谷歌，进入 Google Brain，该实验室在 2023 年并入 DeepMind。

他本人在帖子中写道：「Anthropic 的 AI 研发路径与我的信念高度契合」，并提到将与「包括多位来自 OpenAI 和谷歌的前同事」一起工作。这已经是 Anthropic 近期从 OpenAI 挖角的又一笔，招聘动作此前还包括 OpenAI 前安全负责人。

## 4. 欧盟依 DSA 问询三大平台的推荐算法，Character.AI 换帅

10 月 2 日，欧盟委员会宣布已向 Snapchat、TikTok 和 YouTube 发出信息索取函（RFI），要求三家公司补充说明其内容推荐算法的设计与运行机制，回复期限为 11 月 15 日。委员会称回复结果将决定是否启动正式调查。由于三家均被指定为「超大型在线平台」（VLOP），它们需要额外承担系统性风险缓解义务，包括识别并缓解把 AI 用作内容推荐工具可能带来的风险。

欧盟在框架中划出的重点是防止对用户心理健康和公民讨论造成负面影响，并已警告过以提升互动率为目标的算法可能助长有害内容传播。违反 DSA 的罚则最高可达全球年营业额的 6%。

产品侧，Character.AI 在与谷歌达成 27 亿美元授权交易、CEO Noam Shazeer 回归谷歌之后迎来产品层换帅。公司聘请前 YouTube 体育电影与剧集产品管理全球负责人 Erin Teague 出任首席产品官，她自 2016 年起供职于谷歌，下周正式到岗，此前还担任过搜索、广告、地图、Gemini、助手、购物与支付业务高级副总裁的技术顾问。临时 CEO 兼总法律顾问 Dominic Perella 向 TechCrunch 表示，公司目前约有 100 名员工，将完全聚焦消费级 AI 解决方案，不再追逐通用人工智能。Teague 是联合创始人陆续离开后公司引入的第一位重量级新人。
