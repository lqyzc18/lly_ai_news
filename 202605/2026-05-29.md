# 2026-05-29 AI 大事件

北京时间 2026 年 5 月 29 日（星期五）。5 月 28 日，英伟达研究团队开源了强化学习训练框架 Polar，做法是在 Agent 和模型 API 之间架一个代理，让 Codex、Claude Code、Qwen Code 这些现成的编码智能体不改一行代码就能接入 GRPO 训练，在 SWE-Bench Verified 上把 Codex 的 pass@1 从 3.8% 拉到 26.4%。同日，阿里 Qoder 上线全托管的 Agent 运行平台 Cloud Agents，官方称 Agent 上线周期从一个月缩短到一天；比亚迪则发布了自研的中国首款 4nm 智驾芯片"璇玑A3"。资本一侧，AI 编程公司 Cognition 宣布完成超过 10 亿美元融资，投后估值 260 亿美元。政策一侧，西班牙内阁 5 月 26 日通过了《人工智能合理使用与治理组织法》，AI 生成内容必须打标，违规最高可罚 3500 万欧元。供应链安全方面，安全研究员披露有人借助 Claude 批量生成并向 npm 推送了超过 670 个含恶意脚本的包。

## 1. 英伟达开源 Polar：不改代码给编码智能体接上 GRPO

Polar 由英伟达研究团队于 5 月 28 日开源，论文挂在 arXiv 上编号 2605.24220。它的切入点不是改 Agent 的代码，而是把"模型 API 边界"当作训练入口：在执行框架和推理服务器之间放一个透明代理，拦截转发请求，同时实时记录提示词、采样 token 和对数概率，再重建成强化学习训练器需要的轨迹。

要解决的问题是 harness 的多样性。传统做法要求把 Agent 的调用逻辑改写成 env.init()、env.step()、env.reset() 这类标准接口，Codex、Claude Code、Qwen Code 各自有协议和上下文管理方式，每接一个新框架都要写一套集成代码，改写过程中还容易丢掉工具调用细节和多轮上下文。Polar 的代理方案只关心 API 边界，框架内部怎么实现不管。

效果数据出自论文和官方材料。同一个 Qwen3.5-4B 底座上，接入 GRPO 训练后，Codex 框架的 pass@1 从 3.8% 升到 26.4%，增幅 594.74%；Claude Code 从 29.8% 升到 34.6%，Pi 从 34.2% 升到 40.4%，Qwen Code 提升 0.6 个百分点。工程侧的另一组数字来自 Prefix Merging 轨迹重建策略：训练更新次数从 1185 次降到 218 次，墙钟时间从 189.5 分钟压到 35.2 分钟，GPU 利用率从 20.4% 升到 87.7%。架构上由 Rollout Server 负责任务分发与会话调度、Gateway Node 管理会话生命周期，两者异步解耦。论文也写明局限：奖励函数设计和评估器质量仍由研究者负责，Polar 依赖底层推理服务提供可靠的 token ID 和 log probability。

## 2. Cognition：融资超 10 亿美元，投后估值 260 亿美元

Cognition 5 月 27 日（周三）宣布完成超过 10 亿美元的新一轮融资，投前估值 250 亿美元，投后约 260 亿美元。这轮由 Lux Capital、General Catalyst 和 8VC 联合领投，原有投资方 Elad Gil、Soma Capital、Omri Casspi 和 Founders Fund 跟投，Ribbit Capital、Atreides Management 和 Layer Global 作为新投资方加入。加上这一笔，累计融资超过 25 亿美元。参照系是 2025 年 9 月的 3 亿美元 C 轮，投后 102 亿美元，八个月里估值走了 2.5 倍。

公司给出的经营数据是：年化收入 run rate 约 4.92 亿美元，一年前约为 3700 万美元，十二个月 13 倍；自 2026 年 1 月以来企业客户对 Devin 的使用量增长十倍以上，最近六个月保持月环比约 50% 的增速。客户名单包括高盛、花旗、戴姆勒-奔驰、戴尔、桑坦德银行、Palantir、NASA 以及美国陆军和海军单位。Devin 自身在公司内部贡献的代码比例被公司称为 89%，2025 年 12 月时这个数字是 13%。此外 Cognition 发布了自研模型 SWE-1.6，并把此前收购的 Windsurf 资产整合成 Devin Desktop，随付费方案一起提供。

这一轮的时间点值得对照：过去一年 Anthropic 的 Claude Code、OpenAI 的 Codex 和谷歌的编码工具都在争夺同一块市场。Cognition 把自己定位成"唯一一家做到这个规模的独立厂商"，称自身收入完全取决于 Devin 是否是最好的自主工程师，而不是取决于它是不是某个平台里最好用的插件。收入、客户和内部代码占比均为公司自报，各家基准的口径也不统一。

## 3. 公司与产品三则：Cloud Agents、璇玑A3 与小鹏的量产时间表

阿里 Qoder 于 5 月 28 日上线 Cloud Agents，官方定位是全托管的 AI Agent 运行平台，提供 Agent 底座、模型服务和运行环境等全栈能力，企业通过 API 直接调用，官方口径是 Agent 上线时间从 1 个月缩短到 1 天。企业自己搭推理执行引擎、运行沙箱和长程会话往往要一个月，Cloud Agents 把这套流程封装成托管服务，由 Qoder 底层的 Coding Agent 引擎驱动，官方称接入方无需改代码。每个 Agent 有独立沙箱，每一次工具调用和每一步推理通过 SSE 事件流实时推送，全程可追踪、可回放、可审计；原生支持 Skills 和 MCP 协议。Qoder 家族目前包含 Qoder Desktop、Qoder CLI、JetBrains 插件、桌面智能体工作台 QoderWork、数字员工 QoderWake、Cloud Agents 和移动端等，官方称已服务全球超过 500 万用户。

比亚迪在 5 月 28 日晚的智能化战略发布会上发布自研智驾芯片"璇玑A3"。王传福称其为中国首款 4nm 智驾芯片，已开启规模化量产，支持 L3、L4 自动驾驶，官方口径是三颗芯片总算力超过 2100 TOPS，配合比亚迪自研算法深度优化，算力利用率提升 100%。支撑这套能力的是比亚迪自 2002 年组建的 IC 设计部，已推出 2000 多款芯片产品，拥有 5 座晶圆工厂，覆盖从产品定义到测试七大步骤，官方称是全球唯一具备芯片全流程、全链路制造能力的车企；芯片研发团队超过 7000 人，相关投入超千亿元，设有 4 大研发基地。同场王传福宣布继智能泊车安全兜底之后，再对城市领航提供 1 年安全兜底，天神之眼 A、B 的新车用户自提车之日起享此服务，因辅助驾驶导致的交通事故由比亚迪全额赔付本车应承担的经济损失。这些均为厂商自述。

小鹏的一季度财报与机器人时间表也在同一天晚间公布。当期总交付 62,682 辆，同比减少 33.3%；总收入 130.3 亿元，同比下降 17.6%，略低于市场预估的 131.6 亿元；经营亏损 18.7 亿元，净亏损 17.8 亿元，上年同期净亏 6.6 亿元。公司给出的二季度指引是交付 10 万至 10.6 万辆，环比增长约 60% 至 69%，高于彭博综合预期的 96,923 辆，总收入 196 亿元至 208 亿元，同比增长约 7% 至 14%。何小鹏在电话会上表示，面向量产版本的新一代 IRON 人形机器人软硬件研发进展顺利，即将进入 ET2 软硬件合围阶段，计划三季度正式亮相，目标年底实现高阶人形机器人量产，先在小鹏门店试商用，明年起面向中国及海外商业客户交付；他还称从明年起，人形机器人的硬件收入和 AI 模型收入将是集团收入和毛利增长的重要驱动力之一。小鹏近日召开的机器人量产动员大会有汽车、动力、制造、测试、通用智能等中心近千名员工参加。

## 4. 西班牙：AI 法案落地国内法，标注义务 8 月 2 日起先行

西班牙内阁 5 月 26 日通过了《人工智能合理使用与治理组织法》，提交众议院继续审议，数字化转型与公共管理部随后公布了主要内容。立法目的是把已经生效的欧盟《人工智能法》纳入西班牙国内法体系，同时加强对 AI 生成内容的识别与监管。

罚款分三档。轻微违规（例如拒绝配合监管调查）从 6000 欧元起，最高 50 万欧元或企业营业收入的 0.5%；严重违规最高 3500 万欧元；被认定为"极其严重违规"的，可以达到企业全球营业额的 7%。针对"高风险 AI 系统"另设一档，企业在缺乏人工监督的情况下使用相关系统，最高可罚 1500 万欧元或营业收入的 3%。这组上限与欧盟《人工智能法》高风险条款的处罚标准一致，该条款将于 8 月 2 日生效。

内容侧，法案明确禁止使用 AI 生成色情换脸视频和儿童色情内容；其他类型的深度伪造，比如涉及政治人物或公众人物的 AI 换脸，不完全禁止，但要求从首次发布起就标注"AI 生成"。AI 生成的视频和图片必须在画面角落加清晰可见的"AI"水印，AI 生成音频适用类似规则——无论发布在 Spotify、Apple Music 还是其他平台，应用都必须显示 AI 标识，无法显示水印的，音频本身必须加入 AI 生成提示。这项强制标注从今年 8 月 2 日起实施，比整部法律本身更早。监管分工上，人工智能监管局 AESIA 是主要监管机构，计划在今年年底前招聘 50 名分析师；数据保护局负责生物识别事务，司法总理事会负责司法领域，西班牙银行负责金融系统中的 AI 问题。整部法律预计在 2027 年底前正式生效，在那之前监管机构无法对违规企业正式开出罚单。争议点之一是公共部门被区别对待：按法案内容，警方、政府部门或公共机构违规使用被禁止的 AI 系统不会被直接罚款，只接受训诫或纪律处分；西班牙政府的回应是公共部门将面临更高的透明度要求，包括建立政府 AI 系统公开清单，并新增"AI 专员"职位负责协调和监督行政部门中的 AI 使用。

## 5. 供应链安全：670 余个用 Claude 生成的恶意 npm 包

安全研究员 Sibi Moosa 披露，网名为"mousie-5212-super-formatter"的恶意开发者在短时间内向 npm 仓库推送了超过 670 个含恶意脚本的软件包，攻击者使用 Anthropic 的 Claude 编写恶意代码。这些包伪装成常用工具包，部分模仿知名开源包的名字或功能描述做 typosquatting，一旦被开发者误装，会在后台窃取 npm 和 GitHub 令牌、环境变量等敏感凭据，并把私有代码仓库上传到攻击者控制的存储库。中文媒体在 5 月 27 日至 28 日间作了报道。

攻击手法的变化在于门槛。攻击者向 Claude 提供样本代码和提示模板，批量生成符合 npm 规范、带 README、版本号甚至模拟测试用例的完整包，恶意代码通常藏在 postinstall 钩子或 index.js 入口里并做了混淆。由于生成代码在语法上与手写恶意代码难以区分，依赖签名的静态扫描工具检测率明显下降。多个包在注册表上只存活数小时到数天，但已足以被自动依赖解析工具或 CI/CD 流水线抓取，一旦进入企业内网或云环境，攻击者即可获得持久访问。这起事件的责任归属并未明确：分析意见把它定性为既有供应链治理缺陷的工业化放大，注意力应放在注册表审核与新包发布机制上；也有观点认为这第一次把一个主流商业模型与具体的恶意软件生产直接关联起来，模型安全护栏的有效性、以及平台（npm）、模型提供方（Anthropic）与攻击者之间的责任划分，都需要重新讨论。
