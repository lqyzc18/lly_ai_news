## 1. Anthropic：程序化调用从订阅里剥离，改发月度 Credit

据新智元 5 月 16 日的报道，Anthropic 宣布从 6 月 15 日起，claude -p、Agent SDK、GitHub Actions 以及 OpenClaw、Hermes 等第三方工具的调用，全部从订阅限额中剥离。取而代之的是一笔按 API 零售价计费的月度 Credit：Pro 档 20 美元，Max 5x 档 100 美元，Max 20x 档 200 美元。原有订阅限额保持不变，专供 Claude Code 的交互式使用和 claude.ai 聊天，两个池子互不干扰。Credit 需要手动领取，6 月 8 日发邮件通知，6 月 15 日生效，每月重置、不累积。

缩水幅度是这个调整的实质。报道的测算显示，一个 200 美元/月的 Max 20x 用户，手动交互能消耗的 token 量按 API 零售价折算约值 2000 到 5000 美元；换成 Credit 之后，等值部分被压到 200 美元。Pro 用户拿 20 美元用 Sonnet，只够约六七百万 token 输入或一百多万 token 输出，几轮密集的 Agent 循环就会见底。Anthropic 的帮助文档同时写明，跑生产级自动化的团队应改用开发者平台的 API Key 按量付费。

作为安抚，Claude Code 的限额在同一周连升两次：5 小时滚动窗口翻倍，每周总额再加 50%，叠加生效并截止到 7 月 14 日，所有付费用户自动调整、无需操作。OpenAI 则抓住窗口期推出 Codex 企业免费迁移：30 天内申请、2 个月免费，内置一键迁移工具，可直接搬运 Claude Code 的系统提示词、Skills 和 MCP 配置；Codex 本身不区分交互式与程序化调用。报道把这次调整解释为订阅经济模型的一个漏洞——订阅补贴的前提是人类打字速度有限，机器 24 小时循环调用则不受这个前提约束。报道同时提到 Anthropic 近期的算力扩张（SpaceX 租出 22 万块 GPU、谷歌追加投资、亚马逊容量协议），这几项本次未另行核实。

## 2. 阿里安全 PlugGuard 获 ICML 2026 录用：把防线前移到解码过程中

阿里安全 AIGC 安全团队的研究 PlugGuard 被 ICML 2026 正式录用。论文见 arXiv 2510.09694，项目地址为 Alibaba-AAIG/Kelp。ICML 是机器学习领域的 A 类会议，录用率 26.6%。

这篇工作的出发点是现有内容安全范式的时序问题。主流的"后置检测"要等模型把一整段内容生成完才能开始审查，而违规信息在这之前已经完整展示给用户；流式实时防御则把逐 token 的安全性预测放进生成过程，防御节点从"响应生成后"前移到"解码过程中"。团队认为这一方向长期受阻的原因是缺少可信的评估标准——现有端到端安全评测依赖静态语料库，模型回复多来自异构模型或人工撰写，无法真实模拟目标模型在解码过程中的风险分布。

为此团队构建了业界首个模型相关的流式防御基准 StreamGuardBench：每一条响应都由待测的具体目标模型实时生成，覆盖 Qwen、Llama 等 10 款模型；整合 WildGuard、S-Eval 等数据集并包含图文模态；规模为 26.8 万对 query-response 样本。PlugGuard 本身是一个轻量化插件框架，做法是"旁路监听"模型的中间层状态。两个关键设计是流式隐状态动态感知头（SLD），用封闭式连续时间神经网络对连续文本序列的隐状态建模，从语义波动中提前预判风险；以及锚定时序一致性（ATC）监督，对生成序列尾部的 token 施加约束，以减少流式判断的抖动。

## 3. 上交、创智与瑞金联合发布 CX-Mind：胸片诊断进入可验证推理链

上海交通大学、上海创智学院与瑞金医院联合发布 CX-Mind，论文刊于 Information Fusion（DOI: 10.1016/j.inffus.2025.104027），中文解读于 5 月 16 日在量子位等渠道集中出现。团队称这是目前首个把胸片诊断推进为"可验证推理链"的多模态大模型：不再只输出标签，而是给出从观察到鉴别再到结论的每一步影像证据。

方法上的关键设计是 interleaved reasoning——把医学推理拆成可解析的 think-answer 交错单元，封闭式问题逐项评估候选答案并给出保留或排除的证据，开放式问题先提出可能疾病再逐个核验。配套数据集 CX-Set 整合 23 个胸片相关公开数据集，形成 708,473 张影像和 2,619,148 条指令样本，并构建了 42,828 条由真实放射学报告监督的交错式推理样本。训练上提出 CuRL-VPR，即带可验证过程奖励的课程强化学习，奖励同时包含格式、最终结果与过程三项，用真实放射科报告核查每一步推理是否有影像证据支撑。

论文报告的结果是：视觉理解、报告生成、时空对齐三大能力域平均提升 25.1%；单疾病识别相对 CheXagent 和 ChestX-Reasoner 平均提升 19.5% 和 21.0%，多病共存诊断提升 63.5% 和 21.2%；报告生成上与 GPT-4o 相比 Finding Generation 的 BERTScore 高 1.6%、BLEU 高 7.6%、ROUGE 平均高 11.1%，Impression Generation 的 BERTScore 达到 90.3% 和 80.7%。真实世界测试集 Rui-CXR 来自瑞金医院 2018 至 2023 年采集的 80,648 名患者标准 PA 位胸片及报告，脱敏筛选后为 4,031 张、覆盖 14 种常见胸部疾病，mean recall@1 领先。团队还邀请多中心、跨资历的临床医生做主观评估，在临床相关性、逻辑连贯性、证据支持、鉴别诊断覆盖度和解释清晰度五个维度上均取得最高平均分。这些均为论文自身的评测结果。

## 4. 浙大与阿里安全：MetaCompress 指出注意力分数准则在多轮场景失效

浙江大学宋明黎教授团队与阿里巴巴集团安全部联合提出的 MetaCompress 被 CVPR 2026 录用，方向是多轮视觉问答场景下的学习式 Token 压缩。论文的切入点是现有压缩方法在多轮对话中集体失效：Prompt 依赖型方法（如 FastV）只按首轮文本 prompt 筛选 token，天然偏向初始问题；Prompt 无关型方法（如 PruMerge）则依赖人工先验设计的注意力分数这类启发式准则。

团队把剪枝与合并统一形式化为可学习的压缩映射优化问题，为每张图单独学习最优压缩矩阵，再与启发式注意力分数做对照。核心发现是：绝大多数被最优策略保留的 token 与注意力分数没有明显相关性，即便有少量高注意力 token 被保留，占比也只有 1.71%。结论是依赖人工先验的注意力分数准则在多轮场景下并非最优的 token 保留策略，应当改用数据驱动的方式学习通用的压缩映射。相关结论均出自论文自身的实验。
