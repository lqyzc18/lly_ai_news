# 2026-05-19 AI 大事件

北京时间 2026 年 5 月 19 日（星期二）。5 月 18 日最重的一条是裁决：加利福尼亚州奥克兰一家联邦法院的陪审团认定马斯克诉 OpenAI 的主张已超过诉讼时效，马斯克一方败诉，OpenAI 等被告不承担责任，马斯克当晚表示将向第九巡回上诉法院提起上诉。中国一侧同日落地两条数据：百度发布一季度财报，AI 业务收入 136 亿元、占一般性业务收入的 52%，首次过半，AI 云收入 88 亿元、同比增长 79%；《每日经济新闻》据 OpenRouter 测算，5 月 11 日至 17 日这一周，中国大模型周调用量 7.693 万亿 token，是美国的 1.81 倍，连续三周反超，腾讯 Hy3 preview 以 2.66 万亿登顶。企业侧，Anthropic 收购了为 OpenAI、谷歌、Cloudflare、Meta 提供官方 SDK 的 Stainless；OpenAI 则与戴尔合作把 Codex 送进客户机房；Salesforce 同期披露今年预计要在 Anthropic token 上花掉约 3 亿美元。

## 1. 马斯克诉 OpenAI 败诉：陪审团只裁了诉讼时效

据新华社旧金山 5 月 18 日电，加利福尼亚州奥克兰市一家联邦法院的陪审团 18 日裁定，马斯克针对 OpenAI 的相关主张已超过诉讼时效，马斯克一方败诉，OpenAI 等被告不承担相应责任，主审法官接受了该裁决。法院公开资料显示，该案 2024 年 8 月立案；马斯克指控 OpenAI 联合创始人萨姆·奥尔特曼和格雷格·布罗克曼等人违背创立初衷，把商业利益置于公共利益之上，庭审围绕创立宗旨、架构变化、与微软的合作以及人工智能公共利益承诺展开。

OpenAI 方面的抗辩是：马斯克早就知道 OpenAI 的架构变化，起诉时间过晚。判决公布后，OpenAI 律师称马斯克发起这场诉讼"只是企图损害竞争对手"。马斯克当晚在 X 上发文说，法官和陪审团仅仅考量了诉讼时效这个技术性问题，并非就案件是非曲直作出裁决；他表示将上诉，同时坚持 OpenAI 的创立初衷是造福全人类，奥尔特曼和布罗克曼"实际上是通过窃取一家慈善机构获利"。

需要写清的是裁定的范围：这是一份时效裁决，法院没有对 OpenAI 是否放弃非营利使命这一实体问题作出判断，马斯克一方也没有因此承担赔偿责任。2015 年马斯克与奥尔特曼、布罗克曼等共同创立非营利实体 OpenAI，2018 年离开，2023 年创立 xAI；本月他宣布 xAI 今后将成为 SpaceXAI 的人工智能产品。

## 2. 百度一季度财报：AI 业务占比首次过半，昆仑芯 P800 交付万卡集群

百度 5 月 18 日发布 2026 年第一季度财报。季度总营收 321 亿元，同比下降约 1%、环比下降 2%，但超过市场预期的 314.9 亿元；一般性业务收入 260 亿元，同比增长 2%；归属百度的净利润 34 亿元。AI 业务收入 136 亿元，占一般性业务收入的 52%，连续多个季度增长，是这个比例首次超过一半。李彦宏在财报中的说法是，这表明"AI 已成为百度的核心驱动力"。

云是这季度的主力。百度 AI 云收入 88 亿元，同比增长 79%；GPU 云收入同比增长 184%。百度智能云升级为面向大规模智能体应用的全栈 AI 云，Agent Infra 与 AI Infra 能力同步进化。AI 应用收入 25 亿元，AI 原生营销服务收入 23 亿元、同比增长 36%；3 月百度 App 月活跃用户 6.55 亿。

算力一侧：昆仑芯 P800 完成规模化验证，交付多个万卡集群，昆仑芯全国产集群已完成文心大模型 5.1 重要版本的训练；基于昆仑芯的天池 256 卡超节点已点亮，将于 6 月上市，吞吐性能较上一代提升 25%，完成文心、DeepSeek、GLM、MiniMax 等主流模型适配，推理效率提升 50%。萝卜快跑一季度提供 320 万次全无人驾驶出行服务，总单量同比增长超 120%，累计出行服务超 2200 万次，覆盖 27 座城市，自动驾驶总里程突破 3.3 亿公里，其中全无人驾驶 2.2 亿公里。财报发布后 5 月 19 日港股开盘，百度股价一度涨近 3%。

## 3. OpenRouter 周榜：中国大模型调用量连续三周超过美国

《每日经济新闻》据 OpenRouter 数据测算，5 月 11 日至 17 日这一周，全球 AI 大模型总调用量 26.9 万亿 token，环比增长 4.7%，连续四周上涨。其中中国 AI 大模型周调用量 7.693 万亿 token，与前一周基本持平；美国 AI 大模型周调用量 4.24 万亿 token，环比上涨 12.77%。中国是美国的 1.81 倍，连续三周反超并稳居全球首位。

榜单前两名都是中国模型。腾讯 Hy3 preview 以 2.66 万亿 token 周调用量登顶，环比上涨 210%，接替此前两周位居榜首的 Hy3 preview (free)；DeepSeek-V4-Flash 以 2.06 万亿排在第二，环比上涨 86%，DeepSeek-V3.2 和 DeepSeek-V4-Pro 同期也都在榜且环比上升。月之暗面 Kimi K2.6 周调用量 1.05 万亿，环比下滑 35%，跌出前五。匿名模型 Owl Alpha 以 0.895 万亿排名第八、环比上涨 121%，据 OpenRouter 称是面向智能体工作流的基础模型，支持工具调用、百万上下文和代码生成。

按厂商汇总，OpenRouter 上 DeepSeek 旗下模型的周调用总量达 4.25 万亿 token，超过 Anthropic 和谷歌，居第一。这份榜单只统计经 OpenRouter 路由的调用，不等于全球 API 调用总量，OpenRouter 自己的模型上架情况也会影响排名。

## 4. Anthropic 收购 Stainless：把 SDK 与 MCP 连接层收进自己手里

Anthropic 于 5 月 18 日收购了 SDK 与 MCP 服务器创业公司 Stainless，据 The Information 报道，交易金额"至少 3 亿美元"，部分以 Anthropic 股权支付，Anthropic 未披露具体数字。Stainless 创办于 2022 年，创始人是前 Stripe 工程师 Alex Rattray，公司用一套托管流水线从 API 规范生成 TypeScript、Python、Go、Java、Kotlin 等多种语言、带完整类型的 SDK。

Stainless 的客户名单里不只有 Anthropic——OpenAI、谷歌、Cloudflare 和 Meta 的官方客户端库都出自它的流水线。它同时生成 MCP 服务器，也就是把智能体接到外部 API 的那层连接件；MCP 是 Anthropic 2024 年 11 月推出的开放协议，2025 年 12 月被捐给 Linux 基金会下的 Agentic AI Foundation。Anthropic 平台工程负责人 Katelyn Lesse 的说法是："智能体只有连得上东西才有用。"创始人 Rattray 说，客户会保留已经生成的 SDK 并可以继续扩展，但托管的 SDK 生成产品将被关停，后续维护由谁接手没有说清。

这笔交易的实质是拿掉一个跨厂商的维护依赖：竞争对手的 SDK 不会明天就坏掉，但随着语言生态、运行时和底层 API 漂移，谁来持续维护就成了问题。Anthropic 说 Stainless 团队会在公司内部继续现有工作。

## 5. 企业侧的两笔账：Codex 进本地机房，Salesforce 付 3 亿美元 token

OpenAI 与戴尔 5 月 18 日宣布合作，把 Codex 带进 Dell AI Data Platform 和 Dell AI Factory，也就是戴尔已经部署在 5000 多家企业客户那里的本地基础设施。OpenAI 说 Codex 现在每周有超过 400 万名开发者在用（4 月 21 日的数字，两周新增 100 万），并明确把 Codex 的适用范围从代码审查和测试覆盖扩展到"报告准备、反馈路由、线索筛选、后续跟进，以及跨业务系统的协调"。公告里用的词是"智能体 AI harness 与模型"，Codex 在被重新定位成通用的企业智能体底座，而不只是编程工具。戴尔 AI Factory 的组合是 PowerEdge 服务器、PowerScale 存储、PowerSwitch 网络和本届 Dell Technologies World 上新发的 PowerRack 机架级系统。公告没有给出具体的推出时间表，"探索 Codex 如何连接"和成熟运营模式之间还有距离；消息发布当天戴尔股价跌 3% 至 234 美元。

另一笔账在 Salesforce。CEO Marc Benioff 在 5 月 16 日发布的 All-In 播客里说，公司今年预计会在 Anthropic 的 token 上花大约 3 亿美元，绝大部分用于编程智能体工作负载。他的原话是："这些编程智能体很棒，Anthropic 很棒，我今年大概会在 Salesforce 用掉 3 亿美元的 Anthropic，成本会一路降下来。"Salesforce 约 1.5 万名工程师现在与 Anthropic 模型、OpenAI Codex 和 Cursor 并行工作，他从 2024 年末宣布 2025 年不招软件工程师，称 AI 工具带来的效率提升超过 30%。Agentforce 的年度经常性收入达到 8 亿美元，同比增长 169%，累计签下 2.9 万单；Slack 收入预计今年到 30 亿美元。Benioff 还提出需要一个中间层，把复杂推理任务路由到前沿模型、简单任务路由到更便宜的模型。
