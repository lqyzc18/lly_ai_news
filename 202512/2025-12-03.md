# 2025-12-03 AI 大事件

北京时间 2025 年 12 月 3 日（星期四）。DeepSeek 发布 V3.2 与 V3.2-Speciale 双模型，正式转正稀疏注意力（DSA），把长文本计算复杂度从 O(n²) 降到 O(n)，首次在开源模型实现百万 token 单卡推理。Mistral AI 推出 Mistral 3 系列开源模型，14B 版本单张 A100 即可跑满 128K 上下文。商汤联合南洋理工 S-Lab 开源原生多模态架构 NEO，数据量减 90% 仍拿下 SOTA。

## 1. DeepSeek V3.2 双模型：DSA 转正，百万 token 单卡推理

据 AIBase 报道，DeepSeek 发布 V3.2（标准版）与 V3.2-Speciale（深度思考版）。官方评测显示，V3.2 在 128k 上下文场景下与 GPT-5 互有胜负；V3.2-Speciale 在 MMLU、HumanEval 等基准中与 Gemini 3 Pro 打平，IMO 2025 盲测拿到 83.3% 的金牌分数线。

核心升级是稀疏注意力（DSA）转正：它通过「目录」式路由 token，把长文本计算复杂度从 O(n²) 降至 O(n)，显存占用下降 40%，推理速度提升 2.2 倍，首次在开源模型中实现百万 token 的单卡推理。

后训练环节，团队把超过 10% 的整群算力投入强化学习，采用组对强化学习（GRPO）加多数投票，让模型在代码、数学与工具调用任务上逼近闭源对手。V3.2-Speciale 还取消了「思考长度惩罚」，鼓励更长的链式推理：平均输出 token 较 Gemini 3 Pro 高 32%，准确率提升 4.8 个百分点。

## 2. Mistral 3 系列开源：14B 单卡 A100 跑满 128K

据 AIBase 报道，法国独角兽 Mistral AI 于 12 月 2 日推出 Mistral 3 系列模型，包括 3B、8B、14B 三个小型密集模型，以及迄今最强的 Mistral Large 3，覆盖从边缘设备到企业级推理的全场景需求。新模型沿用 Apache 2.0 开源协议，权重已同步上传至 Hugging Face 与 GitHub，允许商业免费使用。

Mistral 3 在保持前代低延迟优势的同时把上下文长度扩展到 128K，并在 MMLU、HumanEval、MT-Bench 等主流基准中与 Llama 3.1 同规格模型打平或小幅领先。公司介绍，通过「滑动窗口注意力 + 分组查询注意力」的混合设计，14B 版本在单张 A100 上即可完成 128K 全上下文推理，批量场景下吞吐量提升 42%，为学术研究、商业分析、教育内容生成等场景提供更高性价比。

Mistral AI 联合创始人兼首席科学家 Guillaume Lample 的表态是：「我们的使命是让高性能 AI 摆脱供应商锁定。开发者无需巨额预算，也能获得与闭源方案媲美的效果。」目前 Mistral Large 3 已在公司官方平台 Le Platforme 上线 API。

## 3. 商汤 NEO：原生多模态，数据需求只要业界 1/10

据 AIBase 报道，商汤科技联合南洋理工大学 S-Lab 发布行业首个原生多模态架构 NEO，并同步开源 2B 与 9B 两款模型。新架构摒弃「视觉编码器 + 投影器 + 语言模型」的传统三段式方案，从注意力机制、位置编码到语义映射全部重写，官方称在同等性能下数据需求仅为业界平均的 1/10，首次实现「像素到 Token」的连续映射。

据商汤技术负责人介绍，NEO 通过原生图块嵌入层直接读取像素，取消独立图像 Tokenizer；三维旋转位置编码（Native-RoPE）在同一向量空间内同时表达文本与视觉时空频率；多头注意力采用「视觉双向 + 文本自回归」混合计算，空间结构关联得分提升 24%。实测显示，在 0.6B~8B 参数区间内，NEO 在 ImageNet、COCO 与 Kinetics-400 上取得 SOTA，边缘设备推理延迟低于 80 毫秒。GitHub 已公开模型权重与训练脚本，商汤计划明年第一季度开源 3D 感知与视频理解版本。业内人士认为，NEO 的「深层融合」路线有望结束多模态「拼积木」时代。
