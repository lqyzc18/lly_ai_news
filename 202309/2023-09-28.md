# 2023-09-28 AI 大事件

北京时间 2023 年 9 月 28 日（星期四）。AWS 宣布完全托管的生成式 AI 服务 Amazon Bedrock 由预览转为正式商用（GA），首批在美东（弗吉尼亚）与美西（俄勒冈）两个区域上线；同步正式商用的是自研的 Amazon Titan Embeddings，并预告 Meta 的 Llama 2 将在数周内上架——Bedrock 因此成为首个以托管 API 提供 Llama 2 的服务。

> 日期依据：AWS 官方博客该篇的发布时间标注为太平洋时间 2023 年 9 月 28 日 05:40，对应北京时间 9 月 28 日 21 时 40 分，归 9 月 28 日。

## 1. Bedrock 转正：模型阵容与首批能力

Amazon Bedrock 于 2023 年 4 月 13 日在 AWS 峰会上以预览形式亮相，半年后转为正式商用。转正时平台已提供 AI21 Labs、Anthropic、Cohere、Meta、Stability AI 与 AWS 自研 Amazon Titan 六个来源的基础模型，开发者通过统一的 API 访问，可私有微调、可用检索增强生成（RAG）改造、可挂载托管代理（Agents）完成预订、处理保险理赔、生成广告素材、编写代码等复合业务任务，且全程无需管理底层基础设施。

同步转正的 Amazon Titan Embeddings 是 Amazon Titan 家族首个面向客户的模型，作用是把文本转成数值向量以支撑搜索、个性化与 RAG。官方给出的参数是：支持 25 种以上语言，上下文长度最长 8,192 token，输出 1,536 维向量，在低延迟与高精度之间做折中。官方还提到，同类嵌入模型已在亚马逊商品搜索中投入使用。

Llama 2 则是转正当天最受关注的一项预告。官方明确 Bedrock 是首个以托管 API 提供 Meta Llama 2 的服务，13B 与 70B 两个版本将在「数周内」上架；官方同时说明 Llama 2 相比 Llama 1 训练数据量增加 40%、上下文长度提升到 4,000 token。

## 2. 合规与治理：HIPAA、GDPR 与预置吞吐

转正的同时，Bedrock 新增了一整套面向受监管行业的能力。官方宣布该服务已成为 HIPAA 合格服务（HIPAA eligible），并可按 GDPR 要求使用，这意味着医疗机构、金融机构等此前因合规顾虑无法上线的客户可以接入；治理侧新增了与 Amazon CloudWatch 的用量集成（可自定义看板）以及与 AWS CloudTrail 的集成，用于监控 API 活动与排障。

AWS 也在同一天补上了此前缺失的容量确定性能力：客户可以预留按「每分钟处理的 token 数」计量的预置吞吐（provisioned throughput），从而在节假日等流量高峰时段维持一致的用户体验，而不必在高峰期承受不可预测的成本与性能波动。

## 3. 同批发布的另两项：CodeWhisperer 定制与 QuickSight 生成式 BI

除 Bedrock 本身，AWS 当天还发布了两项生成式 AI 增量。其一是 Amazon CodeWhisperer 的私有代码库定制能力：管理员可以把公司内部私有代码库（GitHub 或 Amazon S3 路径）接到 CodeWhisperer 上，让代码建议贴合内部 API、类与包结构，官方称该能力将以预览形式在即将推出的 CodeWhisperer Enterprise 档位提供，且定制内容不会被用于训练模型；集成伙伴 Persistent 的研究显示，定制后开发者完成任务的效率提升约 28%。

其二是 Amazon QuickSight 的生成式 BI 创作能力预览：业务分析师用自然语言描述即可生成图表、格式与计算，QuickSight Q 现提供免费试用，官方点名宝马集团、Traeger Grills 等已用它做生成式分析。AWS 数据与 AI 副总裁 Swami Sivasubramanian 在公告中把这次发布称为「让每一家企业、每一位员工都能用上生成式 AI」的一步。

## 4. 同日另一条：Meta 把 Llama 2 做成社交平台里的 28 个 AI 角色

在 Bedrock 之外，智源社区于 9 月 28 日 14:32 收录了 Meta 的另一条发布：基于 Llama 2，Meta 在 WhatsApp、Instagram、Messenger 三个平台上线 28 个 AI 聊天角色（AI Characters），用户可以为其设定性格标签后与其对话。这是 Meta 首次把生成式对话能力直接嵌入自有社交产品，路径上与 AWS 把 Llama 2 做成托管 API 恰好相反——一个向消费端要交互，一个向企业端要托管与合规。两条发布落在同一天，也说明当周「开放权重模型如何被产品化」是竞争的主线。
