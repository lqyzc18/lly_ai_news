# 2023-09-27 AI 大事件

北京时间 2023 年 9 月 27 日（星期三）。法国新创公司 Mistral AI 发布首个模型 Mistral 7B：73 亿参数，以 Apache 2.0 协议开放权重，官方称在全部评测中超越 Llama 2 13B。它把当时还很少被采用的分组查询注意力（GQA）与滑动窗口注意力（SWA）同时用进一个 7B 稠密模型，成为此后开源社区最常用的轻量基座之一。

## 1. 模型规格与基准成绩

Mistral 7B 是 73 亿参数的稠密 Transformer，架构为 32 层、隐藏维度 4096、32 个注意力头配 8 个 KV 头（即分组查询注意力），上下文窗口在首个版本为 8K，词表 32000。模型以 Apache 2.0 协议发布，权重通过 BitTorrent 与 Hugging Face 同时释出，无使用限制，可自由商用、微调与再分发。

按发布论文的表格，Mistral 7B 在 MMLU（五样本）上得分 60.1%，高于 Llama 2 13B 的 55.6%；GSM8K（八样本，maj@8）为 52.2%，对比 Llama 2 13B 的 34.3%；HumanEval（零样本）为 30.5%，ARC-Challenge 55.5%，HellaSwag 81.3%，WinoGrande 75.3%，PIQA 83%，TriviaQA 69.9%，MATH 13.1%。官方表述是：该模型在作者测试的全部基准上超过 Meta 的 Llama 2 13B，并在推理、数学与代码任务上与规模大得多的 Llama 1 34B 相当甚至更好。

## 2. 架构上的两个效率选择

Mistral 7B 在发布时被记住的不只是分数，还有两个后来成为行业标配的效率设计。其一是分组查询注意力：32 个查询头共享 8 组键值头，显著缩小了 KV 缓存并加快解码速度。其二是滑动窗口注意力：每层只关注 4096 token 窗口内的局部信息，信息通过层与层的堆叠向上传播，从而以更低成本处理长序列。官方称在 16k 序列下，对 FlashAttention 与 xFormers 的修改带来约 2 倍加速、并节省一半 KV 缓存。

这两个设计组合起来的效果是：7B 模型可以在单张消费级显卡上运行，同时在多数基准上压过规模翻倍的 13B 开放模型。后续的 v0.2、v0.3 权重更新把有效上下文提升到 32K，v0.3 还把词表扩展到 32768 并加入函数调用支持。

## 3. 对开源竞争格局的影响

Mistral 7B 的发布在两个多月内成为开源社区的默认基座之一：它把「小模型可以打败大模型」这件事用可下载、可商用、无使用限制的权重证明了一遍，直接压缩了中小团队自研基座的空间，也让推理侧的成本讨论从「参数规模」转向「注意力实现与缓存效率」。对法国的 Mistral 而言，这也是一家欧洲公司第一次在开源大模型上以压倒性评测成绩进入全球视野。

生态侧的跟进同样迅速：Hugging Face、Ollama、vLLM、llama.cpp、LM Studio 等工具链都第一时间提供了加载与微调路径，社区基于它派生出的微调版本数量庞大，7B 规模加 Apache 2.0 的组合让教学、边缘部署和隐私敏感场景（数据不出本地）都能直接落地。

## 4. 后续版本的演进

Mistral 随后以 v0.2、v0.3 两次权重更新继续打磨这一支模型：有效上下文从首版的 8K 提升到 32K，v0.3 把词表扩展到 32768 并加入函数调用支持，模型 ID 也按 open-mistral-7b 的形式在托管 API 上提供。官方 API 端点在 2024 年 11 月 30 日被标记为弃用、2025 年 3 月 30 日停用，继任者转向 Ministral 8B——但权重本身仍可自由下载与部署，这正是 Apache 2.0 协议带来的长期价值：模型可以退役，生态资产不会。
