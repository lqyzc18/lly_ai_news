# 2025-05-26 AI 大事件

北京时间 2025 年 5 月 26 日（星期一）。甲骨文将斥资约 400 亿美元购买约 40 万块 Nvidia GB200 芯片，并租赁给 OpenAI 位于德克萨斯州的一个 1.2GW 数据中心。安全一侧，有研究员用 OpenAI 的 o3 API 分析代码，在 Linux 内核的 SMB 实现里定位到一个零日漏洞 CVE-2025-37899，描述只用了 1.2 万行代码。

## 1. 甲骨文 400 亿美元采购 GB200，租赁给 OpenAI

据 5 月 26 日的每日 AIGC 早报，甲骨文将斥资约 400 亿美元购买约 40 万块 Nvidia GB200 芯片，并将其租赁给 OpenAI 位于德克萨斯州的 1.2GW 数据中心，该中心被称为第一个美国星际之门项目。

同一天还有一条价格消息：在美方出口限制后，英伟达计划推出新款 AI 芯片，价格在 6500 美元至 8000 美元之间，远低于 H20 的 10000 美元至 12000 美元售价。这与 5 月 22 日那组消息形成对照——当时黄仁勋称下一款面向中国的芯片将不会来自 Hopper 系列。

## 2. Operator 换用 o3，o3 找出 Linux 内核零日漏洞

据 5 月 26 日的每日 AIGC 早报，OpenAI 表示其可以利用网络执行任务的 AI 代理 Operator，将很快使用基于 o3 的模型，此前使用的是 GPT-4o 的自定义版本。

同一份早报记录了一起安全研究：安全研究员通过使用 OpenAI 的 o3 API 分析代码，发现 Linux 内核 SMB 实现中的零日漏洞（CVE-2025-37899），仅需 1.2 万行代码描述即可定位复杂内存错误，效率远超人类研究员。

## 3. 生成内容的可信度：Veo 3 假新闻与多邻国撤回表态

据 5 月 26 日的每日 AIGC 早报，尽管谷歌设置了防护措施，但 Veo 3 用户仍在生成关于新闻、灾难和虚构事件的逼真剪辑，其中一些剪辑包含提示中未包含的对话。

同一天还有一条企业侧的反向表态：多邻国 CEO Luis von Ahn 一周内态度大反转，撤回"AI 取代员工"言论，明确表示 AI 不会替代员工，公司仍在正常招聘，并承诺为员工提供 AI 培训支持。这与 5 月 5 日早报里"多邻国 CEO 宣布 AI 优先战略，将逐步停用人类承包商处理 AI 可替代的工作"形成对照。

## 4. 开发实践与国产模型：微软的智能体修 Bug，字节开源 BAGEL

据 5 月 26 日的每日 AIGC 早报，微软 .NET Runtime 项目的 GitHub 仓库下，微软员工调用 Copilot 智能体修 Bug 频频出错，甚至有"唯一贡献是改 PR 标题"的吐槽，AI 给出的方案常"治标不治本"导致测试失败，最终仍需人类手动修复。

同一天的早报还记了国产模型侧的几条：豆包 App 上线视频通话功能，基于最新视觉理解模型，可融合视觉与语言输入进行深度思考，能完成解微积分、分析论文图表等复杂任务以及联网搜索；字节跳动开源多模态模型 BAGEL，集成图像生成、编辑、3D 合成等功能，性能超 Stable Diffusion 3 和 GPT-4o，登顶 Hugging Face 趋势榜，支持一键试妆、多轮对话等玩法。5 月 26 日的每日 AI 早报还记了腾讯的两个预告：宣布将推出全球首个全模态模型"混元-O"，最快今年发布；正研发基于自研大模型混元的首个端到端语音通话模型 Hunyuan-Voice，最快 6 月上线元宝 App。
