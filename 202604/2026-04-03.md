# 2026-04-03 AI 大事件

北京时间 2026 年 4 月 3 日（星期五）。国产编程模型在 4 月 2 日晚间同日发布：阿里通义实验室推出 Qwen3.6-Plus，智谱推出首个原生多模态 Coding 基座模型 GLM-5V-Turbo，4 月 3 日 LMArena 旗下 Code Arena 的 React 专项榜更新，千问 3.6-Plus 以 1452 分位居全球第二，成为榜上排名最高的中国模型。编程工具侧，Cursor 3 也在 4 月 2 日发布，把产品从代码补全改写为"用智能体构建软件的统一工作区"。视频生成方面，可灵 AI 移动端 3 月月活 780 万，超过 Sora 的 470 万，火山引擎同日开放 Seedance 2.0 的 API 申请。监管方面，中国广播电视社会组织联合会演员委员会 4 月 2 日发布严正声明，明确未经书面授权的 AI 换脸、声纹克隆不因标注"非商用"而免责。

## 1. 千问 3.6-Plus：4 月 3 日 Code Arena React 榜第二

阿里通义实验室 4 月 2 日发布新一代模型 Qwen3.6-Plus。官方口径是：原生多模态理解与推理能力，编程与 Agent 能力突出，默认支持 100 万 token 上下文窗口；可通过阿里云百炼平台调用，API 兼容 OpenAI 与 Anthropic 协议，因此能直接接入 Claude Code、Qwen Code、OpenClaw 等工具。百炼上每百万 tokens 输入最低 2 元。同系列后续还会开源其他尺寸，旗舰 Qwen3.6-Max 称将于近期发布。

4 月 3 日的实测结果来自 LMArena 旗下专注 AI 编程的 Code Arena。央广网报道，Qwen3.6-Plus 在 React 专项榜以 1452 分位列全球第二，排在 Anthropic 的 Claude-Opus-4.6-Thinking（1540 分）之后，以 4 分领先 OpenAI 的 GPT-5.0-High（1448 分），并以 12 分领先 Google 的 Gemini 3.1 Pro Preview（1440 分）。该榜考察的是模型在真实复杂 Web 开发场景下能否独立完成从项目初始化、编码到调试运行的全流程，不是单点补全测试。在覆盖 AI 编程能力的总榜上，Qwen3.6-Plus 同样位居国产模型之首；报道据此称阿里在全球 AI 实验室排名中升至第四，次于 Anthropic、OpenAI 和 Google。

需要分清口径的是，榜位是第三方盲测平台的实测结果，而"国产最强编程模型"是媒体与公司的表述。另有转述称该模型在 HumanEval 上 pass@1 达 92.3%、较上代提升 18.7 个百分点，这一数字目前只出现在二手报道中，未见官方发布页核对。同花顺财经转述界面新闻的说法是，其在智能体编程 SWE-bench 系列、真实世界智能体任务 Claw-Eval 等评测中，编程表现接近 Claude 系列；这条是"接近"，与榜单上"在两个榜位上已经反超"并不矛盾——说的是不同评测。

## 2. 智谱 GLM-5V-Turbo：为 Agent 装上眼睛的多模态 Coding 基座

智谱 4 月 2 日发布 GLM-5V-Turbo，定位是首个原生多模态 Coding 基座模型。官方技术说明写得很具体：从预训练阶段就深度融合视觉与文本能力，原生理解图片、视频、设计稿、文档版面，支持画框、截图、读网页等多模态工具调用，上下文窗口扩展至 200k。

能力与适配方面，智谱称该模型在多模态 Coding、Tool Use、GUI Agent 等核心基准上以更小尺寸取得领先表现，在 AndroidWorld、WebVoyager 等真实 GUI 操控基准上同样突出；纯文本维度上，CC-Bench-V2 的 Backend、Frontend、Repo Exploration 三项保持稳定表现，即引入视觉后文本编程能力未退化。在 AutoClaw（智谱本地版 OpenClaw，"澳龙"）中接入后，"龙虾"能看懂 K 线走势、估值区间图和券商研报图表，四路数据源 60 秒并行采集，输出图文交错的研报。

技术路线是四层系统升级：新一代 CogViT 视觉编码器、兼容多模态输入且推理友好的 MTP 结构、强化学习阶段同时优化 30 多个任务类型（覆盖 STEM、grounding、video、GUI Agent），以及新增的多模态工具链。智谱称从预训练阶段就注入 Agentic 元能力，例如把 GUI Agent 的 PRM 数据加入预训练以降低幻觉。

合作方的评价属于外部口径而非智谱自测。智谱列出的内测反馈包括 TRAE 模型测评团队称"实现了从设计稿到代码的完整还原"，美团某团队称"原生多模态能力的引入并未削弱其编程逻辑"，快手万擎模型测评团队称"为 Agent 安上了眼睛"。官方 Skills 已上线 ClawHub，模型通过智谱 MaaS 平台与 BigModel 开放平台接入。

## 3. Cursor 3：编程工具从"补全"改为"统一工作区"

Cursor 团队 4 月 2 日发布 Cursor 3，官方定义是"借助智能体构建软件的统一工作区"。据多家媒体汇总的官方博客信息，这一版从零重构，围绕 Agent 而非编辑器设计：统一工作区支持多代码仓库并行布局；侧边栏集中管理本地与云端 Agent，包括从移动端、Web、Slack、GitHub 启动的任务；本地与云端会话可以互相推送，任务在离线后仍可继续；内置浏览器 Agent，可直接打开本地网站做交互测试；并支持数百款 MCP 与技能插件的插件市场。

底座是自研的 Composer 2 编程模型。官方给出的用户结构变化是：2025 年 3 月，Tab 功能用户数是 Agent 用户的 2.5 倍；到这一版发布时，Agent 用户规模已是 Tab 用户的 2 倍，且仍在快速增长。这组数字来自 Cursor 自己的统计。

这个产品方向与 4 月 2 日两件事直接相关：一件是 Qwen3.6-Plus 与 GLM-5V-Turbo 都把多模态 Agentic Coding 推到台前，另一件是 Claude Code 源码在 3 月 31 日泄露后，社区用净室重写的方式做出替代品。Cursor 3 把"多 Agent 协同"作为产品主轴，是在这条线上的正面应对。

## 4. 可灵 AI 月活 780 万，Seedance 2.0 开放 API

Sensor Tower 的数据经人民财讯转述：快手旗下可灵 AI（Kling AI）移动端上周全球周活跃用户环比增长 4%，达到平均 260 万；3 月移动端平均月活跃用户为 780 万，高于 Sora 的 470 万。Sora 服务中断后，可灵在移动端 AI 视频应用的用户规模上排到第一。

火山引擎同期开放 Seedance 2.0 视频生成模型的 API 申请，主打"生产级可控性"，支持文本、图像、音频、视频多种输入。字节的节奏是分两步：2 月 7 日 Seedance 2.0 上线，官方当时表示 API 服务预计在 2 月中下旬上线火山方舟，实际开放时间是 4 月 2 日，延迟与版权合规和内容安全有关。4 月 2 日万兴科技宣布旗下万兴剧厂首批上线满血版 Seedance 2.0 全能力，客户无需排队、可分钟级生成。

需要说明的是，"可灵月活 780 万"是第三方数据机构 Sensor Tower 的移动端口径，"登顶"限定在移动端 AI 视频创作应用这一细分，不等于整体视频模型市场。Seedance 2.0 的 API 开放当日，另一侧阿里也把 Seedance 2.0 的价格上调了——4 月 16 日的报道显示，即梦 2 分钟视频制作成本从 5 元涨至 40 元，涨价被解读为从补贴定价回归商业化定价与算力控流，而非需求旺盛的单边信号。

## 5. 广电联合会演员委员会：AI 换脸不因"非商用"免责

中国广播电视社会组织联合会演员委员会 4 月 2 日发布严正声明，针对 AI 换脸合成、声纹克隆复刻、影视素材任意篡改魔改、擅自抓取演员影像声频用于 AI 模型训练等行为。声明称演艺人员依法享有肖像权、声音权、艺术形象权等人格权益，任何主体未经本人书面正式授权，严禁擅自采集、使用、合成、传播相关影像、声纹与专属艺术形象。

声明里最具体的一条是：凡可关联特定公众演员的 AI 撞脸、仿声演绎、换脸短剧、商业植入、虚拟人复刻、素材二创改编等侵权内容，即便标注"非商用""公益分享""个人二创"等字样，均不构成合法免责依据，仍需承担全部侵权责任。对平台的义务是落实内容审核主体责任、建立 AI 演艺内容授权核验长效机制、全面排查下架存量侵权作品、全程留存侵权数据记录配合取证；对 AI 技术研发及服务平台的要求是强化前置审核，对用户上传的演员肖像、声频影像严格核验授权资质。委员会同时宣布启动全网常态化侵权监测、公证固证及批量维权行动，自律维权电话为 010-81105000。

4 月 3 日，这条声明开始被媒体跟进报道，争议对象从行业层面落到具体案例上。已有演员工作室就 AI 短剧盗用肖像发声并委托律师维权，法律界则提出举证责任倒置的建议——由于 AI 生成角色带有随机性与融合性，当事人往往要承担"证明我是我"的困难。中广联合会声明的实际约束力取决于平台执行与后续诉讼，这一点目前没有可核实的进展。
