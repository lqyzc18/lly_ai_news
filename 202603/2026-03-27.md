# 2026-03-27 AI 大事件

北京时间 2026 年 3 月 27 日（星期五）。OpenAI 启动 Safety Bug Bounty，把「模型被滥用」也纳入赏金范围。安全研究者同日公开 ShadowPrompt，演示任何网站都能无声劫持 Claude Chrome 扩展。国内两条：2026 中关村论坛 AI 开源前沿论坛开讲，智谱发布面向 Agent 的 GLM-5-Turbo 并宣布提价；美团开源多模态长文本模型 LongCat-Next。商业侧，Shopify 把 560 万家店铺的货架搬进了 ChatGPT、Gemini 和 Copilot。

> 本期记 5 条：OpenAI 的 Safety Bug Bounty、ShadowPrompt 零点击提示注入、中关村论坛与智谱 GLM-5-Turbo、美团开源 LongCat-Next、Shopify Agentic Storefronts。

## 1. OpenAI 启动 Safety Bug Bounty

3 月 26 日，OpenAI 宣布启动面向公众的 Safety Bug Bounty，通过 Bugcrowd 运作。它的定位是补充原有的 Security Bug Bounty——后者自 2023 年 4 月以来已奖励 409 个安全漏洞——把那些不符合传统安全漏洞标准、但确实构成滥用或安全风险的问题也纳入受理范围。所有提交由 OpenAI 的安全与安全漏洞赏金团队统一分拣，再按职能在两个计划之间流转。

受理范围分三类。第一类写明是「智能体风险，包括 MCP」：第三方提示注入与数据外泄，例如攻击者输入的文本能稳定劫持受害者的智能体（Browser、ChatGPT Agent 及同类产品），诱导其执行有害操作或泄露用户敏感信息，这类报告要求至少 50% 的可复现性；还包括 OpenAI 智能体产品在 OpenAI 网站上大规模执行被禁止的操作，以及未列出的其他潜在有害操作，但需要证明可能造成实质性的严重损害。针对 MCP 风险的测试，必须遵守相关第三方的服务条款。

第二类是 OpenAI 专有信息，包括模型生成返回与推理相关的专有信息、以及泄露其他 OpenAI 专有信息的漏洞。第三类是账户与平台完整性，例如绕过防自动化控制、操纵账户信任信号、规避账户限制、停用或封禁。越狱不在受理范围内，OpenAI 说明会针对特定损害类型定期开展私密赏金活动，例如 ChatGPT Agent 与 GPT-5 中的生物风险内容问题。没有实质安全影响的一般内容政策绕过也不在范围——比如模型只是说了粗鲁的话，或返回搜索引擎就能找到的信息。

## 2. ShadowPrompt：任何网站都能无声劫持 Claude 扩展

3 月 26 日公开披露的 ShadowPrompt 是一条由两个独立缺陷组合而成的零点击攻击链，目标是 Anthropic 的 Claude Chrome 扩展。Koi Security 的 Oren Yomtov 于 2025 年 12 月 27 日通过 Anthropic 的 HackerOne 漏洞赏金项目提交，公开前协调了大约十三周。

第一处缺陷在扩展的 postMessage 事件处理上：它用通配符校验来源，把任何托管在 `*.claude.ai` 子域上的页面都当作完全可信。第二处在由 Arkose Labs 提供、托管在 `a-cdn.claude.ai` 的验证码组件上：它不校验 `event.origin`，并把来自消息的 `stringTable` 字段未经清洗地写进 React 的 `dangerouslySetInnerHTML`，构成一个 DOM XSS。攻击者把有缺陷的验证码组件嵌进隐藏 iframe，送入 XSS 载荷，注入的脚本在可信的 `*.claude.ai` 上下文里执行，再向扩展发一条 postMessage——扩展因为通配符匹配就照单全收，Claude 收到的指令与用户亲手输入的没有区别。

后果的严重性来自扩展自带的权限。攻击者可以让 Claude 交出 Gmail 访问令牌、读取 Google Drive 文件、导出 Claude 会话历史，或以受害者身份发邮件；整个过程只需访问一个恶意页面，没有点击，没有权限提示。暴露面是 1.0.41 版本之前的全部 300 万以上扩展用户。修复分两半：Arkose Labs 于 2 月 19 日修好 XSS，Anthropic 随后发布 1.0.41，把通配符换成对 `claude.ai` 的严格精确匹配。

同一周还有两篇论文从另外两层给出同类问题。复旦 Shen 等人的 TIP 把针对 MCP 智能体的黑盒攻击建模成树结构搜索，用大模型迭代生成能绕过指令阻断、sandwich 阻断、困惑度过滤和分类器检测的载荷，在无防御设置下对 Llama、Qwen 等模型的攻击成功率超过 95%，四种防御同时开启仍高于 50%（arXiv:2603.24203）。PIDP-Attack 则把提示注入与数据库投毒合成一个复合的 RAG 攻击，不再要求攻击者预先知道受害者查询，用两份投毒文档在 8 个 LLM、3 个数据集上取得 98.125% 的平均攻击成功率，比 PoisonedRAG 高出 4 到 16 个百分点（arXiv:2603.25164）。

## 3. 中关村论坛 AI 开源前沿论坛：智谱发 GLM-5-Turbo 并提价

3 月 27 日，2026 中关村论坛年会「AI 开源前沿论坛」召开。工信部科技司司长魏巍在论坛上表示，中国已成为 Hugging Face 平台上月下载量最大的模型来源国。议题集中在开源模型与 Agent 基础设施，月之暗面创始人杨植麟、智谱 CEO 张鹏、小米 MiMo 大模型负责人罗福莉等都在场讨论大模型的演进趋势，OpenClaw 是全场出现频率最高的一个词——张鹏把它比作大模型应用的「脚手架」，罗福莉的说法是它「点燃了大家的想象力」。

会上智谱发布了面向 Agent 场景的 GLM-5-Turbo 模型，并宣布提价。张鹏给出的解释是：「干活背后的 Token 消耗是简单问答的 10 倍甚至 100 倍，长期低价竞争不利于行业发展。」这句话把定价逻辑的转向说得很直白：按席位、按问答次数计费的竞争正在让位于按执行量计费。

生态侧的另一个数字来自 MCP。Model Context Protocol 的月度 SDK 下载量（Python 加 TypeScript）已突破 9700 万，Anthropic、OpenAI、Google、Microsoft、Amazon、xAI、Mistral、Cohere 等主要厂商都已采用，它从「实验性协议」变成事实标准的速度快于多数人的预期。

## 4. 美团开源 LongCat-Next：68.5B MoE 与 20 万字节长文本

3 月 27 日，美团技术团队开源新一代多模态大模型 LongCat-Next，模型同步上传至 GitHub 与 Hugging Face 供开发者下载商用。这是美团 LongCat 系列在 LongCat-Flash（2025 年 9 月，560B MoE）之后的又一次迭代，定位是本地生活、企业服务和复杂业务交互场景。

架构上是 68.5B 参数的 MoE，核心指标是长文本处理：支持最高约 20 万字节的超长文本输入，同时兼顾语音、文本、图片的多模态理解与交互能力，对话延迟控制在毫秒级，多轮对话逻辑连贯。模型对本地生活的订单处理、客服咨询、业务流程审批等场景做了专项优化，支持企业二次微调和私有化部署，不必依赖云端大规模算力。

社区反馈是开源首日下载量突破万次。这条路线的商业意图写在美团自己的定位里：与其和别家比参数，不如把模型塞进自己最密集的生活服务场景，用真实交易数据反哺模型能力。

## 5. Shopify：560 万家店铺进入 ChatGPT、Gemini 和 Copilot

3 月 26 日，Shopify 对外公布 Agentic Storefronts 的落地情况。符合条件的美国商户已经默认接入，覆盖 560 万家店铺的商品，这些商品出现在 ChatGPT、Microsoft Copilot、Google AI Mode、Gemini 应用和 Perplexity 里。Shopify 的产品副总裁 Mani Fazeli 说得很直接：「Agentic commerce 不是我们在被动应对，而是我们正在实现的愿景。」

底层的标准叫 Universal Commerce Protocol（UCP），由 Shopify 与 Google 联合开发，定位是 AI 智能体与商户交互的开放标准，3 月的更新加入了多商品购物车、实时目录查询和会员体系集成。参与的除了 Walmart、Target、Etsy 等零售商，还有 American Express、Mastercard、Stripe、Visa 等支付与金融机构，共 20 余家。Shopify 另一条产品线是独立的 Agentic Plan，让不使用 Shopify 的品牌也能把商品上传进 Shopify Catalog，借同一套基础设施铺进这些 AI 界面。

有意思的是分工。OpenAI 撤掉了此前对 Instant Checkout 完成的交易抽取 4% 的做法，改成把用户导回商户站点结账；ChatGPT 走的是「发现 + 跳转」，Copilot 和 Google AI Mode 则提供嵌入式结账，顾客不必离开 AI 界面。商家仍然是 merchant of record，客户数据不转移给 OpenAI、Google 或 Microsoft，订单带渠道归因回到 Shopify Admin。OpenAI 商务产品负责人 Neel Ajjarapu 的说法是：「在 ChatGPT 里购物始于发现——帮人们探索选项、比较产品、找到真正合适的。」

数据是这套东西最直接的诱惑。Shopify 2026 年第一季度的数据称，AI 带来的店铺流量同比增长 8 倍，AI 搜索带来的订单增长近 13 倍，AI 引荐访客的转化率比自然搜索高近 50%；Adobe Analytics 的测量则给出 AI 引荐购物者转化率高 42%。
