# 2026-03-24 AI 大事件

北京时间 2026 年 3 月 24 日（星期二）。Anthropic 把「让模型自己操作电脑」做成了正式功能，Claude 在 macOS 上第一次拿到可授权的鼠标和键盘控制权。OpenAI 与核聚变公司 Helion 谈电力交易的消息发酵，Sam Altman 为此辞去 Helion 董事长。阿里达摩院在上海发布玄铁 C950，称这是第一颗原生支持千亿参数大模型的 RISC-V 服务器 CPU。AI 基础设施那一层也不太平：PyPI 上出现了两个带凭证窃取器的 litellm 版本。

> 本期记 5 条：Anthropic 的 Computer Use 与 Dispatch、OpenAI 与 Helion 的聚变谈判及奥尔特曼辞任、阿里达摩院玄铁 C950 与 RISC-V 原生 AI 引擎、litellm 供应链投毒、国家数据局给出的日均词元调用量。

## 1. Anthropic：Claude 拿到 macOS 的鼠标和键盘

Anthropic 的官方博客在美西时间 3 月 23 日发布《Put Claude to work on your computer》，公司账号同日发帖，落到北京时间已是 3 月 24 日。功能叫 Computer Use，在 Claude Cowork 和 Claude Code 中开启，形态是研究预览（research preview），面向 Claude Pro 与 Max 订阅者。Windows 版当时不可用，Team 和 Enterprise 也不在其中。

机制上 Anthropic 说 Claude 会先找最精确的工具：先走 Slack、Google Calendar 这类 connector，没有可用集成时才直接控制浏览器、鼠标、键盘和屏幕，滚动、点击、按需探索。规矩是每接一个新应用都先要用户明确授权，用户随时可以叫停；系统还会在模型内部扫描提示注入迹象。公司同时把它和前一周发布的 Dispatch 绑在一起——手机派任务、桌面执行，回来时看结果。

公司自己给出的保留意见比宣传语更重：相比 Claude 的编程或文本交互能力，电脑操控「仍然很早期」，会出错，威胁也在演变，建议先从信任的应用开始，不要处理敏感数据，部分应用默认禁用。第三方媒体援引早期用户反馈称，非琐碎任务的成功率在五成上下，复杂多步流程容易卡住、漏步骤或误读指令。

## 2. OpenAI 与 Helion：奥尔特曼辞去董事长

财联社北京时间 3 月 24 日凌晨发稿：Sam Altman 在社交媒体上确认，由于他投资的核聚变公司 Helion 正与 OpenAI 探索「开展大规模合作」，他将辞去 Helion 董事长一职。他的说法是，随着两家商谈合作，很难同时在两家公司董事会任职，辞职能让双方更容易处理相关事宜。

利益关系是这条消息的另一面。奥尔特曼在 OpenAI 不持有股份，但持有相当数量的 Helion 股权：2021 年领投了 Helion 总额 5 亿美元的 E 轮融资，去年又参与了 4.25 亿美元那轮，Helion 的其他投资者包括软银和 Peter Thiel 的 Mithril Capital。去年他也以类似理由辞去过模块化核反应堆公司 Oklo 的董事长。

据知情人士，谈判的规模远超该行业现有进度：OpenAI 可能锁定 Helion 部分聚变产出的保障配额，初始 12.5%；讨论中的数字是 2030 年获得 5 吉瓦电力，2035 年扩大到 50 吉瓦。Helion 称每座反应堆可发电 50 兆瓦，按此推算，2030 年前需部署 800 座，2035 年前再部署 7200 座；目前包括 Helion 在内的私营公司都还没有实现「科学收支平衡」。后续发展是：OpenAI 最终否决了直接持股，改以协议方式获得 2035 年前采购至多 500 亿瓦电力的权利。

## 3. 阿里达摩院：玄铁 C950 与 RISC-V 原生 AI 引擎

3 月 24 日，阿里巴巴达摩院在上海主办 2026 玄铁 RISC-V 生态大会，发布新一代旗舰 CPU 玄铁 C950，并推出两款 RISC-V 原生 AI 计算引擎。规格上，C950 采用 8 指令译码、16 级流水线、超 1000 条指令乱序窗口，最高主频 3.2GHz，单核通用性能在 SPECint2006 基准测试中首次突破 70，公司称其刷新了全球 RISC-V 性能纪录；它支持 RVA23.1 的全部标配和可选扩展，原生支持 CoVE 机密计算。

两件事值得分开看。第一是通用性能：C950 支持 RVA23.1 全部标配和可选扩展，原生支持 CoVE 机密计算；经软硬件协同优化，在 MySQL、Redis、Nginx、OpenSSL 等云计算典型任务下达到业界领先水平，云网络、云存储性能较部分主流产品可提升 30% 以上。第二是与模型直接相关的：Vector 加速引擎和 Matrix 加速引擎与玄铁 CPU 统一编址，把通用算力和 AI 算力合在一颗芯片上，官方给出的可流畅运行模型是 Qwen3-235B-A22B 和 DeepSeek V3-671B。这是 RISC-V CPU 第一次原生支持千亿参数大模型。

产品线与生态方面，达摩院同时推出高能效 CPU 玄铁 C925，较 C930 能效比提升 11%、面积减少 32%，至此 C925、C930、C950 构成覆盖边缘到高端服务器的旗舰矩阵。会上还发布了 Flex 可扩展平台，提供建模、验证环境与工具链，支持芯片设计企业自定义修改玄铁 CPU。达摩院称玄铁处理器已落地 200 多款量产芯片及近千款热门终端产品，并与北京开源芯片研究院、中国科学院软件研究所签署战略合作，联合研发下一代开源香山 CPU。中国工程院院士倪光南在现场援引 SHD Group 的预测，称到 2031 年 RISC-V 设备出货量将达 360 亿颗。

## 4. litellm 供应链投毒：两个恶意版本在 PyPI 上活了不到一小时

3 月 24 日，PyPI 上出现 litellm 的 1.82.7 和 1.82.8 两个恶意版本，公开窗口为当日 10:39 至 16:00 UTC，对应北京时间 3 月 24 日 18:39 到 25 日 0 时。litellm 是被广泛使用的 LLM 网关，PyPI 隔离这两个版本前它们已存在了一段时间；考虑到该包日均下载量约 340 万、月下载量接近 1 亿，暴露面本身不小。

手法是劫持维护者账号后绕过官方 CI/CD 直接上传。攻击者自称 TeamPCP，此前用同样方式污染过 Trivy 的 GitHub Actions 标签，而 BerriAI 的流水线恰好用 Trivy 做扫描，PyPI token 和 GitHub PAT 因此在 CI 上被窃。1.82.7 把载荷嵌在 litellm/proxy/proxy_server.py 里，import 即执行；1.82.8 追加了一个 34,628 字节的 litellm_init.pth，利用 Python 启动时处理 site-packages 下 .pth 文件的机制，让任何 Python 进程启动都执行，哪怕根本没 import litellm。同一时间，BerriAI 组织下 15 个仓库的描述被改成「teampcp owns BerriAI」，维护者个人账号下 182 个仓库的 README 被覆盖。

窃取范围超出模型密钥：环境变量（含 OPENAI_API_KEY、ANTHROPIC_API_KEY）、~/.aws/credentials、gcloud 与 azure 凭据、~/.kube/config、SSH 私钥、Git 与 Docker 凭据、.env 文件、数据库口令、SSL/TLS 私钥乃至多个平台的加密钱包文件，都被收集后用 AES-256-CBC 加密、以硬编码的 RSA-4096 公钥封装，POST 到 models.litellm.cloud。载荷还会在 Linux 上安装伪装成「System Telemetry Service」的 systemd 用户服务作为持久化，在 Kubernetes 里则用特权 Pod 逃逸到宿主机。云安全公司 CloudSEK 关联到 2500 多家潜在受害组织，包括 NVIDIA、Cisco、Deloitte、Volkswagen、FedEx 和 Siemens，微软的 GraphRAG、Google ADK Python、browser-use、crawl4ai 等项目把它当作传递依赖引入。官方建议是固定到 v1.82.6 或更早版本，轮换受影响主机上的全部凭据，并检查 site-packages 中是否存在 litellm_init.pth。

## 5. 国家数据局：日均词元调用量超 140 万亿

3 月 22 日至 23 日举行的中国发展高层论坛 2026 年年会上，国家数据局局长刘烈宏把 Token 的官方中文译名定为「词元」。3 月 24 日国新办新闻发布会上，他给出了对应的量级：到 2026 年 3 月，我国日均词元调用量已超过 140 万亿，相比 2024 年初的 1000 亿增长了 1000 多倍，相比 2025 年底的 100 万亿，三个月又增长了 40% 多。

同场披露的还有数据侧的情况：截至 2025 年底，全国已建成的高质量数据集超过 10 万个，总体量超过 890PB，约相当于中国国家图书馆数字资源总量的 310 倍。国家数据局的下一步是以场景需求为牵引推进新一轮高质量数据集建设行动，打造 AI-Ready 的数据集供给。

这份数字也立刻反映到产业链上。中国经济网在 3 月 25 日的评论中提到，调用量暴增引发算力链的连锁反应，阿里云、腾讯云等相继上调 AI 算力服务价格，高端 GPU 一卡难求，存储芯片价格同步上涨。
