# 2025-07-17 AI 大事件

北京时间 2025 年 7 月 17 日（星期四）。台积电二季度营收创历史新高，并把 2025 全年美元营收增速目标从「接近 20% 中段」上修到约 30%。模型与架构一侧，谷歌 DeepMind 推出用递归替代注意力的 MoR 架构，亚马逊发布企业级智能体搭建工具包 Bedrock AgentCore；学术界则放出了开源定理证明模型 Goedel-Prover-V2。工具侧，月之暗面 Kimi 开放平台上线 Kimi Playground，MiniMax Agent 拿到全栈开发能力。

## 1. 台积电二季度营收 9337.9 亿新台币，全年指引上调至约 30%

台积电 2025 年二季度合并营收新台币 9337.9 亿元，美元口径 300.7 亿，同比增长 38.6%；税后纯益新台币 3982.7 亿元，EPS 新台币 15.36，净利与 EPS 同比均增 60.7%，毛利率 58.6%。

公司把 2025 全年美元营收年增目标从「接近 20% 中段」上修至约 30%，主因是 3nm、5nm 需求与 HPC 平台扩张，三季度营收指引 318 至 330 亿美元。收入结构上，3nm 占晶圆营收 24%、5nm 占 36%、7nm 占 14%，7nm 及更先进制程合计 74%。全年资本支出维持 380 至 420 亿美元区间；美国第二座 3nm 厂已竣工，完工后约 30% 的 2nm 及更先进产能落在亚利桑那。

## 2. 谷歌 DeepMind 推出 MoR 架构；亚马逊发布 Bedrock AgentCore

谷歌提出 Mixture-of-Recursions（MoR）架构，尝试用递归结构替代 Transformer 的注意力机制。官方说法是推理速度提高两倍、KV 内存消耗减半，两项收益在单一框架里同时实现。做法上，MoR 用同一组参数处理不同任务时动态分配计算资源。

亚马逊在纽约峰会上发布企业级 AI 智能体搭建工具包 Bedrock AgentCore，覆盖生产环境智能体的七项核心服务：AgentCore Runtime（低延迟无服务器运行环境、会话隔离）、AgentCore Memory（会话与长期记忆管理）、AgentCore Observability（代码执行逐步可视化）、Agent Identity（安全访问 AWS 服务和第三方工具）、AgentCore Gateway（把 API 和 Lambda 函数转成智能体可用工具）、Agent Browser（托管浏览器实例）、AgentCore Code Interpreter（隔离环境运行生成代码）。

## 3. 普林斯顿等开源 Goedel-Prover-V2

来自普林斯顿大学、清华大学、英伟达、斯坦福大学等机构的研究者联合发布数学定理证明模型 Goedel-Prover-V2，有 32B 和 8B 两个版本，目标是让更小的算力也能在多个基准上拿到 SOTA。上一代 Goedel-Prover 已被 COLM 2025 录用。

数字上，在 IMO 级别的 MathOlympiadBench 上，Goedel-Prover-V2 解决了 73 道题；作为对照，671B 的 DeepSeek-Prover 只解决了 50 道。

## 4. Kimi 开放平台上线 Kimi Playground；MiniMax Agent 拿到全栈开发

月之暗面 Kimi 开放平台正式上线 Kimi Playground，为开发者提供一站式工具调用能力体验：直观的工具调用界面、便捷的调试，可以快速选择不同工具并实时调整参数，用来看 K2 的工具调用能力。

MiniMax Agent 发布全栈开发功能，用户只用一句话就能生成复杂全栈应用，不需要编程基础。功能支持 Supabase 后端托管、Stripe 支付、定时任务等，官方举的例子是演唱会选座系统、实时金融看板、出海独立站、企业数据看板。

## 5. 当天的其他动态

AI产品榜·2周年大会成功举办，感恩相聚与同行，期待下次再会！。 OpenAI发布ChatGPT Agent，可自主思考行动、自选工具处理复杂任务。 谷歌搜索新增AI代打电话功能，可自动预约本地服务，如宠物美容。

MiniMax发布Agent全栈开发，无代码生成电商网站，支持定时任务等。 美国编程器Cursor限制中国区访问Claude模型，Kimi K2调用量激增。 ChatGPT录音模式向Plus用户开放，macOS端实现语音交互功能。
