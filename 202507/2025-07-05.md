# 2025-07-05 AI 大事件

北京时间 2025 年 7 月 5 日（星期六）。阿里通义实验室开源首个音频生成模型 ThinkSound，第一次把思维链用在音频生成上，配了一份 2531.8 小时的多模态音频数据集 AudioCoT。华为盘古团队就开源模型被质疑「结构与 Qwen-2.5 14B 高度相似」公开回应，称盘古 Pro MoE 是在昇腾硬件平台上从零训练的基础模型。SemiAnalysis 同期复盘 DeepSeek 开源 128 天之后的处境：调用量涨了约 20 倍，但自有平台份额在往下走，首 token 延迟和 64K 上下文都成了槽点。

## 1. 阿里通义开源 ThinkSound：把思维链带进音频生成

通义实验室开源了首个音频生成模型 ThinkSound，目标之一是打破「静音画面」的限制。做法是第一次把思维链（CoT）应用到音频生成上，让模型分步骤理解画面事件与声音之间的关系，从而生成高保真、强同步的空间音频。

为支撑链式推理，通义构建了多模态音频数据集 AudioCoT，含 2531.8 小时高质量样本。模型本身分成两部分：多模态大语言模型负责理解画面，音频生成模型负责产出声音。

## 2. 华为盘古团队回应「抄袭」质疑

事情的起点是一项发布在 GitHub 上的分析：它比较后认为，华为盘古 Pro MoE 与阿里通义千问 Qwen-2.5 14B 在参数结构上高度相似，两个模型注意力参数分布的平均相关性达到 0.927，远高于其他模型对比的正常范围。这篇分析在 7 月 4 日的专业论坛上引发热议。

7 月 5 日，诺亚方舟实验室发布声明回应。盘古 Pro MoE 开源模型是基于昇腾硬件平台开发、训练的基础大模型，并非基于其他厂商模型增量训练而来；在架构设计、技术特性上做了关键创新，是全球首个面向昇腾硬件平台设计的同规格混合专家模型，创新性地提出分组混合专家模型（MoGE）架构，用于解决大规模分布式训练的负载均衡难题、提升训练效率。声明同时承认，盘古 Pro MoE 部分基础组件的代码实现参考了业界开源实践，涉及其他开源大模型的部分开源代码，公司严格遵循开源许可证要求，在开源代码文件中清晰标注版权声明。

分析人士给出的判断是：盘古 Pro MoE 大概率没有直接用 Qwen-2.5 14B 的预训练权重做初始化，两者偏置绝对数值分布存在本质差异，难以通过常规微调或持续预训练从一个模型状态演变到另一个。但也不排除两者在架构设计上高度一致——结构趋同在大模型里不是问题。

顺带厘清一件事：盘古的开源本身是 6 月 30 日的事，当天华为开源了 70 亿参数的稠密模型和 720 亿参数的盘古 Pro MoE，并推出基于昇腾的模型推理技术，官方给出的单卡吞吐数字是 1528 tokens/s。7 月 5 日是回应，不是发布。

## 3. SemiAnalysis 复盘 DeepSeek：开源 128 天之后

SemiAnalysis 的复盘文章日期是 7 月 3 日，标题是「DeepSeek Debrief: 128 Days Later」，中文媒体在 7 月 5 日完整转述。文中的一组核心数字是：DeepSeek R1 在第三方托管平台上的总用量自发布以来增长近 20 倍，但 DeepSeek 自有平台贡献的 token 份额逐月下滑；R1 首发时的价格比同级别模型低约 90%。

延迟与上下文是批评的重点。DeepSeek 官方 API 在主要厂商里首 token 延迟最高；上下文只有 64K，是头部厂商中较小的一档，而 Lambda、Nebius 等在同价位给出 2.5 倍以上。第三方托管方 Parasail、Friendli 的报价是每百万 token 3 到 4 美元，延迟接近零；Microsoft Azure 的价格约为 DeepSeek 官方的 2.5 倍，换来大约 25 秒的延迟下降。R1-0528 的多数托管实例目前首 token 延迟已压到 5 秒以内，输出速度约每秒 25 个 token。

作为对照，文章提到 Anthropic 的 Claude 4 Sonnet 发布以来 API 输出速度下降了 40%，只剩每秒 45 个 token 出头；但 Claude 模型的输出总 token 数在主流推理模型里最少，Gemini 2.5 Pro 和 DeepSeek R1-0528 的输出啰嗦程度是 Claude 的三倍。文中还提到 Anthropic 与 Amazon 签下了超过 50 万颗 Trainium 芯片的协议。

这些是 SemiAnalysis 的第三方统计口径，不是 DeepSeek 或 Anthropic 的官方数字。
