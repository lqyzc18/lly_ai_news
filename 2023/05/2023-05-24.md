# 2023-05-24 AI 大事件

北京时间 2023 年 5 月 24 日（星期三）。微软 Build 2023 大会首日主题演讲公布 50 余项产品与功能，宣布采用与 ChatGPT 同一套开放插件标准；同一天，Anthropic 宣布完成 4.5 亿美元 C 轮融资。两项公告的官方首发日均为美东时间 5 月 23 日，微软新闻室中文版综述稿于 5 月 24 日发布，按北京时间落在 24 日。

## 1. Microsoft Build 2023：插件标准与 Azure AI Studio

微软 Build 2023 大会（5 月 23—25 日，西雅图）首日主题演讲公布 50 余项产品与功能，AI 是绝对主线。核心宣布包括：采用 OpenAI 为 ChatGPT 推出的同一套开放插件标准，保证插件在 ChatGPT、Microsoft 365 Copilot 与 Dynamics 365 Copilot 之间互通；Azure OpenAI Service 预览版更新，引入 Azure AI Studio、预置吞吐模型与插件能力，并新推出 Azure AI Content Safety；开源的 Semantic Kernel SDK 同时支持 C# 与 Python 并正式可用；发布统一分析平台 Microsoft Fabric（预览版，基于 OneLake）。

官方称当时已有超过 4500 家客户在用 Azure OpenAI Service，并推出面向 50 多家伙伴的插件早期访问计划，伙伴包括 Atlassian、Adobe、ServiceNow、Thomson Reuters、Moveworks 等。会上 OpenAI 联合创始人兼总裁 Greg Brockman 与微软技术负责人 Kevin Scott 在台上对谈，Scott 对现场开发者说，「你们才是会让 AI 变得伟大的人」。

微软 CEO Satya Nadella 在主题演讲中表示，软件栈的每一层都将被永久改变，开发者构建软件的方式正在发生根本性变化。会上还集中展示了与 OpenAI 技术相关的开发者工具：Azure 云上用于定制化文本摘要的新工具、用于处理与准备数据的即将上线的聊天机器人、可在 ChatGPT 与微软自家产品内工作的插件，以及将 Windows Terminal 命令行与 GitHub Copilot 代码建议打通的聊天机器人。演示中，Windows 聊天机器人可播放 Spotify 播放列表、用 Adobe Express 生成公司标识并通过 Teams 发给同事。

## 2. Anthropic 完成 4.5 亿美元 C 轮融资

据澎湃新闻报道，5 月 23 日，总部位于旧金山的人工智能初创公司 Anthropic 宣布已完成 4.5 亿美元的 C 轮融资，由 Spark Capital 领投，参投方包括谷歌、Salesforce 和 Zoom 等科技巨头。Anthropic 并未披露其当时的估值，但 3 月初来自 The Information 的报道显示，公司正在寻求以超过 41 亿美元的估值筹集资金，实际数字可能落在这一区间，也有消息人士称其当前估值接近 50 亿美元。Spark Capital 合伙人 Yasmin Razavi 加入 Anthropic 董事会。

据 PitchBook，这是 2023 年 1 月微软投资 OpenAI 以来规模最大的 AI 融资轮。两个月前 Anthropic 刚以 41 亿美元估值完成 3 亿美元融资；再往前一个月，谷歌投资 3 亿美元取得约 10% 股权，本轮投资方直接列为 Google 而非 GV/CapitalG。公司称资金将用于继续训练更安全的模型，包括 Claude 的后续版本。

## 3. Anthropic 的算力与竞争位置

这轮融资前，Anthropic 刚刚把 Claude 的上下文窗口从 9000 个 token 扩大到 10 万个 token，公司称升级后的 Claude 需要每秒高达 10^25 次的浮点运算，比当时最大的模型还要高出几个数量级，并暗示未来 18 个月大约要花掉 10 亿美元。Anthropic 预计未来两年再融资 50 亿美元，其产品已在医疗保健、人力资源和教育等行业建立客户基础，竞争者包括已融资 2.25 亿美元的 Inflection AI、已融资 4.15 亿美元的 Adept，以及成立更早的 Cohere 和 AI21 Labs。

Anthropic 的差异化被放在安全路线上：Claude 3 月 15 日正式面世，可依据特定指令执行检索文件、汇总、写作、编码及问答等任务，当时仅提供 API 接口；其「Constitutional AI（宪法 AI）」训练方法在 5 月 9 日的文章中被详细解释，依据联合国人权宣言等原则把模型输出引导到更安全、更有帮助的方向。
