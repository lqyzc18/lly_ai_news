# 2023-10-02 AI 大事件

北京时间 2023 年 10 月 2 日（星期一，国庆假期第二天）。这一天的大模型新闻有两个方向：一是 ChatGPT Plus 推出邀请制，把 Plus 会员资格开放给朋友免费使用；二是 Bing 开始提供 DALL·E 3 的免费额度，每天可生成 100 张且支持中文。工具侧则有一条有趣的交叉——数学家陶哲轩公开表示 GitHub Copilot 在他写数学博客时「非常有帮助」，同时又承认「有点让我不安」。当晚，最新一届诺贝尔生理学或医学奖揭晓，授予 mRNA 相关的两项突破。

## 1. ChatGPT Plus 推出邀请制

ChatGPT Plus 推出邀请制，用户可以把 Plus 会员资格分享给朋友，对方可免费使用 GPT-4，最长有效期 90 天。这一改动出现在需求侧持续吃紧的背景下——当时 ChatGPT Plus 的新用户注册曾因访问量过大一度暂停，恢复时间一度未公布。

邀请制的设计意图是平衡两类需求：一方面把付费用户的额度用满，另一方面在算力供给受限时用存量会员的闲置额度换取留存。对用户而言，这实际构成了一种「拼车」机制——被邀请者免费获得 GPT-4 访问，邀请者则可以把剩余额度变现。中文社区在 10 月中旬一度出现「卖号租号全网溢价」的现象，邀请制的出现也在一定程度上把这种灰色需求导向了平台内的正规路径。

## 2. Bing 上线 DALL·E 3：每天免费 100 次，支持中文

Bing 图像搜索开始集成 DALL·E 3，量子位实测确认免费用户每天可生成 100 张，并且支持中文提示词。实测显示，风格化提示词（如「宫崎骏风格，天空之城」）的出图效果不错，能一次给出 4 张不同画作；写实人物测试同样稳定。

不过实测也指出了实际可用性上的瑕疵。在「用一张海报概括人工智能历史」这类需要生成文字的任务中，生成图里的英文单词出现了拼写错误。这类问题在 DALL·E 3 之前的图像模型上同样存在，属于当时生成式图像的共性短板——模型能画形状，但渲染文字仍不可靠。入口在 Bing 图像搜索页内的创建功能。

对当时的用户结构而言，Bing 的加入意义在于打破了「要用 DALL·E 3 必须有 ChatGPT 订阅」的门槛，把生成式图像推到了一大批只用搜索引擎的用户面前。

## 3. 陶哲轩用 GitHub Copilot 写数学博客

陶哲轩在博客中点名 GitHub Copilot，这是他继 GPT-4、VS Code 之后又一次为 AI 工具「带盐」。他的具体描述是：Copilot 在他撰写近期博客文章的过程中非常有帮助，能够正确预测数学论证的几个步骤。他举的例子是先把一个积分分成三块，用语言描述如何估计第一块和剩下两块的内容，然后 Copilot 基于他给出的描述一次性提出一大段建议。

陶哲轩的结论相当克制：虽然 Copilot 给出的建议不都是可用的，但最终估计有十几句被他用到了博客文章里。总的印象是「非常有帮助（并且有点让我不安）」。这次推荐之所以被广泛讨论，除了名人效应，更因为它触及了数学写作这类高专业度场景——陶哲轩此前的表述是「用 GitHub Copilot 撰写数学文章，如果不借助它我可能会崩溃」，而这次则是给出了具体的、可以核对的合作方式与复用比例。

## 4. 当晚：诺贝尔生理学或医学奖揭晓

最新一届诺贝尔生理学或医学奖公布，授予卡塔琳·卡里科（Katalin Karikó）与德鲁·魏斯曼（Drew Weissman)，表彰他们在 mRNA 领域的突出贡献。诺贝尔奖委员会的表述是：今年的获奖者通过突破性发现，从根本上改变了人们对 mRNA 如何与免疫系统相互作用的理解。两人共享 1100 万瑞典克朗奖金，约合 732 万元人民币。二人此前已在 2021 年拿下拉斯克奖的临床医学研究奖。

这件事与 AI 的关联在当天的中文报道里被反复提及：一周后斯坦福团队在《自然》上发表的研究显示，用 GPT-4 预测诺奖获奖方向时，对 mRNA 疫苗方向的预测与人类评审的判断没有明显差别。
