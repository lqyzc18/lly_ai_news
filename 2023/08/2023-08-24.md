北京时间 2023 年 8 月 24 日（星期四）。当日主线是Meta 发布 Code Llama：7B/13B/34B 三档开源代码模型，上下文扩至 10 万 token。

## 1. Meta 发布 Code Llama：7B/13B/34B 三档开源代码模型，上下文扩至 10 

模型与产品Meta 发布 Code Llama：7B/13B/34B 三档开源代码模型，上下文扩至 10 万 token。Meta 在 Llama 2 基础上发布代码专用大模型 Code Llama，首批开放 7B、13B、34B 三档，各含基础版、Python 专用版与指令微调版（Instruct），共 9 个权重，采用与 Llama 2 相同的社区许可证允许商用。各档在 5000 亿 token 代码及相关数据上训练，Python 版额外在 1000 亿 token 纯 Python 代码上继续训练；全部在 16k token 序列上训练，通过位置编码改造可稳定支持最长 10 万 token 输入。7B/13B 的基础版与 Instruct 版支持 fill-in-the-middle 代码插补。HumanEval 最高约 53%、MBPP 最高约 55%。70B 版本在 2024 年 1 月 29 日才发布。
