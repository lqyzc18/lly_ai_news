# 2023-11-07 AI 大事件

北京时间 2023 年 11 月 7 日（星期二）。OpenAI 在旧金山举办首届开发者大会 DevDay，并于美东时间 11 月 6 日 13:00（太平洋时间）起向客户推送新功能：GPT-4 Turbo 预览版、Assistants API、DALL·E 3 与语音合成 API、Whisper large-v3 开源权重，以及让任何人都能零代码创建定制版 ChatGPT 的 GPTs。

## 1. GPT-4 Turbo：128K 上下文与降价

开发者平台侧最先落地的是 GPT-4 Turbo 预览版（gpt-4-1106-preview）。上下文窗口扩到 128K，单个提示中可容纳相当于 300 多页文本的内容；知识截止时间更新到 2023 年 4 月；输入价降至每千 tokens 0.01 美元、输出价 0.03 美元，分别比 GPT-4 便宜 3 倍与 2 倍。新版本还改进了指令跟随与 JSON Mode，允许在一条消息里调用多个函数，便于开发者把多个操作打包进一次请求。速率限制方面，GPT-4 Turbo 的 token 速率限制翻倍。

视觉能力同步开放为 GPT-4 Turbo with Vision（gpt-4-vision-preview），可完成生成标题、详细分析图像、阅读带图形文档一类任务。官方给出的成本示例是：把一张 1080×1080 像素图像传给 GPT-4 Turbo 花费约 0.00765 美元。

## 2. 平台与工具链

OpenAI 同时推出全新 Assistants API（beta），内置代码解释器、检索、函数调用，并支持无限线程，把此前分散的搜索、工具调用与代码执行整合进同一套开发者接口。图像与语音能力也全面开放：DALL·E 3 API 上线，起价每张 0.04 美元，开发者可以把 DALL·E 3 直接集成进企业应用；新的文本转语音 API 提供 tts-1 与 tts-1-hd 两档模型，每千字符起价 0.015 美元，共六种预设声音。GPT-3.5 Turbo 16K（gpt-3.5-turbo-1106）在格式遵循上提升 38%。OpenAI 还开源了 Whisper large-v3 这一自动语音识别模型及其一致性解码器。

大会披露的规模数字是：平台上有 200 万名开发者，92% 的《财富》500 强公司在使用其产品，ChatGPT 周活跃用户突破 1 亿。

## 3. GPTs：零代码的定制版 ChatGPT

与 DevDay 同日，OpenAI 发布 GPTs，允许用户通过对话式的 GPT Builder 创建特定用途的定制版 ChatGPT，可设为个人使用、企业内部使用或公开分享，全程不需要写代码。发布当日先向 ChatGPT Plus 与 Enterprise 用户开放试玩，官方称之后会向更多用户提供。

GPT Store 宣布于当月晚些时候上线，将收录经认证的构建者作品，支持搜索与排行榜，并计划在未来数月按使用量向构建者付费。ChatGPT 界面同期改版。此外 OpenAI 推出定制微调的实验性访问计划，允许开发者创建 ChatGPT 的自定义版本，包括修改训练过程的每一步、额外做领域预训练，以及运行针对自身领域的强化学习后训练。
