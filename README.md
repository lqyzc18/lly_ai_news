# lly_ai_news

按北京时间整理的 AI 大事件日报。每天一篇，按年月放进目录，文件名仍是日期。

## 最新

[2026-10-15](./202610/2026-10-15.md)（星期四）

- Anthropic 向准投资者表示，第三季营收 168 亿美元，比上一季增 45%，经调整后已经盈利。路透社称公司以超过 2 万亿美元的估值为目标。公司没有立即置评。

## 目录

- 目录名是六位年月：`YYYYMM`。
- 文件名是 `YYYY-MM-DD.md`。
- 日期按北京时间（Asia/Shanghai）。美国当地前一晚发生、北京时间已经跨日的消息，记入当天。

## 更新时间

北京时间每天 12:00 生成或更新当天的笔记，并改写上面的「最新」一节，提交后直接推送到 `main`。

- 当天文件已经存在时，只补充遗漏的重要事件，不另建一份。
- 没有新的重要事实时，不做空提交。

## 写法

- 中文，按事件分节，先写结论。
- 只记录有来源的事实。未经公司证实的说法标明「据报道」，并在文末附来源链接。
- 金额和评测数字来自公司表态或媒体引述，不另做原始评测核实。
- 范围包括模型发布、公司与产品、监管与政策、开源和算力基础设施。
