## 归档口径

| 规则 | 说明 |
|:--|:--|
| 时区 | 北京时间（Asia/Shanghai）。美国当地前一晚发生、北京时间已经跨日的消息，记入当天 |
| 跨日 | 美东前一日下午到深夜的发布归当天；12:00 封稿时这一段还没写进前一篇 |
| 补录 | 前一篇漏掉的重要事件补进当天，正文注明原始发布日与出处 |
| 去重 | 同一条事件不在两篇笔记里各写一遍 |

## 更新时间

北京时间每天 12:00 生成当天的笔记，并改写上面的「最新」一节，提交后直接推送到 `main`。

- 当天文件已经存在时，只补充遗漏的重要事件，不另建一份。
- 没有新的重要事实时，不做空提交。

## 写法

- 中文，按事件分节，先写结论。
- 只记录有来源的事实。未经公司证实的说法标明「据报道」，并在文末附来源链接。
- 金额和评测数字来自公司表态或媒体引述，不另做原始评测核实。
- 范围包括模型发布、公司与产品、监管与政策、开源和算力基础设施。
