## 归档口径

| 规则 | 说明 |
|:--|:--|
| 时区 | 北京时间（Asia/Shanghai） |
| 归日 | 以**发布方的发布时间**为准：事件公开那一刻换算成北京时间落在哪一天，就归哪一天 |
| 跨日 | 美东上午发布多落在北京时间当日下午到深夜；美东下午到深夜发布多落在北京时间次日凌晨到上午。正文同时标注发布方的原始发布时间 |
| 旧闻剔除 | 中文转载日通常比事件日晚 1~2 天，一律回官方渠道核过真实发布时间再收录；无法回到官方渠道判定的条目直接丢弃 |
| 补录 | 前一篇漏掉的重要事件补进当天，正文注明原始发布日与出处 |
| 去重 | 同一条事件不在两篇笔记里各写一遍 |
| 短篇 | 确有达标事件才建文件，2~5 节为常态，不注水、不凑节数 |

## 更新时间

北京时间每天 12:00 生成当天的笔记，并改写上面的「最新」一节，提交后直接推送到 `main`。

- 当天文件已经存在时，只补充遗漏的重要事件，不另建一份。
- 没有新的重要事实时，不做空提交。

## 写法

- 中文，按事件分节，先写结论。
- 只记录有来源的事实。未经公司证实的说法标明「据报道」，并在文末附来源链接。
- 金额和评测数字来自公司表态或媒体引述，不另做原始评测核实。
- 范围包括模型发布、公司与产品、监管与政策、开源和算力基础设施。
