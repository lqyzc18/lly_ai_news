## 口径

> **归日以发布方的发布时间为准** —— 事件公开那一刻换算成北京时间落在哪一天，就归哪一天，正文同时标注发布方的原始发布时间。

| 维度 | 规则 |
|:--|:--|
| **跨日** | 美东上午发布多落在北京时间当日下午到深夜，美东下午到深夜发布多落在次日凌晨到上午。 |
| **旧闻** | 中文转载日通常比事件日晚 1~2 天，一律回官方渠道核过真实发布时间再收录，核不回的丢弃。 |
| **补录** | 前一篇漏掉的重要事件补进当天，注明原始发布日与出处。 |
| **去重** | 同一条事件不在两篇笔记里各写一遍。 |
| **短篇** | 确有达标事件才建文件，2~5 节为常态，不注水、不凑节数。 |
